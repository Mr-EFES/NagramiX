## Устройство и изменения

- `ios/` — авторитетные Swift/Objective-C исходники, ресурсы и точные overlay-патчи; `ios/apply_overlay.py` — общий вход. `product/` — контракты, [настройки](product/SETTINGS.md), [реестр](product/features/registry.json), текущая аннотация и каталог возможностей.
- `scripts/`, `tests/`, `ios/Tests/` — необходимые проверки. Файлы стадий с прежними номерами версий и canonical `.inc`/JSON остаются зависимостями воспроизводимой сборки 0.8.4. Не удалять и не переписывать их по возрасту; обычные исправления оформлять последующим guarded stage. Не ослаблять anchors, SHA, BUILD guards и upstream PostboxImportCheck; все prechecks до первой записи.
- `docs/` — технические контракты текущего кода. Документы ранних стадий объясняют промежуточные преобразования; актуальное состояние реализации описано в [AI_HANDOFF](docs/AI_HANDOFF.md). Журналы старых релизов удалены.
- Менять только запрошенное поведение, сохранять незакоммиченную работу, API, stable IDs, форматы и пользовательские ключи/настройки. Отсутствующий ключ и сохранённый OFF различать; обновление не сбрасывает ручной выбор. Не добавлять зависимости без необходимости.
- Корневой `README.md` содержит только утверждённое описание. Не редактировать его без отдельного прямого указания, в том числе при повышении версии. Все новые документы, коммиты и PR — на русском; английский допустим в коде/API/локализации.
- Темы, палитры и шрифты штатные; начальные русский язык и системное оформление применяются однократно. Длинные подписи измерять и переносить, не сокращать и не уменьшать шрифт. Сохранять nameDisplayOrder, динамическую высоту и RGB24.
- Не менять без прямой задачи камеру кружков, per-story approval/read gate, запрет свайпа камеры историй, скрытие историй, ID/дату регистрации, широкие посты/альбомы, Контакты/Звонки, прокси и спонсора. Удалённую подмену профиля не возвращать, stable ID136 не переиспользовать. Редактор альбомов и постоянное удержание приложения не реализованы; бесплатная подпись не даёт APNs.

- Порядок этапов задан в `ios/apply_overlay.py` и `.github/workflows/build-unsigned-ipa.yml`; не переставлять и не отключать этапы без отдельной задачи. `upstream_13_2_post` применяется после проверок предыдущей цепочки, перед компиляцией. Этап `hybrid_pip` отключён; не подключать его обратно.
- GitHub API может возвращать устаревшее имя/время текущего шага. Не отменять сборку и не менять код только по этим данным: сверять общий итог задания и фактический журнал. У попытки 165/1 профиль был готов за секунду, хотя API продолжал показывать его создание; нативная компиляция была ошибочно прервана агентом.
- Завершающая guard-only стадия `release_085_validation_support` сохраняет неизменяемый вход GalleryUI при обратном снятии overlay в старых проверках. Она проверяет SHA и не меняет код приложения; не убирать её как пустую стадию и не ослаблять исторические проверки.
- Новые Swift-регрессии в workflow запускаются перед прежней цепочкой для раннего выявления несовместимости компилятора. Все проверки и warnings-as-errors сохраняются; порядок применения overlay и финального upstream post-port не меняется. В тестах освобождения использовать weak storage в объекте-пробе: новая диагностика Swift отклоняет неизменяемую локальную weak var при строгих предупреждениях.
- В тестовой границе геометрии расширенного редактора условный import CoreGraphics нужен на macOS для Equatable у CGSize; одного Linux Foundation недостаточно для проверки этой зависимости UIKit.
