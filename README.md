Готов проверенный unsigned IPA для физического iPhone: **0.5.4 / build88**, Telegram13.0, ARM64, iOS15.0+. [Скачать IPA](https://github.com/Mr-EFES/NagramiX/releases/download/v0.5.4/NagramiX-0.5.4-unsigned.ipa) · [Тестовый релиз](https://github.com/Mr-EFES/NagramiX/releases/tag/v0.5.4). Нативная сборка и публикация успешны; пакет независимо проверен. Требуется внешняя подпись, например SideStore.

[Описание возможностей](product/releases/0.5.4.md), [статус сборки](docs/RELEASE_STATUS.md), [план проверки iPhone](docs/IPHONE_TEST_0.5.4.md). Единственная рабочая ветка — `main`; прежние релизы сохраняются.

**NagramiX** — независимый, неофициальный и некоммерческий клиент Telegram для iPhone.

Проведён [аудит стабильности](docs/STABILITY_AUDIT.md): исправлены бесконечное ожидание рекордера, гонка очистки оригинального видео и ошибка доступности API сохранения архива. Исправления включены в build88; физическая проверка ожидается.

NagramiX является самостоятельным iOS-продуктом с собственными функциями, настройками и брендингом. Базой служат актуально проверенные официальные исходники Telegram-iOS.

Подготовлены [авто-мьют новых каналов и точное время последнего посещения](docs/CHANNEL_MUTE_AND_EXACT_TIME.md): новые подписки без уведомлений по умолчанию и доступный статус с секундами по желанию пользователя. Эти функции включены в сборку №84; проверка на iPhone предстоит.

Подготовлено [исправление микропаузы музыки и зависания повторных записей](docs/RECORDING_WITH_MUSIC.md). Включено в build86; динамик и Bluetooth/AirPods нужно проверить на устройстве, причина сетевого ожидания после отправки ещё не подтверждена.

Подготовлена [ссылка на профиль в новых сообщениях](product/features/profile-link-messages.md): отдельный экран настройки и выбора ID. Нативная сборка№86 пройдена, физическая проверка ожидается.

Подготовлены [«Непрочитанные сверху»](product/features/unread-chats-first.md): сортировка по счётчику во всех папках, закрепления прежние, по умолчанию включена. Включено в build86; тест на iPhone предстоит.

Подготовлены [свайпы между категориями настроек](docs/SETTINGS_CATEGORY_SWIPE.md): «Интерфейс», «Функции» и «Прочее» переключаются горизонтальным жестом с синхронизацией верхних кнопок. Включено в build88, нативная компиляция пройдена; физическая проверка ожидается.

Подготовлено [исправление отправки архивных сообщений](docs/ARCHIVED_MESSAGE_TRANSFER_FIX.md): «Переслать без» открывает одиночную подготовку в чате получателя; «Рассылка» отправляет локальные копии нескольким адресатам, с проверкой сохранённых файлов. Включено в build88, нативная компиляция пройдена; физическая проверка ожидается.

Подготовлены [исправление состояния прокси-переключателей и отдельный DNS Telegram](docs/PROXY_VPN_AND_LAYOUT.md): сохранение ручного выбора, автонастройки при начале использования прокси, прежний Системный DNS первым. Включено в build88; нативная компиляция пройдена, тест на iPhone ожидается.

Подготовлены [приветственные экраны NagramiX](docs/BRANDED_ONBOARDING.md): наш логотип, шесть коротких описаний и новые иллюстрации, включая современный смартфон на вводе номера. Включено в build88; нативная компиляция пройдена, тест на iPhone ожидается.

Подготовлено [сохранение голосовых и кружков из удалённых сообщений](docs/ARCHIVED_MEDIA_SAVE.md): подходящий звук добавляется в библиотеку уведомлений, видео — в галерею, с проверкой полного локального файла. Включено в build88; нативная компиляция пройдена, тест на iPhone ожидается.

Подготовлено [«Не спрашивать оценку звонка»](docs/SKIP_CALL_RATING.md): включено по умолчанию, сохраняет выбор и скрывает автоматическую оценку; выключение возвращает штатный запрос, ручная оценка доступна. Включено в build88, нативная компиляция пройдена; физическая проверка ожидается.

В неё входят все подготовленные функции: отложенные реакции в предпросмотре, три способа пересылки в панели выделения, настройки музыки и последовательного воспроизведения, скрытие приветствия, авто-мьют каналов, точное время, новые панели выбора и управление прокси с VPN.

## Структура репозитория

```text
product/     функции, настройки, терминология и release scope
ios/         overlay, брендинг и Swift/Objective-C реализации для Telegram-iOS
scripts/     проверка iOS upstream и упаковка IPA
.github/     единственный workflow сборки неподписанного IPA
docs/        bootstrap и актуальный handoff
```

Полные исходники Telegram-iOS не копируются в репозиторий. CI получает закреплённый официальный commit и накладывает контролируемый exact-anchor overlay.

## Проверка актуальности официальной базы

```bash
python3 scripts/check_upstreams.py
python3 scripts/check_upstreams.py --require-current
```

Перед IPA build workflow проверяет официальный `master`. Если pin устарел, сборка останавливается до осознанной миграции и аудита patch anchors.
