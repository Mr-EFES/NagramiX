**NagramiX** — независимый, неофициальный и некоммерческий клиент Telegram для iPhone.

NagramiX является самостоятельным iOS-продуктом с собственными функциями, настройками и брендингом. Базой служат актуально проверенные официальные исходники Telegram-iOS.

## Платформа

| Платформа | Официальная база | Нативная реализация | Артефакт |
| --- | --- | --- | --- |
| iOS / iPhone | `TelegramMessenger/Telegram-iOS` | Swift, Objective-C/Objective-C++ | unsigned ARM64 IPA |

Продуктовое поведение описывается в [`product/`](product/README.md), а реализация и брендинг находятся в [`ios/`](ios/).

## Актуальная версия разработки: 0.4.5

**0.4.5 включает накопленные исправления для проверки на физическом iPhone.** Устаревшие release-файлы в рабочем дереве не хранятся.

### Реализовано в iOS

- категории настроек «Интерфейс», «Функции» и «Прочее» с глобальным поиском;
- управление вкладками, названиями и отдельным поиском;
- восемь иконок NagramiX;
- настройки ленты историй, жеста камеры, подтверждения просмотра и репоста;
- выбор начальной камеры круглого видео с сохранением штатного переключения и zoom;
- режимы пересылки с источником и copy-as-new без источника; независимые переключатели «Переслать без» и «Выделить от автора» в разделе «Контекстное меню»;
- локально наблюдаемые удалённые сообщения и история правок;
- ID, примерная дата регистрации и значок взаимного контакта в профиле;
- system/custom DoH, проверка прокси, автоматический failover и постоянная кнопка прокси;
- Force TCP для звонков;
- русский язык по умолчанию и стандартные темы Telegram: при чистой установке «Системная» с ночной темой «Тёмная», затем сохранённый выбор пользователя;
- максимально широкие посты во всех обычных лентах каналов при включённой настройке с сохранением штатных реакций;
- защита offline/proxy запуска.

Версия 0.4.5 закреплена как единственная актуальная линия NagramiX. Для неё
настроены ARM64-сборка, проверка упаковки и публикация нового unsigned IPA в GitHub Actions.
Статус stable присваивается только после успешной сборки и полного
runtime-регресса на физическом iPhone.

## Совместимость

- текущий официальный pin: Telegram-iOS 12.9.2;
- минимальная версия: **iOS 13.0**;
- IPA не содержит Apple-подписи и требует внешней подписи, например через SideStore.

Подробности: [`product/COMPATIBILITY.md`](product/COMPATIBILITY.md).

## Структура репозитория

```text
product/     функции, настройки, терминология и release scope
ios/         overlay, брендинг и Swift/Objective-C реализации для Telegram-iOS
scripts/     проверка iOS upstream и упаковка IPA
.github/     единственный workflow сборки неподписанного IPA
docs/        bootstrap и актуальный handoff
```

Полные исходники Telegram-iOS не копируются в репозиторий. CI получает закреплённый официальный commit и накладывает контролируемый exact-anchor overlay.

## Проверка актуальности официальной базы

```bash
python3 scripts/check_upstreams.py
python3 scripts/check_upstreams.py --require-current
```

Перед IPA build workflow проверяет официальный `master`. Если pin устарел, сборка останавливается до осознанной миграции и аудита patch anchors.
