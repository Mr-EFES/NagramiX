# NagramiX

**NagramiX** — независимый неофициальный клиент Telegram для iOS и Android.

Проект применяет небольшие изолированные overlay к закреплённым исходникам Telegram-iOS и NagramX: полный upstream-код обеих платформ не копируется в репозиторий.

## Текущая версия: 0.2.4 pre-release

NagramiX 0.2.4 — предварительная тестовая версия на базе Telegram-iOS 12.9.2 с исправленным offline/proxy-запуском, настоящим режимом «Переслать без», локальным архивом удалённых сообщений и историей правок.

В ней сохранены сетевые возможности предыдущей версии и доработаны интерфейс, истории, круглые видео, автопереключение прокси и первоначальная настройка приложения.

Экспериментальные изменения сборок 0.1.2–0.1.5 в неё не возвращены.

В состав текущей версии входят:

- отдельная группа «Настройки NagramiX» перед группой «Мой профиль»;
- переключатель скрытия вкладки «Контакты»;
- переключатель скрытия вкладки «Звонки»;
- переключатель отдельной кнопки поиска;
- восемь системных иконок NagramiX, первая из которых является основной;
- доступный выбор основной иконки №1 после переключения на любую альтернативную иконку;
- запись и отправка круглого видеосообщения с той же камеры, которая отображается в предпросмотре;
- скрытие ленты историй;
- отключение свайпа, запускающего запись истории;
- подтверждение перед просмотром чужой истории;
- управление штатным действием репоста в историю.
- увеличенные и выровненные иконки нижней панели при скрытых названиях вкладок;
- подтверждение только перед ещё не просмотренными чужими историями без преждевременной отметки о просмотре;
- включение задней камеры до начала предпросмотра и записи круглого видео;
- скрытие канала спонсора прокси по умолчанию с отдельным переключателем;
- защита автопереключения прокси от конкурирующих таймеров и устаревших callbacks;
- русифицированное Debug-меню;
- русский язык, тёмная тема и встроенный игровой фон Telegram при чистой установке;
- единый selector DNS: системный, Google, Quad9, AdGuard, Mullvad, Cloudflare или пользовательский DoH;
- настоящий DNS-over-HTTPS для разрешения доменных имён сетевым слоем MTProtoKit;
- проверка и безопасное хранение пользовательского HTTPS DoH URL;
- автоматическое переключение на следующий доступный MTProto/SOCKS5-прокси через 15, 30 или 60 секунд;
- постоянная кнопка прокси на экране «Чаты», включая чистую установку без сохранённых прокси;
- полное название кнопки «Изменить»;
- расположение «Настройки NagramiX» перед пунктом «Мой профиль».
- информационный блок со ссылками на возможности NagramiX, канал обновлений и бота помощи.
- категории настроек «Интерфейс», «Функции» и «Прочее» с равными секциями верхней панели;
- Force TCP для голосовых и видеозвонков через штатную конфигурацию Telegram VoIP;
- ручная штатная проверка всех сохранённых прокси без смены активного прокси;
- отдельные режимы «Переслать от» и «Переслать без», где второй создаёт новое исходящее сообщение без forward metadata;
- локальное отображение полученных, а затем удалённых сообщений и история реально полученных редакций;
- отображение ID, примерной даты регистрации и значка взаимного контакта в профилях;
- безопасный запуск интерфейса при отсутствии сети или недоступном proxy.

Значения по умолчанию:

- «Контакты» скрыты;
- «Звонки» скрыты;
- имена вкладок отображаются;
- кнопка поиска скрыта;
- широкая панель содержит только «Чаты» и «Настройки»;
- круглые видеосообщения по умолчанию открываются на фронтальной камере; задняя включается отдельной настройкой;
- все четыре настройки историй выключены.
- DNS использует системный resolver;
- автоматическое переключение прокси выключено;
- интервал переключения равен 15 секундам;
- кнопка прокси отображается.

## Сборки

### iOS

- База: Telegram-iOS 12.9.2, закреплённая в `nagramix/upstream.env`.
- Bundle ID: `com.mr-efes.nagramix`.
- Результат: `NagramiX-0.2.4-unsigned.ipa` без Apple-подписи.

GitHub Actions собирает нативное ARM64-приложение на macOS.

### Android

- База: NagramX 1258, точная ревизия закреплена в `android/upstream.env`.
- Package ID: `com.mr_efes.nagramix`.
- Результат: `NagramiX-0.2.4-android-arm64.apk`, подписанный временным debug-ключом CI для тестовой установки.

GitHub Actions собирает Android ARM64 APK на Ubuntu; функциональная матрица находится в `docs/ANDROID-FUNCTION-PARITY.md`.

Сертификаты Apple, профили разработчика и секреты подписи в репозитории не хранятся.

Для сборки используются секреты `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
