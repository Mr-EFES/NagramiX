# NagramiX 0.5.2

Подготовлена новая версия для физической проверки на iPhone: все накопленные исправления и функции включаются в чистую ARM64-сборку на Telegram13.0. [Чистая сборка №85](https://github.com/Mr-EFES/NagramiX/actions/runs/38166584585) запущена из `6d7407102c754c6b7c86503525fd874a55a26574`; результат и тестовая публикация ожидаются. Нужна iOS15.0 или новее и внешняя подпись, например SideStore.

[Описание возможностей](product/releases/0.5.2.md), [статус сборки](docs/RELEASE_STATUS.md), [план проверки iPhone](docs/IPHONE_TEST_0.5.2.md). Ссылка на новый IPA появится после успешной сборки и проверки. Единственная рабочая ветка — `main`; прежние релизы сохраняются.

**NagramiX** — независимый, неофициальный и некоммерческий клиент Telegram для iPhone.

NagramiX является самостоятельным iOS-продуктом с собственными функциями, настройками и брендингом. Базой служат актуально проверенные официальные исходники Telegram-iOS.

Подготовлены [авто-мьют новых каналов и точное время последнего посещения](docs/CHANNEL_MUTE_AND_EXACT_TIME.md): новые подписки без уведомлений по умолчанию и доступный статус с секундами по желанию пользователя. Эти функции включены в сборку №84; проверка на iPhone предстоит.

Подготовлено [исправление микропаузы музыки и зависания повторных записей](docs/RECORDING_WITH_MUSIC.md). Пока только в исходниках; динамик и Bluetooth/AirPods нужно проверить в следующем пакете, причина сетевого ожидания после отправки ещё не подтверждена.

Подготовлена [ссылка на профиль в новых сообщениях](product/features/profile-link-messages.md): отдельный экран настройки и выбора ID. Новая функция ожидает нативной сборки и физической проверки.

Подготовлены [«Непрочитанные сверху»](product/features/unread-chats-first.md): сортировка по счётчику во всех папках, закрепления прежние, по умолчанию включена. Пока только в исходниках, нативная сборка и тест на iPhone предстоят.

## Тестовый выпуск 0.5.2

Пользователь разрешил новую чистую ARM64-сборку для физического iPhone с публикацией тестового релиза. В неё входят все подготовленные функции: отложенные реакции в предпросмотре, три способа пересылки в панели выделения, настройки музыки и последовательного воспроизведения, скрытие приветствия, авто-мьют каналов, точное время, новые панели выбора и управление прокси с VPN.

[Краткая аннотация](product/releases/0.5.2.md) · [Состояние сборки](docs/RELEASE_STATUS.md) · [План физической проверки](docs/IPHONE_TEST_0.5.2.md).

Новая чистая сборка и тестовая публикация готовятся. Исходный SHA, workflow и ссылка на проверенный IPA будут записаны в [отчёт](docs/RELEASE_STATUS.md).

### Реализовано в iOS

- категории настроек «Интерфейс», «Функции» и «Прочее» с глобальным поиском;
- выключенный по умолчанию «Компактный список чатов»: меньшие аватары, одна строка предпросмотра и плотная высота без резерва скрытого индикатора активности;
- включённая по умолчанию настройка «Опции чатов по тапу»: удерживание вне аватарки — штатное меню, свайпы — для папок; полный просмотр по аватарке без поля ввода и пункты «В архив» / «Из архива» включены в исходники;
- настройки качества фото/фотоисторий, размера стикеров и крупных эмодзи, показа времени в категории «Функции»;
- подготовлено «Фото без сжатия», заменяющее отдельный переключатель больших фото: обычное фото с JPEG100 и HD-размером до2560 пикселей, со штатным просмотрщиком у получателя; native build и физический тест ещё ожидаются ([границы](docs/HIGH_QUALITY_PHOTOS.md));
- подготовлено «Видео без сжатия»: исходный файл из галереи, MP4/MOV со стандартным видеоплеером; native build и проверка оригинала/совместимости на устройстве ещё ожидаются ([границы](docs/ORIGINAL_VIDEOS.md));
- включённые по умолчанию «Видео PiP свайпом» в «Прочее» и «Воспроизводить видео в фоне» в «Функции»: [поведение и план проверки](product/features/video-playback-options.md);
- управление вкладками, названиями и отдельным поиском;
- восемь иконок NagramiX;
- настройки ленты историй, жеста камеры, подтверждения просмотра и репоста;
- просмотр новых историй инкогнито без Premium (отдельный переключатель, выключен по умолчанию); подготовленный экран с блюром поясняет режим один раз при открытии просмотрщика, без повторного обычного предупреждения (ещё не включён в опубликованный IPA);
- полный системный и классический каталог звуков уведомлений, загрузка собственных звуков;
- два режима ускорения: «Среднее» и «Максимум», включение только чекбоксом;
- подготовлены единые нижние панели выбора ускорения и задержки прокси: заголовок, крестик, пояснения и галочка выбранного варианта; новая версия панелей ещё не включена в опубликованный IPA;
- возврат исходной яркости после QR-кода и отдельные кнопки поиска и редактирования;
- выбор начальной камеры круглого видео с сохранением штатного переключения и zoom;
- пересылка с источником; разделены «Переслать без» одному адресату и «Рассылка» копий нескольким адресатам, с независимой видимостью в разделе «Контекстное меню»;
- локально наблюдаемые удалённые сообщения и история правок; отдельный архив файлов фото, видео, голосовых, кружков, аудио и документов, с независимым разрешением временных/одноразовых вложений;
- ID, примерная дата регистрации и значок взаимного контакта в профиле;
- подготовлено отключение автоматического перехода к следующему голосовому или кружку, включённое по умолчанию; ручное воспроизведение сохраняется. Нативная сборка выполнена; физическая проверка ожидается;
- подготовлена настройка продолжения музыки других приложений при записи кружков и голосовых; на чистой установке включена, ручной выбор сохраняется. Нативная сборка выполнена; проверка звука на iPhone ожидается;
- подготовлено скрытие приветственного стикера и приветствия собеседника в пустом личном чате без загрузки стикера; настройка включена по умолчанию, сборка выполнена; физическая проверка ожидается;
- подготовлен временный обход прокси при VPN с сохранением выбранного сервера; отдельные кнопки проверки и отправки списка перед серверами. Прежняя реализация прошла нативную сборку №84; физическая проверка этой правки ожидается;
- system/custom DoH, проверка прокси, автоматический failover и постоянная кнопка прокси;
- Force TCP для звонков;
- полные русские названия кнопок и вкладок, сохраняющиеся после обновления перевода;
- русский язык по умолчанию и стандартные темы Telegram: при чистой установке «Системная» с ночной темой «Тёмная», затем сохранённый выбор пользователя;
- максимально широкие посты во всех обычных лентах каналов при включённой настройке с сохранением штатных реакций;
- защита offline/proxy запуска.

## Структура репозитория

```text
product/     функции, настройки, терминология и release scope
ios/         overlay, брендинг и Swift/Objective-C реализации для Telegram-iOS
scripts/     проверка iOS upstream и упаковка IPA
.github/     единственный workflow сборки неподписанного IPA
docs/        bootstrap и актуальный handoff
```

Полные исходники Telegram-iOS не копируются в репозиторий. CI получает закреплённый официальный commit и накладывает контролируемый exact-anchor overlay.

## Проверка актуальности официальной базы

```bash
python3 scripts/check_upstreams.py
python3 scripts/check_upstreams.py --require-current
```

Перед IPA build workflow проверяет официальный `master`. Если pin устарел, сборка останавливается до осознанной миграции и аудита patch anchors.
