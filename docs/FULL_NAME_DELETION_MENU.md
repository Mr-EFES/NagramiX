# Полное имя и единое меню удаления

После физического теста NagramiX0.5.5/build89 пользователь сообщил об обрезанной подписи «Удалить у меня и у Анастасия Владимир…» и разных видах обычного подтверждения удаления.

## Изменения

В `ios/apply_features.py` добавлен последний этап `apply_full_name_deletion_menu`: один полный SHA входа `ChatControllerAdminBanUsers.swift`, 18 точных замен, проверяемых до записи. Обычный и секретный личный чат получают полное имя через `EnginePeer.displayTitle(strings:displayOrder:)`, с текущим порядком имени/фамилии и существующим разрешением собеседника. Контактные данные не редактируются и не сокращаются отдельно.

Подписи действий и предупреждения используют штатный `ContextMenuActionItem.textLayout = .multiline`. В проверенной базе Telegram13.0 этот режим задаёт `maximumNumberOfLines = 0`; штатный renderer измеряет весь текст в доступной ширине и увеличивает высоту кнопки и меню. Сохраняются округлое оформление, цвета, системный масштаб текста и предел ширины экрана. Глобальный renderer и другие меню не меняются.

Обычные live, archive-only, mixed и выбор автора теперь используют один native ContextController. Предупреждения о числе выбранных сообщений и локальных копий остаются отдельными неактивными строками того же меню. Контекстное удаление заменяет пункты существующего меню; нижняя панель открывает меню у исходной кнопки. Для вызова без исходной кнопки используется native reference к экрану чата вместо другого ActionSheet.

Для native `.unsendPersonal` (только часть набора допускает отзыв) checkbox другого окна заменён явным действием «Отозвать мои сообщения» и прежним предупреждением с полным именем. «Удалить у меня» остаётся отдельным локальным действием. Типы операций прежние: выбранный отзыв → `.forEveryone`, локальное действие → `.forLocalPeer`; ограничения Telegram определяются прежними `ChatAvailableMessageActionOptions`. Удаление серверных сообщений, разделение локальных копий и Undo не изменены. Никакие сообщения не удаляются при показе/закрытии предупреждения.

Специальные дополнительные предупреждения о платных предложенных постах, повторяющихся запланированных сообщениях и действующих розыгрышах сохранены: у них отдельные финансовые/повторяющиеся последствия. Эта правка унифицирует обычное меню выбора области удаления, а не все системные alert приложения.

## Проверка и границы

`scripts/validate_deletion_menu.py` проверил точный scope (1 изменённый native output, 464 побайтно прежних), 18 замен и обратное восстановление, неизменность backend/Undo/специальных предупреждений, отказ SHA drift и повторного применения без частичной записи. Полный overlay применён к чистому fixture; output совпал со scoped применением. Swift grammar, Python compile, metadata и diff check пройдены. Public native ContextController/ContextActionNode сверены по Git blob точного upstream pin. Новые строки/ключи/настройки/зависимости не добавлены.

Статус: **source_checked / native_compile_pending / device_pending**. Linux не компилирует UIKit и не проверяет экранную геометрию. Опубликованный 0.5.5/build89 не изменён; сборка, push и commit не запускались.

При следующей разрешённой сборке проверить на iPhone: полный контакт «Анастасия Владимировна», длинное многословное имя, emoji и увеличенный текст; портрет/альбомная ориентация; 1/несколько/live/archive/mixed/выбор автора; пункты у себя/у обоих, ограниченный отзыв своих сообщений; закрытие по тапу вне меню, Undo и отмена без потери локальных копий; обычный и секретный чат, Saved Messages и группы с разными правами.
