# Режим проверок патчей при сборке

По прямой команде владельца «сними блокировку блока проверки патчей на Apple Swift» длительные повторные исторические проверки исключены из обязательного пути выпуска. Шаг не был заблокирован: в опубликованной сборке190 он занял105,9минут, отдельно от92,8минут нативной компиляции.

Workflow получил параметр `extended_patch_tests`, по умолчанию false. При false пропускаются189 вызовов исторических регрессионных валидаторов внутри шага применения overlay. При true они выполняются в прежних местах; ошибка остаётся ошибкой, а не превращается в успешный результат.

Сохранены безусловно:

- исходный `apply_overlay.py` и все34 последующие команды применения патчей;
- проверки входов, SHA, anchors и guards внутри самих загрузчиков;
- итоговый обратный контроль всех поздних стадий, полный аудит custom members, upstream/source parse, строгая локализация и PostboxImportCheck;
- ранние проверки метаданных, базы, зависимостей, авторизации, геометрии Apple Swift;
- чистый кеш, реальная SDK-компиляция ARM64 и независимая проверка IPA/происхождения/владельца.

Одноразовая проверка нормализованного workflow подтверждает побайтно прежний сценарий применения патчей: удаляется только переключатель и оболочка повторных тестов. SDK- и package-шаги побайтно прежние. Прикладные снимки `ios/`, пользовательские настройки и версия0.9.2 не менялись. [Результат](PATCH_VALIDATION_MODE_CHECKS.json).

`validate_patch_validation_mode.py` исполняет настоящую bash-оболочку: быстрый режим пропускает выбранный тест, расширенный передаёт exit17, успешный тест возвращает0, неверный параметр отклоняется с64. Отрицательный вариант с необязательным итоговым SHA-контролем должен быть отвергнут. Проверяется синтаксис всего shell-шага, включая heredoc и многострочные команды.

Изменение workflow не изменяет уже выполняющийся запуск. Попытка191 отменяется по новому распоряжению владельца; новая чистая попытка той же0.9.2 использует новый workflow. Это не устранение ошибки приложения и не подтверждение успешного IPA заранее: настоящая ошибка SDK или пакета по-прежнему требует исправления и повтора.
