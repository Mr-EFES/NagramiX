# SD/HQ/MAX в пятой кнопке круглого видео

Пользователь выбрал эскиз «Пресет качества»: в прежней прямоугольной рамке показывается SD для «Стандарт», HQ для «Высокое» и MAX для «Максимум». При выключенной функции «Качественные кружки» отображается SD. Нажатие открывает прежнюю сводку «Качество кружка».

## Причина пустой рамки

`Display.generateImage(...rotatedContext:)` передаёт CGContext и поворачивает систему координат, но не помещает его в стек UIKit. Рамка рисовалась непосредственно через CGContext, а NSString.draw искал текущий контекст UIKit. Поэтому рамка могла появляться без текста. В новом renderer контекст подключается через UIGraphicsPushContext; defer гарантирует UIGraphicsPopContext после рисования, включая восстановление внешнего контекста.

## Изменение

Стадия96 `round_quality_preset_badge` после95 `round_quality_title_layout` меняет только два файла:

- `ChatMediaEditorBottomControlsComponent.swift`: прежняя рамка28×22pt с буквенным кодом SD/HQ/MAX, согласованный tint, центрирование и новый ключ кеша изображения. Размер кнопки, зона нажатия и расположение панели сохраняются.
- `ChatMediaEditorScreen.swift`: значок получает пресет из текущего snapshot кружка после прежнего разрешения настроек; при отсутствии tuning используется стандартный480. Это обозначение пресета, а не измерение ширины исходного файла. При выключенной функции штатный экспорт Telegram по-прежнему может ограничиваться размером исходника.

Коды SD/HQ/MAX — фиксированные технические обозначения внутри изображения значка, утверждённые пользователем, как HD/4K. Их начертание одинаково во всех языках. Полные названия пресетов, сводка и VoiceOver используют прежние локализованные строки. Новых переводимых сообщений и пользовательских ключей нет; все71 каталога сохраняются.

Остальные четыре инструмента, обычные фото/видео, выбор пресета, битрейт/FPS/кодек, киноэффект, capture, отправка и камера не меняются.11 guards защищают зависимости, включая фактический GenerateImage/Font и модель настроек. Прежние `.inc` и планы остаются неизменными.

## Проверки и ограничения

Исполняются настоящие mapper/renderer, ветка кеша компонента, модель настроек, resolver и блок обновления snapshot/выражение выбора пресета. Явная граница UIKit записывает, в какой CGContext попадает текст, и проверяет внешний контекст, отсутствие исходного контекста, три tint, расположение и размер. Она использует условные метрики шрифта и не проверяет пиксели iPhone.

Намеренно ошибочные варианты без push, без pop, с неверным MAX и с неверным default OFF обязаны отклоняться. Прежняя развилка toolbar и сценарий открытия сводки/capture/guards выполняются отдельно. Только входные/ожидаемые битрейты старого сценария86 приведены к текущим допустимым ступеням88; production-тела и assertions сохранены.

Перед будущей macOS SDK-компиляцией обязательная ранняя проверка typecheck использует настоящие UIKit/NSString/UIFont/CoreGraphics. На Linux этот шаг возвращает `not_run`. Итоговые результаты: [ROUND_QUALITY_PRESET_BADGE_CHECKS.json](ROUND_QUALITY_PRESET_BADGE_CHECKS.json).

Новая IPA и физическая проверка этой задачи не выполняются. Опубликованный IPA0.9.8/build219 этой правки не содержит. После следующей сборки проверить SD/HQ/MAX при трёх пресетах, OFF, входе/выходе из круглого режима, повторном открытии редактора, обеих темах и повороте. Пятая кнопка должна оставаться читаемой и открывать сводку с тем же пресетом.
