# Проверка выпуска0.8.9 на iPhone

До успешной сборки и публикации статус device_pending. Установка производится из нового IPA0.8.9, чей source и SHA256 указаны в [RELEASE_STATUS](RELEASE_STATUS.md); старый IPA не заменяет новую проверку.

1. Обычный запуск и повторный вход после перезапуска; существующие чаты, настройки, локальный архив и загруженные Whisper/Vosk модели сохраняются после перехода на13.2.
2. Репост обычного видео/альбома с подписью сохраняет штатную ссылку на автора. Переслать создаёт редактируемую копию одному получателю, Рассылка — нескольким. Проверить текст/entities/ссылки, фото, видео, смешанные группы, документы, голосовые, кружки и одноразовые сохранённые вложения, а также отправку без звука и по расписанию.
3. Длинное видео из доступного источника не требует предварительной полной загрузки для server copy. Для недоступного native-copy пути проверить полную локальную загрузку, отмену, повтор после ошибки и отсутствие частичной/повторной отправки.
4. Выбор существующих получателей не переставляет список. Новый получатель из поиска остаётся видимым и появляется в чатах после доставки. Проверить тему группы, платную отправку и отказ сервера без ложного успеха.
5. Кружок с подписью доставляет весь текст/entities. При сбое и повторе не дублирует уже доставленное медиа; disable-link-preview сохраняется. Сохранённые одноразовые записи остаются доступны для повторного прослушивания и транскрипции после серверного удаления.
6. PiP запускается с первого нажатия и с быстрого свайпа вверх. Возврат, пауза и воспроизведение соответствуют команде, без двойного toggle. Проверить cached-status lag, буферизацию, HLS, background, закрытие и повторный вход; сравнить скругление/кадры с native13.2. Выключенный swipe не отключает кнопку.
7. Сохранение удалённых сообщений: первое удаление даёт анимацию,50% прозрачности и метку, повторное удаляет локальную копию. Альбом не распадается и не оставляет зазор; закреплённые/отложенные копии не показывают. Очистить локальный архив удаляет весь архив.
8. Обычный и расширенный редакторы одинаково прикрепляют файлы и плавно переключают клавиатуру/эмодзи/форматирование. Не добавляют лишнее раскрытие ссылки при копии поста.
9. Настройки/debug: RU/EN/DE и выбранные другие языки, новые16 строк, RTL; Whisper/Vosk idle показывает размер, скачивание — процент, установленная модель — только название/галочка. Проверить старые выбранные/скачанные модели.
10. Камеры кружков, tuning, геометрия нового списка чатов/side list, компактные строки, VoiceOver, инкогнито/read watermark и фильтр заблокированных сообщений, включая синхронизацию с другим клиентом.

При ошибке указать iPhone/iOS, source/build из IPA, состояние переключателей и короткую последовательность. Для анимации приложить запись экрана; для падения ZIP crash report. Успех SDK/пакетной проверки не закрывает эту физическую приёмку.
