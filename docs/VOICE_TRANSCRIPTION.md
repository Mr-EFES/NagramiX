# Расшифровка голосовых сообщений и кружков

Актуальное завершение исходников: [Vosk, Cloudflare, четыре модели и локальный резерв](TRANSCRIPTION_COMPLETION.md). Ниже сохранено описание раннего этапа.

Статус27октября: базовая расшифровка входит в 0.7.6/build139; описанные ниже новые страницы, модели и Grok — локальные изменения после139, ещё не собраны Apple SDK и не проверены на iPhone. [Результат предыдущего выпуска](RELEASE_STATUS.md).

Реализация после согласования эскизов, 27 октября 2026 года. Guarded стадия `voice_transcription` после `translation_gpt_oss`; последующие SDK-адаптеры описаны в [разборе](SDK_COMPATIBILITY.md). Опубликованный 0.7.5/build134 её не содержит. SDK и IPA139 проверены, физическая приёмка ожидается; следующие сборки требуют отдельной команды.

## Интерфейс и начальные значения

NagramiX → Прочее → «ТРАНСКРИБАЦИЯ»: переключатель «Расшифровка сообщений» и условный переход «Настройки транскрибации» с текущим способом. Master и авто выключены на чистой установке; Apple и Русский — исходный выбор. Внутри — авто, Telegram, Apple/Whisper и облачные Gemini/ChatGPT/Grok. Под выбранным движком появляется его отдельная страница; старый Groq остаётся доступным, если уже выбран, без подмены ключа или сброса настроек.

Apple показывает системные поддерживаемые и установленные локали и отдельно загружает выбранную через AssetInventory, если версия iOS поддерживает эту возможность. Speech API не предоставляет надёжного локального автоопределения: пункт показан недоступным, используется выбранный язык. Whisper показывает список распознаваемых языков, режим auto для многоязычных моделей и отдельные модели с удалением свайпом; англоязычные модели обозначены и фиксируют английский язык. При выборе незагруженной модели она активируется после успешной проверки и установки, только если исходные настройки ещё актуальны.

Для облачных служб — персональный Keychain-ключ, колесо модели и выключенное по умолчанию согласие на передачу аудио; сохранение в верхнем баре. Старый ключ из настроек перевода автоматически не читается. Скачивание моделей на дорогом подключении предлагает продолжить или отменить; Wi-Fi включается пользователем средствами iOS. Настройки и ключи старых версий сохраняются, общие тема, статус-бар и размер шрифтов прежние.

Ручная расшифровка — штатной кнопкой →A у голосового/кружка или пунктом контекстного меню. Повторное нажатие во время своей операции отменяет её; готовый текст разворачивается/сворачивается штатным способом. Контекстная операция имеет «Отменить расшифровку» и уведомляет о готовности. Ошибка понятная, без удаления оригинала. Локальные результаты имеют native transcription ID0 и `didRate=true`, не отправляются в Telegram как оценки серверной расшифровки.

## Локальные движки

Apple: на iOS26+ и Swift6.2+ — `SpeechTranscriber`/`SpeechAnalyzer` с реально установленным точным locale. Язык отдельно загружается по явной кнопке через `AssetInventory`; системой могут планироваться повторные попытки установки. При отсутствии подходящих новых assets — только локальный `SFSpeechRecognizer` с реальным `supportsOnDeviceRecognition` и `requiresOnDeviceRecognition=true`. На старых ОС этот путь основной. Серверный fallback Apple не разрешён. Legacy-разрешение запрашивается только вручную, автоматический режим не показывает окно разрешений. Проверка устройства/языка/availability проводится перед запуском; поддержка не выводится из названия iPhone. Старый Speech API имеет собственные ограничения длины/доступности; Whisper остаётся отдельным выбором, без скрытого переключения.

Whisper: библиотека whisper.cpp v1.7.6, commit `a8d002cfd879315632a579e73f0148d06959de36`, архив SHA256 `7b17da903114ed45d82f48c030e3be6a5a8a279f884b2f733706dbb4e832fb6b`. CPU и Accelerate. Все33 GGML-файла закреплённого каталога `5359861c739e955e79d9a303bcbc70fb988958b1` проверены по имени, размеру и SHA256, включая англоязычные и крупные варианты; прежние `.base` и `.small` сохраняют старые файлы. Веса загружаются отдельно, SHA256 проверяется до атомарной установки, файлы защищены lease при использовании и исключены из backup. На старых iPhone крупные модели могут требовать больше памяти, чем доступно: проверка на устройстве необходима. Лицензия доступна в настройках.

Распознавание выполняется в отдельной последовательной очереди, максимум четыре CPU-потока. C++ abort callback получает cancellation token. Тишина/невалидные PCM/пустой результат имеют отдельный отказ. Качество и скорость на реальных iPhone ещё не измерены; локальное распознавание не означает отсутствие расхода памяти и батареи.

## Облачные движки и Telegram

- Groq: собственный ключ, audio/transcriptions, default `whisper-large-v3-turbo`. Бесплатный план и лимиты определяет сервис.
- Grok: отдельный ключ xAI, `https://api.x.ai/v1/stt`, multipart с файлом в последнем поле, модель `grok-voice-transcribe-2.0`. Не использует ключ/маршрут Groq.
- Gemini: собственный ключ, `generateContent`, default `gemini-3.1-flash-lite`, audio/m4a inline. JSON с дословным текстом; незавершённый ответ не принимается. Бесплатная квота доступна не всем проектам/моделям/регионам.
- ChatGPT: собственный OpenAI API-ключ, специализированный `/v1/audio/transcriptions`, default `gpt-transcribe`. Веб-подписка ChatGPT не оплачивает API.
- Telegram: прежний native путь, все реальные Premium/trial/boost ограничения сохраняются. Новый автоматический режим его не вызывает.

Отправляется только подготовленная звуковая дорожка выбранного сообщения. Ни кадры кружка, ни соседняя переписка не отправляются. Фиксированные HTTPS-хосты, POST; ключи не попадают в URL, нет HTTP-redirect/cookie/disk cache. Нет автоматического переключения провайдера, бесплатного/платного тарифа или модели. 401/403, 402/429, сеть, пустой и неполный результат обрабатываются отдельно. После quota-ответа cooldown учитывает числовой Retry-After с ограничением30–3600секунд. Пользовательский текст и ключи в логи не пишутся. DeepSeek/GPT-OSS не добавлены в ASR: документированного raw-audio входа для этой интеграции не подтверждено.

## Очередь, ресурсы и запись результата

Один активный worker и максимум восемь ожидающих, совпадающие запросы объединяются. Отмена последнего потребителя не освобождает slot, пока настоящий decoder/recognizer не завершит работу: быстрые свайпы не создают параллельные декодеры. Выключение функции/смена параметров отменяет старую revision, background и предупреждение о памяти останавливают активную обработку независимо от времени жизни экрана чата. Настройки после правки ключа инвалидируют старые результаты и незавершённые записи.

Автоматически обрабатываются только видимые загруженные входящие записи обычного открытого чата, не scheduled, preview, secret, self-expiring/view-once или copy-protected media. Автоматических скачиваний или запросов разрешения Speech нет. Неудачные автоматические задачи не крутятся бесконечно; есть ограниченный backoff. Вручную полный ресурс может быть скачан по message reference. Лимит15минут, исходник до100МБ, подготовленное аудио до25МБ; извлечение AAC64кбит/с и PCM16кГц mono выполняется в фоне, без `AVAudioSession`, `AVPlayer`, изменения воспроизведения, read/consume/send событий. Временная копия удаляется по окончании использования.

Ключ операции содержит аккаунт, peer, namespace/message ID, ресурс и параметры. Native текст хранится в локальном Postbox; provenance — собственный ключ в `DerivedDataMessageAttribute`, остальные entries сохраняются. Кеш учитывает ресурс, модель, язык, credential revision; master/auto toggles сами по себе не расходуют квоту повторно. Перед записью заново проверяются ON, revision, cancellation, существование сообщения, eligibility и точный media fingerprint. Caption, entities, дата, flags, thread, grouping, остальные attributes/media сохраняются; удалённое сообщение не воссоздаётся. Оригинал не заменяется и на сервер не отправляется.

## Проверки и границы

`python3 scripts/validate_voice_transcription.py --source <полная-композиция> --swiftc <swiftc>` проверяет точные входы, BUILD/templates/pins, fail-closed до первой записи, обратное восстановление и строгие проверки предыдущих translation/round/scheduled stages. Swift исполняет реальный Settings/Cloud/Coordinator/Runtime/Credentials с явными границами HTTP/Keychain/ML/Postbox в debug и optimized. Отдельная проверка SpeechAnalyzer подставляет только Apple API-границу; это не компиляция Apple SDK.

Базовая проверка исходной реализации:203Swift-проверки в каждом debug/optimized (406суммарно),130отказов некорректных overlayвходов без частичной записи, полная композиция327modifiednative и21sourcevalidator.309прежних modifiednative побайтно сохранены.

На Linux реально собраны24файла pinned whisper.cpp и production C bridge. Проверенный SHA модели base-q5_1, публичный `samples/jfk.wav` распознан на CPU; тишина, NaN PCM, отсутствующая модель, отмена активного распознавания пройдены. Аудио пользователя не отправлялось, платные API не вызывались. После успешной SDK-сборки139 необходима физическая проверка загрузок/языков Apple, Keychain, AVFoundation, UI, нагрева/памяти/скорости Whisper, настоящих ключей/квот и одновременного воспроизведения/PiP.
