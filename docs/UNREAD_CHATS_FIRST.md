# Непрочитанные сверху

Настройка «Интерфейс → Чаты → Непрочитанные сверху», без footer. Новый ключ `nagramix.interface.unreadChatsFirst`, absent ON; сохранённые OFF/ON не сбрасываются на запуске. Stable ID139, RU/EN, поиск. Переключение обновляет все существующие folder nodes через отдельное уведомление; observer удаляется при deinit.

Обычный список во всех папках, включая архив: закреплённые, архивная строка и промо сохраняют штатный порядок. Незакреплённые чаты, группы, каналы и свёрнутые communities сортируются по фактическому счётчику непрочитанных по убыванию; при равенстве остаётся native message index, то есть обычный порядок последнего сообщения. Звук и mute не влияют на приоритет. Родные правила состава папки сохраняются: настройка не добавляет в неё исключённые чаты. Ручная отметка «непрочитано» без непрочитанных сообщений имеет счётчик0. После прочтения счётчик0 возвращает чат в обычную часть списка.

Сортировка касается представления, не timestamp сообщений, не Postbox indices и не серверных закреплений. Snapshot rank входит в equality/Comparable native entries, поэтому list diff видит перемещения. Сортируются только slots незакреплённых peer rows; остальные строки, включая contact suggestions и section headers, сохраняют точные штатные места. Native peer/thread identity, pin drag, reveal/select/context actions, архив, readonly предпросмотр и read receipts прежние. Pickers адресатов, списки тем форумов/Избранного, поиск — штатные.

Чтобы старый чат с большим счётчиком тоже оказался наверху, загрузчик расширяет реактивный native tail view папки80→160→320… до конца. Фиксированного обрезания на первой странице нет. Состав папки, загрузка holes и community summaries остаются native. Каждый шаг отменяет прежнюю подписку; расширение ждёт окончания hole filling. Проверка поколения count исключает повторное расширение от старого snapshot. OFF возвращает штатные chronological windows и пагинацию. В ON chronological navigation из viewport отключена, явный scroll сохраняется и находит точный native index в отсортированном списке. Повторные Initial при расширении преобразованы в Generic; нативная виртуализация строк и лимит history preload30 остаются.

Полная глобальная сортировка требует хранения metadata всех чатов открытой папки; большие аккаунты требуют отдельной оценки памяти и времени на iPhone. Пока локальная база/сервер заполняет holes, порядок может уточняться. Не утверждать, что эта правка уже проверена в нативной сборке.

## Проверки исходников

Telegram13.0 pin `f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838`. `apply_unread_chats_first` применяется последним: full-SHA256 проверяет4входа перед изменениями, все16уникальных substitutions готовятся в памяти до записи. Два `.inc` — durable source; временные доказательные деревья не коммитить.

`python scripts/validate_unread_chat_overlay.py --baseline /tmp/nagramix-051-preview-selection-toolbar-proof --audited-native /tmp/nagramix-unread-audit`:16обратных substitutions восстанавливают точные входы;4drift и rerun отклоняются до записи. Grammar7изменённых Swift sources, Pythoncompile, release metadata, JSON и diff check. Это проверки интеграции исходников, не runtime unit tests. Нативный compile/device — pending; версия0.5.2/опубликованный №84 прежние, нового IPA нет.

## Физическая проверка следующего пакета

1. Чистая установка: ON. Сохранить OFF, перезапустить: OFF. ON/OFF во время открытой папки и возврат в ранее открытую папку.
2. Создать незакреплённые chat/group/channel со счётчиками1/2/20, различным последним временем и mute. Ожидаемый порядок20/2/1; прочитанные ниже по обычному времени. При равенстве — штатное время.
3. Оставить закреплённые в ручном порядке независимо от их счётчиков; закрепить/открепить/перетащить при ON. Архив и промо прежние.
4. Поместить наиболее непрочитанный старый чат за пределами80/160/320строк. После загрузки он должен подняться; нет пропусков/дубликатов. Проверить большой аккаунт, память, прокрутку, background/foreground и offline holes.
5. Новые сообщения, чтение с другого клиента, mark read, частичное чтение, pending clear/remove, удаление чата; счётчики и порядок обновляются без перезапуска.
6. Обычные/кастомные папки, архив, исключения и community summaries, несколько аккаунтов. Выключение возвращает обычный порядок и глубокую штатную пагинацию.
7. Переход к конкретному чату, выделение1/N, пересылка, аватарный readonly preview и отложенные реакции. Сортировка не отправляет отметку чтения. Поиск, адресаты пересылки, forum topics прежние.
