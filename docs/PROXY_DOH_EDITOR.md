# Редактор пользовательского DoH

По утверждённому референсу и уточнению владельца основной блок прокси теперь располагается в порядке: использование прокси, DNS-сервер, URL пользовательского DoH, «Предпочитать IPv6», автоматическое переключение, интервал и обход при VPN. Строка URL показывается только при выбранном пользовательском DoH. Меняется порядок, стабильные идентификаторы строк сохраняются.

В редакторе адреса ровно две кнопки: «Удалить» слева и «Сохранить» справа. Верхнего крестика и отдельной кнопки отмены нет. Крестик внутри текстового поля только очищает ввод: он не закрывает окно и не меняет сохранённый DNS. При пустом или некорректном адресе сохранение недоступно. Штатное закрытие окна без действия сохраняет прежние настройки.

«Удалить» очищает сохранённый адрес, возвращает DNS-провайдера, использовавшегося до перехода на пользовательский DoH, и закрывает редактор. Прежний выбор хранится в отдельном ключе `nagramix.network.dnsProviderBeforeCustomDoh`; он переживает перезапуск. Повторное редактирование URL и изменение других настроек его не перезаписывают. Если пользователь ещё не сохранил первый DoH-адрес, удаление оставляет текущий обычный DNS. Для старой установки с уже выбранным DoH, где история ещё не записывалась, возврат использует существующий начальный вариант Telegram. Удалённые номера провайдеров и ошибочная история тоже не возвращают неподдерживаемый DNS.

«Сохранить» оставляет прежние проверки HTTPS, имени сервера и доступности DoH. После успешной проверки сохраняются адрес и выбор пользовательского провайдера, затем окно закрывается. При ошибке окно остаётся открытым с существующим сообщением об ошибке. Повторное нажатие и Return не запускают вторую проверку одновременно. Удаление или закрытие отменяет выполняющийся запрос; его поздний ответ не может применить старый URL. Завершённое действие выполняется только один раз.

## Раскладка и совместимость

Причина прежнего выхода кнопки за окно — три действия в горизонтальной раскладке AlertScreen, рассчитанной на две половины ширины. Новый редактор передаёт ровно два действия. Размеры, отступы, цвета, адаптация длинных локализованных подписей и отступ от клавиатуры остаются штатными. Общий AlertScreen и поле ввода не меняются.

Поздняя стадия `proxy_doh_editor` применяется после `round_video_editor`: три замены, 17 неизменяемых зависимостей и 23 новых снимка. Все 2621 прежних `.inc` сохраняются. Новых файлов приложения, библиотек и UI-строк нет. Используются имеющиеся переводы удаления и сохранения. Порядок и ID DNS-провайдеров, endpoints, резолвер, IPv6, автопереключение, настройки VPN, уведомления переподключения, запись и отправка кружков сохраняются.

## Проверка

`scripts/validate_proxy_doh_editor.py` исполняет настоящий контроллер с его callbacks, проверку URL, историю провайдера и реальные выражения горизонтальной геометрии кнопок. UI, Signal и транспорт ограничены явными адаптерами. Поздние callbacks намеренно доставляются даже после отмены для проверки защиты от применения устаревшего результата. Проверяются удаление до/после первого сохранения, пустой ввод, ошибочный адрес, повторное нажатие, успешная проверка, ошибка и повтор, удаление/закрытие во время проверки, старый провайдер System с ID0, остальные провайдеры и старые данные без истории.

Сохранение истории проверяется также отдельными холодными процессами с реальным Foundation UserDefaults. Публичные типы Core и настоящий callback удаления из SettingsUI проверяются отдельными модулями. Обязательны смысловые отрицательные варианты в debug/`-O`, отказ загрузчика до записи, строгая локализация, общий source gate, обратимость стадий и PostboxImportCheck.

Точные результаты — [PROXY_DOH_EDITOR_CHECKS.json](PROXY_DOH_EDITOR_CHECKS.json). Проверки исходников не подтверждают пиксели UIKit, работу клавиатуры на iPhone, доступность конкретного DoH-сервера или Apple SDK. Физическая приёмка: открыть редактор с пустым и сохранённым адресом, очистить поле, удалить, сохранить, проверить возврат DNS после перезапуска, обе темы, узкий экран, длинные переводы и исчезновение окна после действия. Новая сборка этой командой не запускается; опубликованная 0.9.1/build190 и метаданные остаются прежними.
