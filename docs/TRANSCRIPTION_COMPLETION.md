# Завершение согласованных настроек расшифровки

Текущая реализация находится в финальных этапах `transcription_whisper_safety`, `transcription_cloud_ui`, `transcription_local_fallback`, `transcription_cloudflare`, `transcription_vosk`. Ранние проверенные входы сохранены; Actions/IPA/SDK не запускались.

Актуальный контракт моделей и памяти заменён [LOCAL_ASR_MODELS](LOCAL_ASR_MODELS.md): BaseQ5/Small full/TurboQ8 и compactru0.22/архивный graph-вариант ru0.10. Предыдущие четыре полные модели и multiplier-memory guard ниже относятся к историческому входу; новые исходники проверены отдельно, SDK/iPhone pending.

## Поведение

В «Прочее» группа «РАСШИФРОВКА ГОЛОСОВЫХ», включение и условные настройки с выбранным способом. На странице «Расшифровка» короткие подписи «Авторасшифровка» и «Резервный способ». Telegram Premium виден только после подтверждения подписки текущего аккаунта. Apple, Whisper, Vosk расположены в группе на устройстве; Cloudflare, Gemini, ChatGPT, Grok — через интернет. Legacy Groq не сбрасывается. Перевода текста на другой язык этот экран не выполняет.

Whisper показывает четыре полные многоязычные модели: base-full/147951465 bytes, small-full/487601967, medium/1533763059, large-v3/3095033483. Названия на русском «Базовая», «Малая», «Средняя», «Максимальная»; добавлены переводы для 17 локализаций и английский fallback. Старые enum/data/файлы не удаляются, новая установка использует base-full. Перед PCM и запуском модели проверяется доступная память процесса, с понятным отказом. Это не доказательство устранения любого Jetsam на физическом устройстве.

Vosk реализует третий утверждённый вариант: выбор языка, затем список компактных/точных моделей выбранного языка, состояния загрузки, отметка выбранной установленной модели, удаление свайпом, отмена загрузки повторным нажатием. При дорогом интернете есть предупреждение. После установки модель активируется только при неизменной revision. Каталог закреплён в исходниках: 52 актуальные модели для 30 языков, для которых в официальной таблице явно указана Apache 2.0. Остальные лицензии и устаревшие модели не включены в загрузку.

Установка проверяет размер, официальный MD5, имена ZIP entries, общий распакованный размер и доступное место. Все файлы извлекаются поштучно в новый staging-каталог; оригинальные атрибуты симлинков не восстанавливаются. Установка заменяет каталог после проверки am/final.mdl и conf/model.conf. Маркер сверяется с каталогом; leases защищают используемые файлы от удаления. Модели исключены из backup. HTTPS-редиректы допускаются только на alphacephei.com. MD5 служит проверкой совпадения с официальным каталогом; источником транспорта остаётся HTTPS.

Библиотека Vosk — сторонняя сборка santalex/libvosk v0.3.50, архив XCFramework закреплён SHA256. Проверены arm64, platform iOS(2), minimum iOS12; используется device-срез. Текущий BUILD рассчитан на физический iPhone, simulator-срез отдельно не подключён. Официальный пример alphacep сам требует отдельно собранную библиотеку. Ссылка, SHA, лицензия, каталог и header provenance сохранены в ios/vosk_runtime.

Распознавание Vosk проходит через общий coordinator и подготовку звука: PCM16000 mono, native RAII, отмена, освобождение памяти, сбор всех endpoint-фрагментов и финального текста. Входной float PCM преобразуется в масштаб, ожидаемый Vosk. Проверка памяти выполняется до запуска. Язык модели должен соответствовать заданному языку речи; автоопределение Vosk не обещается.

Резерв выключен по умолчанию, использует уже доступные Apple/Whisper/Vosk после отказа выбранного способа. Не скачивает модели и не вызывает новые разрешения. Отмена, тишина и превышение допустимого размера завершают задачу без перебора. Повторного прохода по одному provider нет; ревизия и отмена проверяются до каждой попытки. В кеш включаются параметры резервных моделей. Сетевые сервисы вызываются только при явном выборе основного provider; Telegram сохраняет отдельный штатный путь. Cloudflare не включён в автоматический резерв: один API-токен не доказывает бесплатный тариф или остаток общей квоты аккаунта.

Cloudflare принимает персональные API-токен/Account ID, хранит их вместе в device-only Keychain и использует фиксированный endpoint Whisper Large v3 Turbo с base64 аудио/task=transcribe. Ответ проверяется как Cloudflare envelope. Личная квота и тариф определяются Cloudflare; бесплатный безлимит не обещается. Страницы облачных служб содержат ссылки на получение данных доступа, ключ/модель/Save. Отдельный переключатель передачи аудио скрыт по указанию пользователя; согласие фиксируется явным выбором provider или сохранением параметров. Ключ и параметры последнего этапа сохраняются одним уведомлением/revision. Ключи переводчика не подставляются.

## Проверено

- Композиция всех stages поверх прежней проверенной базы; reverse исходной цепочки; source/hash checks и fail-closed без частичной записи. Логи `/tmp/nagramix-vosk-compose.log`, `/tmp/nagramix-vosk-validation.log`.
- C++ bridge компилировался g++ с warnings-as-errors; исполняемый тест с C API boundary проверяет отмену, масштаб PCM и сохранение endpoint-фрагментов.
- Тот же bridge исполнялся с настоящим Linux Vosk0.3.45 и официальной небольшой английской моделью на публичном samples/jfk.wav. Получен осмысленный текст; это не проверка iOS-библиотеки и не измерение качества всех моделей.
- Swift production syntax tree, Python compile, 739 TelegramCore import-access файлов, метаданные и git diff.

Не выполнены: Apple SDK/ARM64 линковка целого приложения, UIKit, реальный Keychain и HTTP с пользовательскими ключами, все 52 модельные архивы, проверки памяти/скорости/нагрева/ASR на физическом iPhone. Код подготовлен для следующей отдельно разрешённой сборки; готовность на устройстве не подтверждена. Резерв через Cloudflare/Telegram и simulator не реализованы как часть текущего локального резервного режима.
