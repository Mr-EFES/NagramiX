# Именные ссылки без автоматических карточек

Статус: `source_checked / native_compile_pending / live_rpc_pending / device_pending`. Владелец утвердил эскиз после видео `-8028816325223924185.mp4` (18,8 с): строка «Радио Таврия — подписаться» остаётся кликабельной, а отдельная карточка канала с описанием, логотипом и «Перейти в канал» не появляется. Кадры видео и эскиз находятся вне Git; исходное пользовательское видео не публикуется.

Правило одинаково действует в обычном и расширенном редакторах, при первой вставке текста, повторном редактировании скопированного/пересланного поста, отправке «Переслать» без автора и рассылке. Название, адрес, UTF16-диапазоны и форматирование ссылки сохраняются. Настоящие вложения поста остаются на месте; переход по названию ссылки остаётся штатным.

Причины прежнего расхождения:

- Этап59 запрещал лишний preview только при наличии собственных файлов. Текстовая именная ссылка снова попадала в запрос `webpagePreview`.
- При открытии редактирования `updatedChatEditInterfaceMessageState` переносил готовый webpage из сообщения. Отдельная editing query могла его загрузить заново; запоздавшие ответы возвращали карточку.
- Сборщик копий сохранял webpage и preview-only атрибуты. Быстрая пересылка без автора передавала исходный cloud ID вместе с уже готовой карточкой, а отключить её этим RPC нельзя.

Стадия79 `named_link_preview` после `original_video_media` меняет семь существующих Swift-файлов. Новый UI-предикат читает штатный `ChatTextInputTextUrlAttribute`, общий Core-предикат — настоящие `.TextUrl` entities. Query не запрашивает карточку для именной ссылки. Обновление обоих редакторов снимает карточку и подписку, а callback проверяет актуальный текст повторно. Инициализация редактирования не переносит старый webpage. Обычная и rich-отправка передают `.disableLinkPreviews`, сохранение редактирования — native `no_webpage`, сохраняя entities и настоящие медиа. Core повторяет проверку при прямом запросе редактирования и не загружает webpage как новое вложение.

Копии всегда передают запрет автоматического preview, снимают webpage-media и относящиеся только к нему атрибуты; положение настоящей подписи сохраняется. Сообщение с webpage использует существующий путь самостоятельной копии. Для его обычных облачных фото/видео сохраняется быстрая ссылка на ресурс без обязательного скачивания полного файла. Выбранный альбом остаётся на одном транспорте; сообщения без карточки сохраняют прежний fast route. Права, оплата, темы, расписание, отмена, retry и отдельный штатный «Репост» остаются прежними.

Обычный новый ввод голого URL сохраняет прежний Telegram preview. Это не отключение отображения входящих сообщений, не блокировка открытия ссылки и не массовое изменение уже отправленной истории. Повторное сохранение старого поста с именной ссылкой отправляет запрет карточки даже без изменения текста. Блоки документа, прикреплённое медиа и отдельные URL-кнопки не уплощаются.

Новых настроек, строк, ресурсов приложения, зависимостей или изменений подписи/SDK нет. Впервые изменяемый `ChatInterfaceStateContextQueries.swift` независимо проверен через GitHub API на official pin `24638bc69bd083981b178dd1e7f921eebbf7fc46`, blob `2b3f3484ea73431dae350a8228d9ed30c0b12e7e`; этот origin закреплён в плане и loader. Все входы/guards/templates проверяются до первой записи. Прежние снимки не переписываются.

```sh
python3 scripts/validate_named_link_preview.py \
  --source <native> --swiftc <swiftc> --report <json>
```

Регрессия UI исполняет реальные типы entities/URL-атрибутов, SignalKit, URL-query, выбранные production state/callback/send ветки, инициализацию редактирования, сохранение и решение Core edit RPC. Вторая регрессия исполняет полный реальный copy builder, authorless planner, recipient batch, media staging и native EnqueueMessage. URL-detector, UI/rendering, Postbox/сеть и граф медиа представлены явными границами. Проверяются ссылка с emoji, голый URL/обычный текст, compose/edit/late callback/reopen, обычный/rich путь, сохранность аудио- и видеовложений, source preview, три адресата, альбом, server flags и неизменность тела/сущностей. Старый builder и смысловые мутации должны воспроизводить ошибку. Ранний gate и post-apply validator обязательны.

Итог — [NAMED_LINK_PREVIEW_CHECKS.json](NAMED_LINK_PREVIEW_CHECKS.json). Локальные проверки не подтверждают iPhone-пиксели, live RPC и серверное сохранение. Published0.9.7/build213/source74 остаётся прежним; новая SDK/IPA — по прямой команде.

Приёмка на iPhone: первый paste и повторная вставка в оба редактора; текст без вложений и текст с аудио/видео/фото; редактирование старого поста с уже существующей карточкой; сохранение без изменения текста; переход между редакторами, задержка/отключение сети и быстрое изменение поля; «Переслать», три адресата рассылки, альбом. Ожидание: кликабельное название и форматирование сохранены, вложения не пропадают, отдельная карточка не закрывает сообщение и не возвращается после сохранения/повторного открытия.
