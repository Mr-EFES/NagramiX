# Перенос доработок на Telegram13.2 для выпуска0.8.9

Личная команда владельца: сначала перенести все доработки на официальную13.2, затем отправить их в main, собрать чистый IPA0.8.9 и опубликовать обычный релиз от Mr-EFES. Причины неуспешных попыток исправлять и повторять сборку до успеха. Новая версия после этого выпуска потребует отдельной команды.

Закреплённая база: `24638bc69bd083981b178dd1e7f921eebbf7fc46`, app13.2, Xcode27.1, Bazel9.2.0. Историческая база overlay `279f89e4d4f63f17227bf877dc3d8990f22ecd58`/13.1.2 сохранена только для точных промежуточных входов и проверок. Реальный конечный исходник и provenance используют13.2. Минимальная версия iOS сверяется с Telegram/BUILD и Mach-O готового IPA.

Узкое исправление получения зависимостей закрепляет опубликованную официальную`38dcea121f10638c42098f226f05c298a392f95c` с production v2wasm/InstanceV2Pump интерфейсом. Это явная замена одной зависимости, а не точный исходный gitlink13.2. `dependencies.json` фиксирует все12native gitlinks/URL, один checkout override и SHA6ключевых файлов. До fetch проверяются rootHEAD13.2,точный.gitmodules и весь набор native gitlinks; остальные11 используются без замены. Не используется плавающая ветка. Замена обязательной отдельной строкой включается в BUILD-PROVENANCE и проверяется перед публикацией. Два отсутствующих в опубликованной библиотеке test-only C++ источника не входят в production target; тесты ими не подменяются. SDK/живая приёмка звонков должны подтвердить совместимость.

Новый отдельный NativeAccountIntermediateState132.inc содержит точный вход13.2; исходный Before148.inc сохранён. Все конечныеoutputs/реализации неизменны. ## Воспроизводимая композиция

Сравнение полных исходников:897 новых upstream-коммитов,5204 изменённых пути,197 пересечений с620 путями наших доработок;35 конфликтующих файлов,106 областей решений. Шесть областей CrashReportsController сохраняют согласованный локализованный интерфейс и отправку с согласием только проверенному @NagramiX_bot. Остальные100 областей объединяют новые native-изменения с нашими функциями.

`upstream_13_2_release_pre` выполняет196 замен и временно восстанавливает2 исторических файла, необходимых старым стадиям. Все прежние стадии, snapshots, SHA, проверки и порядок воспроизводятся без их подмены. После исторической `upstream_13_2_post` новая `upstream_13_2_release_post` выполняет274 замены, проверяет358 зависимостей и удаляет2 устаревших файла. Все входы, шаблоны, назначения и удаления проверяются до первой записи; повторное применение и повреждение входов отклоняются.

Архивирование входящих/изменённых/удалённых сообщений, защита сохранённых media-ресурсов и транскрипции перенесены в новые State/Sync/StateReplay файлы. Интерпретатор обновлений остаётся без Postbox: изменения списка блокировки передаются как delta состояния, объединяются с channel-веткой и применяются после native replay rejection guard. Очерёдность native синхронизации, решения сервера, auth gates и allowlists не ослаблены. Приватный read watermark записывается после определения native readIndex.

Background ownership PiP перенесён из удалённого JS HLS-класса в текущий HLSVideoNativeContentNode. Native PiP13.2, быстрый свайп и прямые play/pause сохранены. Убраны устаревшие LottieSettings аргументы snapshot-копирования костей. Новый фильтр onlyLocationResults сохраняет native бит18; наш transient notification-фильтр использует20, copy-фильтр19. Сохранённых настроек это не меняет.

Сохраняются R1: полный состав копии поста, R2: отдельная подпись кружка с entities/content-info и корректным retry, R3: идемпотентные команды воспроизведения PiP. Все накопленные изменения после выпуска0.8.8 входят в новый исходник, а не в старый IPA.

## Локализация и проверки

Для16 новых debug-подписей подготовлены переводы всех71 языков: итог629 ключей каждого каталога. Старые613 значений сохранены. Финальная строгая проверка выполняется после миграции без восстановления исторических каталогов и без allow-incomplete: source contracts, точные SHA, format arguments, полный production Swift resolver в debug/-O. Проверка IPA требует точные71×629 для0.8.9; прежние опубликованные пакеты по-прежнему проверяются по613 ключам.

`validate_upstream_13_2_release.py` проверяет финальные SHA, наличие перенесённых hooks, отсутствие устаревших файлов, уникальность наших selector-битов, корректное применение pre/post и отказ до записи при повреждениях. На настоящих конечных production-блоках исполняются тесты PiP, native поведения, подписей кружков и состава копий в debug/-O с отрицательными вариантами. Изменённые Swift-файлы проходят parser и неизменённый native PostboxImportCheck.

Эти исходные проверки не подтверждают Apple SDK, живую сетевую доставку, UIKit/AVKit анимации и физический iPhone. Результат чистой сборки, digest исходного Actions ZIP/IPA и публикация фиксируются отдельно в [RELEASE_STATUS](RELEASE_STATUS.md). Физическая приёмка — [DEVICE_CHECK_089](DEVICE_CHECK_089.md).
