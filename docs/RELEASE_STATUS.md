# Сборка NagramiX 0.4.8 для iPhone

Пользователь разрешил новую чистую ARM64-сборку и публикацию тестового релиза. Первая попытка №78 завершилась ошибкой Swift; причина исправлена, готовится повторная чистая сборка. IPA и релиз ещё не опубликованы.

- Версия: 0.4.8; main.
- Исходный коммит: bc7aad7b70e16c236f094840eb15df5b5ed0cde7.
- [Первая чистая сборка №78](https://github.com/Mr-EFES/NagramiX/actions/runs/37831201805), run 37831201805; завершилась ошибкой компиляции ChatListUI.
- Telegram-iOS: 12.9.2, pin 6ad963e5b62d354da79040f388ae2b9132fb17b8. Проверка официальной базы перед запуском: CURRENT.
- Workflow: build-unsigned-ipa.yml; clean_build=true, artifact_run_id пустой, publish_release=true, prerelease=true.
- Русская аннотация возможностей: [0.4.8](../product/releases/0.4.8.md).
- Подготовленные исходники прошли проверки overlay, Swift syntax, exact anchors, Python, метаданных и diff.

В новый билд включены жесты папок/меню и просмотр по аватарке, компактная плотность, воспроизведение архивного медиа и метка удаления, тихая/отложенная отправка копий, PiP свайпом и фоновый звук видео. «Переслать от» для удалённого серверного оригинала не добавлен; согласование отдельной текстовой подписи автора не завершено.

В открытии чата через аватарку EngineChatList.Group передавался как EnginePeerGroupId. Теперь используется groupId._asGroup(), как в соседнем штатном маршруте Telegram. Повторное применение полного overlay: изменена только эта строка ChatListController.swift, остальные 320 generated-файлов совпадают. Swift syntax, Python, метаданные и diff проходят. Полная нативная компиляция ещё ожидается.

После успешной повторной сборки будут проверены упаковка и опубликованный IPA. Предыдущие релизы сохраняются. Физические сценарии пока не выполнены: [план iPhone](IPHONE_TEST_0.4.8.md).
