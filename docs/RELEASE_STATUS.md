# Тестовая сборка NagramiX 0.4.7

Пользователь разрешил новую сборку для физического iPhone и публикацию тестового релиза с краткой русской аннотацией. Версия назначена 0.4.7. Подготавливается новый clean ARM64 workflow; результат компиляции, упаковки и публикации пока ожидается. Прежний IPA №75 не содержит последних исправлений и не используется как новый артефакт.

Включены:

- плотность компактного списка: аватар/текст/строки/отступы, default OFF;
- удержание аватарки для штатного предпросмотра и остальной строки для меню; свайпы — папки;
- отдельный архив полных файлов входящих медиа, штатное открытие копий и очистка с отменой загрузок;
- «Временные сообщения» после «Удалённых сообщений», default OFF, требуется ON обоих для временных/одноразовых вложений.

Наложение на закреплённый Telegram-iOS 12.9.2, pin 6ad963e5b62d354da79040f388ae2b9132fb17b8, CURRENT. Статические проверки пройдены: область архивного расширения 13 changed/1 added/266 identical, обратный diff stock paths, 36 отрицательных anchors, Swift-разбор новых участков, defaults/IDs/RU/EN и metadata. Нативная компиляция новых функций и реальные MediaBox/жесты ещё не подтверждены.

Установка: iPhone 17 Pro Max / iOS 27.0 / SideStore с внешней подписью. [Аннотация](../product/releases/0.4.7.md), [план](IPHONE_TEST_0.4.7.md), [архив](../product/features/deleted-messages.md). Физическая проверка ожидается. Последний stable/latest 0.4.5 сохраняется.
