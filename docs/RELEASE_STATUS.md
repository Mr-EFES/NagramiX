# NagramiX 1.0.7

28 ноября 2026 года владелец поручил проверить новые правки и собрать выпуск 1.0.7 для физического iPhone с iOS 15 и новее.

В выпуск входят стадии 149–156. Исправлены отправка кружков после минутного лимита, переключение и возобновление видео в PiP и галерее, завершение плеера по окончании ролика. Доработан запуск YouTube через официальную страницу в плеере.
