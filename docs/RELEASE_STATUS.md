# NagramiX 0.5.0: чистая сборка для физического iPhone

Пользователь разрешил новую сборку 2026-10-10. База Telegram 13.0 / `f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838` повторно проверена CURRENT. План: новый исходный коммит на main, clean_build=true, пустой artifact_run_id, publish_release=true, prerelease=true. Восстановление и сохранение кеша отключены.

[Описание возможностей](../product/releases/0.5.0.md), [план iPhone](IPHONE_TEST_0.5.0.md). Статическая проверка overlay пройдена; новые изменения ожидают нативной компиляции. Прежний IPA не переиздаётся и не заменяется. Версия требует своего нового пакета с проверенными source/build/run, ARM64, локализацией, 31 мелодией и checksum.

## Статус

Подготовка исходников. Новый IPA пока не получен. Физическая проверка на iPhone не выполнена; компиляция и проверка упаковки не заменяют проверку воспроизведения, жестов, яркости, уведомлений и серверного списка зрителей историй.
