# Сборка NagramiX 0.4.8 для iPhone

Пользователь разрешил новую чистую ARM64-сборку и публикацию тестового релиза. Сборка ещё не запущена; успешный результат пока не подтверждён.

- Версия: 0.4.8; main.
- Telegram-iOS: 12.9.2, pin 6ad963e5b62d354da79040f388ae2b9132fb17b8. Проверка официальной базы перед запуском: CURRENT.
- Workflow: build-unsigned-ipa.yml; clean_build=true, artifact_run_id пустой, publish_release=true, prerelease=true.
- Русская аннотация возможностей: [0.4.8](../product/releases/0.4.8.md).
- Подготовленные исходники прошли проверки overlay, Swift syntax, exact anchors, Python, метаданных и diff.

В новый билд включены жесты папок/меню и просмотр по аватарке, компактная плотность, воспроизведение архивного медиа и метка удаления, тихая/отложенная отправка копий, PiP свайпом и фоновый звук видео. «Переслать от» для удалённого серверного оригинала не добавлен; согласование отдельной текстовой подписи автора не завершено.

Нативная компиляция, упаковка и опубликованный IPA будут проверены после запуска. Предыдущие релизы сохраняются. Физические сценарии пока не выполнены: [план iPhone](IPHONE_TEST_0.4.8.md).
