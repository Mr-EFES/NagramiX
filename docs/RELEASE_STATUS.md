# NagramiX 0.5.10: подготовка разрешённого релиза

Пользователь разрешил сборку для физического iPhone и полноценный GitHub Release с описанием возможностей мессенджера. Версия0.5.10, полноценный release (не prerelease). Новые правки: [системный PiP свайпом во всех направлениях](DIRECTIONAL_PIP_SWIPE.md), [исключения уведомлений во всех категориях](NOTIFICATION_EXCEPTION_PICKER_FIX.md). Прежние исправления включены.

Подготовка идёт в изолированном checkout от origin/main; root WIP/staged rename сохранены. База Telegram13.0 f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838 актуальна. Новая нативная компиляция и проверка IPA ещё не завершены; исходный SHA/run/build будут записаны после dispatch. Предыдущий готовый0.5.9/build97 и его артефакты сохраняются.

[Пользовательский changelog](../product/releases/0.5.10.md) · [Проверка на iPhone](IPHONE_TEST_0.5.10.md). Физический тест выполняется на устройстве; его прохождение и отсутствие всех возможных вылетов не следуют из компиляции. Camera XCTest подготовлены ранее, но не запускались.
