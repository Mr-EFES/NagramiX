# Сборка NagramiX 0.4.6

2026-10-08 пользователь разрешил новый IPA для физического теста и публикацию тестового релиза. Подготовленные изменения: штатные варианты тем, полные русские подписи, «Опции чатов по тапу», параметры фотографий/стикеров/эмодзи и выключенный по умолчанию компактный список чатов.

Метаданные, Python/Swift syntax, scoped overlay и защитные проверки проходят. Upstream-аудит подтвердил актуальную базу Telegram-iOS 12.9.2, pin `6ad963e5b62d354da79040f388ae2b9132fb17b8`. Запущена чистая ARM64-сборка [№75](https://github.com/Mr-EFES/NagramiX/actions/runs/37726223234) из исходного SHA `bb9b1c6ef9d0a66446fb9d68ea580604ca72bd0e`. Проверка базы и применение overlay прошли; сейчас идёт нативная компиляция. Workflow настроен на публикацию тестового релиза после проверки IPA. Готовый файл, SHA256 и физическая приёмка ещё ожидаются.

Предыдущий стабильный релиз [0.4.5](https://github.com/Mr-EFES/NagramiX/releases/tag/v0.4.5) сохраняется. Новый выпуск предназначен для проверки на iPhone 17 Pro Max / iOS 27.0 / SideStore; физическая приёмка ещё не выполнена.
