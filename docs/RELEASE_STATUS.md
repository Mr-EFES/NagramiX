# NagramiX 1.0.7

28 ноября 2026 года владелец поручил проверить новые правки и собрать выпуск 1.0.7 для физического iPhone с iOS 15 и новее.

Исходный коммит сборки №240 — `2369f29d184b3292578c466cfe60aba2df9e0104`. Выбраны чистая сборка без кеша Bazel и четыре параллельные группы проверок; обязательные проверки Apple сохранены.

После сборки №240 в `main` добавлена стадия 157: исправлены повторный Play через кнопки iOS и передача звука для YouTube. В IPA №240 этой правки нет; следующая сборка требует отдельной команды.

В выпуск входят стадии 149–156. Исправлены отправка кружков после минутного лимита, переключение и возобновление видео в PiP и галерее, завершение плеера по окончании ролика. Доработан запуск YouTube через официальную страницу в плеере.
