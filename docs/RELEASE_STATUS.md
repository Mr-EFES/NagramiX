# Тестовая сборка NagramiX 0.4.7

Пользователь разрешил новую сборку для физического iPhone и публикацию тестового релиза с краткой русской аннотацией. Первая чистая попытка [№76](https://github.com/Mr-EFES/NagramiX/actions/runs/37763976227), source SHA 6c1e92da8d0c6eb1a61d0ef0a91e50faa95bc83b, остановилась на TelegramCore: SimpleDictionary<PeerId, Peer> нельзя передать как Swift Dictionary. В captureTemporaryBeforeViewing добавлено штатное преобразование reduce, как в соседнем Telegram-коде; остальные пути не изменены. Проверки overlay/синтаксиса/метаданных повторно прошли. Готовится новая чистая попытка; IPA/релиз ещё не созданы. Прежний №75 не используется как новый артефакт.

Включены:
