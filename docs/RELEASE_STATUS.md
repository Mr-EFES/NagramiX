# Сборка NagramiX 0.4.6

2026-10-08 пользователь разрешил новый IPA для физического теста и публикацию тестового релиза. Подготовленные изменения: штатные варианты тем, полные русские подписи, «Опции чатов по тапу», параметры фотографий/стикеров/эмодзи и выключенный по умолчанию компактный список чатов.

Метаданные, Python/Swift syntax, scoped overlay и защитные проверки проходят. Upstream-аудит подтвердил актуальную базу Telegram-iOS 12.9.2, pin `6ad963e5b62d354da79040f388ae2b9132fb17b8`. Нативная компиляция, новый IPA/source SHA/build и публикация ожидаются.

Предыдущий стабильный релиз [0.4.5](https://github.com/Mr-EFES/NagramiX/releases/tag/v0.4.5) сохраняется. Новый выпуск предназначен для проверки на iPhone 17 Pro Max / iOS 27.0 / SideStore; физическая приёмка ещё не выполнена.
