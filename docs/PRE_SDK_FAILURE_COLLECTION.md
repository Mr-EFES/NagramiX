# Полный отчёт ранних проверок перед компиляцией

Владелец попросил сделать сборки результативнее после отказов214/215/216 в тестовой обвязке. Система Bazel, release_arm64, Xcode/SDK, зависимости, подпись и код приложения сохраняются.

В существующем раннем macOS шаге все5независимых команд выполняются даже после ошибки предыдущей. Их статусы накапливаются; обязательный финальный `test` возвращает ошибку при любом сбое и блокирует overlay/компиляцию приложения. Это проверяется реальным shell-тестом с ошибкой в каждой из5позиций: последующие проверки выполняются, маркер компиляции не создаётся. Guard нельзя заменить успехом без отказа build-mode validator.

Внутри полного early preflight48точек вызова API/JavaScript/Swift fixtures сохраняют исходные аргументы и assertions, но собирают независимые ошибки. При отказе одного fixture продолжаются остальные; итоговый JSON содержит `preflight_status=failed` и полный `failed_checks`, а процесс обязательно завершается с ненулевым кодом. Успешные результаты возвращаются без подмены. KeyboardInterrupt не поглощается. Ошибки происхождения/материализации/небезопасной очистки остаются немедленными инфраструктурными отказами: компиляция также не начинается.

При настоящем отказе compile/runtime сохраняются точный сгенерированный `.swift`, имя fixture, debug/optimized режим, exit code и stdout/stderr до удаления временного дерева. Ожидаемые отрицательные варианты ошибками не считаются. Диагностический artifact при failure содержит только явно перечисленные отчёты и каталог сгенерированных тестов; конфигурации Telegram API, профили и весь RUNNER_TEMP не выгружаются.

Проверки не отключаются и не становятся optional. macOS/iPhoneOS API-checks по-прежнему используют реальные SDK/frameworks; Linux не объявляется Apple-компиляцией. Даже полный зелёный preflight не заменяет настоящую сборку всех модулей, проверку IPA и тест на телефоне.

216 завершилась ошибкой по immutable source94bbc7f. Улучшение применяется только к следующему запуску проверенной ревизии, которая его содержит; активные попытки не отменяются ради его установки и дубликаты не создаются.
