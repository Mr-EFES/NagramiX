# Проверка NagramiX 0.8.8 на iPhone

Сборка174 завершиласьошибкойTelegramCore, IPA174не создан. Этот список остаётся планом физической приёмки следующего успешно собранного0.8.8; номер/source/символы обновить после новой разрешённой попытки.

Проверять именно новый IPA0.8.8/build174 из [Actions](https://github.com/Mr-EFES/NagramiX/actions/runs/42174985406), source de0d369c6b0a4349ad04994bafa51af0691353c6. До завершения native/package проверок этот документ не подтверждает готовность пакета. Минимальная iOS15.0, ARM64. Физическая приёмка остаётся device_pending.

- PiP: запустить новым первым нажатием кнопки, вернуться, затем одним свайпом вверх; повторить обратный порядок и пять циклов. Проверить медленный короткий и быстрый свайп, отмену жеста, непрерывный звук/позицию, отсутствие предварительного сдвига, прямоугольного следа и двойного управления. Повторить на альбомном, портретном и квадратном видео, с поворотом и Reduce Motion. OFF и свайп вниз должны сохранять обычное поведение. В записанном видео интерфейс внутри самих кадров не считать интерфейсом текущего приложения.
- Удаление: dust ON должен работать и при первом переводе целого поста/альбома в локальную50%копию, и при повторном удалении этой копии. Проверить Undo, отсутствие пустого места, независимые альбомы и полную очистку архива. OFF сохраняет штатный путь; локальные копии не попадают в закреплённые/отложенные.
- Whisper/Vosk: до загрузки справа виден размер, при загрузке только%, после установки подпись скрыта; галочка только у выбранной установленной модели. Проверить первый запуск, отмену, перезапуск, выбор и распознавание. Названия прежние, без technical ID/footer.
- Редактор: приложить файл к тому же тексту в обычном и расширенном окне, дождаться отправки/загрузки, сравнить содержимое у получателя. Исходные ссылки без карточки не должны раскрываться при копировании/рассылке; исходная существующая карточка сохраняется. Ошибка загрузки не должна отправлять пустую замену.
- Переслать/Рассылка: сравнить одиночную и одновременную отправку двух адресатам текста, подписи, альбома, видео и файла. Найти нового получателя без существующего диалога; строка выбора и новый чат должны появляться без перезапуска. Проверить названия «Репост», «Переслать», «Рассылка», single limit, тему форума и штатную отправку. Free Content ON/OFF сохраняет ограничения, викторина копируется только при известном правильном ответе. Принятие локальной очередью не доказывает доставку сервером.
- Остальные функции: повторное воспроизведение и→A для сохранённых временных голосовых/кружков, обычные контекстные действия и копия с подписью автора после исчезновения оригинала. Язык настроек/debug следует выбранному языку приложения, включая English, Deutsch и RTL.

Для crash-отчёта нужны номер174, исходные действия/запись и точный архив. Символы174 после успешной сборки сохраняются отдельным Actions-артефактом; символы173 не подходят. Передавать отчёт третьим лицам только по разрешению владельца.
