# Реакции в предпросмотре и переход по «Ответить»

Доработка после физического теста NagramiX 0.5.1 №83: **implemented / compile_pending / device_pending**. В опубликованном IPA её нет. Сборка, commit, push и публикация ожидают отдельной команды пользователя; версия не меняется.

## Поведение

- Тап или удерживание аватарки в обоих режимах «Опций чатов по тапу» открывает прежний полноэкранный просмотр без поля ввода и автоматической отметки прочтения.
- Обычная или пользовательская эмодзи-реакция отображается локально. До обычного открытия этой переписки запрос изменения реакции и штатная pending action Telegram не создаются.
- Последний выбор, включая снятие реакции, сохраняется отдельно для аккаунта, полного MessageId и темы. Выход назад и перезапуск приложения его не отменяют. Переключатель удалённых сообщений и очистка его архива на эту очередь не влияют.
- При обычном открытии соответствующего чата очередь передаётся штатному механизму Telegram. Он сохраняет pending action и обрабатывает отправку, ограничения количества, альбомы и повтор при отсутствии сети. При отправке очереди запись снимается после завершения транзакции. Новый явный выбор в обычном чате отменяет старую локальную запись; проверка внутри штатной транзакции не даёт старому callback заменить этот выбор.
- «Ответить» после закрытия контекстного меню открывает новый обычный ChatController с выбранным сообщением для ответа. Прежний readonly-контроллер сохраняет свою неизменяемую политику. Для форума сохраняется полный экран, проверка возраста и права; переходы между темами отправляют очередь только открытой темы.
- Сохранить, скопировать, закрепить, удалить, «Переслать от», «Переслать без» и «Рассылка» сохраняют прежние обработчики и не активируют исходный чат. Их собственные серверные эффекты сохраняются: удаление/закрепление не становятся анонимными операциями.
- Stars доступны в обычном чате. Платная реакция из предпросмотра не ставится в отложенную очередь и не запускает оплату; показывается пояснение.

Отправленные ранее реакции и отметки не скрываются. Статус присутствия определяется прежними настройками Telegram; этот механизм не меняет общую сетевую публикацию онлайн-статуса.

## Реализация

`ios/Sources/TelegramCore/NagramiXDeferredReactionsStore.swift` принадлежит account-owned архивному объекту, но хранит самостоятельный `nagramix-deferred-reactions.json` в каталоге аккаунта. Загрузка и атомарная запись идут на utility queue; доступ к снимкам защищён lock. Изменения дают отдельный history update. В UI создаётся синтетический PendingReactionsMessageAttribute и изменяется версия отображаемого Message; исходный Postbox Message не обновляется. Доступные при выборе метаданные пользовательских эмодзи сохраняются вместе с выбором и добавляются в associatedMedia отображаемой копии.

Отправку вызывают только обычный видимый верхний контроллер, foreground/read gate и стандартный режим чата. Конструктор, readonly-предпросмотр, скрытый экран под другим контроллером, окно пересылки и фон этот gate не открывают. In-flight claims исключают повторный запуск одной записи, проверка revision не удаляет более новый выбор после завершения старой операции. При явном новом выборе в обычном чате старая запись инвалидируется. Необязательный shouldApply в native updateMessageReactionsInteractively проверяет revision внутри Postbox transaction до создания pending action; у остальных вызовов default nil сохраняет прежнее поведение. Startup tombstone не даёт поздней загрузке восстановить отменённый выбор. Недоступное удалённое сообщение снимается из очереди без отправки. Сохранение локальной очереди не является обходом серверных ограничений реакций.

`apply_deferred_preview_reactions` выполняется после подготовленных правок голоса и панели пересылки. Восемь SHA256-проверок интегрированных native файлов выполняются до изменений. Нативные ограничения выбора реакций остаются перед локальной записью. Paid quick/context/direct-screen входы защищены до sendStars/forceSend/purchase.

## Проверено локально

Полный feature overlay применён к 351 Git-SHA-проверенному входу Telegram 13.0 / f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838. Против подготовленной панели пересылки сохранены 400 результатов; изменены 12 и добавлен один Core-файл. Все 23 замены восьми native файлов обратимо восстанавливают baseline; результаты отдельного helper совпали с полным overlay. Проверены 16 случаев SHA drift и повторный запуск: отказ до мутаций.

Все одиннадцать изменённых Swift-файлов разобраны tree-sitter без ошибок. Проверены статические запреты сетевых/pending-action вызовов до flush, сохранение readonly gate, thread/revision/in-flight guards. Python, метаданные, русское приветствие, diff и три теста ресурсов звуков проходят.

Проверки не исполняют Swift, Postbox, UIKit или сеть. Нативная компиляция, фактическое сохранение после перезапуска, взаимодействие с Telegram и поведение iPhone пока **не проверены**. Атомарная запись идёт асинхронно; ошибка диска или аварийное завершение до её окончания не дают гарантии сохранения последнего касания.

## Физическая проверка двумя аккаунтами

| Сценарий | Ожидаемый результат |
| --- | --- |
| Непрочитанный чат → аватарка → реакция → Back, ON/OFF опции чатов | Реакция видна локально; у отправителя нет новой реакции или автоматической отметки прочтения |
| Повторный предпросмотр и перезапуск приложения | Последний выбор восстановлен; отправки нет |
| Поставить, заменить, снять реакцию, несколько разрешённых реакций Premium, custom emoji | Локальный выбор и счётчик корректны; до активного открытия нет отправки |
| Обычное открытие после Back или «Ответить» из меню | Штатное чтение и composer; выбранный ответ сохранён, реакция появляется у отправителя в момент активного открытия |
| Сохранить/скопировать/закрепить/удалить/три вида пересылки | Исходный чат остаётся readonly; отложенные реакции не уходят |
| Обычный чат открыт по результату поиска, переход между темами форума | Отправляется очередь именно открытого чата/темы |
| Другой чат, скрытый контроллер, окно выбора адресатов, фон/блокировка | Очередь исходной переписки не отправляется |
| Без сети → обычное открытие → перезапуск → сеть | Штатная pending action переживает перезапуск и отправляет выбранную реакцию |
| Сообщение удалено до обычного открытия, права реакций изменены, повторный быстрый выбор | Нет отправки на отсутствующий MessageId; ограничения штатные, поздний callback не стирает новый выбор |
| Два аккаунта, темы, настройки архива OFF и очистка архива | Аккаунты/темы изолированы, архив не сбрасывает реакции |
| Stars из quick/context/отдельного экрана | В предпросмотре пояснение без оплаты; обычный платный путь сохранён |

Дополнительно проверить подготовленные отмену первой голосовой записи и панель пересылки, сохранённые черновики, темы, папки и обычные реакции. Результаты записывать после установки нового IPA, а не по опубликованному №83.
