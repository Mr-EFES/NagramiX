# Проверка 0.8.5 на iPhone

Установить именно IPA 0.8.5/build165 из [статуса релиза](RELEASE_STATUS.md). Записать модель iPhone, версию iOS, способ подписи и состояния настроек. Нативная компиляция и проверка пакета не заменяют результаты следующих физических сценариев; до получения результатов статус — device_pending.

| Область | Сценарий и ожидаемый результат |
| --- | --- |
| Запуск и обновление | Холодный запуск, вход и обновление поверх прежней версии. Сохранённые настройки, русский язык, оформление и содержимое переписок доступны. Проверить обычную отправку и получение. |
| Удалённые сообщения | При ON удалять входящие/исходящие сообщения, историю и чат у себя/обоих. Копии с меткой остаются в исходной переписке/теме после повторного открытия. Их нет в закреплённых, отложенных и вспомогательных представлениях, включая уже открытые при удалении. OFF скрывает архив и прекращает захват; ON возвращает сохранённое. Полная очистка локального архива стирает сообщения и вложения. |
| Свободный контент | При свежей установке один чекбокс OFF; сохранённые ON/OFF после обновления не сбрасываются. Проверить доступный контент с заглушкой устройства, скриншоты/запись, сохранение и пересылку разрешённых вложений, смену ON/OFF после открытия меню. Проверить прежние обычные чаты и серверные ограничения. |
| Рассылка и копирование | Повторить видео: закрытый канал → «Рассылка» → «Избранное» и второй чат. Каждый адресат получает полный текст, все вложения в исходном порядке и свои правильные альбомы, без дубликатов и зависших элементов. Сравнить с открытым каналом. Повторить на холодном кеше, при разной скорости загрузки, с ошибкой/отменой, комментарием, темой, тихой и отложенной отправкой. Подтверждение очереди не считать серверной доставкой. |
| Временные голосовые | При ON поддерживаемые одноразовые входящие/исходящие голосовые играют в строке чата с огнём, отсчётом и сгорающей дорожкой, без отдельного окна. Сохранённое сообщение остаётся доступным для повторного воспроизведения и копирования, фактического таймера удаления нет. Двумя аккаунтами проверить прежнюю политику прочтения/прослушивания. OFF и кружки сохраняют штатное открытие. |
| Расширенный редактор | Повторить исходное видео: обычное поле → большой редактор → клавиатура ↔ Aa ↔ эмодзи. Проверить первый переход, быстрые переключения, кнопку возврата внутри эмодзи, язык/подсказки, поворот, Reduce Motion и аппаратную клавиатуру. Панель действий остаётся у верхнего края активной панели без промежуточного провала. Выделение, стили и отправка форматированного документа работают. |
| По автору | В обычном и архивном меню один значок человека с галочкой в круге, утверждённый вариант №5. Проверить светлую/тёмную тему и масштаб текста; действие выбирает сообщения нужного автора, включая вложения и альбомы. |
| Аватарка и предпросмотр | Короткий тап открывает доступную историю, при её отсутствии — обычный чат. Удерживание открывает readonly-предпросмотр; отпускание не вызывает второе открытие. Проверить оба значения «Опций чатов по тапу». «Ответить» открывает активный чат с нужным reply и клавиатурой; один Back возвращает в исходное меню/папку. Двойной ответ и поздний callback после ухода не создают лишних экранов. |
| Системный PiP | Видео по кнопке, первый и повторный свайп вверх, авто-PiP при уходе в фон. Свайп вниз закрывает галерею; сохранённый OFF настройки свайпа соблюдается. Проверить позднюю готовность видео, смену центрального элемента, паузу/перемотку, поворот, stop/restore, блокировку и повторное открытие. Плеер и звук остаются в одном экземпляре. |
| Остальные регрессии | Камера и битрейт кружков, просмотр/сохранение историй, прокси после background/foreground, перевод и расшифровка с выбранными провайдерами, темы/иконки, папки/форумы, уведомления. Ошибка ключа не подменяет провайдера; бесплатная подпись не добавляет APNs. |

При ошибке приложить шаги, запись экрана либо crash-архив через штатное предложение отправки в @NagramiX_bot. Не включать в отчёт ключи API или учётные данные.
