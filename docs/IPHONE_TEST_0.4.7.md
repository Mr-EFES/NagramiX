# Проверка NagramiX 0.4.7 на физическом iPhone

Новый ARM64 IPA 0.4.7 / build 77 собран, проверен и опубликован как тестовый релиз. [Скачать IPA](https://github.com/Mr-EFES/NagramiX/releases/download/v0.4.7/NagramiX-0.4.7-unsigned.ipa); source SHA/checksum и результаты — в [RELEASE_STATUS.md](RELEASE_STATUS.md). Устройство: iPhone 17 Pro Max / iOS 27.0 / SideStore. Все физические сценарии пока ожидаются; успешная компиляция не заменяет их выполнение.

Дополнительно проверить [полные русские названия элементов управления](RUSSIAN_CONTROL_LABELS.md): «Все / Пропущенные» в Звонках, профиль/меню/настройки/камера/редактор, обычный и увеличенный размер текста, обновление русского пакета, смену языка и перезапуск. Все сценарии пока ожидают физической проверки.

Правка [опций чатов по тапу](../product/features/chat-actions-on-hold.md) включена в исходники 0.4.7. В новом IPA проверить: default ON; удерживание аватарки открывает штатный предпросмотр без отметки прочтения, удерживание заголовка/предпросмотра/даты/свободной области — только штатное меню действий; короткое нажатие открывает чат. Свайпы в обе стороны поверх любой области, включая аватарку с кольцом истории, переключают 2+ папки без боковых действий. Проверить OFF со штатными свайпами/удерживанием, OFF → раскрытая строка → ON, кэшированные папки и перезапуск с сохранённым OFF. Действия меню: прочитано/не прочитано, закрепить/открепить, звук, архивирование, удаление с подтверждением/отменой, управление папками при их наличии. Повторить с компактным режимом ON/OFF, в архиве/форумах, при редактировании и с VoiceOver. Физическая проверка ожидается после успешной сборки.

Проверить [фотографии, стикеры и эмодзи](../product/features/media-controls.md): начальные значения, сохранение 0/OFF, качество JPEG 0/50/100, стороны 1280/2560, штатные размеры фотоисторий, стикеры/крупные эмодзи 0/50/100 и показ времени со статусами доставки, поиск, темы и VoiceOver. Физические результаты ожидаются.

Проверить [компактный список чатов](../product/features/compact-chat-list.md): default OFF, сохранение ON/OFF, обновление без перезапуска, кэшированные папки, большой текст/темы, автор/черновик/теги/форумы, аватары и бейджи, предпросмотр/меню и независимость от режима свайпов. Физические результаты ожидаются.

В новом IPA проверить расширенный [архив файлов](../product/features/deleted-messages.md) и [«Временные сообщения»](../product/features/temporary-messages.md), которых нет в №75. Новый пункт сразу после «Удалённых сообщений», default OFF и сохранение выбора. Основной ON: входящие текст/фото/видео/документ/музыка/голосовое/кружок/альбом → дождаться получения файла → удалить с другого клиента → очистить stock cache → включить авиарежим → открыть/проиграть копию, затем повторить после старта. Четыре сочетания parent/child, одноразовые фото/видео/голосовые/кружки и истечение таймера; загрузка не должна сама отмечать просмотр. OFF после сохранения не очищает файлы. Очистить архив при открытом меню/player и активной загрузке, убедиться, что файл не вернулся поздним callback. Проверить shared-resource у двух копий, старый JSON при обновлении, сеть/фон/нехватку места, поиск/темы/крупный текст. Все эти сценарии пока не выполнены на устройстве.

Сначала установить новый IPA поверх прежнего приложения через используемый способ внешней подписи. Сохранить одинаковый bundle ID и подпись при обновлении; иначе iOS может создать отдельное приложение. Перед удалением приложения учитывать, что локальный архив удалённых сообщений и предпочтения не восстанавливаются из Telegram. Чистую установку тестировать отдельно, сохранив нужные данные.

## Обязательная повторная проверка следующих исходников

В сборке 0.4.7 проверить чистую установку при английском языке iOS: все страницы приветствия, номер телефона, код, пароль, список чатов и настройки должны быть русскими. Дождаться фонового обновления языкового пакета, перезапустить приложение — русский остаётся. Кнопка «Изменить» полностью русская до/после обновления пакета. Затем вручную выбрать английский, перезапустить и добавить второй аккаунт — ручной выбор сохраняется.

Оформление → темы чатов: stock-палитры, видимые заголовки/подписи/кнопки/ссылки без обрезания; проверить все встроенные темы и размеры шрифта. Категории/поиск настроек NagramiX сохраняют согласованные края. Проверять исходный SHA и номер нового IPA по provenance.

Предпросмотр истории: фото и видео с пустым/прогретым кэшем; первая и следующая история — узнаваемое изображение с одинаковым лёгким blur по первому референсу. Проверить медленную сеть/отсутствие обложки: нет увеличенной мутной миниатюры, можно отменить. До «Просмотреть» seen-state не отправляется; крестик/возврат не отмечают просмотр, подтверждение открывает выбранную историю. При повторной навигации соответствие владельца/истории и кнопки сохраняется. Визуально сравнить на iPhone, а не считать syntax-проверку подтверждением совпадения референсу.

Вкладка «Прочее»: после поиска заголовок «ЗВОНКИ», затем округлый блок Force TCP с переключателем и прежней подписью. Отступы/шрифт заголовка совпадают с «ПАНЕЛЬ ВКЛАДОК» и «КРУГЛЫЕ ВИДЕО». Включение/выключение сохраняется после повторного открытия. Поиск «звонки»/«Force TCP» показывает прежнюю настройку без дублирования заголовков; подтверждение исходящих звонков в «Функции» сохраняет заголовок.

Новая установка без сохранённых предпочтений: проверить все default-переключатели по product/SETTINGS.md. Включены все названные пользователем позиции кроме удалённых сообщений/истории правок/Force TCP; эти три выключены. Поменять несколько ON→OFF и OFF→ON, перезапустить и обновить поверх — ручные значения сохраняются. Ранее установленные пользовательские настройки не должны принудительно переключаться.

## Приёмка текущих исходников после пяти скриншотов

Для этих сценариев использовать опубликованный IPA 0.4.7 / build 77, source bcfdff03c15265462e18b0899673ea460192d3ba из его provenance; сценарии физической проверки пока не выполнены.

1. Выключить ночную автоматику, включить Light и House: зафиксировать три действия профиля, иконки и отправку.
2. Выбрать Chick, затем Snowman/Diamond и другие облачные темы: повторить те же действия, поиск, меню и выбранную вкладку нижней панели. Не должно быть прозрачных акцентных элементов.
3. Пройти House → Chick → House, Light → Dark → Light и Night без закрытия приложения; текст/иконки обновляются штатно.
4. Сохранённая Chick после перезапуска должна отображать действия без повторного выбора темы; пользовательская файловая тема и ARGB с ненулевой alpha сохраняют свои цвета.
5. Проверить нормальный/увеличенный текст; шрифты и типографика остались Telegram.
6. Отдельный clean install: русский до/после входа; «Системная» отмечена, ночная «Тёмная» выбрана; iOS Light/Dark меняет активную тему штатно. Затем ручные Off/Schedule/Auto/Light/Night и restart сохраняют выбор.

Результаты пока не получены. Статический успех не подтверждает визуальное исправление на iOS 27.
