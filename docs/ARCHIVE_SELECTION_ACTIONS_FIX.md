# Действия с архивным выделением и один пункт «Избранное»

Статус: `source_checked / native_build_pending / device_pending`. Правка подготовлена после физических референсов опубликованной версии; новый IPA не собран. Прежние исправления авторизации, удаления, DNS, записи и новых функций сохранены.

## Причины и изменения

В picker рассылки выбранный peer попадал в `foundPeers`; при выборе себя там появлялось «Избранное», которое одновременно уже выводилось отдельной закреплённой строкой. Теперь self исключается из `foundPeers` только при наличии этой отдельной строки. Папки, поиск, native pinned row и остальные peer identity остаются прежними. Перед payment/scheduling/enqueue список получателей дополнительно уникализируется по peer ID с сохранением порядка. Это защищает отправку от повторного адресата, даже если callback передаст его дважды.

Архивное вложение отображалось из snapshot, но панель и часть обработчиков сначала брали сообщение из Postbox. Истёкшая запись с `TelegramMediaExpiredContent` перекрывала полную локальную копию, а внешний экспорт вообще пропускал отсутствующие в базе сообщения. Единый `NagramiXMessageArchive.interactionMessage` сохраняет настоящую неистёкшую запись; для отсутствующей/истёкшей подставляет маркированный архивный snapshot того же ID. Если snapshot отсутствует, вложение не создаётся и действие не отправляет доступную часть набора молча.

Панель отдельно получает native права настоящих записей и возможности переноса полных отображаемых сообщений. Только `.forward`/`.externalShare` берутся из расчёта по snapshots; delete/report/ban/tags остаются native, copy protection учитывается в обоих расчётах. Дополнительные кнопки используют прежний валидатор копирования. Защищённые сообщения, SecretChat и недоступные байты не становятся безусловно разрешёнными.

Доступность наблюдает изменения Postbox и архива. Поколение запроса и выбранные ID проверяются перед применением результата и передачей сообщения; при новом выделении прежние запросы отменяются. Нажатие дополнительных кнопок получает свежий одноразовый snapshot, чтобы обновление архива не открывало picker повторно. Экспорт получает полный упорядоченный набор raw messages и проверяет актуальность выделения. Native ShareController/Photos/upload и проверки подготовки локальных байтов сохранены.

Архивная обычная пересылка переходит в копирование одному адресату, поскольку удалённый серверный source ID использовать нельзя. Только явно выбранная «Рассылка» оставляет несколько адресатов. «Переслать без» по-прежнему открывает draft одного получателя; quiet/schedule/topics/payment остаются штатными. Атрибуция исходного автора для локальной копии не подделывается.

## Проверки

`apply_archived_selection_actions_fix` выполняется последним: шесть full-SHA входов, 15 точных замен и проверка отсутствия нового XCTest до записи native файлов. Отдельный `.swift.inc` меняет только метод доступности; прежние промежуточные SHA предыдущих этапов сохранены.

Полный overlay применён к чистому fixture закреплённой базы. Относительно предыдущего этапа из 462 файлов 455 совпали побайтно, изменены семь (шесть native и Core archive), добавлен один XCTest: итог 463. `scripts/validate_archive_selection_actions.py` проверяет точные обратные замены, scope, шесть сценариев дрейфа, коллизию теста и повторное применение без частичной записи, resolver и границы действий. Восемь изменённых/новых Swift файлов прошли grammar parsing без ошибок. Python compile, метаданные и diff check проходят.

Добавлены семь native XCTest: expired voice/round, отсутствующий текст, приоритет настоящего live сообщения, copy protection, отсутствующая/немаркированная копия, чужой ID, смешанный набор. Они **не выполнялись**: в текущей среде нет Xcode/Apple SDK. Grammar и проверки overlay не доказывают доставку или сохранение на iPhone.

## Приёмка следующей сборки

1. Рассылка → «Избранное»: одна строка до/после выбора, поиска и смены папки; один экземпляр каждого выбранного сообщения у получателя. Повторить с собой и другим адресатом, cancel/quiet/schedule.
2. Обычный чат и просмотр через аватарку: сохранённое удалённое voice/round/video — выбрать один, два и три; смешать с живым текстом/voice/video. Доступны применимые действия; экспорт сохраняет все выбранные файлы в порядке, пересылка копирует все и только выбранные сообщения.
3. «Переслать без» открывает одного адресата и ждёт Send; «Рассылка» позволяет нескольких. Проверить доставку вторым клиентом, отсутствие зависших отправок и дублей.
4. При активном выделении дождаться удаления/истечения сообщения; доступность обновляется на сохранённую копию. Быстро сменить A→B→A/отменить/закрыть чат: прежний callback не открывает picker и не меняет другой набор.
5. Защищённый чат, SecretChat, отсутствующий локальный файл, выключенный показ архива: прежние ограничения и честная ошибка, без пустых файлов и частичной отправки. Delete подтверждение/undo/права прежние; preview не активирует read/composer/reactions.
