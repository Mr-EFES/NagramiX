# Исправление конструктора настроек после SDK192

Сборка192 на source`0163da0b35d5bdb8f1dac4414b9d6b1901a79feb` остановилась в SettingsUI. Первая ошибка: `argument 'updateBackgroundVideoPlayback' must precede argument 'updateRoundVideo'`. В объявлении `NagramiXSettingsControllerArguments` фоновые видео предшествуют круглому видео, а в memberwise-вызове два обработчика были переставлены. Остальные семь диагностик в этом файле относятся к последующему выводу типов контроллера; повторный SDK должен подтвердить их отсутствие после первичного исправления.

Стадия27 `release_092_settings_compile` после `content_interaction_consent` меняет только порядок двух целых строк аргументов. Тела обработчиков, значения и ключи настроек, UI, отправка, плеер и история не менялись. Предыдущие snapshots сохранены, новый файл приложения не добавлен.

Пробел предыдущих проверок закрыт отдельной ранней компиляцией: `validate_settings_argument_bindings.py` берёт настоящее полное объявление структуры и все73 метки из production-вызова. В debug и оптимизированном режиме компилятор связывает аргументы; настоящие тела обработчиков круглого/фонового видео проверяют независимые значения через адаптер хранилища. Старый порядок обязан воспроизвести точную ошибку SDK. Типы двух внешних номинальных параметров и тела остальных обработчиков являются явными границами теста; весь UIKit-граф проверяется полноценным SDK.

Проверка final canonical snapshot добавлена до применения overlay и долгой компиляции; повторная проверка реального исходника идёт сразу после стадии27. Оба вызова обязательны при `extended_patch_tests=false`. Остальные189 исторических тестов остаются необязательными по распоряжению владельца. Итоговые SHA, Postbox, source/member/localization gates и настоящий SDK/IPA не отключены.

[Результат](RELEASE_092_SETTINGS_COMPILE_CHECKS.json). Source27 `/tmp/nagramix-release-092-settings/source`, source26 сохранён.
