# Плотность снега: выравнивание и прозрачный бегунок

Утверждены два эскиза: общие боковые границы с переключателями «Снегопад»/«Показывать в чатах», затем прозрачный стеклянный бегунок. Изменение ограничено строкой плотности группы «АТМОСФЕРА». Снимки и эскизы находятся вне Git. Итоговые проверки — [SNOW_DENSITY_GLASS_CHECKS.json](SNOW_DENSITY_GLASS_CHECKS.json).

Старая строка отступала на24pt с обеих сторон, соседний штатный переключатель — на16pt слева и15pt справа. Теперь заголовок, значение, крайние подписи и видимая шкала используют те же границы. Сохранены динамическое измерение длинного заголовка и перенос значения на отдельную строку при недостатке ширины. Шрифт не уменьшается и не обрезается специально ради выравнивания.

Круглый бегунок28pt содержит настоящий `UIGlassEffect(style: .clear)` на iOS26+ (включая27), тонкую кромку, мягкий блик и тень. На более ранних системах используется прозрачная поверхность с бликом/кромкой. Внутри нет непрозрачного белого изображения или непрозрачного размытия. Штатный `knobView` остаётся владельцем позиции; стекло — его дочерний вид без касаний/Accessibility. Оно движется вместе с исходным thumb, не вычисляя вторую позицию. Круглая маска блика исключает квадратные углы. Темы обновляют оформление; эффект и прозрачное изображение не создаются на каждом кадре.

Положение thumb и обработку панорамирования/нажатий по-прежнему обслуживает исходный `TGPhotoEditorSliderView`. Его реализация при положительном minimum считает позицию через `abs(minimum)+value`, что неверно для10–100. Только данный элемент использует локальный диапазон0–90, отображая/передавая10–100. Core-нормализатор, шаг5%, ключ, сохранённые настройки и праздничное правило75% не меняются. При активном перетаскивании обновление layout не сбрасывает значение; фиксация идёт через прежний callback. VoiceOver сохраняет шаг5 и крайние ограничения.

Собственная шкала занимает общие границы строки. Компенсация7pt учитывает нативный отступ центра thumb и его радиус14pt: ни один край бегунка не выходит за общие границы в крайних положениях. Доступная высота касания44pt сохранена, видимые концы шкалы также принимают касания. На100% активна вся шкала. Изменение не затрагивает другие ползунки и системные переключатели.

Стадия81 `snow_density_glass` после80 меняет один существующий `NagramiXSnowDensityItem.swift`, с12guards и14новыми `.inc`. Новых app-файлов, пользовательских строк/ключей, ресурсов, зависимостей, изменений SDK/подписи нет. Прежние4782`.inc` и293плана сохраняются. Все prechecks выполняются до записи.

```sh
python3 scripts/validate_snow_density_glass.py \
  --source <native> --swiftc <swiftc> --report <json>
```

Локальная программа исполняет полный реальный node, геометрию, glass/control-классы и Core-нормализатор. UIKit/Legacy dispatch, ListView, модель темы и измерение текста — явные адаптеры. Геометрическое выражение Legacy берётся из настоящего `.m`. Проверяются разные ширины/safe area/размеры шрифта, длинные названия, оба края шкалы, все19значений, промежуточные значения, непрозрачность, hit area, VoiceOver, удержание/обновление/фиксация и обе ветки glass/fallback. Смысловые мутации обязаны воспроизводить ошибку.

В начале будущего macOS preflight, до большого runtime-набора, весь реальный node и glass/control-классы typecheck с настоящими UIKit/QuartzCore/CoreGraphics/UIGlassEffect и исходным Objective-C header Legacy при deployment target iOS15. List/theme/Display остаются явными границами; это не полная компиляция приложения. На Linux этот Apple gate отмечается `not_run`. Ни исходные проверки, ни один SDK typecheck не подтверждают реальную оптику стекла, касания и плавность на iPhone.

Приёмка новой IPA: тёмная/светлая темы, размеры текста/длинные переводы,10/75/100%, касание/перетаскивание/отпускание/возврат, VoiceOver, повторное открытие и праздничные75%. Проверить видимость шкалы сквозь бегунок, отсутствие белого диска/обрезки и сброса во время удержания. Ранее опубликованные IPA и релизы сохраняются; новая сборка — по прямой команде владельца.
