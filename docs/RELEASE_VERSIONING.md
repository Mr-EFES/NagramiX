# Правило нумерации выпусков

Стартовую версию **1.0** владелец закрепил 17 ноября 2026 года. Текущий опубликованный выпуск указан в [статусе релиза](RELEASE_STATUS.md). Исправления в main не повышают номер автоматически. Новая SDK-сборка, выпуск или отправка в App Store требуют отдельной команды.

После явного решения о следующем выпуске применяется согласованная схема:1.0 →1.0.1–1.0.9 →1.1 →1.1.1–1.1.9 →1.2 и далее. Номер сборки берётся из run_number и отличается от версии приложения.

Версию берут из строкового поля `release` в `product/features/registry.json`. Ей должны соответствовать строка `NAGRAMIX_VERSION` в workflow, имя файла аннотации в `product/releases/`, заголовки текущих документов и подписи последнего коммита в корне `main`. Валидаторы проверяют именно строку и реальную среду CI; числовой YAML-литерал недопустим.

Релизный тег указывает на фактически собранный исходный commit, документационные коммиты после публикации его не передвигают. README/LICENSE сохраняются; аннотация и GitHub body содержат только утверждённую фразу README. Старые выпуски удаляются исключительно по отдельному прямому поручению владельца; очистка до1.0 не применяется к будущим версиям автоматически.
