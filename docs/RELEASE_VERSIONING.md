# Правило нумерации выпусков

Текущая и стартовая для дальнейшей доработки версия — **1.0**. Владелец закрепил её17ноября2026 перед подготовкой к App Store. Исправления в main не повышают номер автоматически. Новая SDK-сборка, выпуск или отправка в App Store требуют отдельной команды.

После явного решения о следующем выпуске применяется согласованная схема:1.0 →1.0.1–1.0.9 →1.1 →1.1.1–1.1.9 →1.2 и далее. Номер сборки берётся из run_number и отличается от версии приложения.

Источники версии должны совпадать: `product/features/registry.json` (строковое release), quoted `NAGRAMIX_VERSION: "1.0"` в workflow, текущая аннотация `product/releases/1.0.md`, заголовки текущих документов. Валидаторы проверяют именно строку и реальную среду CI; числовой YAML-литерал недопустим.

Релизный тег указывает на фактически собранный исходный commit, документационные коммиты после публикации его не передвигают. README/LICENSE сохраняются; аннотация и GitHub body содержат только утверждённую фразу README. Старые выпуски удаляются исключительно по отдельному прямому поручению владельца; очистка до1.0 не применяется к будущим версиям автоматически.
