# Ошибки записи архива и безопасное восстановление

20 октября исправлен пункт4 [проверки стабильности](STABILITY_REVIEW_2026-10-20.md). Работа в `main`, без SDK, Actions и IPA. Статус: **source_checked / native_compile_pending / device_pending**.

Раньше `persist` скрывал ошибки кодирования и атомарной записи через `try?`, а память уже содержала новое состояние. После перезапуска оно могло исчезнуть. Удаление локальных копий также начинало очищать медиа до подтверждения записи метаданных.

Теперь [NagramiXArchivePersistence](../ios/Sources/TelegramCore/NagramiXArchivePersistence.swift) координирует запись на прежней utility-очереди архива. Только успешная атомарная запись JSON обновляет видимое состояние. Ошибка оставляет прежние подтверждённые записи и единственный последний dirty snapshot. Последующие поступления, правки и удаления объединяются с ним; входящий поток не создаёт отдельный таймер или повторную запись для каждого сообщения при постоянном отказе.

После первой ошибки предусмотрены не более трёх автоматических повторов через1/5/30секунд. Исчерпанный burst ждёт явного повтора, нового пользовательского действия или возвращения приложения на передний план. Старая попытка отменяется по generation, deinit отменяет таймер; сильного цикла с владельцем нет. На iOS выполнение отложенных таймеров зависит от приостановки процесса.

Сигнал состояния различает готовность, повтор и ошибку. ENOSPC распознаётся в Cocoa/POSIX и вложенной ошибке; остальные ошибки записи сообщаются отдельно. AccountContext показывает локализованный RU/EN диалог с кнопкой повтора только на переднем плане, без повторного окна на каждом автоматическом отказе. Ручной повтор может снова сообщить об отказе. Temp-контексты не создают уведомления, подписка освобождается с контекстом. UIKit-представление ещё требует Apple SDK и iPhone.

Очистка медиа выполняется только после успешной записи индекса. Неудачное удаление сохраняет старые записи и файлы. Отложенное удаление не затрагивает ключ, полученный заново, и новые вложения после запроса полной очистки. Полная очистка пишет совместимый пустой JSON до очистки файлов; старые записи не должны вернуться после перезапуска. Нечитаемый существующий JSON не подменяется пустым автоматически: доступен повтор открытия, а заменить его разрешает только явно запрошенная пользователем полная очистка. Формат архива, ключи настроек, defaults, правила редакций, rendering, playback/export и самостоятельный media store не менялись.

**Граница гарантии:** до успешной записи pending-изменения остаются в памяти и могут потеряться при закрытии процесса. Об этом прямо говорит диалог. Нехватку места нельзя исправить гарантией сохранения без освобождения места; приложение сохраняет прежний подтверждённый архив и не выдаёт новый за сохранённый. Ошибки последующего физического удаления лишних медиа остаются прежним отдельным механизмом media store.

## Проверки

[Validator](../scripts/validate_archive_persistence.py) выполняет настоящий coordinator, модели и извлечённые production методы capture/expiration/delete/clear/edit/load/commit. Границы Postbox/очереди/таймера/медиа — doubles; Foundation JSON и атомарные файловые операции настоящие. Реальный отказ создаётся подменой родительского каталога файлом, затем доступ восстанавливается. ENOSPC инъецируется как ошибка writer без заполнения диска.

- 218coordinator checks и30archive/IO checks проходят в debug/optimized с warnings-as-errors. Проверены bounded retries, coalescing burst, latest snapshot, stale timer/deinit, независимый coordinator; byte-identical прежний JSON при отказе, merge capture+deletion, реальный reload, partial/peer/full clear, recapture того же ключа и новые файлы после failed clear, temporary expiration, local edit/revision, unreadable file и явный reset.
- Прежнее тело `persist` в обоих режимах воспроизводит обычный возврат без файла и результата ошибки. Новый путь публикует ошибку, не изменяет committed state и успешно восстанавливается после исправления пути.

Late overlay после thread scope:2SHA/3точных операции/1copy/4provided,14fail-closed cases без partial writes. Ранние guards и зависимости прежние.
- Swift grammar, Python/JSON, RU/EN keys, release metadata и `git diff --check` проверены. Proof `/workspace/.codex-validation-nagramix-archive-persistence-fix/verification.json`. Новый Apple SDK typecheck, файловая защита/полный диск на настоящем iPhone и UI приёмка не выполнялись.
