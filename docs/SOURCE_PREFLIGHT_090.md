# Проверка main перед сборкой 0.9.0

**Последующий SDK186 выявил ошибку, не пойманную этим source-аудитом.** Отчёт ниже описывает исходный проверенный snapshot0855022. Настоящая macOS проверка исходников прошла, но SDK не увидел настройки/ID в author handler. Причина, новая отдельная проверка границ модулей и исправление stage12: [RELEASE_090_SDK186_FIX](RELEASE_090_SDK186_FIX.md). Сборка и повторы текущей0.9.0 уже разрешены новой командой владельца; первоначальные ограничения ниже исторические.

Проверка выполнена по отдельной команде владельца без запуска приложения, Apple SDK, Bazel/Make, Actions, упаковки IPA и публикации. Исходный main — `302b928e0fcbcf8ccb41654cab4ce6e26e9054a8`. Найденные и проверенные исправления уже сохранены владельческим коммитом `f3daf43e75847c1771bbca81b700b1877c8125e0`.

**Результат: исходники готовы к отдельно разрешённой сборке 0.9.0.** Это не статус успешной компиляции с Apple SDK или физической приёмки: они остаются pending до команды владельца. Повторные запуски сборки, Actions и IPA этим отчётом не разрешаются.

## Что исправлено

В многоисточниковой пересылке устранили потерю повторного сообщения источника, выпадение комментария/локального вложения и возможную перестановку пакетов из-за асинхронной подготовки медиа. Теперь следующий пакет создаётся после результата предыдущего локального enqueue. Обычный архив сохраняет поддерживаемые карточки и безопасные атрибуты целиком, отклоняя недекодируемый новый снимок атомарно. Подробности, исходные ошибки и тесты: [RELEASE_090_PREFLIGHT_FIXES](RELEASE_090_PREFLIGHT_FIXES.md).

Также четыре временные полные копии исходников освобождаются только после соответствующих успешных validators. Активные исходники и отчёты сохраняются; неподтверждённая нехватка диска runner не объявляется найденной ошибкой.

## Компилятор и CI

Проверена официальная база: Telegram 13.2, commit `24638bc69bd083981b178dd1e7f921eebbf7fc46`, CURRENT на момент аудита; минимальная iOS — 15.0. Версия приложения остаётся 0.9.0.

По точному закреплённому `rules_swift` подтверждён безусловный `-enable-bare-slash-regex`. С ним native Lexer проходит parse. Официальная таблица Apple указывает для Xcode 27.1 компилятор Swift 6.4; `nonisolated(nonsending)` поддерживается с 6.2 независимо от выбранного режима Swift 5. Поэтому найденные отличия локального parser объяснены настройкой/версией инструмента; Wallet не выдаётся за локально скомпилированный файл.

Прочитаны только metadata последней успешной сборки 185: 3:04:21 всего, 1:20:36 до SDK, 1:43:08 native compile. Текущий timeout — 300 минут. Добавленные проверки оставляют расчётный запас около 95–100 минут при прежнем времени SDK; это оценка по фактическому прошлому запуску, не обещание времени следующей сборки. Dispatch/rerun не выполнялись.
