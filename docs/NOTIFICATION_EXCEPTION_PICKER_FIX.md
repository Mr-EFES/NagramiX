# Выбор чата для исключения уведомлений

После физического теста0.5.8/build94 пользователь показал пустой модальный экран «Добавить исключение» в настройках уведомлений групп и каналов. Это этап выбора чата, отдельный от уже исправленного каталога звуков персонального исключения.

## Найденный сценарий

NotificationsPeerCategoryController передаёт `.onlyGroups` или `.onlyChannels` обычному PeerSelectionController. В этом пути ChatListNode сначала получает последние200 чатов без предиката категории, затем отбрасывает неподходящие строки. Если нужные группы/каналы расположены глубже, остаётся только HeaderEntry. В новой верхней странице hasLater=false, firstIndex=0, а переход к более старой странице требует firstIndex>=5 — дальнейшая загрузка не запускается. Архив отдельно не включён в эту выборку. Поиск связан с прогрессом прокрутки и может остаться свёрнутым у списка без строк.

Этот сценарий подтверждён по точной базе Telegram13.0 и моделью с500 личными чатами перед группами/каналами. Он соответствует показанному пустому экрану; исполнение UIKit на конкретном iPhone ещё не проверено.

## Исправление

`apply_notification_exception_peer_picker` в `ios/apply_features.py` применяется последним. Полные SHA256 четырёх входов и7якорей проверяются в памяти до записи любого файла. Новых модулей и зависимостей нет.

- В ChatListNodePeersFilter добавлен свободный transient bit18 `nagramiXNotificationExceptions`. Его выставляет только штатный «Добавить исключение» из NotificationsPeerCategoryController. Это параметр селектора, не настройка пользователя и не сохраняемый ключ.
- В помеченном плоском picker без forumPeerId создаётся временный ChatListFilter с native ChatListFilterData: `.groups`, `.channels` либо `.contacts/.nonContacts/.bots` для личных чатов/историй. Предикат передаётся ChatListNode до tail/around pagination. Прочитанные, muted и архивные чаты разрешены. Фильтр не записывается в папки аккаунта.
- Нативные ограничения `.onlyPrivateChats/.excludeSavedMessages/.excludeSecretChats/.onlyGroups/.onlyChannels` остаются дополнительной проверкой. Возможность отправлять сообщения или включённость общих уведомлений не добавлены в условия выбора: канал только для чтения и чаты при глобальном OFF доступны для исключения.
- Только помеченный controller держит штатный поисковый header раскрытым и не сворачивает его при scroll snapping. При действительно пустой категории остаются поиск и отмена. Поиск, его category flags, выбор ровно одного peer и переход в существующий редактор прежние.

Остальные pickers получают nil вместо временного ChatListFilter и используют прежнее поведение поиска. Форумный выбор тем, пересылка/рассылка, contact selector, плееры, archive storage, read/consume и отправка не менялись. Существующие callbacks добавления, сохранения, отмены и удаления исключений сохранены. Каталог31 звука и соответствие default preview из build94 побайтно прежние; APNs-доставка этой правкой не диагностируется и не изменяется.

## Проверки и приёмка

Статус: **source_checked / compile_pending / device_pending**. В опубликованном0.5.8/build94 этой правки нет. Новая сборка, commit/push и публикация в рамках исправления не запускались; metadata пока0.5.8, следующий рабочий выпуск0.5.9 — по отдельной команде.

Полный overlay585файлов:4изменённых,581побайтно прежний. `scripts/validate_notification_exception_picker.py`:7точных обратных замен; clean/rerun/дрейф каждого из4входов без частичной записи; модель пустой исходной страницы и12category/page сценариев с archive/mute/read; scoped flag, native DB predicate, callback/search contracts. Это модель выборки, не выполнение Postbox/Swift/UIKit. Грамматика4Swift файлов проверена; API ChatListFilterData/ChatFolderTitle сверены с Git blob `44a0d386d95bb14de9d4bf11605ec10830f18d11` точного upstream pin. Полное обратное удаление helper/call восстанавливает исходный patcher.

После новой отдельно запрошенной сборки проверить: Группы и Каналы → «Добавить исключение» при общих ON/OFF, старые и архивные чаты, большой список и прокрутку, readonly каналы, поиск по названию/username, действительно пустую категорию, отмену и повторное открытие. Выбор должен открыть прежние настройки чата; подтвердить/отменить звук, mute и preview, проверить список исключений и сохранение после холодного запуска. Регрессии: Личные чаты/Истории, темы форума, глобальный каталог31мелодии и три режима пересылки. Физическое выполнение пока не объявлять подтверждённым.
