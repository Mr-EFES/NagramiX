# Полные русские подписи NagramiX 0.4.6

По запросу пользователя от 2026-10-07 русские названия действий и элементов управления должны быть полными. «Звонки → Все / Пропущенные» — обязательный сценарий проверки. Сборка разрешена командой пользователя от 2026-10-08; изменения включаются в тестовый выпуск.

## Изменения

В `ios/Resources/ru-full-control-labels.json` перечислены 46 ключей: звонки, изменение фотографии/видео, разблокировка, звук/микрофон, уведомления, мобильная сеть, энергосбережение, автосохранение, камера, настройки сообщений канала, автоматизация, насыщенность редактора и связанные подписи состояний. Например, «Пропущ.» → «Пропущенные», «Изм.» → «Изменить», «Разблок.» → «Разблокировать», «Вкл. звук» → «Включить звук», «Моб. сеть» → «Мобильная сеть».

В полном встроенном русском ресурсе заменены 45 уникальных ключей; Common.Edit уже был полным. Все вхождения повторяющихся ключей исправлены одинаково. Состав ключей, параметры форматирования и остальные строки сохранены. Русские ресурсы NagramiX также просмотрены: сокращений названий действий этого вида не обнаружено. Календарные обозначения, единицы измерения, технические имена/аббревиатуры и пользовательские сообщения не переписываются.

`ios/apply_features.py` проверяет совпадение реестра с ресурсом и формирует общий словарь Swift. В DefaultPresentationStrings он используется для первоначального русского интерфейса. В dictFromLocalization — после обработки полученного языкового пакета и только для русского компонента. Поэтому сетевое обновление перевода не возвращает сокращённые названия; выбранные другие языки используют прежний механизм. Ключи и хранилище предпочтений не меняются.

Для «Сохранять отредактированные фотографии» в DataAndStorageSettingsController включён native maximumNumberOfLines: 0: стандартная ItemListSwitchItem рассчитывает высоту по полному тексту. Шрифты, цвета и сам переключатель не менялись. Проверен путь Calls_Missed → ItemListControllerSegmentedTitleView → HorizontalTabsComponent: штатные вкладки измеряют текст и используют прокрутку при нехватке ширины; собственный компонент не добавлен. Остальные изменения ограничены переводом, функции и ранее подготовленная правка тем сохранены.

## Проверки

Новый overlay применён к чистому набору исходников закреплённого Telegram-iOS 12.9.2. Сравнение с состоянием после предыдущей правки тем: изменены ровно четыре файла — русский ресурс, DefaultPresentationStrings, PresentationData и DataAndStorageSettingsController. Остальные 223 файла проверочного дерева побайтно совпадают. Это ограниченный проверочный набор, не полный checkout.

Разбор tree-sitter трёх Swift-файлов, синтаксис Python и защита штатных файлов проходят. Проверены все 46 значений, отсутствие иных изменений строк, соответствие сформированного словаря, применение после серверных записей и ограничение русским компонентом. Разбор серверных строк/множественных форм не изменился. Проверены 13 русских строк приветствия, метаданные и diff. Чистая нативная сборка №75 в macOS GitHub Actions прошла. IPA 0.4.6 опубликован и проверен: все 46 ключей совпадают. Локально Xcode отсутствует; визуальная проверка на устройстве ожидается.

## Будущая приёмка на iPhone

После отдельной команды на сборку проверить обычный и увеличенный размер текста, портрет/альбомную ориентацию:

- «Звонки»: полностью видны «Все», «Пропущенные» и «Изменить», переключение/выбор/отмена работают;
- настройки, профиль, заблокированные контакты, уведомления, меню чатов, голосовой чат/трансляция, камера и редактор: полные подписи без наложения/обрезания;
- «Сохранять отредактированные фотографии»: перенос текста, правильная высота строки и рабочий переключатель;
- чистый запуск, вход, обновление русского пакета и перезапуск: сокращения не возвращаются;
- ручной выбор другого языка и возврат на русский: язык сохраняется, полные русские подписи восстанавливаются;
- Light/Dark/Night: текст остаётся читаемым. Физические результаты пока ожидаются.
