# Компактная страница настройки кружков

Утверждён вариант с горизонтальными стеклянными переключателями. Порядок разделов: КАЧЕСТВО → ЧАСТОТА КАДРОВ → БИТРЕЙТ → КОДЕК → КИНОЭФФЕКТ. Для каждого раздела используется одна строка таблицы; выбранная кнопка имеет стеклянную подложку и галочку.

- Качество: Стандарт / 480×480, Высокое / 512×512, Максимум / 640×640.
- Частота: 30 кадров/с или 60 кадров/с.
- Битрейт: прежний стеклянный ползунок «Стандарт / Средний / Высокий / Максимум», без чисел. Внутренние значения 1000/1100/1200/1300 кбит/с, правила сохранения и VoiceOver прежние.
- Кодек: H.264 (AVC) / «Стандартное сжатие» и H.265 (HEVC) / «Эффективное сжатие».
- Киноэффект: «Да / Нет», когда доступен. По умолчанию «Нет».

Киноэффект сохраняет прежние проверки: iOS 26+, 30 FPS, реальные форматы обеих камер, достаточный размер, поддерживаемый диапазон частоты и NV12. Список моделей iPhone не используется. При 60 FPS эффект выключается, а раздел скрывается. При включённом эффекте неподдерживаемое качество недоступно; при выключенном можно выбрать его, после чего раздел киноэффекта скрывается. Отсутствие поддержки не подменяется обещанием совместимости будущих устройств.

Настройки применяются сразу и сохраняют существующие ключи и начальные значения. Состояние на эскизе не задаёт новые defaults. Выключенный общий переключатель блокирует и запоздалые события страницы. Смена одного параметра сохраняет остальные. Фон строки не выбирает параметр; обработчик принадлежит соответствующей кнопке. Смена FPS обновляет только необходимый раздел без перезагрузки всей таблицы и сброса прокрутки.

Стекло использует UIGlassEffect на iOS 26+ и системный blur на более ранних версиях. Цвета и размеры шрифта получены из темы приложения. Подписи многострочные, высота рассчитывается AutoLayout; шрифт не уменьшается и текст не сокращается. Порядок элементов задаётся UIStackView с leading/trailing anchors для RTL. Каждая кнопка имеет отдельные VoiceOver-подпись, значение и состояния selected/disabled. Все подписи повторно используют существующие локализации 71 языка; заголовки приводятся к верхнему регистру после локализации.

Стадия 89 `round_quality_compact_page` после 88 меняет только `NagramiXRoundQualityController.swift`. Новый helper находится в том же файле, BUILD и зависимости прежние. Ползунок битрейта, инициализация/проверки камер, сохранение и обновление раздела киноэффекта сохранены побайтно. 11 guards фиксируют модель/камеру/экспорт/отправку. Старые планы и снимки не переписаны.

[Отчёт проверок](ROUND_QUALITY_COMPACT_CHECKS.json) отделяет локальное исполнение настоящих моделей и обработчиков с явными table/presentation hosts от проверки UIKit. В начало будущего macOS preflight добавлена проверка всей страницы с реальным UIKit и публичными Core/MediaSettings. На Linux SDK отсутствует: UIKit, геометрия на экране и физический iPhone остаются непроверенными. Actions/IPA этой задачей не запускаются.
