## Увеличение иллюстраций21октября

Желаемый размер логотипа —300pt вместо200pt на iPhone,360pt вместо240pt на iPad. При каждой нативной раскладке размер рассчитывается заново: видимая часть не шире экрана минус32pt и не выше свободной области между верхним safe area+8pt и началом штатного блока заголовков с12pt отступом. Учитываются прозрачные поля SHA-проверенного оригинала: alpha bounds (83,63)…(935,907) в1024×1024PNG; сам файл не обрезается. Позиция привязана к прежнему центру иллюстрации, с ограничением доступной областью. Поэтому на экранах с меньшим запасом места увеличение меньше1,5раза. Масштаб не накапливается при повороте/повторной раскладке. Все страницы используют один и тот же логотип.

Рисунок телефона —до150×150pt вместо100×100pt. Учитываются фактические insets, высота клавиатуры, измеренные заголовок/описание и переключатель синхронизации при другом аккаунте. При недостатке места иллюстрация уменьшается до прежних100pt; правила скрытия иллюстрации на ширине320pt и штатный layout полей сохранены. Изменение не расширяет исходную100pt область на уже тесных раскладках.

Правка находится только в `apply_nagramix_onboarding` файла `ios/apply_features.py`: полные исходные SHA/точные якоря и прежний lifecycle сохранены. PNG, aspectFit, тексты, ресурсы, поля, страна, callbacks, сетевое восстановление и остальные возможности не изменены. Полный overlay423файла:2изменены,421побайтно прежний. Проверены контрольные суммы оригиналов, ObjC grammar, Swift frontend parse, Python AST,8 расчётных конфигураций приветствия и18 бюджетов формы телефона. Расчётные проверки не запускают UIKit. Proof `/workspace/.codex-validation-nagramix-onboarding-size/verification.json`. Статус **source_checked/native_compile_pending/device_pending**; размеры/поворот/открытую клавиатуру необходимо проверить на iPhone после отдельно разрешённой сборки.

## Штатный интерфейс

RMIntro использует исходный device-specific updateLayout, нативные размеры/шрифты/страницы/точки/кнопку/языковой выбор/анимацию входа/фон Telegram. Вместо GL-иллюстраций один UIImageView с оригинальным Logo на всех6native страницах. Размер native области200pt/240наiPad, позиции и текстовые UILabel берутся из stockкода. Замена GL→UIView требует только центрирования рамки и вызова layout UIImageView. Сигнатуры snapshot/lifecycle сохраняются; Reduce Motion не запускает анимацию. Перелистывание не меняет и не перерисовывает логотип.

Новая собственная компоновка не используется: templates OnboardingLayout/PhoneLayout/PhoneFields оставлены как исторические файлы, но apply_features их не читает. Native PhoneAndCountryNode побайтно прежний; containerLayoutUpdated прежний, кроме удалённых вызовов animated-sticker API. В stock100×100 области вместо IntroPhone находится ASImageNode с оригинальным Phone. Клавиатура/поля/страна/contactsync/passkey/QR/proceed/смена номера и авторизационные callbacks не переписаны.
