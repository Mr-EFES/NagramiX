# Нижние панели выбора ускорения и задержки прокси

Пользователь выбрал первый из трёх визуальных макетов и подтвердил применение к таймеру прокси. Подготовлено после опубликованного №83 для NagramiX 0.5.1: implemented / compile_pending / device_pending. Сборка, commit, push и публикация не запускались.

Общий компонент `ios/Sources/SettingsUI/NagramiXOptionSheet.swift` использует штатные `ActionSheetController`, группы и прокрутку Display. Заголовок с ручкой и крестиком, список с именами слева и отдельной колонкой галочки, пояснение внизу. Палитра — текущая ActionSheetControllerTheme, шрифты — Font и её baseFontSize. Нет собственного fullscreen-плеера, web-прототипа, темы, сетевых запросов или таймера. Изображения интерфейса не вклеиваются в приложение; checkmark/xmark — системные символы.

Ускорение: только «Среднее» и «Максимум», подписи о нагрузке на сеть. Прежняя видимость по enabled, сохранение downloads.mode и применимость параметров к новым загрузкам. Перед сохранением повторно проверяются enabled и разрешённый режим. Таймер: только15/30/60, «Переключить через» и пояснение ожидания подключения; прежний updater proxyAutoSwitchTimeout. Оба меню отмечают сохранённое значение. Чистые defaults, keys, enum raw values, legacy normalization, загрузчик и failover побайтно прежние.

Тап строки сохраняет один раз и закрывает. Крестик/фон/свайп не вызывают storage callback. Общий finished guard защищает повторные тапы и действия после закрытия; closures используют weak controller. Минимум60pt для таймера,84pt для строки с описанием; фактическая высота зависит от измеренного текста. Текст переносится, колонка галочки резервируется и для невыбранных строк. RTL зеркалит аксессуары, VoiceOver получает заголовок, доступную кнопку закрытия и название/описание/selected строки. Длинная панель прокручивается штатной группой.

Durable интеграция: SettingsController вызывает общий компонент; `apply_option_selection_sheets` последним helper проверяет SHA256 integrated ProxyListSettingsController `df0d21843e665276dcdc4da23584ce69df24aa629267234e93c611afdfabe77f`, точный блок selectTimeoutImpl и наличие компонента перед изменением. Остальной proxy controller сохраняется. Компонент копируется в SettingsUI/Sources, существующий BUILD glob включает его и уже имеет все зависимости. Пять новых RU/EN ключей в Core, старые строки не изменены.

Полный feature overlay: `/tmp/nagramix-option-sheet-proof` из352 прежних проверенных входов. 415 результатов против `/tmp/nagramix-story-mode-proof`:409 сохранены,5 изменены,1 новый компонент. Изменены только два SettingsUI call site, PresentationStrings и RU/EN. Обратная замена proxy и download selector восстанавливает прежние файлы точно. 2 drift +1 rerun отклоняются до мутаций. `/tmp/nagramix-validate-option-sheets.py` проверяет границы сохранения/отмены, допустимые значения, ключи, сохранность прежних ресурсов и BUILD discovery. Четыре Swift-файла прошли grammar parser; Python/metadata/diff проверяются отдельно. API Display прочитаны в9 Git-SHA-verified stock blobs pinned13.0.

Это статическая проверка. Swift type checking, реальный UIKit layout, VoiceOver, жесты и смена темы/размера текста не запускались: среда Linux без Xcode и физического iPhone. Макет — выбранная визуальная цель, а не screenshot готового приложения.

В следующей разрешённой сборке проверить оба меню на светлой/тёмной теме, узком экране, RU/EN/RTL и увеличенном шрифте. Открытие должно показывать текущую галочку; выбрать каждый режим и15/30/60, повторно открыть, перезапустить — выбор сохранён. Повторный тап выбранного значения ничего не отключает. Крестик, фон, свайп, быстрые повторные тапы, фон/возврат и прокрутка не меняют значение без выбора и не оставляют затемнение. При enabled OFF ускорение не предлагает выбор. VoiceOver читает выбранный вариант и закрытие. Наконец проверить реальную загрузку и таймаут переключения — оформление не должно менять их поведение. Все пять предыдущих подготовленных доработок также требуют проверки.
