# NagramiX 0.1.8 — описание тестовой версии

Файл сборки: `NagramiX-0.1.8-unsigned.ipa`.

Сборка не подписана сертификатом Apple и предназначена для последующей подписи и установки через SideStore или совместимый сервис.

## Исправления

- Для основной иконки №1 добавлен отдельный системный ресурс предпросмотра в настройках.
- Основная иконка остаётся настоящей primary-иконкой iOS и возвращается вызовом `setAlternateIconName(nil)`.
- После выбора любой иконки №2–8 иконку №1 можно снова выбрать без ограничений.
- Перед записью круглого видео фактический поток камеры синхронизируется с камерой, показанной в предпросмотре.
- При включённой настройке «На заднюю камеру» отправленный кружок записывается задней камерой.
- При выключенной настройке отправленный кружок записывается фронтальной камерой.
- Ручное переключение камеры сохраняет штатное поведение Telegram.

## Значения по умолчанию

- Вкладки «Контакты» и «Звонки» скрыты.
- Подписи вкладок отображаются.
- Отдельная кнопка поиска скрыта.
- Круглые видеосообщения записываются задней камерой.
- Все настройки историй выключены.

## Проверка на iPhone

- Удалить предыдущую сборку перед чистой установкой, чтобы исключить системный кэш иконок.
- Переключить иконку №1 на №8 и обратно на №1.
- Записать и отправить различимые тестовые кружки задней и фронтальной камерами.
- Воспроизвести именно отправленные сообщения и сравнить их с предпросмотром записи.
