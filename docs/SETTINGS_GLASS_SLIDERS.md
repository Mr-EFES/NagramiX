# Единый стеклянный бегунок настроек

Владелец утвердил перенос оформления плотности снегопада на все ползунки настроек NagramiX. Стадия82 `settings_glass_sliders` следует за81, сохраняет прежние планы и использует существующие BUILD globs и прямые зависимости от NagramiXCore.

Общий `NagramiXGlassSliderThumbView` содержит тот же прозрачный 28pt бегунок: native UIGlassEffect.clear на iOS26+, прозрачный fallback на прежних системах, тонкую кромку, блик и тень. Тема берётся из приложения. Декорация не принимает касания и не создаёт отдельного элемента VoiceOver.

`NagramiXGlassSlider` сохраняет штатный UISlider для битрейта качественных кружков, температуры расшифровки и перевода. Геометрия вычисляется через публичный thumbRect, без поиска приватных UIKit views. Высота не менее44pt; RTL, состояние disabled и анимированное округление после отпускания поддерживаются.

`NagramiXLegacyGlassSliderView` декорирует исходный knob Legacy для плотности и процентных строк: качества фото, размера стикеров и параметров эффектов ввода. Геометрия вынесена в общий helper: края16/15pt как у штатных строк, прозрачный thumb28pt и компенсация7pt для Legacy. Плотность по-прежнему хранит10–100 и шаг VoiceOver5, используя только внутренний adapter0–90. Процентные значения хранят0–100 без нового округления; прежний шаг VoiceOver5 сохранён.

Диапазоны, единицы, callbacks, момент сохранения, защита удерживаемого значения и доступность температуры по модели сохраняются. Три consumer-контроллера меняют только создание и оформление control; обработчики и сохранение сверяются с точными preimages. Камера/кодеки, провайдеры, записи настроек, плееры, зависимости и подпись не меняются. Новых UI-строк нет.

[Проверки](SETTINGS_GLASS_SLIDERS_CHECKS.json) разделяют Linux runtime с явными UIKit/List/theme/model границами, будущий Apple SDK preflight и физическую проверку. Apple gate сначала собирает настоящий публичный Core module, затем проверяет actual Legacy wrapper, оба node, bitrate cell и temperature consumer methods извне модуля с реальными UIKit и ObjC header при target iOS15. Это не полная сборка приложения.

Публикация проверенных исходников в main разрешена. Новые Actions/IPA/релиз в этой задаче не запускаются. Все существующие релизы и файлы выпуска сохраняются; внешний вид и реальные жесты на iPhone ожидают проверки.
