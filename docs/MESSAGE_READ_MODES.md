# Прочтение сообщений

Актуально19октября: отдельный server mode удалён. Остаются «Читать сообщения локально» и независимое «Чтение по действию», оба OFF при отсутствии выбора. Обычное чтение Telegram работает, когда оба выключены. [Продуктовый контракт](../product/features/message-read-mode.md), [реализация/миграция/проверки](PRIVACY_SETTINGS.md).

Локальные read/history/content receipts и увеличение просмотров каналов подавляются. На устройстве непрочитанные снимаются, private watermark сохраняется на аккаунт/peer. Ответ подтверждает границу предыдущей истории, реакция — выбранное сообщение и более ранние. Новая история во время RPC, частичный ответ или ошибка не теряют защиту. Глобального временного bypass нет.

Cold start не сбрасывает настройки. Старое server значение становится ordinary standard без отдельного checkbox или функции. Новая iOS-сборка не запускалась; прежний IPA108 этих изменений не содержит. Для физической проверки нужна отдельная команда на сборку.
