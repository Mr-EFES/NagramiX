# Проверка0.8.6 на iPhone

Исходники проверяются отдельно от Apple SDK и готового IPA. Эта таблица — план физической проверки новых изменений, а не подтверждение их работы на устройстве. Минимум приложения — iOS15.0; проверить старый поддерживаемый iPhone и современный аппарат владельца. Прежние сценарии0.8.5 сохраняются в [предыдущей проверке](DEVICE_CHECK_085.md).

| Сценарий | Ожидаемый результат |
| --- | --- |
| Whisper: новая установка | Три предложения загрузки: «Базовая» Base Q5≈59,7МБ, «Средняя» Small full≈487,6МБ, «Максимальная» Turbo Q8≈874,2МБ. Выбор по умолчанию — Base; загрузка только после явного действия. |
| Whisper: обновление | Прежние выбранный ID и скачанный файл не меняются автоматически. Старые Medium/Large доступны как сохранённый выбор, хотя не предлагаются для новой загрузки. |
| Whisper: русский голос/отмена/повтор | Выбранная модель расшифровывает локальную запись; отмена освобождает обработку и временный PCM, следующий запрос работает. Оценивать задержку и ошибки по реальным записям, не по Linux-пробам. |
| Vosk: русский язык | Два предложения: «Базовая» small-ru0.22≈46,2МБ и «Альтернативная» ru0.10-lgraph≈175,7МБ. Скачивание, выбранный ID, отмена и повтор работают; альтернативный вариант не обещает большей точности. |
| Память и смена provider | Последовательные запросы Whisper/Vosk не выполняют две native inference одновременно. При реальном недостатке памяти — понятный отказ без удаления голосового и без скрытой смены модели. Измерить память на устройстве; совместимость по iOS не гарантирует доступную RAM каждой модели. |
| Временное голосовое, функция ON | Прежние воспроизведение в чате, огонь, повтор и сохранение остаются. Расшифровка доступна для поддерживаемых живых и сохранённых голосовых; локальный текст не вызывает consume/read/expiry. |
| Premium временного голосового | Проверить реальный ответ сервера для живого сообщения. Сохранённой копии без серверного сообщения не отправлять native Premium-запрос. Локальные provider работают по прежнему выбору. |
| Удаление целого поста при ON | Пересылка, рассылка и репост с альбомом выделяются целиком. Первое удаление оставляет целую полупрозрачную копию с подписью, порядком и вложениями; повторное явное удаление выбранной копии удаляет этот пост. Undo возвращает только отменённую операцию. |
| Область архива и очистка | Копии видны только в исходной обычной переписке/теме. В закреплённых, отложенных и других специальных представлениях их нет. Полная очистка удаляет весь локальный архив. При OFF штатное удаление сохраняется. |
| Расширенный редактор | Клавиатура ↔ эмодзи ↔ быстрое форматирование плавно переключаются в обоих направлениях, включая быстрые повторные нажатия. Нет прыжков, мгновенной замены и поздних callbacks старой панели; Reduce Motion сохраняется. |
| Иконки меню | У «По автору» голова по центру над плечами. В «Рассылке» фигуры переставлены по утверждённому эскизу; действия меню прежние. |
| PiP: первый вход и возврат | Холодно открыть видео; один tap и отдельно один свайп вверх без предварительного прогрева кнопкой. Проверить позднюю готовность, повторный вход после возврата, все4 угла без чёрных прямоугольных фаз, отсутствие дублирующего постера. Проверить отказ/уход во время ожидания, смену видео, Reduce Motion, портрет/альбомную ориентацию. Свайп OFF/запреты/вниз/авто-PiP и прежнее воспроизведение сохраняются. |
| Язык настроек и debug | RU/EN, затем несколько других языков и RTL: все уровни настроек, подписи моделей, ошибки и debug соответствуют выбранному языку приложения, длинные строки читаются. Все71 каталога должны присутствовать в готовом IPA. |

Записывать модель iPhone, iOS, версию/build IPA, выбранную модель распознавания и результат каждого сценария. Не отмечать всю таблицу пройденной по одной успешной сборке.
