# Проверка0.8.6 на iPhone

Исходники проверяются отдельно от Apple SDK и готового IPA. Эта таблица — план физической проверки новых изменений, а не подтверждение их работы на устройстве. Минимум приложения — iOS15.0; проверить старый поддерживаемый iPhone и современный аппарат владельца. Прежние сценарии0.8.5 сохраняются в [предыдущей проверке](DEVICE_CHECK_085.md).

| Сценарий | Ожидаемый результат |
| --- | --- |
| Whisper: новая установка | Три предложения загрузки: «Базовая» Base Q5≈59,7МБ, «Средняя» Small full≈487,6МБ, «Максимальная» Turbo Q8≈874,2МБ. Выбор по умолчанию — Base; загрузка только после явного действия. |
| Whisper: обновление | Прежние выбранный ID и скачанный файл не меняются автоматически. Старые Medium/Large доступны как сохранённый выбор, хотя не предлагаются для новой загрузки. |
| Whisper: русский голос/отмена/повтор | Выбранная модель расшифровывает локальную запись; отмена освобождает обработку и временный PCM, следующий запрос работает. Оценивать задержку и ошибки по реальным записям, не по Linux-пробам. |
| Vosk: русский язык | Два предложения: «Базовая» small-ru0.22≈46,2МБ и «Альтернативная» ru0.10-lgraph≈175,7МБ. Скачивание, выбранный ID, отмена и повтор работают; альтернативный вариант не обещает большей точности. |
| Память и смена provider | Последовательные запросы Whisper/Vosk не выполняют две native inference одновременно. При реальном недостатке памяти — понятный отказ без удаления голосового и без скрытой смены модели. Измерить память на устройстве; совместимость по iOS не гарантирует доступную RAM каждой модели. |
| Временное голосовое, функция ON | Прежние воспроизведение в чате, огонь, повтор и сохранение остаются. Расшифровка доступна для поддерживаемых живых и сохранённых голосовых; локальный текст не вызывает consume/read/expiry. |
| Premium временного голосового | Проверить реальный ответ сервера для живого сообщения. Сохранённой копии без серверного сообщения не отправлять native Premium-запрос. Локальные provider работают по прежнему выбору. |
| Удаление целого поста при ON | Пересылка, рассылка и репост с альбомом выделяются целиком. Первое удаление оставляет целую полупрозрачную копию с подписью, порядком и вложениями; повторное явное удаление выбранной копии удаляет этот пост. Undo возвращает только отменённую операцию. |
| Область архива и очистка | Копии видны только в исходной обычной переписке/теме. В закреплённых, отложенных и других специальных представлениях их нет. Полная очистка удаляет весь локальный архив. При OFF штатное удаление сохраняется. |
| Расширенный редактор | Клавиатура ↔ эмодзи ↔ быстрое форматирование плавно переключаются в обоих направлениях, включая быстрые повторные нажатия. Нет прыжков, мгновенной замены и поздних callbacks старой панели; Reduce Motion сохраняется. |
| Иконки меню | У «По автору» голова по центру над плечами. В «Рассылке» фигуры переставлены по утверждённому эскизу; действия меню прежние. |
| PiP: первый вход и возврат | На исправленном кандидате повторить оба пути crash170: presentation-copy ошибка должна отсутствовать. Холодно открыть видео; один tap и отдельно один свайп вверх без предварительного прогрева кнопкой. Проверить позднюю готовность, повторный вход после возврата, все4 угла без чёрных прямоугольных фаз, отсутствие дублирующего постера. Проверить отказ/уход во время ожидания, смену видео, Reduce Motion, портрет/альбомную ориентацию. Свайп OFF/запреты/вниз/авто-PiP и прежнее воспроизведение сохраняются. |
| Язык настроек и debug | RU/EN, затем несколько других языков и RTL: все уровни настроек, подписи моделей, ошибки и debug соответствуют выбранному языку приложения, длинные строки читаются. Все71 каталога должны присутствовать в готовом IPA. |

Записывать модель iPhone, iOS, версию/build IPA, выбранную модель распознавания и результат каждого сценария. Не отмечать всю таблицу пройденной по одной успешной сборке.

После отдельно разрешённой следующей сборки дополнительно проверить [MESSAGE_COPY_AVAILABILITY](MESSAGE_COPY_AVAILABILITY.md): Free Content OFF скрывает запрещённые copy пункты protected/secret, ON показывает и отправляет копии; screenshot anonymous poll, private-left/kicked и protected group/channel, обычные secret text/photo/file/video, два адресата/целый альбом, отключение перед Send, отмена/ошибка fetch. Нового кода в IPA171 нет.

После отдельной команды на новую сборку проверить [TEMPORARY_MEDIA_ACTIONS](TEMPORARY_MEDIA_ACTIONS.md): →A у входящих/исходящих одноразовых голосовых и кружков до/после воспроизведения, перезапуска и потребления официальным клиентом; master ASR OFF/Telegram без Premium/с Premium/Whisper/Vosk. Кнопка остаётся, результат открывается локально, новый unavailable запрос даёт понятный отказ без consume/скрытой пересылки. Четыре вида временного медиа: меню, реальный reply или локальная цитата удалённого, save/files/Photos/tone, авторский Repost (у кружка соседний текст), безымянная single copy и два получателя с альбомом. Повторное удаление/полный clear, OFF во время ASR/picker/save, поздний Premium update после clear не возвращает данные. ON/OFF Free Content не подменяет Temporary policy. В старой171 этих изменений нет.

После отдельно разрешённой сборки проверить [ARCHIVE_DELETION_VISIBILITY](ARCHIVE_DELETION_VISIBILITY.md): при «Удалённые сообщения» ON удалить одиночный пост и альбом из4 элементов у себя/обоих. Полная полупрозрачная копия с меткой остаётся видимой без пустой ячейки и повторного входа. Проверить соседние обычные сообщения и прокрутку, задержанную загрузку архива, Undo, повторное локальное удаление, OFF, выключенный эффект/Reduce Motion. При реальном стирании строка схлопывается, dust альбома не дублируется; высокий пост или ошибка snapshot не оставляют паузу под несуществующий эффект. Проверить текст/фото/видео/голосовое, обычные и временные копии. Это план проверки, не результат новой IPA.

После отдельно разрешённой сборки проверить [LOCAL_MODEL_MENU](LOCAL_MODEL_MENU.md): Whisper три коротких названия, Vosk два, без raw IDs/footer/loaded/MB; одинарная строка во всех состояниях. Установленные модели без процентов, выбранный установленный ID отмечен единственной native галочкой. Другая загрузка показывает только процент и не переносит выбор; после завершения stale100% исчезает. Проверить выбор каждого установленного варианта, отмену/повтор/удаление, ошибку сети/проверки файла, сохранение после запуска, Wi-Fi consent. RU/EN и длинный/RTL язык, небольшой iPhone и увеличенный текст: без переносов/наложений, шрифт не уменьшать. Лицензии и прочие настройки остаются прежними. Это план проверки будущей IPA.

После отдельно разрешённой сборки проверить [PIP_VISUAL_HANDOFF](PIP_VISUAL_HANDOFF.md) по двум новым видео: первый tap и первый свайп вверх, включая ещё не готовое видео; повторить быстрый вход/возврат/закрытие. Нет незавершённой перемещаемой плашки после принятого свайпа, скачка crop/радиуса, большого placeholder и второго fade после появления системного окна. При отказе/уходе во время ожидания галерея возвращается в центр с фоном/controls/жестами; ложного сообщения об успехе нет. Само готовое окно iOS можно перемещать, менять размер и скрывать у края. Проверить portrait/landscape/square, поворот, play/pause/buffering/seek/rate, сохранение позиции/звука и background. Возврат показывает ту же готовую галерею без restart/seek; закрытие без возврата оставляет чат на месте. Отмена/закрытие во время возврата не открывает галерею позднее. Проверить Reduce Motion, существующие запреты и swipe OFF, поддерживаемый старый iPhone/iOS15+ и устройство владельца. Записать новую IPA/build и экран с высокой частотой кадров; Linux suite не подтверждает отрисовку AVKit. В171 этого исправления нет.
