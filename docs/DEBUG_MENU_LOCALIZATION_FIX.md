23 октября пользователь показал сборку122: верхняя строка называла приложение «Telegram for iOS», заголовки LOGS/RESET APP и пояснение об исключении личных данных оставались английскими. Прежний перевод обрабатывал в основном `title:`, поэтому не охватывал `text:`, описания, динамические меню и новый экран отчётов о сбоях Telegram13.1.1.

Подготовлено после опубликованного Release0.6.9/build122: **source_checked/native_compile_pending/device_pending**. В существующем IPA122 этой правки нет. Сборка, публикация, stage/commit/push не выполнялись; работа в main, предыдущая правка форматирования сохранена.

## Изменения

- Верхняя строка: `NagramiX для iOS <версия> (<сборка>)`, ниже прежний фактический bundle identifier. Значения версии, сборки и идентификатора не подменяются.
- Переведены заголовки «ЖУРНАЛЫ», «СБРОС ПРИЛОЖЕНИЯ», «ЭКСПЕРИМЕНТАЛЬНЫЕ НАСТРОЙКИ» и пояснение об исключении конфиденциальных данных из журналов. Длинная подпись переключателя сокращена до «Исключать личные данные» с сохранением смысла и обработчика.
- Переведены динамический список типов журналов, ограничения размера, способы отправки, подписи режимов камеры, названия сетевого движка/сервера и темы письма с названием NagramiX.
- Переведены экран отчётов о сбоях, просмотр журнала, контекстное меню, пустое состояние, ошибки, подтверждения, предложение отправки после сбоя и кнопка тестового сбоя, доступная только в DEBUG. Раздел учётных записей также включён в проверку полноты.

Используется существующий `PresentationStrings.nagramiXDebugLocalized` и RU/EN bundle; при русском языке приложения все перечисленные подписи русские, выбор языка и английский fallback прежние. Динамические значения передаются аргументами `%@`, а не входят в ключ локализации. Технические имена VGA/HD, JPEG X, реальные адреса и идентификаторы, содержимое журналов, стек и сообщения внешних API сохраняются как данные.

Отправка отчёта штатному боту `iOSCrashReportsBot` остаётся отправкой команде Telegram; подпись честно называет получателя «Отправить команде Telegram». Бот, маршруты, данные архивов, подтверждения, настройки, значения по умолчанию и действия не менялись. Автоматической отправки журналов эта правка не добавляет.

## Интеграция и проверки

Финальный `ios/debug_menu_localization.py` применяется после `quick_format_panel`, перед брендингом. План фиксирует четыре полных входных/выходных SHA256 и59 точных операций: два Swift-файла DebugSettingsUI и два файла локализации в сформированном NagramiXCore. Все проверки выполняются до записи. Ранние canonical stages, исходные Core resources в overlay и manifest порта351outputs/78resolutions не изменены. Новых нативных файлов или зависимостей нет: DebugSettingsUI уже зависит от NagramiXCore.

`scripts/validate_debug_localization.py` теперь проверяет152 используемые подписи/шаблона, включая динамические enum labels и CrashReportsController, наличие русского текста, плейсхолдеры и брендинг. Нелокализованные литералы допускаются только по рассмотренному списку диагностических идентификаторов, путей, payload и enum keys; новая английская UI-строка приводит к отказу проверки. Проверка уже вызывается существующим workflow после применения overlay.

`scripts/validate_debug_menu_overlay.py` прошёл replay и12 fail-closed сценариев без частичной записи: повторное применение, отсутствие/дрейф каждого из четырёх входов, неверный якорь, выходной digest и небезопасный путь. Настоящий Foundation accessor и реальные `.strings` исполнялись в debug и optimized:810 lookup-проверок на режим для ru/ru-RU/RU/en/de, сохранённый fallback и динамические шаблоны версии/сервера/бота. Внешний тип PresentationStrings представлен минимальной границей данных; UIKit не исполнялся.

Полный CLI overlay на чистой копии закреплённого Telegram13.1.1 с фиктивными API credentials завершился успешно. После брендинга совпали все четыре SHA новой правки и все семь SHA предыдущего форматирования. Swift parser принял оба полных изменённых контроллера. Proof: `/workspace/.codex-validation-nagramix-debug-menu/{verification,integration}.json`.

Apple SDK и физическая проверка ожидаются после отдельной команды на IPA. На iPhone проверить все разделы и вложенные меню отладки в русской теме, версию/сборку, читаемость переключателя, пустой/непустой список отчётов, просмотр/отмену подтверждений и смену языка. Не инициировать отправку данных и сброс/аварийное завершение приложения ради проверки подписей.
