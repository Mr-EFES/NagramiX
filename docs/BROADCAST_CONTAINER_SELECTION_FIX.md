# Рассылка: открытие супергруппы и выбор темы

Актуальный результат: включено в опубликованный Release0.7.1/build127, source32f6b5a; чистая Apple SDK-сборка и проверка IPA пройдены, физическая приёмка ожидается. [Итог выпуска](RELEASE_STATUS.md). Описанные ниже pending/запреты запуска относятся к этапу подготовки.

24 октября пользователь показал серую недоступную строку супергруппы во время рассылки: личные чаты и обычные группы выбирались, но открыть список тем было невозможно. Исправлено в исходниках после Release0.7.0/build123: **source_checked / native_compile_pending / device_pending**. Опубликованный IPA123 не изменён; новая сборка не запускалась.

## Причина

В двух путях `ChatListNode` (создание и обновление строки) штатный peer picker принудительно задавал `enabled = false` для форумов/сообществ при `editing == true`. Этот режим используется множественной рассылкой. Прежние исправления уже сохраняли общий выбор при смене папок и формировали правильный адрес выбранной темы, но были недоступны через такую отключённую строку. Состояние уведомлений группы не является условием этой блокировки.

## Изменение

- Для обычного режима `.copyAsNew` добавляется временный `ChatListNodePeersFilter.nagramiXCopyDestinations` (свободный бит19). Это только поведение открытого окна, без нового checkbox, сохранённой настройки или формата данных. Собственные одноразовые записи, одиночная пересылка и штатный репост не получают этот флаг.
- В обоих путях строки при этом флаге снимается только принудительная блокировка контейнера из-за множественного выбора. Прочие фильтры, права на отправку, Premium и недоступность/закрытость конкретных тем сохраняются.
- Супергруппа/сообщество остаётся контейнером без checkbox. Нажатие вызывает прежний `peerSelected` и штатный экран выбора темы или вложенного чата. Сам контейнер не добавляется к получателям. Обычные собеседники и группы продолжают переключать свою отметку.
- Выбор реальной темы возвращается прежним callback в общий список адресатов. Ранее выбранные личные чаты сохраняются, `peer→thread` snapshot и явный RPC reply target остаются прежними. Автоматического выбора General/первой темы нет.
- Основное окно `.copyAsNew` получает существующее локализованное название **«Рассылка»**. Подэкран тем сохраняет имя группы.

Нативный `openPeerForSelection`, код возврата из подэкрана, сохранение папок/контактов, проверки и отправка после `nagramiXConfigureCopySelection` побайтно прежние. Правка не подменяет серверные права или существующие ограничения одноразовых записей. Она применяется до фильтров конкретного содержимого, поэтому обычные текст, фото, видео, файлы и аудио используют один исправленный выбор адресата.

## Интеграция и проверка

Новый последний этап `ios/broadcast_containers.py` после `quick_format_surface` применяет `broadcast_containers_patches.json`: три входных/выходных SHA256,11 точных замен. Пути, входы, якоря и результаты проверяются до первой записи. Предыдущая незакоммиченная правка границы/заголовка/наложения форматирования сохранена; ранние canonical overlays и manifest13.1 не менялись. BUILD/dependencies и нативные файлы не добавлены.

Проверено:

- `scripts/validate_broadcast_containers.py`: **50 новых +107 прежних проверок** в debug/optimized. Выполняются реальные извлечённые native блоки обеих строк, action callbacks, OptionSet, включение флага, handoff папок и методы enqueue. Старые блоки воспроизводят отключённый форум; новые открывают контейнер без добавления root. Проверены обычные чаты/группы, forum/mono/community, opt-out, peer-ID pickers, запреты, конкретная тема, отсутствие fallback/утечки темы в личные чаты и сохранность копий для двух собеседников плюс темы.
- `EngineMessage.Id` в тестовой границе соответствует настоящему `typealias Id = MessageId` из Telegram13.1. UIKit/widget gating и сеть представлены boundaries; это не реальная доставка на iPhone.
- **21 fail-closed** сценарий без частичной записи, Swift parser всех трёх полных файлов и Python AST прошли.
- Полный CLI на чистой закреплённой13.1.1 с фиктивной конфигурацией прошёл до конца брендинга. Относительно предыдущей полной версии изменены только три заявленных файла; остальные34479 файлов побайтно прежние. Выходные SHA совпали; четыре выхода предыдущей правки форматирования сохранены.
