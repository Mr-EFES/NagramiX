## Настройки

Порядок разделов: качество → битрейт → частота кадров → кодек → киноэффект, если он поддерживается при30FPS. Качество по-прежнему480×480/Стандарт,512×512/Высокое,640×640/Максимум; кодеки H.264 (AVC)/Стандартное сжатие и H.265 (HEVC)/Эффективное сжатие. Переключатель «Качественные кружки» остаётся OFF по умолчанию в отдельной группе «Прочее».

В разделе «БИТРЕЙТ» одна ячейка с подписью «Битрейт:1,0Мбит/с», числом1000справа и UISlider. Диапазон1000–2000кбит/с, шаг100кбит/с:11положений, то есть1,0/1,1/…/2,0Мбит/с. Значение округляется к ближайшей ступени и сохраняется сразу. Цвета и шрифты берутся из штатной темы/размера списков; высота автоматическая. VoiceOver получает значение с единицами. При перемещении ползунка обновляются существующие подписи и ячейки, без reloadData/reloadRows или пересоздания страницы/ползунка.

Новый ключ `nagramix.roundVideo.quality.bitrate` хранит биты/с как Int. Если его ещё нет, используются прежние значения выбранного качества:480→1_000_000,512→1_200_000,640→1_500_000. После сохранения это независимый параметр: смена качества/FPS/кодека его не сбрасывает. OFF/ON, Назад/повторное открытие и перезапуск сохраняют выбор. Неподходящие числовые значения ограничиваются1_000_000…2_000_000и округляются по100_000; вычисление безопасно и для Int.min/max.

Киноэффект сохраняет прежние аппаратные/форматные ограничения. Его необязательная секция теперь имеет индекс4; при30↔60 вставляется/удаляется только она. Старое нажатие на скрытый раздел или неверную строку игнорируется; masterOFF не позволяет изменить сохранённые параметры через старый экран.

## Параметры настоящего энкодера

Camera и NagramiXMediaSettings компилируют одинаковую модель из одного проверенного шаблона. Neo VideoRecorder передаёт выбранный `settings.bitRate` в AVVideoAverageBitRateKey; разрешение, FPS и кодек по-прежнему берутся из snapshot записи, а не из названия строки.

Проверена существующая маршрутизация кодека: H.264 выбирает AVVideoCodecType.h264 и AVC profile/CABAC; H.265 выбирает AVVideoCodecType.hevc и HEVC Main profile без H.264 entropy key. Эти настройки передаются в assetWriter.canApply и AVAssetWriterInput. Если encoder не принимает HEVC, остаётся native failure; незаметной замены на H.264 нет. В отправляемых атрибутах сохраняются instantRoundVideo и соответствующий h264/h265 codec identifier.

Snapshot для обрезки/отложенной конвертации расширен с `[side,FPS,codec]` до `[side,FPS,codec,bitRate]`. MediaEditorValues сохраняет его прежним optional JSON-массивом и переносит всеми прежними copy/update методами. Export использует записанный битрейт и кодек, даже если пользователь уже сменил настройки. Старый массив из3элементов принимается с прежними1,0/1,2/1,5Мбит/с. Неверные/неизвестные snapshots не включают override. Штатный writer экспорта сохраняет выбранные AVVideoCodecKey и AVVideoAverageBitRateKey до создания AVAssetWriterInput. OFF и истории продолжают использовать штатный путь.

Средний битрейт является целевым параметром encoder. При одинаковом битрейте длительность и размер H.264/HEVC будут близки; преимущество HEVC — эффективность/качество при заданном размере. Точный размер, фактический codec tag готового файла и серверный round-type требуют проверки файла с iPhone; по Linux boundary это не объявляется доказанным.

## Интеграция и проверка

Последний stage `round_video_bitrate` после `scheduled_archive_isolation`:6nativeSwift/6точных замен/14guards/2templates. Проверяются BUILD, конфигурация/обработка кадров камеры, Cinematic helpers, штатные export/writer, отправка и native fonts. Ранние canonical sources/SHA не меняются. Validator предыдущих sheet/page/refinement признаёт только точный новый результат и направляет его на актуальную проверку; затем новый validator обратными точными заменами восстанавливает предыдущие SHA в отдельной временной папке и запускает прежние проверки. Проверяются все3качества×2FPS×2кодека×11битрейтов, миграция/перезапуск/OFF, устаревший FPS callback после смены битрейта, legacy snapshot, malformed/nil/story, codec/profile/entropy и отказ неподдерживаемого HEVC, все положения slider, порядок разделов, subtitle, стабильность cells/offset, Cinematic и старые нажатия.
