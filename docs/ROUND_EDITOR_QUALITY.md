# Качество кружков в редакторе круглого видео

При включённых «Качественных кружках» новый переход ролика в круглый формат использует выбранные разрешение, частоту кадров, кодек и независимый битрейт: Стандарт480×480, Высокое512×512, Максимум640×640. При выключенной настройке новая конвертация сохраняет штатный экспорт с пределом480×480. Отдельная камера кружков, запись звука и существующие параметры пользователя не меняются.

Причина прежнего сброса: редактор выбирал `MediaQualityPreset.videoMessage`, но не задавал существующий `nagramiXRoundTuning`. Поэтому native export не видел выбранного профиля и использовал480/H.264. Отдельно toolbar всегда получал legacy index3 и рисовал480, даже при другом сохранённом snapshot.

Исправление — поздняя guarded стадия73 `round_editor_quality`, после `transcription_cached_read`. Выбор качества фиксируется в существующем четырёхэлементном snapshot `[side,FPS,codec,bitRate]` этого вложения. Новый immutable copy-method переносит все43 поля конструктора и заменяет только tuning. Новые пользовательские ключи и новые форматы хранения не добавляются.

При новом включении круглого режима берутся текущие настройки. При выходе восстанавливается tuning исходного обычного ролика. Повторное открытие или смена страницы сохраняет уже выбранный профиль этого вложения; старый круглый draft без snapshot получает текущие настройки, если функция включена. Настройки, изменённые во время подготовки другого файла, не переписывают ранее подготовленный draft или отложенную отправку.

Готовый snapshot проходит через прежние JSON-adjustments, обрезку и native copy/update. Существующий export уже поддерживает480/512/640,30/60FPS,H.264/HEVC и битрейт1,0–2,0Мбит/с. Его реализация остаётся прежней. Обе обычные отправки получают размеры из той же export configuration; подпись, звук/выключенный звук, отрезок до60секунд, round attribute и запрет альбомной группировки остаются прежними. Киноэффект остаётся свойством захвата камеры; новый эффект в редактор не добавляется.

В toolbar круглый профиль получает отдельное значение размера в пикселях вместо legacy index обычного видео. Значок показывает ширину export configuration, включая штатный меньший размер исходника при выключенной функции; фото/HD и обычные видео используют прежние значки. Кнопка качества не открывает обычный ползунок пресетов в круглом режиме.

## Проверки

Реальные constructor/copy, snapshot helper, round-toggle, crop/restore, полный recommendedVideoExportConfiguration, JSON tuning statements и toolbar branch исполняются в debug/optimized. Проверяются132 сочетания3разрешений×2FPS×2кодеков×11битрейтов, выключенный master, повторное открытие/сохранение, смена настроек и возвращение обычного режима. Отдельный отрицательный сценарий использует настоящий прежний72 toggle; семантические мутации должны отклоняться.

Telegram graph, UI и аппаратный writer представлены явно обозначенными границами. Настоящий settings module и межфайловый вызов через contextual `.current` компилируются отдельно. На Apple обязателен UIKit/CoreGraphics probe реального drawing helper. Эти проверки не заменяют полную Apple SDK-компиляцию и файл с физического iPhone.

В тестовой среде устранены два препятствия: переполнение temp при накоплении уже завершённых compiler caches и блокирующее ожидание в старом CLI ASR fixture. Кэши теперь освобождаются после их последнего потребителя; ожидание сохраняет5секунд и обслуживает настоящую main queue через RunLoop. Старое ожидание детерминированно отвергнуто в обоих режимах; ASR приложения не менялась. Все три первоначальных журнала сохранены в receipt, проверки не отключались. Статусы round_video_editor/round_video_quality — compile_pending/device_pending. Новая SDK/IPA не запускалась; опубликованные релизы сохранены.
