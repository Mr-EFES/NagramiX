# Панель параметров скачивания до нижнего края

Утверждённый владельцем эскиз: «Параметры скачивания» прилегают к нижней границе, фон продолжается под индикатором «Домой», скруглены только верхние углы. Зазора и второй видимой панели снизу быть не должно. Реализация предназначена для main; новая сборка не разрешена.

## Реализация

Причина — штатный floating layout `ActionSheetController`: боковые и нижний отступы по10pt, дополнительный нижний inset и четыре круглых угла. Для этого меню добавлен opt-in `nagramiXBottomAttached`, по умолчанию false. Фабрика `nagramiXOptionSheet` передаёт его в Display; включён только вызов из `openDownloadAccelerationMode`. Прокси-таймер и остальные sheets продолжают использовать native floating layout.

В режиме прилегания одиночная группа заканчивается ровно на нижней границе. Нижняя безопасная область включена в размер группы и scroll content; она окрашена тем же `itemBackgroundColor` поверх существующего blur. Insets текста увеличены с20до30pt внутри группы: после удаления внешнего10pt отступа сохраняются прежние абсолютные колонки заголовка, текста, крестика и галочки. Родные safe side insets сохраняются для боковых вырезов и других размещений.

Clipping и рисунок затемнения имеют только верхние круглые углы. Движение внешнего scroll view вверх ограничено нулём, чтобы не открыть зазор; движение вниз для native dismiss сохранено. У внутренней прокрутки отключён bounce в этом режиме, но длинное содержимое продолжает прокручиваться. При возврате к floating layout сбрасываются padding, четыре угла и bounce. Для keyboard sheets и нескольких групп новый режим не применяется.

Не меняются строки и локализации, raw values режимов, persisted keys/defaults, загрузчик, доступность по enabled и callbacks сохранения. Штатные анимации открытия/закрытия, dismiss с фона/свайпа и finished guard сохранены. Тап строки сохраняет один раз; закрытие не выбирает режим.

## Проверки

Stage15 `download_sheet_edge` после `pip_gallery_placeholder`: шесть замен, десять guards, четыре дополнительных точных native input proofs Telegram13.2. Исторические snapshots не меняются. [Manifest](../ios/download_sheet_edge_patches.json), [source receipt](DOWNLOAD_SHEET_EDGE_CHECKS.json).

В debug/`-O` выполняются633 проверки production layout и28 проверок production фабрики/выбора. Есть узкий и большой iPhone, landscape safe placement, tablet viewport, safe area0/21/34, большие измеренные строки, keyboard/multiple-group fallback, повторное использование и запрет нижнего зазора при bounce. Floating frames/content insets сравниваются с настоящими предыдущими production bodies. Пять mutants на режим возвращают нижний зазор, неправильный leading inset, поднимающий панель bounce, четыре угла и повторное сохранение. Отдельный Display module проверяет настоящую public property и SettingsUI caller; private-visibility вариант отвергается компилятором.

UIKit rendering, пиксели верхних углов, VoiceOver и настоящие жесты iPhone этими адаптерами не исполняются. Предстоит физическая приёмка после отдельно разрешённой SDK/IPA-сборки. Проверить светлую/тёмную тему, русский/английский/RTL, большой шрифт, поворот, нижнюю область, выбор обоих режимов и отмену. Новые сборки или публикация релиза этой задачей не запускаются.
