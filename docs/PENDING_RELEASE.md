## Публикация ожидает загрузку файлов

Общий workflow завершился failure после успешного build: job публикации не создан; повтор failed-jobs возвращал HTTP500. GitHub сообщает инцидент Git Operations/Pull Requests/Actions. Проверенный IPA сохранён — повторная компиляция не требуется.

Через GitHub API создан собственный черновик v0.4.5 (release id405895197) с краткой русской аннотацией и target `1c85d9a8fa83edcdbaf5ebc59e9e06a8f50d1051`. Assets отсутствуют: uploads.github.com возвращает HTTP401 Bad credentials, тогда как api.github.com и gh auth status подтверждают учётную запись. Черновик не публиковать без IPA/BUILD-PROVENANCE.txt/SHA256SUMS. Пользователю предложено обновить GH_TOKEN в секретах окружения, только Contents Read/write для этого репозитория; секреты в чат/код не помещать. После обновления загрузить три проверенных файла без clobber, опубликовать prerelease/latest=false, скачать публичные файлы и повторить валидатор. Тег должен указывать на исходный commit сборки, а не последующую документацию.

Устройство: iPhone 17 Pro Max, iOS 27.0, SideStore. Физические результаты новой версии ожидаются. Общий регресс сохранённых функций — по плану. Stable до физической приёмки не заявлять.
