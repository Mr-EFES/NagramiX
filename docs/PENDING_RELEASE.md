# Сборка и физическая проверка 0.4.2

Пользователь разрешил собрать и опубликовать обычный релиз **0.4.2** после исправления штатного оформления и русского default. Единственная ветка — `main`; workflow запускается с publish_release=true и prerelease=false. Успешный IPA этой версии пока отсутствует.

Изменения: убраны изменения темы в defaultPresentationData и фоне экрана настроек NagramiX, исправлено определение системного оформления до создания корневого контроллера. При отсутствии выбранного языка сетевой языковой пакет — ru, development region приложения — ru; русский интерфейс доступен офлайн. Ручной выбор темы/языка сохраняется.

Полное применение overlay к pin прошло; синтаксис Swift/Python/Shell проверен. Определения штатных тем и начального presentation data совпадают с upstream. Другие generated-файлы функций совпадают с предыдущей версией. Это не нативная компиляция или проверка новых сценариев на iPhone.

База — Telegram-iOS 12.9.2, pin 6ad963e5b62d354da79040f388ae2b9132fb17b8; проверка актуальности пройдена. Пользователь сообщил работу всех функций предыдущей версии, кроме оформления. Новые проверки — по [плану](IPHONE_TEST_0.4.2.md): iPhone 17 Pro Max, iOS 27.0, SideStore. Не выдавать прежний IPA за новую версию.
