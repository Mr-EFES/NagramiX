# Подготовка следующей сборки

Целевая версия — **0.4.0**. Опубликованный релиз остаётся **0.3.9**; версия workflow и текущего реестра пока не переключены, сборка не запускается.

В `main` подготовлены изменения для следующей сборки:

- полный русский интерфейс по умолчанию, без автоматического предложения языка iPhone; ручной выбор языка сохранён;
- стандартная Tinted при первом запуске, без перезаписи сохранённой темы;
- поле поиска в настройках капсулой по пользовательскому референсу;
- отмена подготовки первого кружка штатным свайпом, даже до создания состояния записи.

Все эти изменения требуют новой нативной компиляции и проверки на iPhone. Подтверждения пользователя для широких постов и «Выбрать от автора» относятся к установленной сборке; их нужно сохранить при регрессе.

При отдельной задаче подготовки релиза одновременно переключить реестр, workflow, текущие аннотации и README, затем собрать и проверить IPA. Не объявлять будущую версию выпущенной по одному наличию исправлений в коде.

- Иконки главного экрана настроек: «Настройки NagramiX» — штатная шестерёнка Telegram на синей плитке; «Возможности NagramiX» — штатная лампочка на фиолетовой плитке. Пользовательский пазл удалён после проверки ссылок. Переходы и содержимое разделов не менялись. Нативная сборка и проверка на iPhone ожидаются.

- Прокси: включение использования активирует автопереключение; нажатие строки включает и выбирает сохранённый сервер. Исправлен сброс таймера при обычном подключении. За пределами экрана настроек выполняется ограниченная периодическая проверка резервов; свежие доступные серверы выбираются по истечении 15/30/60 секунд.
- DNS: добавлены DoH GET и резервный POST, сериализованы отмена и callback, усилена проверка повреждённых DNS-ответов. Системный DNS остаётся резервом при ошибке DoH.
