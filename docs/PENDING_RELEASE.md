# Сборка и физическая проверка NagramiX 0.4.4

Пользователь разрешил сборку и публикацию новой версии 2026-10-06. Ветка main. Основа — официальный Telegram-iOS 12.9.2, pin `6ad963e5b62d354da79040f388ae2b9132fb17b8`.

Включены совместимость RGB24/ARGB акцентов облачных тем, первый запуск System/Dark, исправление взаимного контакта и все накопленные функции. Штатные палитры/шрифты и ручной выбор пользователя сохраняются. [Краткая аннотация](../product/releases/0.4.4.md), [аудит](THEME_AUDIT.md), [план проверки](IPHONE_TEST_0.4.4.md).

Нативная сборка и публикация готовятся. Перед публикацией workflow проверит версию/build/source/upstream SHA, ARM64, полные русские ресурсы, checksum/provenance и отсутствие временных профилей/подписей. Публикация выполняется как версия для проверки на iPhone, без заявления стабильности. Старые теги/файлы релизов не перезаписываются.

Устройство: iPhone 17 Pro Max, iOS 27.0, SideStore. После получения нового IPA повторить House → Chick → профиль/send и остальные темы, live switch и System/Dark первого запуска. Визуальные результаты ожидаются.
