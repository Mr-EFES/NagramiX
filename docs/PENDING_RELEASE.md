# Сборка и физическая проверка NagramiX 0.4.5

Пользователь 2026-10-07 разрешил сборку и публикацию новой версии с краткой русской аннотацией. Ветка main. Основа — официальный Telegram-iOS 12.9.2, pin `6ad963e5b62d354da79040f388ae2b9132fb17b8`.

Включены только исправление «Выделить от автора», сохранение найденных сообщений для штатного удаления и понятные уведомления. Права Telegram сохраняются; остальные функции не меняются. [Аннотация](../product/releases/0.4.5.md), [анализ](AUTHOR_SELECTION_AUDIT.md), [план на iPhone](IPHONE_TEST_0.4.5.md).

Нативная сборка и публикация готовятся. Workflow проверяет metadata/upstream/overlay, собирает ARM64, проверяет IPA/version/build/source/RU/checksum/provenance и отсутствие временных подписей/профилей до публикации. Новый тег/релиз не заменяют существующие. Версия публикуется как prerelease для проверки, без преждевременного заявления стабильности.

Устройство: iPhone 17 Pro Max, iOS 27.0, SideStore. После получения нового IPA проверить выбор входящих/исходящих, удаление у себя/у обоих, обычные группы/супергруппы с правами и без, старые сообщения и 300+, отмену/ошибку сети/смену чата, пересылку и жалобу. Общий регресс всех сохранённых функций — по плану. Физические результаты новой версии ожидаются.
