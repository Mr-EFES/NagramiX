# Сборка и физическая проверка 0.4.1

Версия разработки — **0.4.1**, единственная ветка — `main`. Пользователь дал команду собрать и опубликовать тестовую версию. Подготовлен запуск workflow с publish_release=true и prerelease=true; успешный IPA и релиз пока отсутствуют. Проект краткой русской [аннотации](../product/releases/0.4.1.md) готов.

Все накопленные правки поиска, архивных сообщений, системной темы и прокси входят в исходники следующего обновления. Прежний опубликованный IPA build 65 их не содержит. Предыдущий релиз сохраняется на GitHub; его артефакт не переименовывать и не выдавать за новую версию.

Workflow проверит pin, выполнит нативную компиляцию, упаковку ARM64 IPA, проверку версии и русских ресурсов, сохранит исходный SHA и SHA-256. Новый релиз разрешено публиковать только с успешно собранным артефактом.

Физические испытания — на iPhone 17 Pro Max через SideStore по [плану](IPHONE_TEST_0.4.1.md); версию iOS получить у пользователя. Успех синтаксических проверок и прежней сборки не подтверждает текущий typecheck, реальную работу таймера, отсутствие всех крашей или нагрузку батареи. Статусы и ограничения — [AI_HANDOFF.md](AI_HANDOFF.md).
