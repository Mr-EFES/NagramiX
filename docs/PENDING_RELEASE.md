# Сборка и физическая проверка 0.4.0

Версия **0.4.0**, сборка **65**, успешно собрана и [опубликована](https://github.com/Mr-EFES/NagramiX/releases/tag/v0.4.0) 2026-10-04. Ветка — `main`. Состав зафиксирован в [аннотации](../product/releases/0.4.0.md).

Нативный workflow сначала проверяет актуальность официальной базы, компилирует и упаковывает неподписанный ARM64 IPA, проверяет версию/bundle ID и русскую локализацию, записывает исходный SHA и SHA-256. Только после успеха разрешена публикация нового релиза с этим артефактом. Существующий релиз не перезаписывается автоматически.

Полную стабильность нельзя объявлять по успешной компиляции. Для проверки нужен iPhone пользователя: модель, версия iOS, способ внешней подписи и фактические результаты сценариев. Инструкция — [IPHONE_TEST_0.4.0.md](IPHONE_TEST_0.4.0.md).

Статусы native build, релиза и тестов отражаются в [AI_HANDOFF.md](AI_HANDOFF.md). Предыдущие подтверждения широких постов и функции выбора автора относятся к прежней установленной сборке; для нового IPA требуется регресс.

Проверенный источник: `a2730925803c2984c1565feef65282cb7ce22347`; запуск [37198280820](https://github.com/Mr-EFES/NagramiX/actions/runs/37198280820). IPA скачан и проверен: версия/bundle ID, ARM64, русские строки, отсутствие временных подписей, SHA-256. Физическая проверка ожидает установки через SideStore на iPhone 17 Pro Max.
