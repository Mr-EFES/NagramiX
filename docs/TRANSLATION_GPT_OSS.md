Пользователь 26 октября 2026 года подтвердил добавление отдельного пункта **«GPT-OSS · Бесплатно»**. Это седьмой переводчик в Прочее → Перевод → Настройки перевода. Прежние названия и порядок Apple, Google, Яндекс, Gemini, ChatGPT, DeepSeek сохраняются. Выбранный ранее переводчик, master/auto OFF, языки и настройки чатов не меняются автоматически.

GPT-OSS 20B работает онлайн через **Pollinations Classic**, без ключа. Получатель текста указан в описании пункта и на странице «Параметры GPT-OSS». Это самостоятельная модель; она не подменяет ChatGPT, Gemini или DeepSeek. У GPT-OSS нет поля ключа, редактируемого имени модели, платного fallback или платежного запроса. Ключи других сервисов не читаются и не передаются посреднику.

В «Дополнительно» появилась страница «Параметры GPT-OSS»: температура 0–2 с шагом 0,1, по умолчанию 0,2. Она хранится отдельно в прежнем optional temperatures; меняет revision, отменяя старые результаты и кеш. Ключевые страницы остаются только у трёх прежних API-нейросетей. Название модели закреплено как gpt-oss-20b; даже произвольное значение в прежнем models не меняет бесплатную модель.

## Запрос и очередь

Используется документированный POST `https://text.pollinations.ai/openai`: весь массив фрагментов одного задания передаётся JSON в теле, вместе с отдельной инструкцией перевода и выбранной температурой. Текст и ключи не помещаются в URL. Сохраняются ephemeral URLSession, отсутствие cookies/дискового кеша, запрет redirects, ограниченные очередь и memory cache, account/revision scope и отмена через прежний runtime.

Сервис разрешает один текстовый запрос на IP не чаще раза в 30 секунд. Общий клиент сериализует GPT-OSS между всеми аккаунтами и выдерживает интервал между началами запросов. Ожидающая задача не занимает активный HTTP-слот другого переводчика. Ожидание использует отменяемый асинхронный wake, без sleep на main. Deadline запроса начинается после ожидания бесплатного интервала. При активном автопереводе нескольких сообщений ожидание может быть заметным; лимит указан на странице параметров.

HTTP 402/429 возвращает ошибку квоты и откладывает следующие задачи по Retry-After (число секунд или HTTP-date, от 30 секунд до часа). Отказавшая задача автоматически не повторяется, оплата/другая модель не включаются. Отмена, master OFF или смена revision удаляют неразрешённые задания; уже готовый кеш не требует нового сетевого запроса.

Принимается только полный JSON translations ожидаемой длины, finish_reason=stop и ответ именно модели gpt-oss-20b. Рассуждения и служебные поля не показываются. Неполный, пустой, HTML или ответ другой модели не записывается. Прежние защищённые entities, исходный текст и Postbox metadata сохраняют общий контракт перевода.

Публичные источники: [Pollinations Classic API](https://github.com/pollinations/pollinations/blob/master/APIDOCS.md), [каталог бесплатной модели](https://text.pollinations.ai/models). Это бесплатный сервис с ограничениями, а не гарантия доступности из любой сети или безлимитный API.

## Исходники и проверка

Новая последняя стадия `translation_gpt_oss` после `translation_free_modes`: пять точных замен, 23 SHA/BUILD/исходных guards, пять templates. Все входы, пути и выходы проверяются до записи. Ранние stages/templates не переписываются. SettingsUI меняет только поисковое описание перевода, чтобы GPT-OSS/Pollinations находились поиском в «Прочее»; stable IDs и группа прежние.

`scripts/validate_translation_gpt_oss.py` проверяет точное применение, повторное применение, drift/missing/templates/hash/path без частичной записи. Для старых source validators восстанавливаются точные предыдущие SHA, неизвестные входы не обходятся. В debug/O исполняются production settings/codec/client и весь runtime с явными границами HTTP, Apple ML, signal/Postbox и Keychain lookup. Часы квоты подаются как граница, базовые 30 секунд не сокращаются для положительных тестов. Отрицательный вариант без интервала должен падать.

Локально пройдены на каждый режим: 50 новых codec/queue/quota/model проверок, 7 actual GPT-OSS runtime и 240 предыдущих free/policy/runtime/routing — всего 297. Негативный вариант без 30-секундного интервала отвергнут в debug и O. Живой production Swift URLSession/CloudCodec/CloudClient получил [Привет, мир., Спасибо!] для нейтральных [Hello world., Thank you!] без ключа, модель gpt-oss-20b, 26 октября 2026 в 23:00 МСК.

Доказательства: `/workspace/.codex-validation-nagramix-gptoss/` — verification.json, behavior.log, live.json и полная композиция. Эти проверки не являются Apple SDK-компиляцией, реальной проверкой Keychain/TranslationSession/UIKit или тестом на физическом iPhone. Новая SDK/IPA139 опубликована по отдельной команде пользователя; физическая приёмка ожидается.

Полная чистая композиция и 21 source validator PASS: 314 модифицированных native файлов, 5 изменений относительно предыдущей free-цепочки, остальные 309 прежних модифицированных native побайтно сохранены. Swift parse и SHA исполнявшихся production helpers совпадают с итоговой композицией. 72 некорректных входа отклонены без частичной записи.
