## Поведение

Текущая раскладка — единая сетка4×3: десять прежних команд и две дополнительные занимают равные ячейки. «Выносная цитата» находится под «Датой», «Выделить всё» — под «Зачеркнуть». Отдельные широкие кнопки выпуска122 заменены по утверждённому макету. При крупном шрифте число столбцов адаптируется; подписи однострочные, прокрутка внутри прежней внешней высоты.

«Выделить всё» доступно при непустом вводе без предварительного выделения. В обычном редакторе выбирается полный UTF16-диапазон. В новом редакторе вызывается штатный `RichTextEditorView.selectAll()` с полным структурным диапазоном документа: плоский attributedText не записывается, таблицы, вложения и оформление не пересоздаются.

«Выносная цитата» использует штатные `.pullQuote`/`makePullQuote()`, отдельно от обычной цитаты. В чате нужны выделение, нативный rich backend и отсутствие ограничения секретного чата — как в его штатном меню. Старый текстовый backend не поддерживает эту структуру, поэтому кнопка там недоступна. Активность читается из штатного `EditorState.isPullQuote`. Все команды повторно проверяют состояние в момент нажатия.

В расширенном `RichTextAttachmentScreen` кнопка Aa находится непосредственно перед эмодзи, когда эмодзи присутствует в штатной панели. При выделении текста кнопка форматирования также остаётся доступной среди действий. Цвет берётся из той же штатной ветки action bar; активный режим показывает клавиатуру без отдельной цветовой подсветки. Добавлена подпись VoiceOver.

Верхние углы панели скруглены на30pt, как фон штатной панели эмодзи. Высота и положение форматирования берутся из результата того же `ChatEntityKeyboardInputNode.updateLayout`, который использует панель эмодзи. Для измерения узел скрыт, его видимые анимации отключены; при готовности данных высота обновляется. Пока данные эмодзи ещё не готовы, используется стандартная высота устройства. Оба режима используют один нижний inset/editor scroll obstruction и штатное скрытие нижней панели вложений. Переключение между ними атомарное: placeholder остаётся, промежуточный layout с пустым режимом не отправляется. Возврат к клавиатуре очищает только свой inputView; устаревшее завершение скрытия проверяет поколение перехода. Наблюдатель настроек удаляется при освобождении экрана.

Checkbox и ключ `nagramix.messages.quickFormatting` прежние: absentOFF, сохранённые ON/OFF не сбрасываются. Без выделения стили недоступны, исключение — новая команда выбора всего. Ссылка открывает прежний диалог. Дата по-прежнему недоступна в нативном rich backend, где у базы Telegram нет её реализации.
