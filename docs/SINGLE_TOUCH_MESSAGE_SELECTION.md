# Выделение сообщений протягиванием одним пальцем

Владелец подтвердил две особенности жеста: начало на отмеченном сообщении только расширяет выделение; обратный ход снимает только отметки, добавленные текущим жестом. Прежние отметки сохраняются. Видеопример `-6199446643273163293.mp4` использован для анализа жеста; содержимое переписки и кадры в репозиторий не включены.

В открытой переписке сначала включается штатное выделение через меню сообщения. Затем вертикальное протягивание одним пальцем в колонке галочек выделяет диапазон. При удержании у верхнего или нижнего края работает существующая прокрутка истории. После отпускания результат остаётся отмеченным. Обратное движение сокращает добавленный диапазон, переход через начало продолжает его в противоположную сторону. Повторное протягивание запоминает уже выбранные сообщения как исходный набор.

Распознаватель включается только в режиме выделения, в колонке шириной44pt с учётом safe area и доступной высоты. В остальных местах он отказывается от касания сразу; горизонтальное движение также освобождает жест. Обычное нажатие на галочку и штатный двухпальцевый распознаватель сохраняются. Новый распознаватель находится на настоящем scroll-pan host обоих backend; зависимость штатного однопальцевого scroll pan от его отказа предотвращает одновременную прокрутку и выделение.

Диапазон определяется индексами всех загруженных строк, включая промежуточные сообщения при быстром движении. Позиции остаются в кеше до завершения жеста при смене подгруженного окна. Альбом — единая строка с набором ID; служебные события не выбираются. При попадании в небольшой промежуток между строками используется ближайшая доступная строка. Реальные координаты получает backend `itemNodeFrame`, включая CoreList. Применение идёт через прежний `toggleMessagesSelection`, сохраняющий правила логических постов и права действий.

Существующий двухпальцевый алгоритм и edge-autoscroll сохранены точно: область50pt, активация0,45с, ограниченная скорость и обновление диапазона через кадр. Для нового жеста остановка, отмена, отключение жестов и выход из режима выделения очищают его состояние, таймер и display link. Транспорт, read receipts, геометрия сообщений, настройки, UI выделения, удаление, пересылка и список чатов не изменяются.
