# Скрытие приветственного стикера

Подготовлено после опубликованного №83 для NagramiX 0.5.1. Нативная сборка и физическая проверка ожидаются.

## Реализация

«Скрывать приветственный стикер» — Интерфейс / Чаты, с пояснением и поиском. `nagramix.interface.hideGreetingSticker`: true только при отсутствии значения; сохранённые ON/OFF не перезаписываются на старте. Новые stable IDs126/127 не меняют старые.

После штатной классификации ChatEmptyNode заменяет greeting обычной regular-надписью Conversation_EmptyPlaceholder. Не создаётся greeting renderer, не запускаются его подписка и media fetch, скрыт attached business footer. Штатные шрифт, цвет и геометрия обычной надписи сохранены. Другие служебные состояния и явный customGreeting редактора business-приветствия остаются прежними. Weak settings observer обновляет уже открытый пустой чат; observer удаляется в deinit.

Отдельный PrefetchManager также проверяет настройку перед randomGreetingSticker и загрузкой файла. При включении отменяет текущую greeting-загрузку и очищает её promise; обычная предварительная загрузка медиа не меняется. Выключение возобновляет greeting. Если сохранённый preload-сигнал возвращает nil после прежней отмены, native renderer использует штатный randomGreetingSticker, поэтому обратное переключение не оставляет пустую картинку. Эта настройка относится к автоматическому приветствию пустой переписки, а не к явно открытому редактору собственного business-приветствия или стикерам сообщений.

## Проверки

Исходные ChatEmptyNode.swift, его BUILD и PrefetchManager.swift получены с pinned Telegram 13.0 и проверены по Git blob SHA. Последний helper проверяет три full SHA256 и13 якорей до записи. Полный overlay на356 audited inputs даёт420 outputs; относительно VPN proof с добавленными stock inputs412 файлов сохранены побайтно,8 изменены.13 замен reverse exact;6 drift +1 rerun отклонены до мутаций.5 Swift grammar деревьев без ошибок. Старые RU/EN значения, stock классификация, другие empty реализации и обычный media prefetch сохранены. Прежние семь подготовленных задач не изменены.

Нет Apple SDK/Xcode: эти проверки не являются нативной компиляцией, проверкой сетевых запросов, UIKit или доказательством отсутствия крашей.

## Физическая проверка после новой сборки

1. Чистая установка: checkbox ON; открыть пустой личный чат с обычным пользователем и с business-приветствием — только штатная надпись, без стикера, заголовка/текста/подписи business-карточки.
2. Выключить: обычный стикер или business-приветствие возвращается; перезапустить холодным запуском — OFF сохранён. Включить и перезапустить — ON сохранён. Обновление сохраняет оба значения.
3. Включить во время медленной загрузки: приветствие скрывается, загрузка отменяется. Выключить снова без выхода из чата: стикер появляется даже после nil preload. Проверить несколько быстрых переключений, уход/возврат приложения и два аккаунта.
4. Проверить отсутствие greeting file fetch на холодном старте с ON и при открытии нескольких пустых чатов. Обычные стикеры/медиа истории продолжают загружаться согласно прежним настройкам.
5. Боты, удалённые/заблокированные аккаунты, группы, темы, секретные чаты, Избранное, scheduled/premium/stars экраны и явный редактор business-приветствия сохраняют штатную механику. Уже непустой чат не меняется.
6. Узкий экран, крупный шрифт, RU/EN, светлая/тёмная тема и VoiceOver: название переносится полностью, чекбокс и описание доступны. При краше сохранить журнал iOS.
