# Видимость Telegram-переводчика по подписке

Уточнение пользователя: в настройках NagramiX вариант перевода через Telegram показывать только при активном Premium текущего аккаунта. Это продуктовый выбор для данного списка, не утверждение об отсутствии перевода отдельных сообщений в бесплатном Telegram.

После `translation_inline_telegram` применяется guarded-stage `translation_premium_visibility`. Он меняет только `NagramiXTranslationPreferences.swift`: одна точная замена, guard TranslateUI BUILD, все prechecks до записи. Предыдущий этап сохранён неизменным входом.

При подтверждённом Premium показываются группы «ПЕРЕВОД», «TELEGRAM», «СЛОВАРИ», «ИСКУССТВЕННЫЙ ИНТЕЛЛЕКТ». Без Premium и до получения статуса остаются три группы, без пустого заголовка, заблокированной строки, предложения подписки и текста проверки. Подписка на EngineData уже относится к контексту текущего аккаунта; изменение статуса вызывает reloadData. Скрываются и заголовок, и строка.

Видимые индексы преобразуются в прежние логические IDs для числа строк, заголовков и выбора сервиса. Поэтому после скрытия Telegram первая строка словарей остаётся Apple, затем Google/Яндекс; выбранная нейросеть по-прежнему раскрывает собственные настройки. Ключи, модели, Save, температура, target/исключения, inline-перевод и серверная проверка Premium не меняются. Старый выбор Telegram не подменяется другим облачным сервисом при истечении подписки.

Source-проверка проверяет точные снимки и неизменность обработчиков, семь missing/drift/template/reapply случаев без частичных записей и reverse предыдущей цепочки. Добавлен boundary-suite с извлечёнными реальными методами production для семи выбранных провайдеров и статусов nil/false/true, включая появление и исчезновение группы. Swift compiler в среде отсутствует: suite не исполнен; синтаксис production, шаблона теста и сгенерированного harness проверен tree-sitter. SDK/UIKit/iPhone ожидают отдельной команды на сборку. Доказательства: `/tmp/nagramix-translation-premium-validation.log`, итоговое дерево `/tmp/nagramix-media-composed`. Actions/IPA/публикация/commit/push не запускались.
