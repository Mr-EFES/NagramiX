# Единая видимость вкладок и меню скрытия

Владелец подтвердил: «Скрывать “Контакты”» и «Скрывать “Звонки”» включены — вкладки скрыты; выключены — видны. «Показывать “Поиск”» имеет прямую полярность: включён — отдельная круглая кнопка справа видна. Удержание элемента открывает меню скрытия и меняет тот же сохранённый переключатель. Вернуть элемент можно через «Интерфейс → Панель вкладок». Это действует при широкой и штатной панели; настройка ширины сохраняет прежнюю геометрию.

## Причины и исправление

В Telegram13.2 «Контакты» стали преимущественно отдельным экраном поверх настроек. Старый root сохранял только слабую ссылку, которая могла исчезнуть после скрытия вкладки; отдельное открытие контактов также заменяло эту ссылку. У контроллера не было значка и подписи вкладки. Теперь root отдельно удерживает контроллер вкладки; обычный экран контактов и его API сохраняются. Новый аргумент `isTab` по умолчанию false. Для вкладки используются прежний ресурс `Chat List/Tabs/IconContacts` и штатное локализованное название; только в этом режиме убирается действие «Назад» отдельного экрана. Смена языка обновляет подпись. Скрытие/возврат и мягкий перезапуск сохраняют экземпляр вкладки.

Штатное меню звонков меняло `CallListSettings.showTab`, а root уже выбирал вкладки по ключам NagramiX и игнорировал этот аргумент. Теперь корневой TabBarController делегирует меню «Контактов» и «Звонков» root. Сохранены два пункта звонков, их значки и оформление ContextUI. «Начать новый звонок» вызывает тот же `beginCallImpl` через штатный `tabBarActivateSearch`; скрытие меняет `NagramiXTabSettings.hideCalls`. Контакты меняют `hideContacts`. Другие вкладки и экземпляры TabBarController сохраняют native context-action fallback. Старый штатный флаг не получает приоритет над переключателем NagramiX; его хранилище/кодек не меняются.

Круглая кнопка поиска получает удержание и VoiceOver-действие, открывающие «Скрыть поиск». Оно записывает `showSearchButton=false`. При активном текстовом поиске этот жест выключен; на прочих экземплярах поиска callback отсутствует. Обычный tap и закрытие поиска прежние. Callback и заголовок входят в сравнение Search, действующий callback берётся при обновлении. Устаревшее меню после замены корневой панели не меняет настройки.

Открытые настройки теперь подписываются на прежнее уведомление `NagramiXSettingsChanged`. Они отражают изменения из меню без повторного открытия, сохраняя прежний ValuePromise для явного обновления вычисляемых настроек. Подписка и observer снимаются при закрытии. Удаление выбранной вкладки использует прежний переход в «Чаты» по identity; другие выбранные вкладки, новости и маршруты поиска сохраняются.

Ключи, defaults, stable IDs, UI переключателей и сохранённые ON/OFF не меняются. Начальные скрытые контакты/звонки и выключенный поиск остаются прежними. Широкая панель не меняется вместе с видимостью.

## Воспроизводимость и проверки

Стадия103 `tab_visibility_sync` после `round_video_encoding`:8 Swift-файлов и71 каталог,22 guards,180 новых `.inc` и один реестр переводов. Два новых действия переведены во все71 языка; прежние678 значений сохранены, итог680. IPA0.9.8 сохраняет контракт678; новые680 обязательны начиная с0.9.9, включая короткие1.0/1.1. Тег, опубликованная IPA219 и её файлы не изменяются.

Новый вход ContactsControllerNode побайтно сверён с официальным Telegram13.2 на pin `24638bc69bd083981b178dd1e7f921eebbf7fc46`, Git blob `c3965b20e4feca3be390b0d62b0d09efb581a87d`. BUILD и allowlists не расширяются. Предыдущие планы и снимки остаются неизменными; все60 исторических manifest восстанавливаются из текущего полного дерева и checkpoint.

[Проверки](TAB_VISIBILITY_SYNC_CHECKS.json) исполняют реальные Foundation-модули Core/media, SwiftSignalKit и извлечённые тела фильтрации, владения, меню, fallback, подписки настроек и жестов. UIKit, навигация, показ/закрытие меню и создание неизменённых контроллеров — явные IO-границы. Проверяется также ранний путь через настоящий canonical_projection/CheckCollection; для103 он включает точные71 каталога. Будущий macOS gate проверяет реальные UIKit selectors/регистрацию жеста и Search-модель; это не полная компиляция приложения. На Linux Apple API, пиксели и iPhone не проверялись. SDK/Actions/IPA по прямому запрету владельца не запускаются.

Приёмка на телефоне после отдельно разрешённой сборки: все16 сочетаний ширины/контактов/звонков/поиска; скрытие удержанием из выбранной и невыбранной вкладки, возврат переключателями, перезапуск приложения и панели, отдельные контакты из настроек, обычный tap поиска, активное поле, VoiceOver и смена языка. Сохранить штатные меню «Чатов»/«Настроек», новости и корректный выбранный экран.
