# Название Premium-переключателя без аннотации

**Уточнение владельца:** итоговое название — «Скрыть рекламу Premium». Оно применяется последующей стадией `premium_label_spelling`; аннотация остаётся скрытой. [Проверки уточнения](PREMIUM_LABEL_SPELLING_CHECKS.json).

По команде владельца русское название в «Интерфейс → Чаты» заменено на «Вскрыть рекламу премиум» — дословно из сообщения. Пояснение «Без баннеров о подарке, покупке и продлении Premium над списком чатов» больше не передаётся в строку переключателя.

Стадия `premium_label_cleanup` идёт после `poll_copy_transport`: две точные замены, пять guards, девять новых `.inc`. В SettingsUI удалён только аргумент `text`; в русском ресурсе заменено только значение существующего ключа. Новых ключей нет. Остальные 70 ресурсных каталогов, механизм скрытия предложений, начальное ON, сохранённый OFF, callbacks, поиск и высота штатной строки прежние. Ресурс пояснения оставлен для совместимости и поиска, в строке он не показывается.

Существующие проверки обратимости/SHA, парсер Swift, проверка custom members и строгая локализация выполняются перед SDK. Контракт IPA сохраняет точные опубликованные каталоги 0.9.2; новое название применяется к 0.9.3 и последующим версиям. Подробные результаты — [PREMIUM_LABEL_CLEANUP_CHECKS.json](PREMIUM_LABEL_CLEANUP_CHECKS.json).

Правка исходников предназначена для main. Новая Apple SDK-сборка и проверка на iPhone не выполнялись; статус `compile_pending/device_pending`. Опубликованная 0.9.2/build193 не меняется, следующая сборка 0.9.3 — только по отдельной команде.
