# История выпуска0.5.7

Тестовый выпуск со всеми накопленными правками после0.5.6/build92.

- Последний согласованный список названий переключателей, полные переносы и правильные цветовые названия иконок. Идентификаторы и сохранённый выбор прежние.
- «Свайп для записи» историй absent OFF; ON разрешает запись жестом. Сохранённый выбор не сбрасывается.
- «Двойной тап для правки» absent ON; ручной OFF сохраняется после перезапуска.
- «Показать рекламу» absent OFF скрывает sponsor proxy и встроенные Telegram ads; ON возвращает штатную рекламу. Обычные посты администраторов не фильтруются.
- Ранний PiP коротким свайпом и непрозрачный фон во время жеста; сохранены защита времени жизни источника и исправление повторных поворотов.
- Меню чата: «Репост» с автором, «Переслать» без автора и «Рассылка» нескольким адресатам. Названия переключателей этих функций прежние.
- Согласованные иллюстрации первого запуска одинакового масштаба и с полями, без обрезания соседними ячейками. На странице «Бесплатно»: «Наши функции — без подписки».
- Крупный смартфон на вводе номера по последнему референсу; адаптация под системную клавиатуру и сохранённая нативная авторизация.

Все предыдущие исправления записи/таймера селфи/музыки, удаления с полным именем, поиска, архивных медиа и видео сохраняются. База Telegram13.0, минимальная iOS15.0. Для unsigned ARM64 IPA нужна внешняя подпись. Физические сценарии и плавность на iPhone проверяются отдельно от компиляции.
