# Единые значки историй

Актуальный результат: эта правка вошла в0.7.5/build134/sourcefe620c5f7c2463882455d1609622779db8b3239c. SDK и публичный IPA проверены; физическая приёмка ожидается. Ниже описан также предшествующий этап source-проверок. Подробности — [RELEASE_STATUS](RELEASE_STATUS.md).

По скриншоту физического теста глаз у «Засчитать просмотр» был чёрным среди белых значков. У него использовался отдельный путь SF Symbol с withTintColor/alwaysOriginal. Теперь символ глаза или галочки сначала растеризуется в UIImage, затем окрашивается через тот же generateTintedImage и theme.contextMenu.primaryColor, что штатные пункты меню. Отдельная принудительная схема цвета для этого пункта удалена; жёсткий белый для меню не задаётся, чтобы сохранить тему.

Верхняя кнопка сохранения использует ровно тот же asset Chat/Context Menu/Save, что «Сохранить в галерею»: стрелка вниз в кружке, исходный24×24. Цвет верхней кнопки остаётся белым. Её44×44 область нажатия, координаты, отступы, порядок, accessibility, disabled/progress alpha и действие сохранения не меняются.

Последний guarded stage story_icon_consistency после story_download_quality: один Swift-файл, две точные замены; guards StoryContainerScreen BUILD и Contents/PDF общего значка. Старые шаблоны и guards не переписываются. Проверки явного просмотра/качества сохранения учитывают только точный SHA новой стадии и обратимо восстанавливают свои прежние результаты для проверки. Скачивание, HQ, права Фото, инкогнито и RPC не меняются.

Проверки: validate_story_icon_consistency, полная чистая overlay-цепочка с прежними валидаторами, метаданные и Swift parse. Новый UIKit-результат и новая SDK-сборка пока не проверены. Это исходники после исходного коммита сборки132; не выдавать их за содержимое уже запущенного IPA. На iPhone проверить обычное и тёмное меню, pending/recorded состояния и верхний бар на фото/видеоистории; все активные значки должны совпадать по цвету, круглая стрелка должна совпадать с меню.
