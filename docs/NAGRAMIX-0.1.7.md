# NagramiX 0.1.7 — описание тестовой версии

Файл сборки: `NagramiX-0.1.7-unsigned.ipa`.

Сборка не подписана сертификатом Apple и предназначена для последующей подписи и установки через SideStore или совместимый сервис.

## Изменения

- Причиной неверного масштаба основной иконки №1 был отдельный путь Icon Composer, тогда как иконки №2–8 подключались обычными PNG-наборами.
- Основная иконка №1 переведена на тот же набор PNG-ресурсов, что и семь корректно работающих альтернативных иконок.
- Все восемь наборов содержат полный комплект квадратных RGB-ресурсов без альфа-канала, а системную маску и скругление применяет iOS.
- Для скрытия имён вкладок добавлено подтверждение и безопасное пересоздание панели вкладок без завершения процесса приложения.
- Добавлена секция «КРУГЛЫЕ ВИДЕО» с настройкой «На заднюю камеру».
- Добавлена секция «ИСТОРИИ» с четырьмя независимыми переключателями.
- Ленту историй можно скрывать без удаления историй и без отметки их просмотренными.
- Свайп, запускающий запись истории, можно отключить отдельно от остальных жестов списка чатов.
- Перед просмотром чужой истории можно включить подтверждение.
- Штатное действие Telegram «Репост в историю» можно показывать или скрывать без обхода ограничений приватности.
- Русские и английские подписи NagramiX вынесены в отдельный ресурсный пакет локализации и выбираются по активному языку Telegram.

## Значения по умолчанию

- Вкладки «Контакты» и «Звонки» скрыты.
- Подписи вкладок отображаются.
- Отдельная кнопка поиска скрыта.
- Круглые видеосообщения начинают работу с задней камеры.
- Все настройки историй выключены.

## Ограничения тестирования

Полная проверка камеры, системного кэша иконок, всех точек открытия историй и установки IPA выполняется на физическом iPhone после получения сборки.
