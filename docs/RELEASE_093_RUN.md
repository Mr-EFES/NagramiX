# Выпуск NagramiX 0.9.3

Владелец разрешил чистую SDK-сборку, исправления подтверждённых ошибок и повторные попытки той же версии до успешной проверки IPA и обычной публикации от Mr-EFES. Следующий новый выпуск после успеха потребует новой команды.

Источник подготовки — main после `f2db7bc407d75201b4738c76a71a657dbbd0fe7c`, все 32 поздние стадии. Новые изменения после опубликованной 0.9.2/build193: единый штатный плеер кружков и дымка, самостоятельные копии опросов с вложениями и обновлением медиассылок, строка «Скрыть рекламу Premium» без аннотации, стабильный фон и клиентские границы PiP. Соответствующие контракты и проверки сохранены в репозитории.

Owner Mr-EFES и public подтверждены API. Официальная база Telegram13.2 актуальна, pin `24638bc69bd083981b178dd1e7f921eebbf7fc46`; Xcode27.1, iOS15+/ARM64. README, старые теги и опубликованные файлы сохраняются. Ресурсных каталогов 71 по635ключей; это не число официальных языков Telegram.

Перед dispatch сверяются исходные SHA последних проверок, вся цепочка стадий, метаданные, режим чистой сборки, owner publisher и точные IPA-каталоги 0.9.3. Параметры: main, пустой artifact_run_id, clean_build=true, extended_patch_tests=false, publish_release=true, prerelease=false. Необязательные исторические тесты остаются выключенными по прежнему распоряжению владельца; обязательные guards/source/Swift/SDK/IPA gates сохранены.
