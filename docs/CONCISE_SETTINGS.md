# Краткие настройки NagramiX

Предыдущая реализация прошла нативную сборку№86; новая версия0.5.4 проходит отдельную сборку, физическая проверка ожидается. [Текущий статус](RELEASE_STATUS.md). Физические сценарии остаются непроверенными.

По запросу пользователя из вкладок Интерфейс / Функции / Прочее убраны25 поясняющих строк. На странице «Ссылка на профиль» убраны два справочных footer, в прокси — пояснение VPN (включая текст о временном обходе) и штатная справка использования для звонков. Заголовки верхним регистром, переключатели, кнопки, числовые значения, conditional rows, native glass темы/шрифты/отступы/разделители и поиск сохраняются. Пустые строки вместо аннотаций не создаются.

Актуальные короткие подписи всех45переключателей утверждены16октября2026: [полный список](SETTINGS_LABELS_COMPACT.md). Предыдущий список34переименований заменён в трёх основных вкладках. Все45строк штатно переносят длинный текст, поиск использует те же названия. «Музыка при записи» и «Автопереход голосовых» сохранены. «Свайп для записи» теперь положительный: ON разрешает жест, OFF запрещает; первая установка OFF, сохранённый выбор не сбрасывается. Хранение остаётся обратным через legacy key. Остальные функции, шрифты, темы и действия прежние. Новые подписи и положительный checkbox: source_checked/native_compile_pending/device_pending; готовый build92 их не содержит.

Справочные локализации сохранены для поиска и возможных будущих tutorial-страниц; новая страница «О NagramiX» сейчас не создаётся. Подтверждения просмотра истории/операций, пояснения в отдельных панелях выбора, ошибки ввода и недоступности профиля, реальные connection/ping статусы не затрагиваются.

## Проверка исходников

Clean overlay на audited Telegram13.0: `/tmp/nagramix-051-concise-settings-proof`,432 outputs. Относительно предыдущего profile-link proof427 файлов побайтно прежние; изменены только root settings UI, profile-link UI, native proxy UI и RU/EN. `/tmp/nagramix-validate-concise-settings.py` подтверждает точное удаление25+2+2 footer entries, сохранение всех заголовков/контролов/поиска и только шести изменённых строк заголовков в каждой локали (название «Скрыть реакции» уже было кратким). Три Swift grammar дерева без ошибок. Политика VPN, callbacks, model/defaults и runtime media/core код прежние.

compile_passed/device_pending: Нативные типы проверены компиляцией№86; реальная геометрия текста на устройстве ещё не проверена. При приёмке build86 проверить все три вкладки, поиск по прежним терминам, прокси и страницу ссылки; обычный и увеличенный текст на узком iPhone, светлую/тёмную тему, отсутствие наложения текста и переключателей. Шрифт не уменьшать, не обрезать текст ради одной строки; native перенос остаётся запасным вариантом при увеличенном системном размере. Правка включена в проверенный build86; новая сборка без отдельной задачи не требуется.
