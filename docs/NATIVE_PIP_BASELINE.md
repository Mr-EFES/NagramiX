# Штатный PiP Telegram 13.1.2 и быстрый свайп

**Позднее согласованное исправление R3:** [команды воспроизведения](PIP_PLAYBACK_COMMANDS.md). После `round_caption_transport` стадия `pip_playback_commands` заменяет только `setPlaying`: прямые play/pause вместо toggle. Остальной native controller, вход, возврат и свайп прежние. Описанные ниже exact native snapshots остаются неизменяемой исторической базой; validator проверяет их после точного снятия поздней стадии. Compile/device pending.

Владелец утвердил восстановление штатного PiP Telegram iOS 13.1.2, включая механизм, окно, вход и возврат. Единственная доработка — ускоренный свайп вверх через тот же обработчик, что и кнопка PiP. Эта задача заменяет прежние требования к собственным readiness/geometry/restore надстройкам. Новая SDK/Actions/IPA-сборка, commit/push и публикация не разрешены этой командой и не выполняются.

## Реализация

Поздняя стадия `native_pip_baseline` применяется после `copy_delivery`. Четыре replacements и 30 точных guards проверяются до первой записи. Исторические canonical стадии сохраняются: новый этап обратимо заменяет их окончательный результат, а старые валидаторы снимают его только по точным SHA.

Официальный pin — `279f89e4d4f63f17227bf877dc3d8990f22ecd58`, версия 13.1.2. Четыре исходных файла из его архива сохранены в `ios/native_pip_baseline/Native*.inc` с SHA. Тринадцать полных блоков сверяются побайтно: native AVKit controller с playback delegate, setup, кнопка, expand, centrality, visibility, controls visibility, placeholder, swipe-down, штатный overlay helper и callbacks галереи. Native параметры, тайминги входа/возврата, источник sample-buffer, current owner и системные callbacks перенесены без собственных изменений. `GalleryControllerNode` совпадает с исходником после удаления только helper и ветки быстрого жеста; `GalleryItemNode` — после удаления только свойства допуска жеста.

Из переходов убраны собственные очереди готовности, фиксация центра/геометрии, дополнительные маски, chrome-анимации и отложенные проверки возврата. Инициализация, запуск и возврат теперь принадлежат штатному механизму. Отдельный AVPlayer, новый decoder, скачивание полного видео и альтернативный плавающий плеер не добавлены.

При отпускании намеренного вертикального свайпа вверх shortcut допускается от 32 pt либо от 8 pt при скорости 0.35 pt/ms. Горизонтальная составляющая не должна преобладать; разворот вниз, неверные/нечисловые значения и малые движения shortcut не запускают. Обработчик вызывает `pictureInPictureButtonPressed()`, включая его штатный setup и dispatch, поэтому первый свайп не зависит от предварительного нажатия кнопки. Штатный автоматический запуск, готовность AVKit и допустимость native источника не заменяются собственным алгоритмом.

Сохранённый `nagramix.video.pipSwipe` и его default true не меняются: OFF отключает shortcut, кнопка остаётся штатной. Сохраняются killswitches и ограничения источника. При ON явный жест PiP вызывает кнопку независимо от server default `video_swipe_up_to_close`; это относится только к добавленному shortcut. Свайп вниз и штатный rebound/закрытие галереи сохранены.

Независимые функции приложения остаются прежними: Free Content/capture policy, архив и временные сообщения, фоновые настройки, поворот, меню сохранения и все предыдущие `copy_delivery` outputs. Адаптация захвата и маски сохранённых кружков не переписывается ради PiP. Штатные `ZoomableContentGalleryItemNode` и `GalleryVideoDecoration` уже совпадают с pin; у `GalleryPagerNode` отличие только в завершающей пустой строке.

## Проверки

`validate_native_pip_baseline.py` запускается первым в workflow. Он проверяет frozen native snapshots, 13 полных исходных блоков, сохранность зависимостей и guard-only отказ до записи. В Swift debug и `-O` проходят по 37 проверок: первый ready button/swipe, один native handler, короткий flick, повторный вход после остановки, общий source layer, штатный owner, вход/возврат и видимость, отключённый shortcut, killswitches/форматы, неверные направления/разворот, rebound, native readiness и удаление оригинала. Пять отрицательных вариантов на режим воспроизводят отдельный swipe entry, прежний длинный порог, реакцию на разворот вниз, игнорирование OFF и невидимый возврат. 78 fail-closed сценариев отвергают drift, пропуски, неверный manifest, unsafe paths, повтор и внешние symlinks. Полные четыре Swift-файла проходят frontend parse.

AVKit/UIKit, сигнальная доставка, окно, навигация и animation clock — явные тестовые границы. Эти проверки не подтверждают физическую плавность iOS, допустимость PiP для любого формата или запуск до готовности AVKit. Сравнение анимаций на iPhone выполняется после отдельно разрешённой сборки. Registry `video_pip_swipe`: `compile_pending/device_pending`. Версия, pin, README, LICENSE и опубликованная 0.8.8/175 не меняются.

Совместимость с предыдущими исходными этапами проверена без ослабления их SHA: `copy_delivery` — 216 checks и 11 отрицательных вариантов в каждом режиме, 132 fail-closed; прежний `pip_transition_geometry` — 166 checks и 11 отрицательных вариантов в каждом режиме, 66 fail-closed. Обратное снятие поздних стадий выполняется только для исторических тестов. В итоговом приложении остаётся новый штатный PiP.

Чистая композиция из официального архива и legacy-входа прошла все 619 owned paths, затем точный завершающий post-port семи файлов и штатный PostboxImportCheck. Независимое сравнение всех 33 964 файлов с предыдущим copy gold выявило ровно четыре ожидаемые замены GalleryUI; остальные файлы, включая copy/temporary/ASR/архив, побайтно прежние. Native*.inc отдельно сверены с байтами официального tar-архива. Strict localization без исключений: 71 язык × 613 ключей, 112 файлов настроек/debug и 594 обращения, новых UI-строк нет. Метаданные, Python AST и `git diff --check` прошли.

Рабочая pre-post проекция: `/tmp/nagramix-native-pip/working`; чистая итоговая композиция после post-port: `/tmp/nagramix-native-pip/fresh`. Доказательства и актуальный статус — `validation.json`, `prior-copy.json`, `prior-pip.json`, `composition.log`, `fresh-prefix-projection.json`, `official-native-snapshot-proof.json`, `native-animation-dependencies.json`, `final-source-proof.json`, `final-source-hashes.json`, `checked-artifact-hashes.json`, `task-state.json` рядом. Stage validators запускаются на pre-post входе; после завершающего post-port используются его точные output SHA и import checker, а не ослабляются старые guards.
