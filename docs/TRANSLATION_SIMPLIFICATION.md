# Согласованный переводчик

Следующий согласованный этап — [Telegram Premium и inline-перевод](TRANSLATION_INLINE_TELEGRAM.md). Он добавляет четвёртую Telegram-группу над словарями и перевод отдельного текста прямо в пузыре; описанная ниже стадия сохранена точным входом SHA-цепочки.

28 октября пользователь утвердил обновлённый референс и разрешил кодирование. Три подписи под группами на главной странице запрещены: про автоматическое исключение языка, про Apple/интернет и про личные API-ключи. Последняя стадия — `translation_simplification` после `media_privacy_fixes`.

## Интерфейс

В Прочее остаются группа «Переводчик», переключатель «Перевод сообщений» и условный переход «Настройки перевода» с текущим сервисом справа. Внутри нет дубликата master.

Страница «Переводчик» содержит пять строк: «Показать кнопку «Перевести»», «Переводить чаты целиком», «Язык перевода», «Не переводить», «Предпочитаемые языки». Затем «СЛОВАРИ»: Apple, Google, Яндекс; затем «НЕЙРОСЕТИ»: Gemini, ChatGPT, DeepSeek. Подписи сервисов без дополнительных описаний. Apple/Google/Яндекс не получают отдельной строки настроек. Только под выбранной нейросетью появляется переход в её параметры. Ни одна из трёх групп главной страницы не получает footer.

Шрифты и цвета берутся из текущей темы/`listsFontSize`, значения языков стоят справа. При обычном размере текста подписи переключателей рассчитаны на одну строку; при увеличенном шрифте сохраняется перенос и доступность, без уменьшения шрифта. Поиск языка есть в выборе target и в предпочитаемых. Выбор target — «Как в приложении» либо явный язык. Имена языков с заглавной первой буквой.

«Не переводить» показывает объединение текущего языка перевода и вручную выбранных предпочитаемых языков. Оба перехода открывают один список исключений; текущий target отмечен и не отключается. Смена target заменяет только автоматическую часть; явные предпочтения сохраняются. Правило действует на общих границах context menu/определения чата/ручного перевода/автоперевода, включая отдельный target чата. При явном выборе другого target язык интерфейса сам по себе не становится скрытым дополнительным исключением. Включение перевода чатов целиком возвращает ранее скрытые панели, заменяя удалённую дополнительную строку их восстановления.

Страницы нейросетей называются Gemini/ChatGPT/DeepSeek, без «Настройки» в navbar. Поле ключа с постоянной подписью, строка модели, ссылка на официальный кабинет и температура. Барабан — штатный `UIPickerView` в нижней панели, без «Готово»: касание вне, жест вниз на заголовке или VoiceOver Escape выбирают остановившуюся строку только в черновике. Правый navbar «Сохранить» фиксирует ключ, модель и температуру. Очищенное поле удаляет ключ только при сохранении. Отдельного действия удаления нет. Существующие выбранные модели сохраняются в списке; основной каталог — проверенный ранее набор сервиса, не обещание постоянной доступности модели API.

Сохранение выполняет Keychain-операцию внутри общей блокировки конфигурации без промежуточного уведомления. После успеха публикуется одна revision с новыми моделью/температурой/ключом. Отказ Keychain оставляет конфигурацию прежней и показывает ошибку. Температура 0–100%, шаг 10%; новый default 20%, сохранённые допустимые значения остаются. Для моделей без поддержки параметр не передаётся.

## Сервисы и миграция

Apple использует определение исходного языка сообщения и общий/явный target. Старая настройка `appleSource` больше не направляет запросы. При первом переводе реальная пара подготавливается через `TranslationSession.prepareTranslation()`, с системным согласием на скачивание при необходимости; скачанные языки не получают дополнительной страницы приложения. iOS 18+ и реальные ограничения Apple сохраняются. Состояние «загружено» не подделывается. Старый `NagramiXTranslationApple.swift` со списком/ручной загрузкой удалён из итогового дерева после точных prechecks.

Google/Яндекс остаются только анонимными бесплатными веб-путями, без доступа к старым платным ключам и без скрытого fallback. Квоты, доступность и поддержка языков зависят от сервисов; ошибки сохраняют оригинал. Нейросети требуют личный API-ключ, запросы идут только на соответствующий официальный endpoint. Бесплатных нейросетевых вариантов нет.

Pollinations/GPT-OSS удалены из итогового enum/UI/HTTP-клиента/очереди/поиска. Исторические канонические stages остаются входами SHA-цепочки. JSON v1 декодируется явно: неизвестный прежний provider становится Apple с выключенным auto, не включая другую облачную отправку; master, кнопка, target, ручные исключения и параметры оставшихся нейросетей сохраняются. Revision получает стабильную migration-пометку. Старые model/temperature-ключи снятых сервисов не перезаписывают остальные. Исходные ключи хранения и dormant Keychain-данные Google/Яндекс не стираются.

Границы сохранения entities, оригинала, кеша по account/revision, проверки fingerprint и отложенной записи остаются. Транскрибация, PiP, история/скриншоты этой стадией не меняются.

## Проверки и пределы

Точный stage изменяет семь файлов, добавляет один picker и удаляет старый Apple-helper. Проверены композиция всех поздних stages поверх проверенного story_profile/Telegram 13.1.1, точный reverse предыдущей цепочки, 42 drift/missing/template/collision/reapply случая без частичной записи или удаления. Проверки прежних историй, recovery и поворотов прошли через обратный снимок. Import-access, Python compile, release metadata, diff и 10 Swift syntax trees проверены. Доказательства: `/tmp/nagramix-translation-simple-compose.log`, `/tmp/nagramix-translation-simple-validation.log`, `/tmp/nagramix-translation-simple-story.log`, `/tmp/nagramix-translation-simple-recovery.log`, `/tmp/nagramix-translation-simple-rotation.log`. Итоговое проверочное дерево `/tmp/nagramix-media-composed`.

`scripts/tests/NagramiXTranslationSimplificationTests.swift` проверяет реальный Codable/исключения/извлечённый Save/кодеки запросов с заменой только UIKit/Keychain и без запросов сети. Есть миграция старого provider, roundtrip, true/false defaults, автоматическое и ручное исключение, draft/сохранение одним уведомлением, удаление/отказ ключа, обязательная авторизация нейросетей и независимость бесплатных веб-путей. Для запуска: `validate_translation_simplification.py --source <tree> --standalone --swiftc <compiler>`. В текущей среде Swift compiler отсутствует: suite и новый Apple SDK не запускались; синтаксис generated Save boundary проверен отдельно. Физические UIKit, Apple download, Keychain и сервисы требуют проверки на iPhone после отдельной команды на сборку. Actions, IPA, релиз, commit/push не запускались.
