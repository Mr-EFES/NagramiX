# Голова значка «По автору» над плечами

После публикации 0.8.5 пользователь утвердил референс: голову выровнять над верхней частью туловища, сохранив само туловище, круг и галочку. Это изменение исходников следующей сборки; опубликованный IPA 0.8.5/build165 его не содержит.

Общий helper `nagramiXSelectByAuthorIcon` по-прежнему используется обычным и архивным меню. Изменена только координата x окружности головы: 4.2 → 5.7 pt при прежних y1.8 и диаметре7.0. Центр головы теперь x9.2, над верхней точкой плеч. Размер24×24, stroke1.6, темы, масштаб, контуры туловища и badge, обработчики выбора и пересылки сохранены побайтно.

Поздняя стадия `author_head_alignment` выполняется после `release_085_validation_support` перед финальным post-port. Один файл, одна замена; SHA исходника, предыдущего шаблона, результата и BUILD проверяются до записи. Прежние canonical стадии не изменены. Новая стадия снимается перед проверками старой цепочки через `validate_system_video_pip`; остальные файлы композиции сохраняются, включая неизменяемый вход GalleryUI.

Проверены:

- Побайтное применение к полным pre/post деревьям: единственное отличие — координата головы; оба места вызова helper сохранены.
- Swift parse полного изменённого файла.
- Прежние проверки author check badge и upright icon.
- Новая ветка совместимости в проверке системного PiP с прежними проверками guards.
- Фактический финальный post-port на полном дереве: все семь выходов совпали с итоговой композицией, голова осталась выровненной.

Статус новой правки: `source_checked / native_compile_pending / device_pending`. Apple SDK, сборка, commit/push и публикация этой задачей не запускались. На устройстве проверить обе ветки меню, светлую/тёмную тему и натуральный размер значка. Временные доказательства — `/tmp/nagramix-icon-reference/`.

Для «Рассылки» пользователь также утвердил большую фигуру слева и маленькую справа. Перестановка реализована следующей стадией, сохранив выравнивание головы «По автору»: [контракт](BROADCAST_ICON_ORDER.md).
