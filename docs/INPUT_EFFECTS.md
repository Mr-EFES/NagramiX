# Эффекты ввода

В **NagramiX → Прочее** после оформления добавлена группа **ЭФФЕКТЫ ВВОДА**. Переключатель называется **«Анимация при наборе»**. По умолчанию он выключен; сохранённый выбор переживает перезапуск и обычное обновление остальных настроек.

После включения появляется строка «Эффект». Выбор открывает существующую панель вариантов с отметкой текущего значения: «Пульсация», «Волна», «Волна панели», «Неон», «Дрожание», «Свой эффект». Начальный эффект — «Волна». Для своего эффекта показываются пять подписанных ползунков: сила, скорость, увеличение, сдвиг и свечение, 0–100% с шагом5. Параметры сохраняются при выключении и смене эффекта. Новые заголовки проходят общий uppercase-контракт; длинные названия и VoiceOver используют штатные многострочные строки/процентные ползунки. Поясняющая аннотация не добавлена.

## Поведение

Декоративные keyframe-анимации подключены после штатной обработки изменения текста в редакторе чата и редакторе подписей вложений. Они действуют на существующее поле; «Волна панели» дополнительно затрагивает кнопку вложений в обычном редакторе. Текст, entities, выделение, курсор, отправка, вставка, IME, клавиатурные переходы и model geometry не меняются. Другие независимые поля приложения не перехватываются.

Аниматор принадлежит конкретному редактору. Он ограничивает частоту запусков, использует только свои CA-ключи и additive transform-анимации. При выключении настройки, переходе в фон, включении энергосбережения или «Уменьшения движения» снимаются только его эффекты. Наблюдатели weak и удаляются при освобождении; target/companion views не удерживаются. Ни таймеров, ни display-link, ни бесконечных анимационных циклов нет. Битмап свечения кешируется по размеру, цвету темы и плотности экрана; переиспользуется один декоративный слой.

Конфигурация хранится отдельно в `nagramix.input.typingEffects`. Прочие tab-settings её не перезаписывают. Неверные значения нормализуются, неизвестный preset возвращается к волне; NaN/бесконечные проценты не доходят до CA. На каждый кадр нет записей в настройки и повторного чтения UserDefaults: применяется опубликованная конфигурация под короткой блокировкой.

## Исходники и проверки

Стадия55 `input_effects` идёт после54 `youtube_playback_policy`:75 замен, включая71 ресурсный каталог, два новых публичных Core helper,10 неизменённых guards. Два впервые изменяемых native input — BUILD и source редактора подписей — побайтно подтверждены по официальному Telegram13.2 pin `24638bc69bd083981b178dd1e7f921eebbf7fc46`. Остальные изменения компонуются с предыдущими стадиями;3881 прежний canonical `.inc` не меняется.

Добавлены14 ключей во все71 языка; итоговый каталог содержит664 ключа. Опубликованная IPA0.9.5 сохраняет точный прежний контракт647;664 требуются начиная новой0.9.6. Отсутствующие переводы, пропущенные ключи, изменение старого каталога и подмена снимков не принимаются проверкой пакета.

[Receipt](INPUT_EFFECTS_CHECKS.json) содержит311 проверок actual production настроек, аниматора и построения строк в debug и `-O`, шесть семантических мутаций в обоих режимах, отдельную компиляцию публичного Core-модуля и внешнего потребителя, loader/native-origin refusals и общие исходные проверки. Native типы target/кнопки сверены с настоящими объявлениями: UIView/UIButton в обычном поле, ASDisplayNode.view в редакторе подписей. Тела прежних composer callbacks точны после удаления единственного декоративного вызова.

Новый fixture входит в обязательный ранний gate:21 полный fixture/42 исполнения до длинного overlay. Полные Core helpers проверяются настоящими UIKit/QuartzCore SDK на Apple до overlay и повторно после55. На Linux исполнение использует явные UIKit/CA adapters, а Apple gate честно сообщает `not_run`; геометрия/события проверяются как состояние, пиксели не рисуются. Новый final-validator, strict localization, public/native member audits, inverse, migration и Postbox gates обязательны.

Статус: `source_checked / native_compile_pending / device_pending`. Системная клавиатура, автокоррекция/IME, фактическая плавность, расположение свечения, длинные локализованные строки и VoiceOver на iPhone требуют проверки новой IPA. SDK/Actions/IPA/релиз в этой задаче не запускались. Теги, опубликованные релизы, README, LICENSE и номера версии/сборки сохранены.
