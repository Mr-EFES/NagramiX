# Локальное чтение: название без кавычек

По скриншоту владельца русский переключатель в группе «ПРИВАТНОСТЬ» называется **Локальное чтение**. Ключ `NagramiX.ReadMode.Local` прежний; общий resolver автоматически использует исправленное название также в результатах поиска настроек.

Stage58 `local_read_label` после57 заменяет только значение этого ключа в русском каталоге. Два точных guards сохраняют действующие formatter и SettingsUI. Остальные70 языков,668 ключей каждого каталога, Swift-код, поведение чтения, обработчик, default OFF и сохранённый выбор не меняются. Старые canonical snapshots и plans не переписываются; strict localization сначала проверяет точную обратную композицию, затем единственное допустимое изменение русского значения.

Использованы существующие проверки обратной композиции и локализации, workflow mode и метаданных. Новые unit-тесты для текстового изменения не добавлялись. Результаты — [receipt](LOCAL_READ_LABEL_CHECKS.json). Новая IPA/SDK/Actions/публикация релиза не запускались; проверенные исходники публикуются в main по постоянному разрешению владельца. Все опубликованные релизы,0.9.5/build201,README/LICENSE/аннотация/версии сохранены.
