## Причина и исправление

Референсы показывают System/Night, System/Dark и девять тёмных миниатюр; пользователь сообщает светлый результат после применения. В закреплённом ThemePickerController предпросмотр запрашивает базу .night/.classic, но применение передавало selectThemeImpl(nil, ...). Штатный загрузчик с параметром dark выбирает группу night/tinted или classic/day; два загрузчика с baseTheme после отсутствия точного совпадения брали первый вариант. Для набора [day, tinted] при запросе night выбирался day. Конкретный серверный набор пользователя и журнал перехода не получены; не заявлять доказанный стек исполнения на его устройстве.

В ios/apply_features.py добавлена точная совместимость двух загрузчиков: точное совпадение → вариант той же светлой/тёмной группы → прежний первый вариант. При nil, точном совпадении и отсутствии нужной группы прежнее поведение сохранено. ThemePickerController передаёт theme.referenceTheme.baseTheme из предпросмотра в selectThemeImpl и использует её для загрузки темы/обоев; существующая запись themePreferredBaseTheme получает показанную базу. Палитры, шрифты, force, System/Schedule/Auto, defaults и сохранённые настройки не менялись. Для одновариантной custom theme отсутствующий тёмный вариант не изобретается.

Изменён только механизм наложения overlay; остальные классы функций не трогались. ThemePickerController добавлен в защиту штатного оформления: 28 путей, 24 побайтно неизменённых, 4 с точными исключениями для чтения цветов/выбора варианта. Прежняя совместимость RGB24/ARGB сохранена. Подробности — [THEME_AUDIT.md](THEME_AUDIT.md).

## Опции чатов по тапу

По последнему пожеланию пользователя название пункта — «Опции чатов по тапу». Переименование меняет только подпись: жест остаётся долгим удерживанием со штатным предпросмотром и меню; обычное нажатие открывает чат. Внутренние ключи и идентификаторы сохранены.

Добавлен chatActionsOnHold: Bool, ключ nagramix.interface.chatActionsOnHold, default true только при отсутствии значения. Явное false сохраняется. Настройка находится в Интерфейс → Чаты, имеет пояснение и участвует в глобальном поиске. Изменены NagramiXTabSettings, NagramiXPresentationStrings, RU/EN ресурсы, NagramiXSettingsController и patch в apply_features.py; контракт/реестр/аннотация обновлены.

Точные якоря добавляют в ChatListItemNode хранение штатных опций и setRevealOptions/setRevealOptionsOpened/gestureRecognizerShouldBegin/didLoad. При ON опции пустые, только распознаватель свайпа строки отклоняется, native флаги блокирования папок снимаются. Активное раскрытие закрывается после очистки опций, чтобы отменённый полный свайп не выполнил старое действие. OFF возвращает штатные опции из актуального кэша. Загруженные строки, включая кэшированные папки, получают changedNotification на main с weak self и удалением наблюдателя в deinit. Новых обработчиков удерживания/меню/таймеров нет; native preview, tap, права действий, подтверждения, accessibility и editing не переписаны.

Новый overlay применяется к чистому scoped набору pin. Отличаются шесть generated-файлов, остальные 222 файла совпадают, включая прежние изменения 0.4.6. Swift-разбор четырёх файлов и Python проходят. Проверены старые preference keys/локализации, новые stable id 8/9 и сохранность всех прежних байтов ChatListItem после исключения добавленного блока/import/deinit cleanup. Это статические проверки, не UIKit/UserDefaults execution и не native compile. ItemListRevealOptionsItemNode, ChatListContainerNode и InteractiveTransitionGestureRecognizer прочитаны, не изменены. chat_actions_on_hold — compile_passed/device_pending. [Описание и приёмка](../product/features/chat-actions-on-hold.md).

## Компактный список чатов

По запросу пользователя добавлен переключатель Интерфейс → Чаты → «Компактный список чатов», default OFF при отсутствующем значении. Ключ nagramix.interface.compactChatList, сохранённые ON/OFF не сбрасываются. Изменены NagramiXTabSettings, PresentationStrings, RU/EN ресурсы, SettingsController и apply_features.py; новый пункт/пояснение участвуют в поиске, stable id 101/102. Контракт, реестр, README, аннотация, статус и план приёмки обновлены.

Точные patches меняют только ChatListItem/ChatListNode: обычная строка списка/архива получает аватар до 44 вместо 60 и один preview. Автор/черновик сохраняются inline с атрибутами. Высота не фиксируется: минимум 56, дальше измеряются title/author/preview/typing/tags и форум. Шрифты/темы не меняются. OFF возвращает прежние параметры, включая сброс шрифта буквенного аватара при reuse. Отдельные темы форума, поиск сообщений, custom message lists, inline и специальная community-разметка исключены. Все жесты/действия/preview и «Опции чатов по тапу» остаются прежними.

Все существующие ChatListNode, включая кэшированные папки, наблюдают специальное уведомление на main с weak self и cleanup в deinit. Оно обновляет прежний revision signal. Atomic сравнивает bool на очереди обработки; изменение включает native forceAllUpdated, иначе неизменные данные записей не вызвали бы rebind строк. Таймеров/polling нет.

Свежий scoped overlay проходит: 7 generated-файлов отличаются от предыдущего подготовленного состояния, 270 совпадают. Синтаксис 5 Swift-файлов/Python, старые keys/defaults/localizations/IDs и полнота switch проверены. Hold-блок и обработчики после revealOptionsInteractivelyOpened побайтно сохранены. Два отрицательных сценария якоря высоты отклоняются; appearance guards проходят. Это не native compile, не UIKit/UserDefaults runtime. Xcode/Swift toolchain отсутствуют. Новая сборка №75 и публикация прошли, compile_passed/device_pending. [Описание и приёмка](../product/features/compact-chat-list.md).
