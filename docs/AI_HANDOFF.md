# Контекст разработки NagramiX 0.8.4

Отправная точка — единственный релиз 0.8.4/build162 и его исходники в `main`. По прямому указанию пользователя 2 ноября 2026 года прежние коммиты, релизы, теги и результаты старых Actions удаляются из доступной истории. Сохраняется успешный запуск 162 с IPA и символами. Новую сборку при очистке не запускать.

## Проверенное состояние

Чистая Apple SDK-сборка и публикация run41355923502 завершились успешно. Скачанный IPA независимо проверен: версия 0.8.4, build162, iPhoneOS ARM64, iOS15+, RU/EN, 31 мелодия, 8 иконок, без подписи и профилей; CRC, SHA256SUMS и provenance корректны. Размер и digest совпадают с GitHub. [Точные сведения](RELEASE_STATUS.md). Установка требует внешней подписи; физическая приёмка остаётся device_pending.

В GitHub основной язык Swift. `.swift.inc` — Swift-шаблоны, прежняя классификация их как C++ исправлена в `.gitattributes`; generated snapshots не искажают статистику. Настоящие C/C++ мосты Whisper/Vosk сохраняются.

## Состав текущего релиза

- Полная замена PiP на Ghostgram `df95ba566c5f25a8f36de2b703bf070ca97c54ba`, включая контроллер, кнопку, жесты, состояния/видимость, переходы и возврат. Старые контроллеры и адаптеры удалены из итогового compiled дерева. [Контракт и ограничение первого свайпа](GHOSTGRAM_PIP_PORT.md).
- Ровный значок «По автору», общий flow выбора адресата, подготовка локальной копии при явной отправке, сохранение выбранных адресатов/режима и отложенной отправки.
- Структурированные посты больше не считаются пустыми: InstantPage-блоки, ссылки и embedded media сохраняются; полный пост запрашивается до копирования, частичная отправка при ошибке/отмене исключена. [Контракт](RICH_CONTENT_COPY.md).
- Защищённое сохранение из галереи требует «Свободный скриншот» вместе с прежними условиями пересылки/рассылки и eligibility. Callbacks проверяют OFF повторно; обычное сохранение не меняется. [Контракт](GALLERY_EXPORT_PRIVACY_GATE.md).
- Финальная стадия `ghostgram_pip_compile_fix` устраняет дубликат глобальной константы и лишнюю class availability annotation, не изменяя reference-controller. Foundation в исполняемой регрессии сохранён.
- Публикация автоматически холодная: cache restore/save отключены, очищается только точный `$GITHUB_WORKSPACE/.bazel-cache`. Четыре сочетания параметров проверяет `scripts/validate_release_build_mode.py`.

## Организация после очистки

Опубликованный IPA и его три release assets не заменяются. Новый корневой коммит и тег содержат те же исходники приложения, ресурсы и регрессии приложения; обновлены документация, корневая лицензия, проверка метаданных и порядок публикации workflow. SHA оригинального source остаётся в BUILD-PROVENANCE.txt как доказательство происхождения уже собранного файла.

Удалены старые планы приёмки и неподтверждённые ранние дизайн-предложения; ссылки ведут на [приёмку 0.8.4](DEVICE_CHECK_084.md). Технические контракты действующих стадий, лицензии/атрибуция, fixtures и проверочные снимки сохранены. Имена `release_076_*`, старые `.inc`/JSON и адаптеры баз — зависимости воспроизводимой цепочки, а не отдельные релизы. Не вырезать их по номеру версии.

Локальный Git bundle до очистки хранится вне проекта: `/tmp/NagramiX-before-cleanup-0.8.4-full.bundle`. Это резерв исходников, не опубликованный релиз; временное окружение не является долговременным архивом.

Дополнительная проверка очистки: удаление тегов оставило девять старых публикаций, которые не показывались в списках REST/GraphQL, но были доступны по прямым release IDs и учитывались счётчиком главной страницы. По прежней явной команде на очистку сами публикации удалены; каждый прежний ID возвращает 404, HTML главной страницы подтверждает releaseCount=1. Релиз 0.8.4 и IDs/размеры/digest всех трёх его файлов сохранены. При будущей отдельно разрешённой очистке проверять прямые IDs и счётчик страницы, а не только списки API.
