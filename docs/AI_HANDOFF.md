# Текущий контекст NagramiX 0.4.0

Обновлено: 2026-10-04 (Москва).

## Репозиторий и выпуск

Единственная рабочая ветка — `main`, upstream `origin/main`. Пользователь явно разрешил сборку и публикацию **0.4.0** с краткой русской аннотацией. Релиз [v0.4.0](https://github.com/Mr-EFES/NagramiX/releases/tag/v0.4.0) опубликован 2026-10-04 в 14:58 (Москва). Нативная сборка **65** и публикация прошли в [запуске 37198280820](https://github.com/Mr-EFES/NagramiX/actions/runs/37198280820). Все сообщения коммитов, документы и аннотации — на русском языке.

Версия реестра, workflow, README, справочной части LICENSE, .gitignore и текущей аннотации переключена на 0.4.0. Исходный текст GNU GPL не менялся. История прежних аннотаций сохраняется в Git. Оставлен один workflow `.github/workflows/build-unsigned-ipa.yml`; новая публикация включается параметром `publish_release` и выполняется отдельным job после успешной сборки. Существующие релизы автоматически не заменяются. Происхождение IPA и его SHA-256 прикладываются к релизу; старый бинарник не выдавать за новый.

## Архитектура и сохранённые функции

Независимый неофициальный Telegram-клиент для iPhone. Репозиторий хранит overlay: Swift/Objective-C и точные патчи `ios/apply_features.py`. База — Telegram-iOS 12.9.2, SHA `6ad963e5b62d354da79040f388ae2b9132fb17b8`, минимум iOS 13.0. Официальный master перепроверен 2026-10-04 и совпадает с pin. Не ослаблять exact-anchor и `--require-current` проверки.

Сохранены вкладки/иконки, истории и их подтверждение, широкие посты и альбомы, copy-as-new, пагинация выбора автора, локальный архив удалённых сообщений/правок, профиль/дата регистрации, взаимный контакт, DNS/прокси и Force TCP. Защищённые пути перечислены в `AGENTS.md`; не менять их без целевой задачи пользователя.

## Состав новых исправлений

- Полный официальный русский ресурс с дополнениями для покрытия pin; отсутствие автоматических предложений другого языка. Ручной выбор сохранён.
- Текущий default тем следует системе iOS через штатные `.dayClassic`/`.night`, `trigger: .system`, `force: false`; пользовательский выбор не перезаписывается. Опубликованная сборка 65 использовала прежнюю стартовую Tinted.
- Поле поиска капсулой с лупой; штатные иконки шестерёнки и лампочки для пунктов настроек.
- Отмена подготовки первого видео через штатный `.dismiss`, инвалидирующий отложенный запрос до появления состояния записи. См. [round-video-camera.md](../product/features/round-video-camera.md).
- Таймер прокси запускается при любом `.connecting`, повторные события его не сбрасывают. Общий кэш штатных проверок с UI через Atomic в Network; два параллельных фоновых probe, предел 12 секунд, следующий проход через 60 секунд после предыдущего. Резерв не старше 90 секунд применяется без дополнительного ping, затем обязан достичь `.online` за 15/30/60 секунд. Отмена защищена поколением и условиями транзакции. См. [network-reliability.md](../product/features/network-reliability.md).
- DoH GET A/AAAA с резервным POST; общий timeout и native fallback сохранены. Отмена и callback сериализованы одним замком, nil-блок не вызывается; усилены границы DNS-парсера. Из Cloud Google/AdGuard ответили GET/POST, Mullvad/Cloudflare GET, Quad9 вернул HTTP 503 шлюза с connection timeout. Работа DNS на iPhone не подтверждена.
- В «Интерфейс → Контекстное меню» добавлены «Переслать без»/«Выделить от автора». Ключи `nagramix.contextMenu.showForwardWithoutAuthor`/`showSelectByAuthor`: `object as? Bool ?? true`; false сохраняется существующим updater. Gate находится при добавлении actions, backend побайтно сохранён. Общий поиск использует модель настроек. См. [context-menu-settings.md](../product/features/context-menu-settings.md).

## Проверки и следующий шаг

Предварительно прошли полное применение feature overlay к закреплённым файлам, синтаксические деревья Swift/Objective-C (это не typecheck), Python/JSON, локализации, метаданные и whitespace. Сравнение overlay при последних целевых задачах подтвердило сохранность других функций и backend обоих действий меню.

Для опубликованной сборки статусы compile были установлены `compile_passed`, device — `device_pending`; последующая правка геометрии поиска имеет `compile_pending`. Пользовательские подтверждения широких постов и выбора автора относились к предыдущей установленной сборке и не доказывают регресс нового IPA. Точный прежний crash/ANR stack trace DNS отсутствует.

Workflow с `publish_release=true` завершился успешно: нативная компиляция, упаковка и публикация. Тег `v0.4.0` указывает на исходный SHA `a2730925803c2984c1565feef65282cb7ce22347`. Новый IPA скачан из публичного релиза и проверен локально: версия 0.4.0, build 65, `com.mr-efes.nagramix`, имя NagramiX, Mach-O ARM64, отсутствие временных `_CodeSignature` и `embedded.mobileprovision`. Основной русский словарь содержит 14 843 ключа; новые строки меню присутствуют в `Frameworks/TelegramUIFramework.framework/NagramiXLocalization.bundle`. SHA-256 совпал с `SHA256SUMS` и GitHub asset digest: `2429b35e015dabfd671fa8502a2187493594f4a893575a6a74e57afb9296e21e`. `BUILD-PROVENANCE.txt` подтверждает SHA и этот запуск. В релизе приложены новый IPA, происхождение и контрольная сумма; аннотация совпадает с `product/releases/0.4.0.md`. Полную стабильность не объявлять до физических тестов.

Пользователь указал **iPhone 17 Pro Max**, установка через **SideStore**; версия iOS ещё неизвестна. План испытаний — [IPHONE_TEST_0.4.0.md](IPHONE_TEST_0.4.0.md). Доступа к физическому iPhone из Cloud нет; результаты фиксировать по фактическим сообщениям/логам пользователя. Следующий шаг — установка нового IPA и последовательная проверка таблицы.

## Исправление геометрии поиска после выпуска

По согласованному пользователем макету расширена капсула поиска: убран повторный горизонтальный inset 16 pt в `ios/Sources/SettingsUI/NagramiXSettingsSearchHeader.swift`. Используются уже рассчитанные боковые отступы ItemListController (на iPhone 16 pt плюс safe insets). Высота поля 48 pt, радиус 24 pt, положение сверху сохранены. Высота элемента 71 pt: 12 pt сверху, поле 48 pt, 11 pt снизу плюс 7 pt штатного заголовка дают видимый промежуток 18 pt.

В `ios/Sources/SettingsUI/NagramiXSettingsController.swift` search entry получает sectionId первого результата/раздела. Это убирает лишний межсекционный отступ 28 pt перед первым заголовком во всех категориях и поисковой выдаче; последующие заголовки и handlers не меняются. Уточнены спецификация глобального поиска и физический сценарий проверки.

Правка не входит в уже опубликованный IPA build 65. Новая сборка не запрашивалась и не запускалась. Следующий шаг — сборка по отдельной задаче и сравнение с макетом на iPhone 17 Pro Max, включая ввод, очистку, категории, поиск без результатов и поворот экрана. Проверки текущей правки: синтаксический разбор обоих Swift-файлов без ошибок, полное применение overlay к закреплённой базе, побайтное совпадение изменённых файлов в результате применения, валидатор метаданных и `git diff --check` прошли. Это не нативный typecheck и не визуальная проверка на устройстве.

## Удалённое сообщение: метка и контекстное меню

Пользователь на iPhone подтвердил отображение сохранённого удаления, но сообщил об исчезновении копии при долгом нажатии/выборе. Установлена причина: ContextExtractedContentSource подписывался на отсутствующий оригинал в Postbox и сразу возвращал shouldBeDismissed=true. Для архивной копии источник теперь наблюдает её наличие в локальном архиве. Для обычного сообщения этот путь не менялся.

Fallback метки заменён на «Это сообщение было удалено»; пользовательский текст/ключ сохранены. Корзинка отрисовывается отдельным ASImageNode, с тем же ресурсом и theme tint. Добавлены локальные действия меню, редактор копии, lookup архивного ID, stableVersion после правок, объединение архивных ID с серверной пагинацией автора, отправка архивного содержимого как нового и кнопки для полностью архивного выбора. Подробные правила и ограничения — [deleted-messages.md](../product/features/deleted-messages.md).

Изменены `ios/apply_features.py`, архив TelegramCore, helper редактора SettingsUI, presentation strings и RU/EN ресурсы NagramiXCore; актуализированы спецификация/реестр/физический план. На закреплённой базе сравнены старый и новый overlay: изменено ровно 11 ожидаемых файлов; другие generated файлы совпали побайтно. Применение всех exact-anchor патчей, синтаксический разбор этих Swift, Python compile, локализации, метаданные и whitespace прошли. Нативный typecheck/сборка и физические действия не выполнялись; соответствующие compile-статусы возвращены в compile_pending. Сборка 65 не содержит эту правку.

Сервер не позволяет закреплять/редактировать/пересылать по удалённому исходному ID. Редактор явно подписан «Редактировать локальную копию», ответ — «Ответить цитатой». Локальное закрепление и внешняя передача архивного выбора не реализованы. При пересылке смешанного набора с архивной копией применяется copy-as-new ко всему набору. Медиа должны оставаться доступными; тестировать фактическую доставку отдельно. Следующий шаг — по задаче пользователя собрать новый IPA, затем проверить меню без исчезновения и все локальные действия на iPhone 17 Pro Max через SideStore. Известные ограничения не выдавать за полный функционал серверного оригинала.

## Системная тема и русский язык по умолчанию

Последний запрос отменил принудительную стартовую Tinted. В `ios/apply_features.py` убрана замена dayClassic на nightAccent. Штатные defaultSettings (`dayClassic`, автоматическая `night`, trigger.system, force.false) сохранены побайтно и проверяются точным anchor. Начальное defaultPresentationData до загрузки параметров выбирает defaultPresentationTheme/defaultDarkPresentationTheme по системному trait; затем действуют штатные пути с WindowUserInterfaceStyle. Переключатели расписания, выключения, автоматических и ручных тем не менялись. Сохранённые настройки не перезаписываются; на обновлении уже сохранённую Tinted нельзя надёжно отличить от ручного выбора.

Русский defaultPresentationStrings, полный RU-ресурс, приветствие/авторизация и подавление автоматических предложений языка сохранены. При загрузке явной localizationSettings используется сохранённый язык; если записи нет, на первом и повторном стартах возвращается русский fallback. Актуализированы README, правила AGENTS, спецификация, реестр и план iPhone-тестов. Аннотация опубликованной сборки 65 оставлена как описание её фактического содержимого; новая тема предназначена для следующей сборки.

Проверки этой задачи: применение overlay к pin, синтаксические деревья Swift, Python, метаданные и whitespace; сравнение с предыдущим overlay подтвердило изменения только PresentationThemeSettings/PresentationData. Settings совпали побайтно с upstream, русский default — с предыдущим overlay. Валидатор 13 русских строк приветствия прошёл. Нативный typecheck и физическая проверка не выполнялись, build 65 не заменён. Следующий шаг — отдельная сборка по задаче пользователя, затем чистый запуск в светлом/тёмном iOS, смена режима системы, сохранность ручных тем/расписания и русского либо выбранного вручную языка на повторном запуске.
