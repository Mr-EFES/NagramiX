# Проверка NagramiX 0.4.1 на физическом iPhone

Пользователь указал iPhone 17 Pro Max и SideStore; версия iOS ещё неизвестна. Сборка 0.4.1 не запускалась, IPA отсутствует. Все сценарии новой версии ожидают фактического тестирования.

Сначала установить новый IPA поверх прежнего приложения через используемый способ внешней подписи. Сохранить одинаковый bundle ID и подпись при обновлении; иначе iOS может создать отдельное приложение. Перед удалением приложения учитывать, что локальный архив удалённых сообщений и предпочтения не восстанавливаются из Telegram. Чистую установку тестировать отдельно, сохранив нужные данные.

Убедиться, что установленная версия — **0.4.1**, а IPA и номер сборки соответствуют `BUILD-PROVENANCE.txt` из релиза. Контрольная сумма — в `SHA256SUMS`.

Для таймера нужны доступные резервные прокси и воспроизводимо зависающий выбранный сервер. Отсутствие физической сети не является проверкой ошибки отдельного прокси. iOS может приостанавливать приложение в фоне: периодические проверки не обещаются во время системной приостановки.

Формат результата: номер/название сценария, выполненные действия, ожидание и факт. Для ошибки указать номер сборки, модель/iOS, сеть Wi-Fi/мобильная и воспроизводимость. Для краша сохранить журнал iOS с трассировкой, исключив личные данные и секреты прокси.
