# Единое разрешение сохранения защищённого медиа

После 0.8.4 общий checkbox переименован в «Свободный контент» и объединён с отображением доступного контента с ограничением устройства. Прежний screenshot key, default OFF и все описанные ниже eligibility/export checks сохранены. [Текущий контракт](FREE_CONTENT.md).

По запросу пользователя стадия `gallery_export_privacy_gate` приводит полноэкранную галерею к проверке, уже используемой в меню сообщения. Защищённое фото/видео можно сохранять, только если включён «Свободный скриншот», включён хотя бы один из пунктов пересылки/рассылки и сообщение допускает копирование. Защита, заданная у чата, учитывается наравне с флагом отдельного сообщения. Сохранение обычного незащищённого медиа и исключение платного содержимого остаются прежними.

Общую функцию `nagramiXCanSaveGalleryMedia` уже вызывают построение меню и обработчики действий для фото, видео, выбора качества и изображения с видеослоем. Они повторно читают актуальные настройки перед началом сохранения: меню, открытое при ON, не позволяет запустить защищённое сохранение после OFF. Уже начатая операция сохранения этой правкой не отменяется. Независимая настройка скачивания историй не меняется.

В GalleryUI добавлена прямая зависимость на существующий Foundation-only `NagramiXMediaSettings`. Ранние снимки overlay не переписаны. Проверены source/BUILD guards, повторное применение и отказ до записи при drift, синтаксис Swift/Python и восстановление предыдущей цепочки. Swift-регрессия использует настоящий код политики и проверяет переключатели, исключения и уже открытое действие; её выполнение включено в SDK workflow, но локально Swift compiler отсутствует. Компиляция Apple SDK и физический iPhone ожидаются. Сборку не запускали.
