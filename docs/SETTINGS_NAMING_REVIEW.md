# Предложения по названиям переключателей

После обсуждения пользователь утвердил34конкретных переименования. Они выполнены по его точным формулировкам: [актуальные названия и проверка](SETTINGS_LABEL_RENAME.md). Таблицы ниже — исходные предложения обзора; для текущего интерфейса приоритет имеет утверждённый список. Остальные предложения не приняты автоматически.

Обсуждение15октября2026. Проверены текущие рабочие исходники NagramiX:45переключателей основных настроек и4на экране прокси (включая штатные «Использовать прокси»/«Использовать для звонков»). Названия и код не менялись в рамках этого обзора; предложения не считаются согласованным переименованием. «Таймер селфи-камеры» уже учитывает предыдущую подготовленную правку, отсутствующую в установленном build89.

Подпись должна описывать включённое действие или состояние. OFF отключает эту дополнительную функцию, но не обязан удалять ранее сохранённые данные или скрывать уже отправленное. Переименование не требует инверсии persisted значений, изменения default или stable ID. Длинные подписи должны переноситься, без многоточий. Пояснения в таблице предназначены для обсуждения, добавление footer под настройками не предлагается.

Особенно существенны исправления смысла: «Меню чата по тапу» сейчас обозначает удерживание; «Фото без сжатия» не является передачей исходных байтов; дата регистрации — приблизительный год; стикеры скрывают привязку к набору, а не отправителя; три переключателя контекстного меню управляют показом действий. Выбор DNS/DoH, задержка прокси, процент качества, размер стикеров, иконки, звук и очистка архива — не checkbox и в45не включены. Удалённая «Подмена профиля» не возвращается.
