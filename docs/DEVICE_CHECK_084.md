# Проверка 0.8.4 на iPhone

Проверять версию 0.8.4/build162. Записать модель iPhone, iOS, способ подписи, состояние нужных настроек и точные шаги. Нативная компиляция и проверка пакета пройдены; результаты ниже пока не подтверждены физическим тестом.

| Область | Сценарий и ожидаемый результат |
| --- | --- |
| Запуск и настройки | Холодный запуск и обновление: сохранённые значения не сбрасываются; русский язык, темы, длинные подписи и поиск отображаются штатно. |
| PiP Ghostgram | Видео по кнопке, свайп вверх, возврат, pause/resume, повороты, блокировка, повторное открытие. Два плеера не должны звучать одновременно. У reference-кода контроллер создаётся кнопкой; первый свайп без подготовки может не запустить PiP — ограничение описано в GHOSTGRAM_PIP_PORT.md. |
| Редактор | Обычный и большой редакторы: клавиатура ↔ эмодзи ↔ быстрое форматирование, без скачков и перекрытия отправки; выделение и форматирование текста сохраняются. |
| Выбор сообщений | «Выбрать» выбирает указанный элемент, «По автору» — сообщения автора, включая вложения и альбомы. Значки ровные и различаются. |
| Копирование | Обычные и защищённые посты: одиночная пересылка и рассылка, разные адресаты/темы и отложенное время. Текст, вложения, ссылки и структурированные посты полные; ошибка/отмена не отправляет частичный результат. Серверный репост соблюдает ограничения Telegram. |
| Защищённый экспорт | «Свободный скриншот» OFF/ON вместе с переключателями копирования. Проверить меню и полноэкранную галерею, фото/видео/качество, выключение после открытия меню. OFF блокирует новый защищённый экспорт; обычное сохранение работает. |
| Перевод | Контекстный перевод, панель чата, русский текст, целевой/предпочитаемые/исключённые языки, Apple/Google/Яндекс и личные Gemini/ChatGPT/DeepSeek. Ошибка ключа не подменяет провайдера. |
| Расшифровка | Telegram Premium при доступности, Apple/Whisper/Vosk, Gemini/ChatGPT/Grok/Cloudflare: повторная явная команда запускает новую расшифровку; отмена, переключение провайдера, загрузка моделей и офлайн-пути. |
| Временные и удалённые сообщения | Включение/выключение настроек, повторное открытие поддерживаемого медиа, независимая обработка реального удаления, корректность архива и отложенных сообщений. |
| Кружки и истории | Битрейт в кбит/с, удобство бегунка, FPS/кодек/камера; HQ-сохранение историй, разрешения Фото, инкогнито и явная отметка одной истории. |
| Регрессии | Темы/иконки, прокси после background/foreground, очистка архива, папки/форумы, уведомления и отправка обычных сообщений. |

При ошибке приложить запись экрана или crash-архив через штатное предложение отправки в @NagramiX_bot. Успех enqueue не подтверждает доставку отчёта; бесплатная подпись не добавляет APNs.
