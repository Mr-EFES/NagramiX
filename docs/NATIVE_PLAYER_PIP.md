# Системный PiP через AVPlayer

Новая команда пользователя после удаления прежнего PiP. Финальная стадия `native_player_pip` после `pip_removal_work`; старые sample-buffer контроллеры не возвращаются. Системный AVPictureInPictureController получает полноценный AVPlayerLayer с отдельным AVPlayer и исходным MP4/MOV из MediaBox. Передача: явный запрос → полный файл/lease → точная позиция → кадр готов/audio activation → системный запуск → didStart закрывает галерею. Пока источник готовится, галерея не закрывается. При ошибке после передачи оригинальный плеер получает позицию/состояние обратно. Уход со страницы до старта отменяет подготовку без сообщения об ошибке. Запрос файла ограничен 60 секундами, подготовка слоя 10 секундами, системный старт отдельными 8 секундами.

Настройка «Картинка в Картинке свайпом» — «Прочее», сразу после звонков, прежний ключ и сохранённый ON/OFF. Кнопка доступна независимо от настройки свайпа. По умолчанию вертикальный свайп вверх/вниз, горизонтальный сохраняет перелистывание. Этот вариант выбран до ответа на уточняющий вопрос. Pinch, масштабирование и UIControls не перехватываются. Движение, resize, скрытие и повороты окна выполняет iOS; положение окна не навязывается приложением. Обычные Play/перемотка и код фонового звука не переписаны.

Поддержаны обычные Native/HLS сообщения с доступным исходным MP4/MOV: для HLS загружается исходный файл, а не локальный HTTP-плейлист. Не поддержаны веб-встраивания/DRM, секретные и защищённые видео, Live Photo, анимации, кружки, платное и исчезающее содержимое. До готовности файла видео продолжает проигрываться; передача в AVPlayer кратко приостанавливает исходный декодер. Старый плеер не получает новый аудиозапуск при отказе до передачи владения. На время PiP отдельная аудиосессия и Now Playing принадлежат AVPlayer; возврат восстанавливает исходную галерею и timestamp, закрытие останавливает AVPlayer и освобождает файл/audio.

Проверено локально: точные SHA/применение stage, отказ при изменении входов без частичной записи, сохранение методов Play/автовоспроизведения/background и синтаксическая проверка Swift tree-sitter. Полная композиция последующих стадий, Apple SDK и физический iPhone ещё не проверены. Нельзя обещать успешный запуск с первого нажатия или отсутствие вылетов до такой проверки. Новая сборка и публикация только по отдельной команде пользователя.
