# Актуальные короткие названия настроек

16 октября 2026 пользователь утвердил точный список всех 45 переключателей трёх вкладок. 33 русские подписи изменены, 12 совпали с прежними. Ниже — текущие названия; более ранние предложения и список из 34 переименований не определяют новые подписи.

Все 45 строк используют штатный `maximumNumberOfLines: 0` (добавлен восьми оставшимся строкам). Сохраняются штатные шрифты, тема, отступы и автоматическое измерение высоты; на узких экранах и при увеличенном шрифте текст переносится без обрезания. Поиск использует те же заголовки. Отдельный экран прокси, заголовки групп и названия действий внутри чата не менялись. По последующим уточнениям16октября «Не показывать Рекламу» заменён положительным чекбоксом **Показывать «Рекламу»**, OFF по умолчанию; единая настройка управляет proxy sponsor и встроенной рекламой Telegram. [Актуальный контракт](ADVERTISING_VISIBILITY.md). Обычные рекламные посты администраторов не фильтруются.

## Свайп для записи

Единственное изменение смысла checkbox: «Свайп для записи» теперь положительный. OFF запрещает запуск камеры историй свайпом, ON разрешает штатный жест. На первой установке без сохранённого выбора checkbox OFF; холодный перезапуск существующей установки сохраняет выбор. Явные кнопки камеры и настройки скрытия/подтверждения/инкогнито историй не изменены.

Для совместимости сохранён `nagramix.stories.disableCameraSwipe`: отсутствующий ключ по-прежнему означает `true`. UI читает `!settings.disableStoryCameraSwipe`, callback сохраняет `!value`; сохранённые `true`/`false` продолжают запрещать/разрешать жест соответственно. Нового ключа, миграции и сброса нет. Положительные имена используются в UI entry/callback/accessor; stable ID остаётся 26. Английская подпись этой строки — `Swipe to record`, остальные EN строки прежние.

## Проверка и ограничения

Чистый полный apply_overlay на закреплённой Telegram 13.0 базе: 573 файла, 4 ожидаемых изменены, 569 побайтно прежние относительно proof сборки 92. Изменены только RU/EN NagramiXCore strings, NagramiXPresentationStrings и NagramiXSettingsController. Все 45 видимых заголовков и заголовков поиска совпали с утверждённым списком; дубликатов ключей нет, остальные локализации прежние. Точное обратное сравнение UI подтверждает сохранение остальных callbacks, категорий, порядка, stable IDs и алгоритма поиска. Проверены default/legacy ON/OFF и запись обратного значения при переключении, неизменность обеих native gates жестов, Swift grammar и порядок аргументов всех 45 switch-вызовов по реальному pinned initializer. Это проверка исходников, а не выполнение UIKit/камеры на iPhone.

Доказательства: `/workspace/.codex-validation-nagramix-short-labels/{before,overlay,labels.json,verify.py,verification.json}`. Нативная компиляция и физическая проверка последней правки не выполнялись: source_checked/native_compile_pending/device_pending. IPA, push и commit не запускались, версия прежняя. Готовый build 92 этих правок не содержит. Следующий шаг: отдельно разрешённая пользователем сборка, затем проверка трёх вкладок с обычным/увеличенным текстом на узком и большом iPhone; первой установки, ON/OFF свайпа и сохранения выбора после холодного перезапуска.
