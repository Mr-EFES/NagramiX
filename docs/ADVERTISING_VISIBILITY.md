# Показать рекламу

16 октября 2026 пользователь запросил единый положительный переключатель вместо «Не показывать Рекламу». Пункт находится в Интерфейс / Панель вкладок, stable ID 5. RU: «Показать рекламу», EN: «Show ads»; поиск использует тот же заголовок. Текущий localization key сохранён, несмотря на прежнее имя HideProxySponsorChannel.

| Состояние | Канал спонсора прокси | Встроенные рекламные карточки Telegram |
| --- | --- | --- |
| OFF, первая установка | Скрыт | Скрыты; запросы рекламных сообщений и рекламных результатов поиска не запускаются |
| ON | Штатный показ при наличии спонсора | Штатный показ при наличии рекламы, с прежними серверными условиями и ограничениями |

Обычные рекламные публикации администраторов каналов не помечены Telegram как sponsored content. Этот переключатель не распознаёт и не удаляет такие сообщения. Не меняются подписки, обычные результаты поиска, пользовательские сообщения, премиум-настройки аккаунта и серверные права.

## Хранение и обновление

Единственный основной сохранённый ключ прежний: `nagramix.interface.hideProxySponsorChannel`, обратное значение. Положительный `showAdvertising` читает/пишет инверсию поля hideProxySponsorChannel. Общий Foundation-only NagramiXAdvertisingSettings читает основной hide key; только при его отсутствии — прежний `nagramix.interface.showProxySponsorChannel`. Когда нет обоих ключей, showAdvertising=false. Основной ключ имеет приоритет над legacy, в том числе при false. После обычного обновления сохраняется hide key, legacy удаляется прежним кодом. Явные ON/OFF сохраняются при холодном перезапуске, принудительного сброса нет.

Специальное advertisingChangedNotification отправляется только при изменении эффективного значения, после сохранения. UI списка чатов пересчитывает штатные entries через существующую ревизию; скрывается прежняя proxy promo entry без удаления обычных диалогов. Core-сигнал с distinctUntilChanged наблюдает ту же настройку; observers и disposables освобождаются.

## Интеграция Telegram 13.0

- AdMessagesHistoryContext — общий источник рекламы каналов/ботов и видео. OFF блокирует чтение рекламного кэша и запуск запроса, отменяет текущую загрузку, публикует пустое состояние. Поздний callback проверяет текущее разрешение и поколение; OFF→ON не возвращает ответ отменённого запроса. ON повторно активирует только уже запрошенные контексты, сохраняя native manual activation.
- Публичный state дополнительно фильтруется текущим разрешением. Native видео-плеер уже очищает adState/adSchedule при пустом состоянии, отдельного плеера или таймера нет.
- ChatHistoryListNode очищает fixed/dynamic рекламу, интервалы и предзагрузку рекламного peer; версия списка повышается для немедленной перерисовки. Рендер и вставка динамической рекламы дополнительно проверяют разрешение.
- AdPeers — при OFF возвращает пустые рекламные результаты без getSponsoredPeers; ON возвращает прежний запрос и парсер. Обычный поиск не меняется. Существующий adsHidden в поиске объединён с текущей настройкой, чтобы убрать и кэшированные карточки.
- View/click sponsored callbacks при OFF не отправляются; обычные read receipts, send/edit/playback и серверная настройка Premium не меняются. При ON прежние API/параметры/парсеры сохранены.

Новая функция apply_advertising_controls вызывается последней и проверяет SHA256 всех пяти входных native-файлов до любой записи; все замены сначала выполняются в памяти. TelegramCore и TelegramUI уже имеют зависимость NagramiXMediaSettings; новых внешних зависимостей нет.
