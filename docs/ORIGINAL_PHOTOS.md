# Прежний вариант оригинальных фотографий

**Заменён по выбору пользователя** на [фото максимального качества](HIGH_QUALITY_PHOTOS.md) в стандартном photo-медиа Telegram.

Подготовленный ранее image-document transport и специальное большое отображение документов в NagramiX удалены из overlay. Они не обеспечивали одинаковый photo bubble в других клиентах и не входят в текущую реализацию. Явная штатная отправка фото файлом остаётся доступна.

Названный пользователем reference **Nagram** относился только к видео; оригинальных фото с обычным видом во всех клиентах он не встречал. У photo API нет контрактного флага сохранения исходных байтов без обработки. По запросу пользователя новый режим называется «Фото без сжатия», сохраняет стандартный тип фотографии и не обещает byte identity.
