# Аватарка: истории по тапу, предпросмотр по удержанию

Сборка **0.8.5/build165** и пакет проверены; физическая приёмка — device_pending. Публикация и точные подтверждения — [RELEASE_STATUS](RELEASE_STATUS.md).

Новая правка после 0.8.4: `source_checked / native_compile_passed / device_pending`. По команде пользователя короткое нажатие и удерживание аватарки в обычном списке переписок имеют разные действия. Поведение одинаково при ON/OFF «Опций чатов по тапу»; ключ, default true и stable IDs этой настройки не менялись.

## Жесты

| Действие | Результат |
| --- | --- |
| Короткий тап, у собеседника есть доступная история | Прежний native маршрут историй с его подтверждениями и политикой просмотра |
| Короткий тап, историй нет | Обычное открытие переписки, как по строке чата |
| Удерживание аватарки | Полноэкранный readonly-предпросмотр без composer и автоматической отметки прочтения |
| Удерживание вне аватарки | Прежнее действие по текущей настройке меню чатов |

Наличие историй берётся из текущего peerData.storyState: `totalCount > 0` либо штатный `hasLiveItems`. Уже просмотренные, но ещё доступные истории также открываются. При отсутствии историй вызывается тот же метод, что и при обычном выборе строки. Нативное тело `ChatListItem.selected` перенесено в один общий `nagramiXOpenChatFromListItem` без изменений: message/peer routing, promo, темы, bot forum и community source остаются прежними.

Существующий eligibility guard аватарки не расширен: editing, раскрытые боковые действия, picker/inline/community layout, displayAsMessage и отсутствие callback не получают новый маршрут. Linked community сохраняет свой native avatar action. Group reference/archive и loading сохраняют прежнюю обработку. Распознавание удерживания по текущим bounds, отмена context extraction и отмена ожидающего короткого tap побайтно прежние. После удерживания короткий tap не должен дополнительно открыть историю или активный чат.

## «Ответить» и кнопка «Назад»

Readonly-предпросмотр сохраняет неизменяемый запрет чтения. «Ответить» по-прежнему ждёт закрытия контекстного меню и создаёт отдельный обычный ChatController с выбранным сообщением, темой и фильтром. Новый экран заменяет ровно текущий предпросмотр в navigation stack; все предшествующие экраны остаются в прежнем порядке. Поэтому один Back возвращает в список/папку/предыдущее меню, а не в прежний readonly-экран.

Замену выполняет native `replaceControllersAndPush` через существующий `NavigateToChatControllerParams.pushController`. Она происходит после штатных проверок навигации и возраста. До commit проверяется, что исходный предпросмотр ещё верхний экран. Callback после Back, перехода на другой экран или уже выполненного ответа не создаёт вторую переписку и не возвращает закрытый просмотр. Слабый захват не удерживает ушедший экран.

Выбранный reply subject, innerSubject, full forum chat, права отправки, frozen checks и фокус composer прежние. Отложенные реакции и их отправка при обычном активном открытии не менялись. Сохранение, копирование, выделение, закрепление, удаление и пересылка в режиме предпросмотра сами по себе не активируют исходный чат. Обработчики обычной переписки и политика подтверждения просмотра историй не переписываются.

## Реализация и проверки

Поздняя стадия `avatar_preview_navigation` после `author_icon_variant_five`: два файла (`ChatListItem.swift`, `ChatControllerLoadDisplayNode.swift`), три точные операции и семь SHA guards. Новых dependencies, ресурсов, настроек или публичных API нет. Canonical ранних стадий неизменны; все inputs/templates/guards/anchors/outputs проверяются до первой записи. Предшествующие validators обратимо снимают новую стадию.

```sh
python3 scripts/validate_avatar_preview_navigation.py --source <native> --swiftc <swiftc> --report <json>
```

В debug и `-O` проходят по 87 проверок с фактическими avatar tap/hold callbacks, eligibility, общим native row-selection body и новым commit closure. UIKit, метаданные peer/story и navigation container представлены явными границами. Проверены оба значения настройки, истории/нет историй/нулевой счётчик/live, фазы tap, повторные удерживания, cancellation, темы и bot forum, linked community и исключения, сохранение предыдущего стека, один Back, отложенный commit после ухода, другой верхний экран, двойной ответ и освобождение preview. Старый реальный tap handler и native default push отдельно воспроизводят ошибки и отвергаются в обоих режимах.

29 неверных входов отвергаются без частичной записи; Swift parse двух целых файлов проходит. Final post-port выполнен после новой стадии на полном подготовленном дереве; последние семь стадий проверены с учётом последовательных правок одного файла. Итог совпадает побайтно, signature pushController сохранена, upstream PostboxImportCheck проходит. Прежняя проверка author badge проходит через актуальную цепочку восстановления. Локальные проверки не исполняют настоящий UIKit, сетевые read receipts или stories API.

Артефакты сессии вне Git: `/tmp/nagramix-avatar-preview/verification.json`, `verification.log`, `composition.log`, `author-regression.log`. Временные файлы не являются долговременным архивом. SDK и IPA подтверждены поздней сборкой 0.8.5/build165; опубликованный 0.8.4 сохранён.
