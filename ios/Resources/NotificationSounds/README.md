# Встроенные мелодии уведомлений

Локальный резерв штатного каталога: 23 системные и 8 классических мелодий. Имена файлов соответствуют ключам cloudSoundMapping Telegram 13.0; серверные ID и формат сохранённых настроек не меняются. 0.m4a остаётся штатным файлом базы.

20 прежних мелодий взяты побайтно из официального Telegram-iOS, ревизия 5b666687531c72e73a8fea920bb4e2f84a05d4ac, каталог Telegram/Telegram-iOS/Resources/notifications. 11 новых системных мелодий — исходные звуки iOS из архивного набора [iOS-System-Sounds](https://github.com/rob-paprocki/iOS-System-Sounds/tree/7d389913639532e390bf9bbf59f2f933f13f2bd0/Current), раздел Encore Infinitum. Они преобразованы из CAF в AAC/M4A, 192 кбит/с, без изменения длительности и скорости. Звуки iOS принадлежат Apple; лицензия MIT архивного набора относится к его инструментам и метаданным, а не к аудио.

manifest.json фиксирует URL, ревизию, Git blob SHA-1 и SHA-256 исходников, преобразование, длительность и SHA-256 каждого итогового файла. Загрузка и преобразование во время сборки не нужны. Overlay проверяет целостность и копирует только 31 файл M4A в существующую группу AppResources; README и manifest в приложение не попадают. Проверка IPA требует тот же полный набор и совпадение хешей.
