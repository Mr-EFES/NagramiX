# Графика и тексты первого запуска

16 октября 2026 пользователь выбрал присланные изображения: отдельную марку NagramiX и лист из шести сцен. Используются прозрачные оригиналы именно этих рисунков, сохранённые в `ios/branding/OnboardingMasters/`. Белые JPEG из сообщения также сохранены для происхождения; заново рисунки не генерировались.

`scripts/prepare_onboarding_artwork.py` разделяет оригинальный лист по фактическим промежуткам, исключает три маленьких фрагмента соседних сцен в промежутках, пропорционально масштабирует рисунки и добавляет прозрачные поля. Цвета, композиции и исходная прозрачность сохраняются. `provenance.json` у master-файлов фиксирует SHA, координаты и масштаб. Нельзя вернуться к равной сетке3×2: её границы пересекают рисунки.

Шесть runtime PNG имеют1024×1024RGBA, Phone —1024×864RGBA; максимальный видимый габарит по alpha>16 составляет800px (±1px после ресэмплинга). Поля не менее~11% по основной оси. PNG:

1. `NagramiXOnboardingLogo.png` — NagramiX.
2. `NagramiXOnboardingCommunication.png` — На связи.
3. `NagramiXOnboardingFree.png` — Бесплатно.
4. `NagramiXOnboardingPersonal.png` — Под вас.
5. `NagramiXOnboardingPrivacy.png` — Приватность.
6. `NagramiXOnboardingNearby.png` — Всегда рядом.
7. `NagramiXOnboardingPhone.png` — Телефон: крупный смартфон с последнего согласованного референса, отдельный master `Phone.png`.

`manifest.json` фиксирует семь SHA256 до наложения на native tree. Старый runtime atlas удалён; оригинальный лист остаётся только master-источником. PNG входят в единственный AppResources; повторно добавлять в ios_application.resources нельзя. App icons1…8 независимы от этой графики и не изменены.

`copy.json` —13RU/13EN строк; на странице «Бесплатно»: «NagramiX — бесплатный клиент. Наши функции — без подписки.» (две строки). EN соответствует: «Our features need no subscription.» Порядок страниц и native callbacks сохранены. У карусели общий frame с aspectFit, единый масштаб, общий уровень заголовков и зазор20pt после безопасной видимой границы рисунка. Экран телефона учитывает доступную высоту и клавиатуру.
