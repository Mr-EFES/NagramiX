# Графика и тексты первого запуска

`copy.json` — единый источник13 строк RU и13 EN для шести страниц и кнопки. При наложении overlay изменяются только соответствующие Tour keys основных локализаций.

`NagramiXOnboardingAtlas.png` — новая ImageGen-иллюстрация RGBA1536×1024. Оригинал получен12октября2026; в репозиторий скопирован без изменения пикселей. Ячейки512×512: верхний ряд — общение, подарок, настройки; нижний — приватность, синхронизация, смартфон. UIKit/CoreGraphics выделяет ячейки при загрузке.

`manifest.json` фиксирует SHA256 atlas и существующей основной иконки `branding/AppIcons/1.png`. Иконка копируется в app bundle как `NagramiXOnboardingLogo.png`, без отдельного дублирования исходника в репозитории. Имена PNG перечислены в Telegram/BUILD, loader использует основной bundle.

[Поведение и проверка](../../../docs/BRANDED_ONBOARDING.md). Сгенерированные иллюстрации не заменяют основной логотип. При намеренной замене atlas/иконки обновить manifest, проверить прозрачность, сетку3×2 и отображение всех7 иллюстраций.
