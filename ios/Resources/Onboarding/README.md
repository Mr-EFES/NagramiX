# Графика и тексты первого запуска

`copy.json` — единый источник13строк RU и13EN для шести страниц и кнопки. Тексты, порядок страниц и штатные callbacks авторизации сохранены.

Три PNG получены через ImageGen15октября2026 и скопированы без дополнительного изменения пикселей:

- `NagramiXOnboardingLogo.png`: прозрачная круглая марка с орбитой, воссозданная по первому экрану после замечания о пропорциях;1254×1254, RGBA.
- `NagramiXOnboardingAtlas.png`: atlas3×2 полных композиций: связь, подарок, персонализация; приватность, синхронизация, телефон. Ячейки512×512; 1536×1024, RGBA.
- `NagramiXOnboardingPhone.png`: отдельный смартфон с маркой и орбитой для ввода номера; 1254×1254, RGBA.

Manifest фиксирует SHA256 всех трёх файлов до наложения на native tree. Основные app icons1…8 теперь независимы от приветственной графики и остаются побайтно прежними. Ресурсы входят в единственный AppResources через существующий glob; не добавлять их повторно в ios_application.resources.

Одна полная иллюстрация на страницу без дополнительных UIImageView поверх марки. Текст, точки и кнопка имеют отдельные области, перед заголовком заложен16pt от видимой границы иллюстрации. При нехватке высоты тело прокручивается. Графика воссоздана по референсам, не вырезана из скриншотов. [Реализация и границы проверки](../../../docs/BRANDED_ONBOARDING.md).
