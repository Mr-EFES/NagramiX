# Встроенная русская локализация

`ru.lproj/Localizable.strings` — официальный русский экспорт https://translations.telegram.org/ru/ios/export, полученный 2026-10-04. SHA-256 исходного экспорта: `f407efa0405c458026c51b9f314407700f500175a10b122184f30cffc1a75db4`.

В конце файла отдельно добавлены русские переводы и совместимые формы для ключей закреплённого Telegram-iOS, отсутствующих в текущем экспорте. Английский словарь не используется как русский. Overlay проверяет покрытие всех ключей английского ресурса upstream и останавливается при пробелах. Обновлять перевод вместе с аудитом новой базы; не возвращать английский fallback в русскую стартовую локализацию.
