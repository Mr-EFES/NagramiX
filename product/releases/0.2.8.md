# NagramiX 0.2.8

NagramiX 0.2.8 is the iPhone-only correction release following physical-device feedback on 0.2.7.

## Corrections in this candidate

1. The entire clean-install welcome carousel and primary start action begin in Russian regardless of iPhone language.
2. Telegram's native alternative action offers the supported iPhone language (for example, English) and continues authorization in that selected language.
3. The clean-install appearance starts with Telegram's built-in tinted dark theme; upgrades retain an explicit user-selected theme.
4. Enabling Wide Channel Posts now forces every ordinary main-timeline broadcast-channel bubble to the maximum safe width instead of only increasing its width constraint. Native reactions, media, metadata and context actions remain intact.
5. The verified rear-camera round-video behavior from 0.2.7 is retained unchanged.

## Validation status

The macOS/Xcode ARM64 build, unsigned packaging, artifact validation and release publication passed in GitHub Actions for source commit `cde451da3fe719e8e83b47f80accca9d25c7b799`. The IPA requires external signing. The corrected clean-install flows and wide-post layouts must still be verified on a physical iPhone; compilation does not prove runtime acceptance. No Android application or APK is part of 0.2.8.

## Superseded after device testing

Physical-device testing found that this build displayed raw `Tour.Title*` and `Tour.Text*` keys on the welcome carousel because its Russian application localization resource was empty. Do not use 0.2.8 for acceptance; the resource packaging correction is assigned to 0.2.9.
