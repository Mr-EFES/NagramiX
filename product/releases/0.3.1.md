# NagramiX 0.3.1

Corrective candidate following physical-device feedback on 0.3.0.

## Corrections

1. Forward Without Author continues through Telegram's real destination composer and native send pipeline. Send When Online remains governed by Telegram's own eligibility rules for the selected private chat, alongside silent and scheduled delivery.
2. Russian remains the application default whenever no explicit user localization exists, on both clean and later launches. An explicit language selected by the user remains authoritative.
3. Telegram's built-in tinted dark theme (`.nightAccent`, shown as “Тёмная”) remains the clean-install/default-settings theme; it is not the black “Ночная” variant.
4. Wide Channel Posts identifies the destination broadcast timeline through `chatLocationPeerId`, covering every rendered text, media, video, grouped and forwarded-content post in that channel while preserving native reactions and footers.
5. Every pre-view story confirmation path requests an intrinsically blurred thumbnail in addition to the full-screen dark visual-effect layer, so source story content is not readable before approval.

## Acceptance status

Native compile and physical-iPhone acceptance are pending for this candidate. No runtime behavior is accepted solely from generated-source validation.
