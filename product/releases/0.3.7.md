# NagramiX 0.3.7

NagramiX 0.3.7 — актуальная и **почти стабильная** базовая версия проекта для iPhone. Вся дальнейшая разработка начинается от этой версии. Файлы заменённых релизов намеренно не хранятся в активном дереве.

## Состав версии

- Полный отслеживаемый нативный iOS overlay и брендинг NagramiX.
- Русский язык при чистой установке и тёмная тема по умолчанию.
- Управление вкладками и историями, пересылка, локальный архив сообщений, метаданные профиля, DNS, прокси, Force TCP, широкие посты каналов и «Выбрать сообщения автора», описанные в `product/features/`.
- Проверка встроенной русской локализации приветственного экрана во время сборки.

## Состояние проверки

Версия 0.3.7 обозначена владельцем продукта как почти стабильная, но ещё не окончательно стабильная. Авторитетная ARM64-сборка на macOS/Xcode и упаковка неподписанного IPA успешно прошли в GitHub Actions (запуск `35615184300`); сохранён только относящийся к 0.3.7 артефакт `NagramiX-0.3.7-unsigned-arm64`. Перед присвоением статуса stable остаётся полный регресс на физическом iPhone. IPA требует внешней подписи.
