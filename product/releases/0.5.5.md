# NagramiX 0.5.5

- Исправлен переход после подтверждения номера: при завершении входа используется уже открытая база аккаунта.
- Исправлены выбор сообщений от автора и удаление смешанного набора обычных и локально сохранённых сообщений.
- Убран дубль «Избранного» в рассылке. Действия с удалёнными голосовыми, кружками и видео используют полные локальные копии при одиночном, множественном и смешанном выделении.
- Список DNS сокращён: Системный, Telegram, Google, AdGuard, Cloudflare и Пользовательский DoH. Убраны повторения DNS в названиях; сохранённые идентификаторы настроек совместимы.
- Уменьшено число переключений аудиосессии при записи с музыкой, исправлены переходы и освобождение сессии.
- Добавлен «Анти-капс» для сообщений из четырёх и более заглавных букв; по умолчанию выключен.
- Добавлены анонимные стикеры с отдельной загрузкой без ссылки на стикерпак и скрытие сообщений заблокированных пользователей в ленте групп. Оба переключателя включены по умолчанию, ручной выбор сохраняется.
- Добавлен отсчёт3–2–1 перед новой записью кружка на селфи-камеру. Включён по умолчанию; задняя камера записывает без таймера, отмена прекращает подготовку.
- «Подмена профиля» / прежняя «Ссылка на профиль» полностью удалена из настроек и автоматической обработки сообщений.

Тестовая версия для iPhone 17 Pro Max с iOS27.0; минимальная iOS15.0. IPA неподписанный, требуется внешняя подпись. Сохранённые пользовательские настройки сохраняются. Работу входа, музыки, камеры, архива и доставки новых сообщений нужно подтвердить на физическом устройстве.
