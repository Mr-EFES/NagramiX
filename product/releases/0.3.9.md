# NagramiX 0.3.9

NagramiX 0.3.9 — кандидат в стабильную базовую версию для проверки на физическом iPhone. Версия собирается как неподписанный ARM64 IPA и требует внешней подписи.

## Главное в версии

- Исправлена внутренняя геометрия настройки «Широкие посты в каналах»: единая адаптивная ширина применяется не только к bubble и одиночному media, но и к штатной mosaic-раскладке альбомов из 2–10 фото/видео, text/caption, forward/reply headers, previews, documents, polls, reactions и footer.
- Добавлен глобальный поиск по настройкам NagramiX из всех трёх категорий «Интерфейс», «Функции» и «Прочее» независимо от выбранной вкладки.
- Переработан visual state локально сохранённых удалённых сообщений: основной content отображается с alpha 0.5, а отдельный нижний footer показывает theme-aware trash icon и настраиваемую однострочную метку удаления.
- Сохранены функции и исправления базовой версии 0.3.7: вкладки и истории, пересылка, локальный архив сообщений, метаданные профиля, DNS/DoH, proxy failover, Force TCP и остальные возможности из `product/features/`.

## Обязательная проверка перед stable

1. В public и private broadcast channels проверить Wide OFF/ON для текста, photo + caption, video, forwarded posts, альбомов из 2–10 media (включая mixed photo/video и длинный caption), polls, webpage, documents, paid media, reactions и comments footer.
2. Убедиться, что группы, supergroups, topics, Saved Messages и личные чаты сохраняют стандартную Telegram-геометрию.
3. Проверить portrait/landscape и, при наличии устройства, iPad/split-screen.
4. На каждой из трёх вкладок настроек выполнить одинаковые запросы `Proxy`, `Истории` и название настройки из «Интерфейс»; набор результатов должен быть одинаковым.
5. Проверить поиск по title, description и section, empty state, очистку, Back, Light/Dark/custom themes и действия найденных строк.
6. Выполнить общий smoke/regression: авторизация, запуск offline/proxy, камера, истории, звонки и основные операции с сообщениями.
7. Проверить normal/deleted cell reuse, live delete, media/albums, footer metadata и пользовательскую метку удаления (64 символа, empty fallback) во всех темах.

## Статус

Статические проверки и применение overlay к закреплённому Telegram-iOS 12.9.2 прошли. Авторитетный macOS GitHub Actions workflow успешно выполнил нативную ARM64-сборку, проверку и публикацию `NagramiX-0.3.9-unsigned.ipa`. До успешной установки, подписи и регресса на физическом iPhone версия остаётся кандидатом и не считается стабильной.
