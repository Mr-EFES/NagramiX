# NagramiX 0.2.6

This release contains native NagramiX 0.2.6 builds produced from the tracked 14-function product contract below. This is the complete **documented 0.2.6 release scope**, not a claim that every feature ever requested by the product owner has been implemented.

## Implemented functions

1. Tab visibility, labels and search controls.
2. Eight NagramiX application icons.
3. Front/rear round-video camera selection.
4. Story visibility, per-story confirmation and repost controls.
5. Forward with source and Copy as New without source, including native silent and scheduled send options.
6. Experimental local deleted-message archive.
7. Experimental locally observed message edit history.
8. DNS provider selection and custom DNS-over-HTTPS.
9. Native proxy checking, visibility controls and automatic failover.
10. Force TCP for calls.
11. Profile ID, approximate registration year and mutual-contact marker.
12. Offline and unavailable-proxy startup hardening.
13. Adaptive wide broadcast-channel posts.
14. Paginated Select From Author across available dialog or topic history.

## Release status

- The list above is an auditable release inventory. Requests that are not represented in the product specifications or feature registry must be inventoried, specified and implemented in a later release rather than retroactively claimed as part of 0.2.6.
- The IPA is unsigned and intended for external signing and physical-device testing.
- Source implementation does not replace native compilation or device acceptance.
- The APK is an ARM64 debug-signed physical-device test build; its metadata, signature report, SHA-256 and upstream provenance are attached.
