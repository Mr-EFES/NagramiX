# NagramiX 0.3.2

Corrective candidate following physical-device feedback on 0.3.1.

## Corrections

1. A clean authorization start no longer mistakes an absent saved localization for an already-applied Russian localization. Pressing the Russian start action now runs Telegram's real `downloadAndApplyLocalization("ru")` path and persists Russian; an explicit later user choice remains authoritative.
2. Both the initial theme and the System night-switch target use Telegram's built-in tinted dark `.nightAccent` theme (“Тёмная”), never the black `.night` variant (“Ночная”).
3. Wide Channel Posts resolves broadcast identity from the message destination peer, which is guaranteed to be present in the message peer dictionary, and keeps maximum-width geometry for text, media, video, albums, forwarded and sponsored channel entries.
4. Forward Without Author continues through Telegram's native destination composer. Send When Online uses Telegram's own presence eligibility, `.whenOnline` action and `scheduleWhenOnlineTimestamp`; it is not replaced with a custom scheduler or forced into ineligible chats.
5. Story confirmation retains the corrected blurred thumbnail and full-screen dark blur from 0.3.1.

## Acceptance status

Native compilation and physical-iPhone acceptance are pending for this candidate. Static validation does not establish runtime acceptance.
