# NagramiX 0.5.2

- «Непрочитанные сверху»: чаты, группы и каналы во всех папках по числу непрочитанных; закрепления сохраняются.
- «Видео без сжатия»: оригинальные видео из галереи с привычным просмотром для поддерживаемых форматов.
- «Фото без сжатия»: максимальное качество обычных фото во всех клиентах; отдельный переключатель больших фото убран.
- Панель действий при выделении нескольких сообщений в просмотре через аватарку; три способа пересылки и отдельная иконка рассылки.
- Завершение голосовых и кружков без запуска следующего; «Автопереход голосовых» выключен по умолчанию.
- Доработаны запись с музыкой и завершение повторных записей.
- «Ссылка на профиль» в новых текстах и подписях, отдельный экран настройки.
- Короткие названия настроек и интерфейс без лишних пояснений под переключателями.
- Локализовано предупреждение авторизации, добавлена защита от повторяющихся одинаковых окон.

Тестовый выпуск для физического iPhone на iOS15.0 и новее. Неподписанный IPA требует внешней подписи, например через SideStore. Сохранённые настройки остаются после обновления. Реальное аудио, отправку и работу жестов необходимо проверить на устройстве. Название «Фото без сжатия» означает максимальное качество стандартного photo-медиа; исходный файл побайтно сохраняется при отправке файлом.
