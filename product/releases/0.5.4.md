# NagramiX 0.5.4

- Свайпы между разделами «Интерфейс», «Функции» и «Прочее».
- Исправлена одиночная пересылка архивных сообщений без автора и отправка локальных вложений при рассылке.
- Добавлено сохранение удалённых голосовых в звуки уведомлений и кружков в «Фото».
- Исправлены состояния переключателей прокси; сохранён ручной выбор, автопереключение включается при двух и более серверах.
- Добавлен отдельный пункт «DNS Telegram» после системного DNS; оба используют штатное разрешение адресов.
- Новые приветственные экраны NagramiX и современная иллюстрация ввода телефона.
- «Не спрашивать оценку звонка» включено по умолчанию; выключение возвращает штатный запрос.
- Исправлены бесконечное ожидание рекордера, гонка очистки оригинального видео и ошибка доступности API сохранения архива.

Тестовая версия для iPhone, iOS15.0+. IPA неподписанный: требуется внешняя подпись. Все прежние функции и сохранённые настройки включены; работу новых изменений нужно проверить на устройстве.
