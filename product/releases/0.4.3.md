# NagramiX 0.4.3

Тестовая версия для проверки на физическом iPhone.

- Исправлено применение русского языка после первой авторизации и полная надпись «Изменить».
- Восстановлены штатные компоненты оформления Telegram; панели NagramiX изолированы.
- Предпросмотр истории использует качественное изображение с лёгким blur.
- В «Прочее» добавлен заголовок «Звонки» над Force TCP.
- Переключатели первого запуска приведены к согласованным значениям; ручной выбор сохраняется.

ARM64 IPA требует внешней подписи, например SideStore. Основа — Telegram-iOS 12.9.2. Стабильность и визуальные исправления ожидают физической проверки.
