# NagramiX 0.4.7

- Исправлен компактный список: уменьшены текст, аватары, высота строк и отступы; настройка по умолчанию выключена.
- Уточнены «Опции чатов по тапу»: удерживание аватарки открывает предпросмотр, остальной строки — штатное меню; свайпы переключают папки.
- Добавлено сохранение полных файлов входящих фото, видео, голосовых, кружков, аудио и документов в локальный архив удалённых сообщений.
- После «Удалённых сообщений» добавлены «Временные сообщения», по умолчанию выключены. При включении обоих сохраняются также временные/одноразовые вложения.
- Открытие сохранённых копий и очистка архива учитывают файлы и активные загрузки. Накопленные настройки и остальные функции сохранены.

Тестовый выпуск для проверки на физическом iPhone. IPA устанавливается через SideStore с внешней подписью. Архив сохраняет полученные доступные файлы; байты, не полученные до исчезновения доступа, восстановить нельзя. Проверка на устройстве ожидается.
