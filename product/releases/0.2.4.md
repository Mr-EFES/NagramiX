# NagramiX 0.2.4 pre-release scope

## iOS

The existing iOS 0.2.4 build contains the currently documented NagramiX feature set and was compiled against official Telegram-iOS 12.9.2. Physical iPhone regression remains required for runtime claims.

## Android

The previous NagramX-based APK is architecturally superseded. Its release asset must be replaced by an APK built from current official Telegram Android after the corrected independent NagramiX Kotlin/Java foundation passes CI. Most shared product features remain Android implementation backlog until ported from the product specifications.

## Release presentation

The GitHub pre-release should expose both IPA and APK only when each artifact's provenance matches the official-base policy. Notes must include iOS 13.0 and Android API 21 minimums for the current audited pins, signing requirements and the parity backlog.
