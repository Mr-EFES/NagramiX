# NagramiX 0.2.4 pre-release scope

## iOS

The existing iOS 0.2.4 build contains the currently documented NagramiX feature set and was compiled against official Telegram-iOS 12.9.2. Physical iPhone regression remains required for runtime claims.

## Android

The removed Android APK did not represent the current official-base architecture. A replacement may be built from current official Telegram Android only after the independent NagramiX Kotlin/Java implementation reaches the 0.2.4 parity gate. Most shared product features remain Android implementation backlog until ported from the product specifications.

## Release presentation

The GitHub pre-release should expose both IPA and APK only when each artifact's provenance matches the official-base policy and every Android feature in the 0.2.4 registry is implemented. Android build and publication workflows enforce this registry gate. Until it passes, the pre-release must not contain an Android APK. Notes must include iOS 13.0 and Android API 21 minimums for the current audited pins, signing requirements and any remaining device-validation backlog.
