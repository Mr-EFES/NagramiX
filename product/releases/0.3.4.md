# NagramiX 0.3.4

Physical-device verification candidate for the maximum-width channel-post correction, retaining the accepted 0.3.2 behavior and the 0.3.3 copy-cancellation and mutual-contact corrections.

## Wide channel post contract

When `interface.wideChannelPosts` is enabled, text-only posts, single photos, single videos, multi-photo albums, multi-video albums and mixed photo/video mosaics in broadcast-channel timelines receive the complete safe horizontal layout budget. Telegram's native media renderer supplies its existing aspect-fill/blur-background behavior, and native reactions, context menus, view counters and media interaction remain unchanged.

The overlay removes the floating share/summarize gutter for eligible channel posts, expands the common content constraint and final outer bubble, and replaces Telegram's compact media-mosaic cap with the full available channel width. Private chats, groups and forwarded channel content shown outside a channel timeline remain on the official Telegram layout.

## Retained corrections

- Russian remains the default localization until the user explicitly chooses another language.
- The selected default night theme remains Telegram's tinted dark (`nightAccent`) theme.
- Cancelling Copy as New clears its transient composer payload.
- The localized mutual-contact badge remains in eligible user profiles.
- Previously accepted round-video and story behavior is unchanged.

## Acceptance status

Post-overlay contract checks passed before native compilation and packaging. The authoritative macOS/Xcode/Bazel ARM64 build and publisher validation passed for commit `fd907453e7e230ab3b7d06f83f4166fa700bdf47`. This proves build compatibility only; the layouts listed above remain pending physical-iPhone verification in this exact 0.3.4 candidate.
