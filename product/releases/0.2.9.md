# NagramiX 0.2.9

NagramiX 0.2.9 replaces the defective 0.2.8 test build, whose clean-install welcome carousel displayed raw `Tour.*` keys because Telegram's generated Russian application localization was empty.

## Corrections in this candidate

1. The overlay now creates a complete bundled Russian application dictionary from the pinned English dictionary and replaces all six welcome titles, all six descriptions and the start button with Russian values.
2. Telegram's Bazel resource list includes that real Russian dictionary instead of generating its normal empty `ru.lproj` placeholder.
3. CI validates every required Russian welcome key both immediately after applying the overlay and inside the natively built `.app`; missing, empty, raw-key or non-Cyrillic values fail the build.
4. The Russian primary action and native alternative iPhone-language action are retained, with a readable bundled fallback before the downloaded langpack is available.
5. The tinted dark clean-install theme and maximum-width channel-post implementation remain included for renewed device testing.
6. The previously accepted rear-camera round-video behavior remains unchanged.

## Validation status

The macOS/Xcode ARM64 build, source and built-app Russian localization validation, unsigned packaging, artifact validation and release publication passed for exact source commit `053822a0093d8597d79c2ed9cebf21bb58d7a2bc`. The unsigned IPA must be externally signed. No corrected runtime behavior is accepted until it is checked on a physical iPhone.
