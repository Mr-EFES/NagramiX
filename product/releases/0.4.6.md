# NagramiX 0.4.6

- Исправлен выбор штатного светлого/тёмного варианта облачной темы при отсутствии точного совпадения базы.
- При применении темы из сетки сохраняется база её предпросмотра и используются соответствующие обои.
- Русские названия кнопок и вкладок раскрыты полностью; обновление языкового пакета сохраняет эти подписи.
- Добавлен выключенный по умолчанию «Компактный список чатов» с меньшими аватарами и одной строкой предпросмотра.
- Добавлены включённые по умолчанию «Опции чатов по тапу»: свайп-действия отключаются, штатный предпросмотр и меню сохраняются.
- Добавлены качество фото и фотоисторий, большие фото до 2560 пикселей, размер стикеров/крупных эмодзи и показ времени; начальные значения 100% / включено / 100% / включено.
- Системный режим, расписание, пользовательские настройки и накопленные функции сохранены.

Тестовый выпуск для проверки на физическом iPhone. IPA устанавливается через SideStore с внешней подписью. Проверка новых функций на устройстве ожидается.
