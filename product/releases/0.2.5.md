# NagramiX 0.2.5 pre-release scope

## Planned iOS changes

- Correct full-width Interface / Features / Other settings selector.
- Add optional wide posts in broadcast-channel timelines.
- Correct the single- and multi-destination “Переслать без” paths so supported
  content is always enqueued as a new editable message rather than a forward.

No 0.2.5 artifact is produced by this source change. Native compilation and
physical-iPhone verification are required before publication.

## Android

Android source parity has passed after archive scoping, global-deletion,
local-action, shared story confirmation, copy eligibility and DNS generation
review. The ARM64 workflow is manual-only and parity-gated. It has not been
dispatched; no APK may be built without explicit owner authorization.
