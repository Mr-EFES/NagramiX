# NagramiX 0.2.5 pre-release scope

## Planned iOS changes

- Correct full-width Interface / Features / Other settings selector.
- Add optional wide posts in broadcast-channel timelines.
- Correct the single- and multi-destination “Переслать без” paths so supported
  content is always enqueued as a new editable message rather than a forward.

The authoritative macOS workflow compiled this scope successfully in run
`34168064256`. The resulting unsigned ARM64 IPA is published in the
`v0.2.5-rc1` pre-release. Physical-iPhone verification remains required before
any runtime claim.

## Android

Android remains on the existing no-build hold until its 0.2.4 source-parity
backlog is complete. Wide channel posts must later receive an independent
native Android implementation before the platforms can claim 0.2.5 parity.
