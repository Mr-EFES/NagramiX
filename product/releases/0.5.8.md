# NagramiX 0.5.8

Тестовый выпуск для реального iPhone со всеми накопленными изменениями после0.5.7/build93. NagramiX — независимый неофициальный клиент на базе Telegram13.0. Наши функции — без подписки; это не предоставляет платные возможности Telegram Premium.

## Новое и исправленное в этом выпуске

- **Автораскрытие спойлеров** в «Функции → Сообщения»: текст, фотографии и видео под обычным спойлером видны без нажатия. По умолчанию ON; выбранные пользователем OFF/ON сохраняются после полного закрытия приложения. При OFF возвращается штатное раскрытие по нажатию. Отдельные ограничения платных, одноразовых и чувствительных медиа сохраняются.
- **Сохранённые удалённые и одноразовые видеокружки:** исправлена цветная подложка при раскрытии. Используется штатный плеер, сохранены50% прозрачности и отметка локально сохранённого сообщения.
- **Панель выделенных сообщений:** убрано временное перестроение внутренних кнопок при добавлении каждого сообщения. Во время проверки нового выбора действия недоступны, затем применяются актуальные права выбранных сообщений.
- **Персональные уведомления:**23 встроенных системных и8 классических звуков доступны независимо от серверного кеша пользовательских мелодий. Сохранены загрузка своих звуков, подтверждение/отмена и настройки отдельных чатов; исправлено соответствие резервного предпрослушивания мелодии «По умолчанию».
- **Компактный список чатов:** кнопка запуска мини-приложения «Открыть» помещается внутри строки. Дата и текст учитывают её размер; при крупном шрифте или узком экране высота строки адаптируется.
- Уточнены подписи: **«Картинка в Картинке» свайпом**, **Видео без сжатия**, **Скрыть оценку звонков**, **Регистрация аккаунта**, **Показывать «Рекламу»**. В контекстном меню — **Выделить**, а название соответствующей настройки остаётся **«Выделить от автора»**.

## Возможности NagramiX и отличия от стандартного Telegram

| Область | Что добавляет NagramiX |
| --- | --- |
| Интерфейс | Компактные строки чатов, широкие посты каналов, сортировка незакреплённых чатов по числу непрочитанных во всех папках, управление нижней панелью канала, реакциями и приветствиями. |
| Вкладки и оформление | Скрытие «Контактов»/«Звонков», кнопки поиска и прокси,8 иконок NagramiX с названиями по цветам. Сохраняются штатные темы, акценты и настройки оформления Telegram. |
| Действия с сообщениями | «Репост» сохраняет автора; «Переслать» отправляет копию без автора одному адресату; «Рассылка» отправляет копии нескольким. Видимость действий настраивается отдельно. Есть выделение сообщений автора и редактирование двойным тапом. |
| Локальная история | По включению доступны локальные копии замеченных удалённых сообщений, временных вложений и история замеченных правок. Сохранённые голосовые можно добавить в библиотеку звуков, кружки — сохранить в Фото при доступных локальных данных. |
| Просмотр чатов | Удерживание открывает меню чата; аватарка — просмотр без обычного ввода и автоматической отметки прочтения. Реакции такого просмотра сохраняются локально до обычного открытия; «Ответить» переводит в активную переписку. |
| Спойлеры и обработка | Автораскрытие текстовых и медиа-спойлеров, анти-капс для новых исходящих сообщений, скрытие сообщений заблокированных пользователей, автоматическое отключение уведомлений новых каналов. |
| Видео и звук | Переход видео в «Картинку в Картинке» коротким свайпом, фоновый звук видео, настройка перехода между голосовыми/кружками, запись с основной камеры и таймер селфи-камеры. Настройка записи без остановки музыки применяется к голосовым и кружкам. |
| Качество отправки | «Фото без сжатия» использует штатную отправку фото с максимальным качеством JPEG и HD-размером без увеличения исходника. «Видео без сжатия» отправляет неизменённый оригинал из галереи; для подходящих MP4/MOV сохраняется штатное представление видео. |
| Истории | Скрытие историй, отдельное разрешение запуска камеры свайпом, подтверждение просмотра, репост и локальный режим анонимного просмотра без отправки новых отметок. |
| Профили | ID, примерная дата регистрации, значок взаимного контакта и точное время последней активности, если оно доступно клиенту. |
| Стикеры и эмодзи | Настройка размера, отображения времени и отправки стикеров без указания автора набора. |
| Соединение | Выбор системного DNS, DNS Telegram или DNS-over-HTTPS, свой DoH URL, проверка и автоматическая смена прокси, обход прокси при VPN, возврат яркости после QR-кода, TCP для звонков и уровни ускорения скачивания. |
| Звонки | Подтверждение исходящего вызова и скрытие автоматического предложения оценить звонок. |
| Реклама | «Показывать „Рекламу“» по умолчанию OFF скрывает канал sponsor proxy и встроенную рекламу Telegram. ON возвращает штатное отображение. Обычные публикации администраторов каналов не фильтруются. |
| Настройки и запуск | Разделы «Интерфейс», «Функции», «Прочее», глобальный поиск по настройкам, переключение разделов свайпом, сохранение ручного выбора и отдельные приветственные иллюстрации NagramiX. |

В стандартном Telegram нет такого набора переключателей NagramiX. Обычная переписка, авторизация, серверные права и протокол остаются на базе Telegram. Возможности, уже существующие в Telegram, используются штатными компонентами там, где это предусмотрено интеграцией.

Локальный архив не восстанавливает неизвестные клиенту сообщения с сервера: сохраняется только доступное приложению содержимое. Отправка копий сохраняет ограничения защищённых чатов и неподдерживаемых вложений. «Фото без сжатия» не означает побайтное сохранение исходного файла; для этого остаётся штатная отправка документом. Информация профиля не раскрывает скрытые сервером сведения.

## Установка и тестирование

- **iOS15.0 и новее, ARM64, физический iPhone.** Файл `NagramiX-0.5.8-unsigned.ipa` не подписан; используйте привычный способ внешней подписи, например SideStore.
- В релиз приложены IPA, `SHA256SUMS` и `BUILD-PROVENANCE.txt` с исходным коммитом и ссылкой на сборку.
- Это тестовая версия. Успешная компиляция и проверка пакета не заменяют проверку на устройстве. Приоритет: ON/OFF спойлеров после перезапуска, обычные/сохранённые кружки, выделение смешанных сообщений, персональные уведомления, mini-app «Открыть», PiP/поворот экрана и запись с музыкой.
- Предыдущие релизы и их файлы сохраняются.
