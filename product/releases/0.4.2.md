# NagramiX 0.4.2

- Оформление использует штатные темы Telegram. Убрано дополнительное изменение фона настроек NagramiX; тема iOS при запуске определяется по окну приложения.
- Русский язык используется по умолчанию в интерфейсе и сетевом языковом пакете. Ручной выбор языка и темы сохраняется.
- Сохранены все функции и исправления предыдущей проверенной пользователем версии: прокси, отмена первого кружка, поиск, архивные сообщения и контекстное меню.

ARM64 IPA для iPhone требует внешней подписи, например SideStore. Основа — Telegram-iOS 12.9.2. Нативная сборка №67 прошла успешно; релиз опубликован. Пользователь подтвердил предыдущие функции, но при проверке этого IPA обнаружил английский язык после первого входа и нарушения отображения оформления. Версия не подтверждена как стабильная. Исправления в main предназначены для следующей сборки и не содержатся в опубликованном IPA.
