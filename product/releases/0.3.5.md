# NagramiX 0.3.5

NagramiX 0.3.5 is an unsigned ARM64 iPhone build of the current tracked NagramiX overlay on the audited Telegram-iOS base.

## Included functionality

1. NagramiX interface, feature and miscellaneous settings.
2. Tab visibility, labels and search controls, plus eight application icons.
3. Front/rear round-video camera selection and story controls.
4. Forward-with-source and Copy as New modes.
5. Experimental locally observed deleted messages and edit history.
6. DNS-over-HTTPS selection, proxy controls and failover, and Force TCP for calls.
7. Profile metadata, Select From Author, and corrected maximum-width channel
   posts that use the full safe timeline width even when portrait media or
   short text has a narrower intrinsic layout.
8. Russian-first clean-install authorization, the iPhone language as the native alternative and the tinted dark clean-install theme.
9. CI validation of the bundled Russian welcome strings in both overlay source and the natively built application.

## Validation status

The authoritative macOS/Xcode ARM64 build, built-application localization check,
unsigned packaging, artifact validation and release publication passed for exact
source commit `1fd5d59c8cb70907066cec2636f86f73701e4cb2`. The IPA requires external
signing. Compilation does not establish runtime acceptance; physical-iPhone
testing of the corrected wide-post geometry remains required.
