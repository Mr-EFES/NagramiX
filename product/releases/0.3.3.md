# NagramiX 0.3.3

Corrective candidate following physical-device acceptance of the working 0.3.2 Russian start, tinted dark theme, round-video camera and story controls.

## Corrections

1. Cancelling Forward Without Author now clears its transient payload, forward accessory and the text/caption seeded by NagramiX. An unrelated draft typed before ordinary Telegram forwarding is still preserved by Telegram's standard path.
2. Wide Channel Posts expands the mosaic layout budget itself, not only the outer bubble, so single media, photo/video albums and mixed photo/video groups can consume the complete safe channel width while native reactions and interactions remain intact.
3. The Mutual Contact option now renders a visible localized `👥 Mutual contact` / `👥 Взаимный контакт` badge in the actual user profile in addition to supported native contact-list rows, and only for real mutual non-bot users.
4. The 0.3.2 Russian localization, `.nightAccent` theme, round-video camera behavior and story controls are retained unchanged.

## Acceptance status

The authoritative macOS/Xcode/Bazel ARM64 build, unsigned packaging and publisher validation passed for commit `45cffc5867a9745828f71e5eafd21a6efc6fcc14`. Physical-iPhone acceptance of the three corrections remains pending. Device-passed 0.3.2 behavior must be regression-tested but is not reset to unverified merely because this candidate was rebuilt.
