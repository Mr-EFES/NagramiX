# Product identity

**NagramiX** is an independent, unofficial, non-commercial Telegram client for iPhone. It is not affiliated with, sponsored by or endorsed by Telegram Messenger Inc.

NagramiX targets iPhone/iOS and is implemented with Swift and Objective-C/Objective-C++ against official Telegram-iOS.

## Product workflow

1. Specify behavior, defaults, privacy constraints and acceptance criteria.
2. Implement it natively for iOS.
3. Validate compilation and physical-iPhone behavior separately.
4. Include only actually verified scope in a release.

## Releases

Development artifacts are unsigned ARM64 IPAs requiring external signing. Release notes must list the upstream version, minimum iOS version, hashes, signing state, implemented features, pending device tests and known limitations.
