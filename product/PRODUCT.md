# Идентичность продукта

**NagramiX** — независимый, неофициальный и некоммерческий клиент Telegram для iPhone. Проект не связан с Telegram Messenger Inc., не спонсируется и не одобряется Telegram.

NagramiX предназначен для iPhone/iOS и реализован на Swift и Objective-C/Objective-C++ поверх официального Telegram-iOS.

## Рабочий процесс

1. Описать поведение, значения по умолчанию, ограничения приватности и критерии приёмки.
2. Реализовать поведение нативно для iOS.
3. Отдельно проверить компиляцию и работу на физическом iPhone.
4. Включать в релиз только действительно проверенный объём.

## Релизы

Артефакты разработки — неподписанные ARM64 IPA, требующие внешней подписи. Примечания к релизу должны содержать версию upstream, минимальную версию iOS, хеши, состояние подписи, реализованные функции, ожидающие проверки сценарии и известные ограничения.
