# Продуктовый слой NagramiX

Этот каталог — источник истины о продукте NagramiX. Здесь определяется, **что** означает функция, прежде чем каталог `ios/` определит, **как** она интегрируется в официальные исходники Telegram-iOS.

## Правила

1. Единственная кодовая база приложения — официальный Telegram-iOS.
2. NagramX и другие клиенты используются только как источники идей; их код не компилируется и не копируется.
3. Идентификаторы настроек, значения по умолчанию, семантика, исключения приватности и критерии приёмки сначала описываются здесь.
4. Компиляция подтверждает совместимость сборки; проверка на iPhone учитывается отдельно.

## Содержимое

- `PRODUCT.md` — идентичность и модель релизов.
- `UPSTREAM_POLICY.md` — политика закрепления официального Telegram-iOS.
- `SETTINGS.md` — канонический контракт настроек.
- `COMPATIBILITY.md` — требования iOS и IPA.
- `features/registry.json` — машиночитаемый статус реализации iOS.
- `features/README.md` — жизненный цикл функций.
- `releases/` — состав и известные ограничения актуального релиза.
