# Совместимость и артефакты

## iPhone / iOS

- Официальная база: версия и commit Telegram-iOS из `ios/upstream.env`.
- Минимальная версия ОС текущего pin: **iOS 15.0**.
- Результат: неподписанный ARM64 IPA.
- Установка: требует внешней подписи; один из возможных способов — SideStore.

Минимальная версия определяется проверенным upstream pin. При каждой миграции upstream необходимо заново проверить deployment target.
