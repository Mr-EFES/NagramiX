# Автораскрытие спойлеров

Функции → Сообщения → **Автораскрытие спойлеров**. Включённый переключатель показывает текст, фотографии и видео под обычным спойлером без нажатия. При выключении действуют штатные раскрытие по нажатию и состояние ручного раскрытия текущего сообщения. Отдельного пояснения под переключателем нет; описание доступно поиску настроек.

Единственный ключ — `nagramix.messages.autoRevealSpoilers`, положительный смысл. При отсутствии ключа ON, включая первую установку и обновление. Явные OFF/ON сохраняются и читаются при холодном старте, без перезаписи значения при запуске. Хранение — существующий Foundation-only NagramiXMediaSettings; settings callback изменяет `settings.media.autoRevealSpoilers`. Stable ID145, прежние ID сохранены. Уведомление displayChangedNotification использует существующий observer и requestMessageUpdate для видимых сообщений; при следующем появлении остальных строк настройка читается заново.

Нативная интеграция `apply_auto_reveal_spoilers` применяется после предыдущих overlay-правок. До записи проверяются полные SHA256 четырёх файлов и все11 якорей. Меняются только два renderer и их BUILD-зависимости от уже существующего NagramiXMediaSettings:

- ChatMessageTextBubbleContentNode: эффективное состояние раскрытия равно настройке OR штатному ручному состоянию. Его используют layout, hit testing, выделение и ссылки. Автораскрытие не записывает искусственное ручное нажатие; штатный updateDisplayContentsUnderSpoilers остаётся прежним.
- ChatMessageInteractiveMediaNode: обычный MediaSpoilerMessageAttribute не создаёт маску при ON; доступность видимого медиа обновляется через прежний updateVisibility. При OFF снова используется нативная маска. При переключении не остаётся блокировки воспроизведения, установленной скрытым спойлером. Нативный pinch gate не изменён.

Сущности текста, подписи, атрибуты спойлера, исходящие сообщения и файлы не переписываются. Платный preview, секретное/одноразовое медиа и проверка чувствительного содержимого сохраняют свои отдельные ветки; функция не открывает такие материалы вместо штатного действия. Автозагрузка, autoplay policy, read/consume, отправка, хранение архива и меню не патчатся.

Статус: **implemented / source_checked / compile_passed / device_pending**. Включено в0.5.8/build94; физическая проверка ещё ожидается.

Локальная проверка: полный overlay585файлов,9изменённых/576прежних;11точных обратных замен; clean/rerun и дрейф каждого из4native файлов без частичных записей; проверка связей настройки/поиска/обновления и неизменности прежних ID. Грамматика5Swift файлов и Python compile проверены. Синтаксическая проверка не заменяет Apple SDK compile, UIKit и реальный UserDefaults после завершения процесса.
