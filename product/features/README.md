# Жизненный цикл функций

Опубликован обычный релиз **0.9.7**, сборка 213, база Telegram 13.2/iOS 15.0+. Нативная компиляция и проверка скачанного IPA пройдены; физические статусы меняются только по результатам пользователя.

[Полный каталог возможностей](../presentation/README.md) · [Статус сборки](../../docs/RELEASE_STATUS.md) · [План iPhone](../../docs/DEVICE_CHECK_097.md).

В реестре 80 compile_passed и 80 device_pending: текущие исходники прошли SDK/IPA проверку. Физические статусы не менять без результатов пользователя. Фоновое удержание и редактор альбомов не реализованы. Бесплатная подпись не добавляет APNs.

| Поле | Статус | Значение |
| --- | --- | --- |
| `specification` | `specified` | Поведение описано. |
| `ios.implementation` | `implemented` | Код включён в overlay. |
| `ios.compile` | `compile_passed` | Текущие исходники прошли Apple SDK compile. |
| `ios.compile` | `compile_pending` | Новая правка ждёт нативной сборки. |
| `ios.device` | `device_pending` | Физическая проверка не подтверждена. |
| `ios.device` | `device_passed` | Конкретная приёмка подтверждена пользователем. |

Защищённые контракты AGENTS.md сохраняются. Команда на текущий выпуск выполнена; следующая сборка — по отдельной команде.
