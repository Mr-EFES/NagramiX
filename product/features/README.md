# Жизненный цикл функций

Опубликован обычный релиз **0.8.4**, сборка 162, база Telegram 13.1.2/iOS 15.0+. Нативная компиляция и проверка скачанного IPA пройдены; физические статусы меняются только по результатам пользователя.

[Полный каталог 70 возможностей](../presentation/README.md) · [Статус сборки](../../docs/RELEASE_STATUS.md) · [План iPhone](../../docs/DEVICE_CHECK_084.md).

После успешной SDK/IPA проверки compile_pending обновить по факту; физические статусы не менять без результатов пользователя. Фоновое удержание и редактор альбомов не реализованы. Бесплатная подпись не добавляет APNs.

| Поле | Статус | Значение |
| --- | --- | --- |
| `specification` | `specified` | Поведение описано. |
| `ios.implementation` | `implemented` | Код включён в overlay. |
| `ios.compile` | `compile_passed` | Текущие исходники прошли Apple SDK compile. |
| `ios.compile` | `compile_pending` | Новая правка ждёт нативной сборки. |
| `ios.device` | `device_pending` | Физическая проверка не подтверждена. |
| `ios.device` | `device_passed` | Конкретная приёмка подтверждена пользователем. |

Защищённые контракты AGENTS.md сохраняются. Команда на текущий выпуск выполнена; следующая сборка — по отдельной команде.
