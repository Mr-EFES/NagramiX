# Жизненный цикл функций

Подготовлена [правка геометрии и запуска сохранённых кружков](../../docs/ARCHIVED_ROUND_VIDEO_FIX.md): штатный плеер, прежние прозрачность 50%, метка и отправка копий. Текущий код `compile_pending/device_pending`, в опубликованный №79 не входит. Следующая тестовая версия — 0.4.9; сборка только по отдельной команде.

`registry.json` описывает реализацию и уровень проверки функций кодовой базы. Поле `release` хранит текущую версию выпуска; новые записи с `compile_pending` готовятся к следующей сборке и не входят в опубликованный IPA. [Нижняя панель канала](channel-bottom-panel.md) — такая новая настройка.

Также подготовлены [редактирование двойным тапом и скрытие реакций](message-interaction-options.md), оба выключены по умолчанию.

[Ускорение загрузки](download-acceleration.md) также подготовлено к следующей сборке: default OFF, выбор Штатно / Среднее / Максимум доступен при ON. Прирост скорости ещё не измерен.

Доработка [опций чатов по тапу](chat-actions-on-hold.md): штатная архивация, полный просмотр по тапу/удерживанию аватарки без поля ввода и отметки прочтения. Статус текущего кода compile_pending, опубликованный IPA №79 этой доработки не содержит.

Подготовлена доработка [фонового видео без PiP](video-playback-options.md), а заголовки всех подкатегорий отображаются в верхнем регистре. Текущий код compile_pending/device_pending; сборка только по отдельной команде.

Доработано [отображение отправленных скриншотов](../../docs/PHOTO_JPEG_COMPATIBILITY_FIX.md): native progressive JPEG с выбранным качеством и чтение полного cached JPEG. Статус compile_pending/device_pending.

Также подготовлено [разделение пересылки и рассылки](message-distribution.md): «Переслать без» — один адресат; «Рассылка» — прежние копии нескольким адресатам. Нативная компиляция и проверка доставки ожидаются.

| Поле | Статус | Значение |
| --- | --- | --- |
| `specification` | `specified` | Поведение описано. |
| `ios.implementation` | `implemented` | Реализация включена в overlay. |
| `ios.compile` | `compile_passed` / `compile_pending` | Нативная компиляция подтверждена / изменённые исходники ожидают следующей сборки. |
| `ios.device` | `device_pending` | Нужна проверка на физическом устройстве. |
| `ios.device` | `device_passed` | Проверка на устройстве подтверждена. |

Реализация, компиляция и проверка устройства — отдельные критерии. Статус одного критерия не заменяет остальные. Для защищённых функций правила `AGENTS.md` обязательны независимо от полноты реестра; уточнять записи по фактическим результатам проверок.

Перед публикацией изменения версии выполнить `python3 scripts/validate_release_metadata.py`. Аннотация текущего релиза находится в `product/releases/` и синхронизируется с GitHub Releases.
