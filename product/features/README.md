# Жизненный цикл функций

Опубликован обычный релиз **0.9.8**, сборка 219, база Telegram 13.2/iOS 15.0+. Нативная компиляция и проверка скачанного IPA пройдены; физические статусы меняются только по результатам пользователя.

[Полный каталог возможностей](../presentation/README.md) · [Статус сборки](../../docs/RELEASE_STATUS.md) · [План iPhone](../../docs/DEVICE_CHECK_098.md).

После опубликованного build219 в `main` сохранены новые исправления очистки DoH, отступов статуса стикеров, названия «Максимум», значка SD/HQ/MAX, обычных file-caption в обоих редакторах и при редактировании, выравнивания «Шрифты» и отправки исходного видео. Для последних исходников в реестре73compile_passed/7compile_pending, все80device_pending; это не подтверждение включения новых правок в опубликованную IPA219. [Текущий статус](../../docs/RELEASE_STATUS.md), [исходное видео](../../docs/ORIGINAL_VIDEO_GALLERY.md). Физические статусы меняются только по результатам пользователя. Фоновое удержание и редактор альбомов не реализованы. Бесплатная подпись не добавляет APNs.

По прямой разовой команде владельца оставлен только релиз0.9.8; прежние публикации/теги/Actions и их артефакты удалены. [Сверка очистки](../../docs/RELEASE_098_REPOSITORY_CLEANUP.md).

| Поле | Статус | Значение |
| --- | --- | --- |
| `specification` | `specified` | Поведение описано. |
| `ios.implementation` | `implemented` | Код включён в overlay. |
| `ios.compile` | `compile_passed` | Текущие исходники прошли Apple SDK compile. |
| `ios.compile` | `compile_pending` | Новая правка ждёт нативной сборки. |
| `ios.device` | `device_pending` | Физическая проверка не подтверждена. |
| `ios.device` | `device_passed` | Конкретная приёмка подтверждена пользователем. |

Защищённые контракты AGENTS.md сохраняются. Команда на текущий выпуск выполнена; следующая сборка — по отдельной команде.
