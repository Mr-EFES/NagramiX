# Жизненный цикл функций

Базовая версия — **1.0**, сборка224, Telegram13.2/iOS15+. Владелец закрепил её для дальнейшей подготовки к App Store. Нативная сборка, пакет и публикация проверены:80compile_passed, все80device_pending.

[Реестр](registry.json) · [Каталог возможностей](../presentation/README.md) · [Статус](../../docs/RELEASE_STATUS.md) · [План iPhone](../../docs/DEVICE_CHECK_100.md) · [База и очистка](../../docs/REPOSITORY_BASELINE_100.md).

| Поле | Статус | Значение |
| --- | --- | --- |
| `specification` | `specified` | Поведение описано. |
| `ios.implementation` | `implemented` | Код включён в overlay. |
| `ios.compile` | `compile_passed` | Текущий код прошёл полный Apple SDK compile. |
| `ios.compile` | `compile_pending` | Новая правка ещё ждёт нативную сборку. |
| `ios.device` | `device_pending` | Физическая проверка не подтверждена. |
| `ios.device` | `device_passed` | Приёмка подтверждена результатом пользователя. |

Статусы новых исправлений обновлять по фактической проверке. Сохранённая история main не заменяет номер source конкретной IPA. Редактор альбомов и постоянное удержание приложения не реализованы, бесплатная подпись не даёт APNs. Следующая сборка и повышение версии — по отдельной команде владельца.
