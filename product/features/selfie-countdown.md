# Отсчёт 3–2–1

В «Настройки NagramiX → Функции → Круглые видео» добавляется переключатель «Отсчёт 3–2–1». По последнему уточнению пользователя включён по умолчанию при отсутствии сохранённого выбора; сохранённое значение ON/OFF не сбрасывается при обновлении или холодном старте. Ключ `nagramix.videoMessages.selfieCountdown` независим от выбора начальной камеры и музыки при записи.

При включении новая запись кружка на переднюю селфи-камеру показывает крупные белые 3 → 2 → 1 по центру живого круглого изображения. Камера предварительно запускает preview и автофокус. После трёх секунд начинается запись видео/аудио; цифры и время подготовки не добавляются в файл или его длительность. Для основной задней камеры таймера нет. При выключении используется штатный старт.

Отмена/отпускание до старта, закрытие экрана и уход в фон отменяют отсчёт без пустого сообщения. Блокировка жеста работает и во время отсчёта. Переключение на заднюю камеру во время подготовки завершает отсчёт и запускает запись. Смена камеры во время уже идущей записи и продолжение существующего кружка не добавляют новый таймер.

Native recording/encoding/send, view-once, editing, музыка, права доступа к камере/микрофону и начальная задняя камера сохраняются. Настройка доступна через RU/EN поиск, без поясняющего footer. Статус: implemented / compile_pending / device_pending. [Интеграция и физическая проверка](../../docs/SELFIE_COUNTDOWN.md).
