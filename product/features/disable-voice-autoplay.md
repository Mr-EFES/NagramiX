# Отключить автовоспроизведение голосовых

Настройки NagramiX → Функции → СООБЩЕНИЯ. По умолчанию включено при отсутствии сохранённого выбора; последующий выбор остаётся после перезапуска и обновления.

После окончания голосового сообщения или кружка следующее не запускается автоматически. Текущее сообщение останавливается и готово к повторному ручному воспроизведению. Выключение возвращает штатное последовательное проигрывание. Ручной выбор сообщения, кнопки следующего/предыдущего и музыка работают по прежней механике.

Состояние: implemented / compile_pending / device_pending. Подготовлено после опубликованного №83, новая сборка запрошена для физической проверки. [Интеграция и приёмка](../../docs/DISABLE_VOICE_AUTOPLAY.md).
