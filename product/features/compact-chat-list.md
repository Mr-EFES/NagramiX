# Компактный список чатов

После проверки предыдущего опубликованного IPA / build 77 пользователь повторно предоставил референс плотного списка Swiftgram, теперь в светлой теме. Подготовлена дополнительная правка высоты строки. Она ещё не входит в опубликованный IPA; текущий код — compile_pending/device_pending. Сборка 0.4.8 и публикация разрешены пользователем; результат — docs/RELEASE_STATUS.md.

Настройка «Интерфейс → Чаты → Компактный список чатов» выключена при отсутствии сохранённого значения. Выбранные ON/OFF сохраняются после перезапуска и обновления. Ключ iOS — `nagramix.interface.compactChatList`. Пункт и пояснение доступны в глобальном поиске; новые ключи/переключатели не добавлены.

## Исправленная плотность

При ON обычная строка чата/архива имеет аватар до 36 пунктов вместо прежних 44. Название — штатный Font.semibold с базовым размером 15; предпросмотр и его курсив — Font.regular/italic 14; дата — Font.regular 12. Размеры по-прежнему зависят от штатного itemListBaseFontSize Telegram. Гарнитуры, начертания, палитры и цвета не изменяются.

Минимальная высота уменьшена с 56 до 48 пунктов. Верхний/нижний отступ измеренной текстовой области — 5 пунктов с масштабированием вместо прежних 8. Положение аватара, горизонтальный отступ текста и разделитель согласованы с плотностью референса. Предпросмотр остаётся однострочным; автор/пометка черновика сохраняются в нём с атрибутами.

Найдена причина сохранения высокой строки при уменьшенном аватаре: штатный ChatListInputActivitiesNode.asyncLayout возвращает переданный boundingSize даже при пустых activities и состоянии .none. Прежний компактный расчёт всегда учитывал его высоту 40 пунктов через max, хотя индикатор был скрыт. Теперь пустая активность исключена из расчёта высоты. Область активного индикатора ограничена одной измеренной строкой предпросмотра и высотой штатного масштабируемого шрифта; такое же измерение передаётся при сбросе состояния. При OFF остаётся исходная область 40 пунктов.

Высота растёт по реальному измерению заголовка, предпросмотра, видимой активности, тем форума и тегов при увеличенном тексте. Дополнительные сведения сохраняются. rawContentRect получает ту же компактную текстовую область: дата, статус доставки, счётчики, pin и mention выравниваются относительно неё. Это предотвращает сохранение прежних больших отступов и неверное положение правых элементов при уменьшенной строке.

OFF использует прежние размеры текста, аватары, отступы и высоту. Штатный шрифт буквенного аватара восстанавливается при повторном использовании узла. Отдельные темы форума, результаты поиска сообщений, пользовательские списки сообщений, inline и специальная community-разметка сохраняют прежнюю геометрию.

## Сохранённые взаимодействия

Компактная геометрия не переписывает действия/подтверждения, редактирование/выбор и переходы между папками. «Опции чатов по тапу» действуют независимо; в текущую версию включено согласованное разделение удержания аватарки/остальной строки, описанное в [отдельном контракте](chat-actions-on-hold.md).

Существующие и кэшированные ChatListNode используют прежнее уведомление на главной очереди с weak self, cleanup и settings revision. Atomic сравнивает bool и включает forceAllUpdated при его смене. Обновление шрифтов использует прежнее создание attributed strings и измерение TextNode. Таймеров/polling нет.

## Проверки

Изменён только apply_compact_chat_list в ios/apply_features.py. Полный overlay применён к свежей ограниченной копии точного pin Telegram-iOS 12.9.2 / 6ad963e5b62d354da79040f388ae2b9132fb17b8. В сравнении с исходниками уже подготовленных исправлений жестов, архивного плеера и тихой/отложенной отправки отличается только ChatListItem.swift; остальные 303 файла совпадают. ChatListTypingNode.swift изучен по тому же pin с проверкой Git blob SHA и не изменён.

Swift-разбор, Python, metadata и git diff --check проходят. Обратная замена четырёх изменений полностью восстанавливает прежний generated-файл побайтно. Привязки theme совпадают, параметры шрифтов/аватаров/default OFF не менялись. Отсутствующие/дублированные новые якоря отклоняются — шесть сценариев; повторное применение также отклоняется.

Это проверки исходников, не исполнение UIKit и не визуальная сверка на iPhone. Новую нативную сборку и запуск на устройстве не выполняли. Прежняя компиляция №77 не подтверждает эту правку.

## Приёмка нового IPA

- Сравнить обычные строки чатов/каналов/ботов с новым светлым референсом: аватар 36 пунктов, название и одна строка предпросмотра, базовая высота 48 пунктов без скрытого резерва 40 пунктов, дата и разделители. Проверить плотность примерно десяти строк на соответствующем участке экрана при обычном тексте.
- Пустые/непустые activities: начать и прекратить набор текста с другого клиента. Индикатор заменяет предпросмотр, не оставляет высокий резерв после исчезновения; крупный текст не обрезается.
- OFF → ON → OFF без перезапуска: восстановление прежних шрифтов/размеров, фото/буквенные аватары и сохранённый выбор; clean install по-прежнему OFF.
- Папки и их кэшированные списки, архив, Избранное, секретный чат, черновик, автор, фото/голосовое, typing, теги и форум.
- Увеличенный текст, Light/Dark/Night, дата, unread/mention/pin/mute/доставка, доступность: отсутствие обрезания и наложения; высота при необходимости растёт.
- Тап, удерживание/предпросмотр/меню, разрешённые свайпы, редактирование и перестановка: проверить текущий согласованный контракт «Опций чатов по тапу» при ON/OFF.
