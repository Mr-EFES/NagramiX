# Не спрашивать оценку звонка

Включено в проверенный IPA0.5.4/build88; нативная компиляция подтверждена, физическая приёмка ожидается.
Функции → Звонки. Включено по умолчанию при отсутствии сохранённого выбора. ON скрывает автоматический запрос оценки; OFF разрешает штатное окно для звонков, по которым Telegram запрашивает оценку. Ручное действие оценки остаётся доступным. Выбор сохраняется после перезапуска.

[Контракт и проверка iPhone](../../docs/SKIP_CALL_RATING.md). implemented / compile_passed / device_pending; новая правка после build86, включено в опубликованный IPA0.5.4/build88.
