# Видео без сжатия

Проверка текущего выпуска: **compile_passed / device_pending**, нативная сборка№86 и независимая проверка опубликованного IPA успешны. [Результат и исходный SHA](../../docs/RELEASE_STATUS.md). Физические сценарии остаются непроверенными.

Функции / Видео, **«Видео без сжатия»**, ON по умолчанию при отсутствии сохранённого выбора. Обычное неизменённое видео из галереи отправляется исходным файлом, без дополнительного кодирования; MP4/MOV получают стандартные атрибуты видео для штатного player у получателя. Сохраняются подпись, спойлер, обложка и допустимая группировка.

Режим OFF возвращает штатную обработку. Явная отправка файлом, реальные правки редактора, slow-motion/камерный tempFile, GIF/Live Photo, timed/paid сохраняют отдельные пути. Неподдерживаемый контейнер передаётся исходным документом; не обещать одинаковый player для любого кодека во всех клиентах. Скачиваемый оригинал и качество автоматически выбранного потока воспроизведения — разные вещи.

**implemented / compile_passed / device_pending**. Нативная сборка№86 пройдена; нужны физическая проверка оригинального SHA256/размера и совместимости официальных клиентов. В предыдущем опубликованном пакете №84 отсутствует. [Контракт и приёмка](../../docs/ORIGINAL_VIDEOS.md).
