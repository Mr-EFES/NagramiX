# Прочтение сообщений

Настройки NagramiX → Функции → Приватность, сразу после «Сообщения».

- **Локальное «чтение»** снимает непрочитанные на устройстве без отметки собеседнику и без увеличения просмотров постов каналов.
- **Прочтение по действию** скрывает автоматические прочтения независимо от первого чекбокса. Отправка сообщения читает предыдущую переписку, добавление реакции — до выбранного сообщения включительно.

Оба пункта изначально выключены. Без них используется стандартное чтение Telegram; отдельный пункт «Читать на сервере» удалён. Выбор сохраняется после перезапуска.

Реакция на третье сообщение из пяти подтверждает только первые три. Более поздняя приватная граница сохраняется после ответа сервера. Новое сообщение, пришедшее после фиксации границы отправки, не попадает под прочтение по этому ответу. Отмена действия, снятие реакции, отсутствующий адресат и отложенная отправка не дают разрешения на прочтение.

Закрытые чаты автоматически не читаются; переключение настроек не публикует локальные прочтения всех чатов. Обычное открытие после выключения обоих режимов может подтвердить видимую границу ранее локально прочитанного чата. Неуспешный запрос не считается подтверждением. Прочтения разделены по аккаунтам, настройка общая для приложения. Просмотр через аватарку остаётся без прочтений; для секретных чатов автоматическое подтверждение по ответу не добавлено.
