# Показывать точное время

Настройки NagramiX → Интерфейс → ПРОФИЛИ. По умолчанию выключено; сохранённый выбор остаётся после перезапуска.

К доступному статусу последнего посещения добавляется время с секундами, например «был(а) 2 часа назад (14:03:27)». Время отображается в часовом поясе телефона. Скрытые статусы сохраняются: настройка показывает только сведения, которые доступны аккаунту в Telegram.
