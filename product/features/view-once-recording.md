# Одноразовые записи

Текущий статус на 21 октября: включено в Release 0.6.7 / build 113; Apple SDK compile и независимая проверка опубликованного пакета пройдены. Физическая приёмка новой версии ожидается. Предшествующие source-only proofs ниже описывают этап до этой сборки; актуальный итог — [RELEASE_STATUS](../../docs/RELEASE_STATUS.md).

Пользователь утвердил 20 октября общий checkbox для круглых видео и голосовых сообщений. Выбранное название — **«Одноразовые записи»**. Пользователь также подтвердил возможность отключать одноразовый режим для конкретной записи перед отправкой.

21 октября добавлены «Переслать» и «Рассылка» для собственных отправленных одноразовых голосовых/кружков: новые копии тоже одноразовые, с новым сроком и собственной загрузкой из полных локальных байтов. Только поддерживаемые облачные личные получатели; чужие записи, текст, сохранение и прочие функции прежние. Нового checkbox нет, свежий default записи остаётся OFF. [Контракт и проверки](../../docs/OWN_VIEW_ONCE_COPY.md). Дополнение пока source_checked/native_compile_pending/device_pending, в IPA112 отсутствует. Разделы ниже описывают исходный default записи.

## Настройка

Настройки NagramiX → Функции → Круглые видео, после «Музыка при записи». Один штатный переключатель без поясняющего footer, с RU/EN заголовком и поисковыми словами для обоих типов записи. Stable ID155, позиция112; остальные ID и разделы сохранены. Позиция112 ранее использовалась только невыводимым footer музыки, этот footer по-прежнему не добавляется в список.

Хранение: `nagramix.recording.viewOnce`, один Bool в существующем app UserDefaults. Отсутствие ключа означает OFF. Чтение не записывает default; явные ON/OFF сохраняются и не сбрасываются при холодном старте. Это общий для аккаунтов приложения default, как соседние настройки записи. `NagramiXRecordingSettings` входит в существующий NagramiXCore; прежний `NagramiXTabSettings` и его сохранённые ключи не изменены. UI callback сохраняет выбор и обновляет список.

## Поведение

- ON задаёт начальное состояние **штатного** одноразового режима новой голосовой записи и нового кружка. Используется `AutoremoveTimeoutMessageAttribute(timeout: viewOnceTimeout, countdownBeginTime: nil)` и штатный серверный протокол Telegram, без собственного таймера или подмены признака только в UI.
- Новое голосовое получает default при создании recorder после разрешения микрофона. Штатная кнопка отображает тот же выбранный режим. Отправка удержанием/отпусканием и через предпросмотр передаёт текущее состояние записи.
- Новый кружок получает default в начальном `CameraState`, только если native `viewOnceAvailable`. Кнопка, анимации, пауза/продолжение, смена камеры и отправка используют прежний state.
- Для каждой записи пользователь может выключить режим штатной кнопкой «1». Продолжение/редактирование этой записи не применяет общий default заново. Переключение для записи не меняет общий checkbox. Следующая новая запись снова учитывает сохранённую настройку.
- OFF сохраняет обычный старт записи и возможность вручную включить штатный одноразовый режим. Смена общего checkbox не переписывает состояние уже начатой записи; восстановленные старые черновики автоматически не переводятся в одноразовые.
- Автоматическое включение действует в поддерживаемых облачных личных чатах. Избранное, боты, группы, каналы, секретные чаты, paid-message чаты и экран отложенных сообщений не получают автоматический режим. Исправлен порядок учёта botInfo в native camera availability: окончательный результат дополнительно проверяет уже вычисленный `isBot`.
- При отправке из native меню «Без звука»/эффекта отсутствие аргумента теперь означает текущее состояние записи, а не безусловный false. Явно переданный выбор сохраняет приоритет. Отложенные и повторяющиеся отправки остаются обычными сообщениями и не получают несовместимый одноразовый timeout.

Камера по умолчанию, отсчёт селфи, аудиомикширование, запись/кодирование/upload, отмена запуска, ограничения отправки, оплата, server enqueue, readonly/read gates, архив, сохранение входящих временных сообщений и PiP не переписываются.
