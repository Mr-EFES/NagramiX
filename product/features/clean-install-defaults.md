# Русский язык и стандартные темы при первом запуске

При чистой установке приветствие, авторизация и приложение после входа используют полный русский ресурс. Сохранённый ручной язык не перезаписывается. Фоновая локализация не включает английский самопроизвольно; русский fallback доступен без сети.

По актуальному заданию начальный выбор при отсутствии записи темы — штатная Telegram «Тёмная» (`.builtin(.nightAccent)`, в upstream английский Tinted), с `force: false`, `trigger: .explicitNone`. Это выбор встроенной темы через обычную запись `PresentationThemeSettings`, а не новая палитра. `defaultSettings`, фабрики, шрифты и стандартный редактор не изменены. Инициализация завершается до `currentPresentationDataAndSettings`, только если preference entry отсутствует; любой сохранённый выбор сохраняется побайтно.

Пользователь может выбрать штатные Light/Classic/Day, Dark/Tinted, Night/Black, System/Auto Night, расписание или custom theme. Дальнейшие переключения полностью обрабатывает Telegram. Русский язык и theme setting независимы; theme seed не меняет язык, камеру, архив и другие функции.

Проверить отдельно: чистая установка на светлой/тёмной iOS начинает с «Тёмной»; ручная Light сохраняется после рестарта; Night/custom также сохраняются; System меняется с iOS; расписание работает; русский до и после входа без сети и после загрузки локализации. У обновления уже сохранённые System/Tinted/Light не сбрасываются. Результат компиляции и ограничения проверки — docs/AI_HANDOFF.md и docs/THEME_AUDIT.md.
