# Русский язык и стандартные темы при первом запуске

При чистой установке приветствие, авторизация и приложение после входа используют полный русский ресурс. Сохранённый ручной язык не перезаписывается. Фоновая локализация не включает английский самопроизвольно; русский fallback доступен без сети.

Требование пользователя от 2026-10-06: «Оформление → Ночная тема → Системная», выбранная ночная тема «Тёмная». При отсутствии preference entry используются `PresentationThemeSettings.defaultSettings` и `AutomaticThemeSwitchSetting(force: false, trigger: .system, theme: .builtin(.nightAccent))`. Дневная тема остаётся встроенной `.dayClassic`. Светлая iOS использует штатную дневную тему, тёмная iOS — штатную «Тёмную» (upstream Tinted). Собственного определения времени/стиля или принудительной Dark при каждом запуске нет.

Инициализация завершается до `currentPresentationDataAndSettings`, только если запись настроек темы отсутствует. Любая сохранённая entry возвращается без изменений. Light/Dark/Night/custom, отключение, расписание и автоматика остаются ручным выбором пользователя. Обновление уже установленного приложения не сбрасывает ранее выбранный режим.

Штатные фабрики палитр, defaultSettings, шрифты и интерфейс выбора тем сохранены. Для legacy RGB24 значений облачных accent/outgoingAccent исправлено только отсутствие alpha byte при чтении; современные ARGB значения с ненулевой alpha не меняются. Ни RGB-палитра, ни формат хранилища/API не изменены. Подробности — [аудит](../../docs/THEME_AUDIT.md).

Проверить на новой сборке 0.5.1 после публикации: clean install на светлой/тёмной iOS, System → Off → Schedule → Auto, ручные Light/Night/custom после перезапуска, русский до/после входа, House → Chick → Snowman → Diamond и действия профиля/отправки. Текущий код скомпилирован в №83; опубликованный IPA 0.5.1 и его ресурсы независимо проверены. Физическая приёмка ожидается.

При применении темы чатов сохраняется база штатного предпросмотра; загрузчик сначала ищет точную базу, затем доступный вариант той же группы. Ночная автоматика и начальные предпочтения при этом не изменяются.

Названия русских действий и элементов управления раскрыты полностью («Пропущенные», «Изменить», «Включить звук» и другие). Общий реестр применяется при первом запуске и поверх последующих русских языковых пакетов. Длинный пункт сохранения отредактированных фотографий переносится штатной ячейкой. Другие языки и выбор пользователя не меняются. Эти изменения прошли нативную компиляцию №83 и включены в проверенный IPA 0.5.1; [аудит и будущая приёмка](../../docs/RUSSIAN_CONTROL_LABELS.md).
