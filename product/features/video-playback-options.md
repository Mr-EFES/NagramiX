# Системный PiP и фоновое видео

По последней команде пользователя добавлена новая реализация PiP через AVPlayerLayer. Настройка свайпа в «Прочее» сразу после звонков использует прежний ключ `nagramix.video.pipSwipe`; сохранённый выбор не сбрасывается. Кнопка и свайп запускают один путь. Вертикальный свайп переводит подходящее видео в PiP; горизонтальный сохраняет перелистывание, пока пользователь не уточнил другой вариант.

Окном управляет iOS: положение, изменение размера, скрытие, поворот. Источник — полный MP4/MOV, включая исходный файл HLS, с загрузкой при необходимости; защищённое содержимое и веб-плееры не подключены. Подробности и ограничения: [контракт](../../docs/NATIVE_PLAYER_PIP.md).

Фоновое воспроизведение остаётся самостоятельной настройкой. Проверки исходников пройдены; новая SDK/IPA-сборка и физическая приёмка ожидаются.
