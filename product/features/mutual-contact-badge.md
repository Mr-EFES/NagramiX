# Значок взаимного контакта

Ключ `nagramix.profiles.showMutualContactIcon` управляет отображением в контактах и профиле. Проверяется уже загруженный серверный `TelegramUser.flags.contains(.mutualContact)`; разрешение на адресную книгу телефона для этой проверки не требуется. Обычный контакт не выдаётся за взаимный. Self, bots, пользователи без имени, device contacts, группы и каналы не помечаются.

В общей native cell `ContactsPeerItem` отметка `⇄ Взаимный контакт` находится в начале второй строки, перед прежним статусом через разделитель. Используются штатные statusFont и itemAccentColor текущей темы. Имя остаётся исходным; длинное имя не скрывает отметку. Последняя активность сохраняется в attributed string и VoiceOver; на узком экране хвост строки может обрезаться штатным layout. В picker без второй строки используется компактный `⇄` перед именем, без изменения высоты строки.

В обычном профиле `PeerInfoProfileItems` добавлена отдельная штатная `PeerInfoScreenLabeledValueItem` с той же отметкой, accent-цветом и уникальным ID11002. ID профиля и дата регистрации не изменены. Заголовок и текст локализованы; русский «Взаимный контакт», английский «Mutual contact».

Изменение переключателя обновляет связанные клетки и открытый профиль на главном потоке, только если изменилось именно это значение. Observer использует weak self и удаляется при deinit. При повторном bind статус строится заново, исключая перенос отметки на невзаимного пользователя.

Исправление отметки включено в 0.4.5. Прежний NSTextAttachment не соответствовал native TextNode; строка профиля отсутствовала. Сейчас используются штатный attributed text и native labeled item. Нативная компиляция сохранённого кода прошла в предыдущей сборке №72; физическая приёмка ожидается.

Проверка на устройстве: заведомо взаимный и невзаимный контакт, ON/OFF без перезапуска, длинные имена, список/поиск/picker/профиль, быстрый скролл, VoiceOver, светлая/тёмная штатные темы и увеличенный системный шрифт. Отдельно проверить Telegram-контакты без разрешения на адресную книгу.
