# Анонимные стикеры

Статус14октября: **implemented / compile_passed / device_pending**, опубликованный0.5.5/build89. [Проверенный IPA](../../docs/RELEASE_STATUS.md); физическая приёмка ожидается.

Функции → Стикеры и эмодзи → «Анонимные стикеры». Включено при отсутствии `nagramix.stickers.anonymous`; сохранённый OFF/ON не сбрасывается. Строка без пояснения, доступна в поиске. Stable ID142.

Новый исходящий стикер отправляется отдельным документом-стикером с пустой ссылкой на набор. Получатель получает обычный стикер; открыть исходный набор тапом по его привязке нельзя. Основные данные WEBP/TGS/WEBM не перекодируются; тип, размеры, emoji и анимационные атрибуты сохраняются. Подтверждение поведения официального клиента ожидается на устройстве.

Исходный объект набора не изменяется. Для исходящего сообщения создаётся отдельный LocalFile MediaId; локальный маркер хранит исходную ссылку для получения полных байтов, переживает перезапуск и повторную отправку. Маркер не передаётся в Telegram API. Обычные файлы, custom emoji и оригинальная `.forward` остаются штатными. Для нового inline-стикера удаляются атрибуты отправки через inline-бота, чтобы сообщение прошло обычную загрузку стикера. Ephemeral/welcome-боты и rich text исключены.

OFF возвращает штатную отправку новых стикеров. Уже поставленный в очередь анонимный стикер сохраняет свой режим. Ошибка получения исходных данных завершает отправку штатной ошибкой; повторное использование старого документа со ссылкой на набор запрещено.

[Интеграция, проверки и приёмка](../../docs/PRIVATE_MESSAGES.md). Статус implemented / source_checked / compile_pending / device_pending. В опубликованном IPA функции ещё нет.
