# Округление чисел

20 октября пользователь попросил инвертировать смысл референса «Отключить округление чисел»: новый checkbox **«Округление чисел»** включает штатные сокращения, а по умолчанию счётчики показывают все цифры.

## Настройка и поведение

Настройки NagramiX → Интерфейс → Чаты, после «Компактный список чатов». Штатный switch без footer, с переносом заголовка, RU/EN строками и поиском. Stable ID156, позиция1011; прежние ID, настройки и разделы не изменены.

Один новый Bool `nagramix.interface.roundNumbers` в app UserDefaults. При отсутствии ключа — OFF; getter не записывает искусственный выбор. Явные ON/OFF сохраняются при последующих холодных запусках и не меняются при обновлении соседних настроек. Настройка общая для аккаунтов приложения, как соседние настройки интерфейса.

- **OFF:** общие счётчики выводят полное целое число. Например, 1234 показывается как `1 234` или `1,234` с разделителем тысяч региона устройства. Ни один разряд не отбрасывается. Форматтер работает с целыми числами, без Double/abs, включая минимальное отрицательное и максимальное положительное значения.
- **ON:** выполняется прежний код Telegram для K/M и других сокращений. Его пороги, десятичный разделитель, `showDecimalPart` и `forceDecimal` сохранены, включая точность штатного отображения.

Перехвачены именно `compactNumericCountString` и `countString` из TelegramPresentationData. Ими пользуются, в частности, непрочитанные в списке/на вкладке, просмотры сообщений и историй, другие штатные сокращённые счётчики. Счётчики, которые Telegram уже показывает полностью, сохраняют свой формат. Даты, длительности, размеры файлов, номера телефонов, денежные/Stars форматтеры и значения самих счётчиков не преобразуются этой настройкой.

Изменение checkbox публикует отдельное уведомление. Наблюдаемый Bool добавлен к существующему pipeline `updatedPresentationData`: при смене режима native labels получают обновление, перезапуск приложения не запрашивается. Повторное сохранение того же значения отфильтровывает `distinctUntilChanged`. Observer живёт только до disposal подписки. В fallback без установленного language pack создаётся новый PresentationStrings с теми же default component/secondary/grouping values: смена identity обновляет кешированные подписи. Темы, шрифты, переводы, даты и палитры не подменяются.

## Интеграция

`NagramiXNumberSettings` находится в существующем Foundation-only NagramiXMediaSettings, который копируется прежним module stage. TelegramPresentationData получает внутреннюю зависимость на него; зависимость на NagramiXCore здесь недопустима, потому что Core сам использует TelegramPresentationData. Новых внешних библиотек нет.

Поздний `ios/number_rounding.py`/JSON hook идёт после once-recording stage. Семь полных SHA256, девятнадцать точных операций, проверка наличия и побайтного совпадения уже скопированного helper до записи. Ранние privacy/screenshot/copy/quality/recording stages и их SHA не ослаблены.

## Проверено

Полный offline overlay на проверенном pinned Telegram-iOS13.0: 403 файла относительно402baseline (предыдущий once-recording398 + четыре дополнительно прочитанных pinned исходника/BUILD). Восемь файлов изменены, один helper добавлен, 394 файла побайтно прежние. Содержимое обоих штатных форматтеров после удаления нового guard точно равно предыдущему; весь остальной diff воспроизведён по exact patch table.

`scripts/validate_number_rounding.py` компилирует и выполняет настоящий Foundation helper, обе новые функции и их исходные версии, реальный NotificationCenter bridge с doubles только на границе SwiftSignalKit. 1884 проверки в debug и optimized: defaultOFF, сохранённые ON/OFF, K/M/native precision parity, региональные разделители, отсутствие потери разрядов, signed/unsigned limits, смена формата/повторное значение/disposal/release. По шесть отдельных холодных процессов для каждого режима проверяют запись UserDefaults и чтение реальным форматтером на следующем запуске. Восемнадцать fail-closed сценариев без частичных записей, Swift syntax, Python/JSON, порядок UI memberwise аргументов и отсутствие цикла зависимостей пройдены.

Proof: `/workspace/.codex-validation-nagramix-number-rounding/verification.json`, финальный native tree `native-after`. Apple SDK typecheck, настоящий UI iPhone и ширина подписи при Dynamic Type не проверены: `source_checked / native_compile_pending / device_pending`. Сборка IPA, Actions, commit и push не запускались.
