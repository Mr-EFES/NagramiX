# Доступ к контактам

Текущий результат: включено в Release0.6.8/build114; Apple SDK compile и опубликованный IPA проверены. Физическая приёмка **device_pending**. Source-only описания ниже — история подготовки; [актуальный статус](../../docs/RELEASE_STATUS.md).


При первом запуске NagramiX не показывает запрос доступа к телефонной книге и продолжает работу по сценарию «Не разрешать». Пользователь может пользоваться контактами Telegram и чатами; данные телефонной книги без разрешения недоступны. Полная работа с телефонной книгой требует явного предоставления системных прав.

Уже выданные пользователем права и сохранённая настройка синхронизации сохраняются. Отключённая синхронизация не включается сама после выдачи прав. Дополнительного переключателя для этой политики нет. Скрытие вкладки «Контакты» — отдельная существующая настройка.

Исправление после113: **source_checked/native_compile_pending/device_pending**. [Контракт и проверки](../../docs/CONTACTS_DEFAULT_DENIAL.md). В опубликованном IPA113 ещё прежняя реализация; новую сборку запускать только по отдельной команде.
