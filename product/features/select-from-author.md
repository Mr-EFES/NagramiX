# Выбрать сообщения автора

## Поведение продукта

Действие контекстного меню определяет настоящий `author.id` сообщения. В личном cloud-чате последовательно читает страницы доступной истории обеих сторон, в группах/каналах использует штатный sender search с учётом ветки/сохранённого диалога и предыдущей группы при миграции. Автор пересылки и отображаемое имя не подменяют настоящего отправителя.

Страницы по 100 сообщений продолжаются до окончания истории/выдачи, включая страницы без сообщений нужного автора; общего лимита 100/300 нет. Курсор должен продвигаться назад. Полученные сообщения выбранного автора и peers сохраняются штатным механизмом Telegram в Postbox до передачи ID панели выбора. Поэтому старые сообщения доступны native проверке удаления, а не только счётчику. Медиафайлы не скачиваются. Перед завершением ID повторно сверяются с базой.

Операция владеет `MetaDisposable`, отклоняет второй параллельный запрос, показывает отменяемый индикатор и проверяет generation/chat/thread, включая отложенный voice-discard callback. Закрытие контроллера/отмена освобождает запрос и loading. Сетевая ошибка, FloodWait, таймаут страницы и неподвижный курсор не превращаются в успешный пустой поиск или полный частичный выбор. Пустой успех и неуспех имеют разные уведомления. Для секретного чата серверная история не применяется.

Удаление остаётся штатным: в личном диалоге доступны разрешённые Telegram варианты «у меня» / «у обоих», в группе — соответствующие роли/права. Чужие сообщения супергруппы требуют права удаления; локального скрытия отдельных сообщений вместо настоящего удаления не добавлено. Только для неизменённого выбора автора реальный запрет объясняется пользователю, кэш предлагается отдельным действием. Ручной выбор, подтверждения, undo, bans, пересылка и жалоба сохраняются. Архивные сообщения по-прежнему объединяются с выбором и имеют прежние локальные действия; серверное удаление архива не имитируется.

Настройка «Интерфейс → Контекстное меню → Выделить от автора» и её включённый default не изменены.

## Проверка

В предыдущей установленной версии пользователь подтвердил выбор/подсчёт сообщений в группе и пересылку, но сообщил проблемы входящих в личном чате и предложения кэша. Исправление сохранено в исходниках 0.4.9 без изменений. Оно скомпилировано в предыдущем опубликованном выпуске №73; физическая проверка ожидается. Анализ и точные изменения — [AUTHOR_SELECTION_AUDIT.md](../../docs/AUTHOR_SELECTION_AUDIT.md).

Baseline/current overlay применены к чистым validation копиям точного pin. Шесть ожидаемых generated-файлов отличаются, остальные 211 совпадают. Swift syntax, Python syntax, локализации/метаданные и diff check пройдены. Нативная компиляция этой функции прошла в текущей сборке №82 на macOS/Xcode; ошибок и предупреждений в изменённых Swift-файлах нет. Скачанный IPA текущего выпуска проверен по version/build/source, ARM64, RU и checksum/provenance. Runtime-приёмка на iPhone ожидается.

На iPhone проверить входящие/исходящие в личном чате; обычные группы и супергруппы с правом удаления и без; старые незагруженные сообщения и 300+; темы форума; отмену/сеть/смену чата; пересылку/жалобу; удаление только выбранного набора с сохранением невыбранных сообщений.
