# Выбрать сообщения автора

## Поведение продукта

Действие контекстного меню определяет настоящий `author.id` выбранного сообщения и выполняет поиск в текущем чате и необязательной ветке ответов через штатный API `searchMessages` из TelegramEngine. Запросы повторяются с возвращённым `SearchMessagesState`, пока `SearchMessagesResult.completed` не станет `true`, после чего накопленные id сообщений передаются в режим выбора чата.

Операция владеет `MetaDisposable`, отклоняет второй параллельный запрос, показывает отменяемый штатный индикатор загрузки Telegram и в каждом callback проверяет поколение, чат и ветку. При закрытии контроллера запрос освобождается. Метаданные пересылки и отображаемые имена не используются как идентификатор автора.

## Проверка

2026-10-04 пользователь подтвердил функцию «Выбрать от автора» как рабочую в установленной NagramiX 0.3.9. Статус устройства в реестре — `device_passed`; источник подтверждения — пользователь, а не автоматический тест этой сессии. Реализация не изменялась.

Общий лимит количества в реализации отсутствует: поиск продолжается страницами до завершения. Конкретный сценарий с 300+ сообщениями и сравнение выделенного количества со всеми доступными поиску сообщениями автора отдельно не подтверждены. Это подтверждение не заменяет регресс в новой сборке после других изменений.
