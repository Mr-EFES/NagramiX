# Авто-мьют новых каналов

Настройки NagramiX → Функции → СООБЩЕНИЯ. По умолчанию включено; сохранённый выбор остаётся после перезапуска.

При подписке на новый канал уведомления автоматически отключаются. Уведомления можно включить обычной кнопкой в канале. Выключение настройки сохраняет текущие подписки и влияет на последующие вступления. Группы и собственные каналы сохраняют свои настройки.

Состояние: implemented / compile_pending / device_pending. Подготовлено после опубликованного №83. [Интеграция, границы и физическая приёмка](../../docs/CHANNEL_MUTE_AND_EXACT_TIME.md).
