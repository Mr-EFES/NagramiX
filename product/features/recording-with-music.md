# Не останавливать музыку при записи кружка

Настройки NagramiX → Функции → КРУГЛЫЕ ВИДЕО. Включено при отсутствии сохранённого выбора, действует на кружки и голосовые сообщения.

Во время записи приложение разрешает штатное смешивание со звуком других приложений. Микрофон может записать звук динамика, поэтому рекомендуется использовать наушники. Выключение возвращает штатную приостановку музыки при записи.

Выбор хранится в штатной MediaInputSettings.pauseMusicOnRecording_v2 в обратном виде. Настройка «Приостанавливать музыку при записи» в «Данные и память» отражает противоположное значение. Ручной выбор сохраняется после перезапуска и обновления; отдельная конкурирующая настройка не создаётся.

Состояние: implemented / compile_pending / device_pending. Подготовлено после опубликованного №83; новая сборка запрошена для физической проверки. [Реализация и сценарии проверки](../../docs/RECORDING_WITH_MUSIC.md).
