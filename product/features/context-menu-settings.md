# Настройки действий контекстного меню

Настройки версии 0.4.1.

## Интерфейс

Путь: **Настройки NagramiX → Интерфейс → КОНТЕКСТНОЕ МЕНЮ**. Два независимых штатных переключателя:

- **Переслать без** — показывать существующее действие копирования и отправки нового сообщения без источника.
- **Выделить от автора** — показывать существующее действие поиска и выделения сообщений автора.

Описание каждой строки поясняет управление видимостью. Раздел не появляется в категориях «Функции» и «Прочее». Русское название действия автора приведено к запрошенному «Выделить от автора»; ключ локализации и обработчик сохранены. Английские строки обеспечивают существующий fallback для остальных языков.

## Хранение и совместимость

`NagramiXTabSettings` использует два новых ключа `UserDefaults.standard`:

- `nagramix.contextMenu.showForwardWithoutAuthor`;
- `nagramix.contextMenu.showSelectByAuthor`.

Оба читаются через `object(forKey:) as? Bool ?? true`. Поэтому чистая установка и обновление без этих ключей сохраняют прежнюю доступность действий. Записанный пользователем `false` не заменяется значением по умолчанию. `NagramiXTabSettings.update` сохраняет оба значения существующим механизмом вместе с остальными настройками; стартовая миграция/принудительное включение не добавлены.

## Интеграция

Проверки находятся в общем `ChatInterfaceStateContextMenus.swift`, формируемом `ios/apply_features.py`. При OFF действие вообще не добавляется, включая относящийся к нему разделитель для выбора автора. При ON сохраняются прежние условия поддержки сообщения, порядок и вызовы существующих обработчиков. Открытое меню не перестраивается задним числом; каждое новое открытие читает `NagramiXTabSettings.current`, поэтому перезапуск не требуется.

Backend копирования/отправки, entities, media, обычной/тихой/отложенной отправки, штатного редактирования, определения автора, пагинации и выбора не менялся. Обычные действия Telegram и доступные контексты не ограничивались.

Переключатели включены в `nagramiXAllSettingsEntries`. Существующий глобальный поиск использует их названия, описания, секцию и категорию; отдельного поискового обработчика нет. Заголовок и пояснения сами по себе не создают дублирующихся результатов.

## Проверки и ограничения

В Cloud успешно выполнены:

- применение полного feature overlay к закреплённым исходникам Telegram-iOS;
- проверка синтаксических деревьев Swift, Python syntax, локализационных ключей и уникальности ID строк;
- проверка условий default=true, чтения сохранённого false и записи обоих ключей в исходниках;
- сравнение результатов старого/нового overlay: изменены только модель, строки, экран настроек и две проверки видимости; весь backend обоих действий и остальные интеграционные файлы совпали побайтно;
- проверка поиска по общей модели и метаданных релиза, `git diff --check`.

Эти проверки не являются нативной компиляцией, typecheck или испытанием `UserDefaults`/UI на устройстве. Прежняя сборка 65 прошла; нативная сборка текущих изменений ещё не выполнена. Acceptance tests на iPhone пока не выполнены.

## Acceptance tests после сборки

1. Чистая установка: обе строки включены в «Интерфейс → Контекстное меню».
2. Установка поверх прежней версии без новых ключей: оба действия остаются доступными.
3. ON/ON, OFF/ON, ON/OFF и OFF/OFF: видимость строго соответствует переключателям; обычные Telegram Reply/Forward/Copy/Delete/Select продолжают работать.
4. OFF/ON после полного перезапуска: значения сохраняются. Повторное включение возвращает действие при следующем открытии меню без перезапуска.
5. Поиск «переслать» и «автора» находит соответствующие строки с группой «Интерфейс · Контекстное меню»; очистка возвращает выбранную категорию.
6. В уже поддерживаемых каналах, группах, личных чатах и ботах функции при ON сохраняют прежнюю работу. Проверить копирование text/entities/media, обычную/тихую/отложенную отправку и редактирование собственного сообщения. Проверить выделение автора и пагинацию 300+ сообщений.
