# Настройки действий контекстного меню

Последняя доработка20октября добавляет защищённые копии и сохранение: source_checked/native_compile_pending/device_pending. Она ещё не входит в IPA110; новая сборка только по отдельной команде.

Путь: **Настройки NagramiX → Интерфейс → Контекстное меню**. Три независимых штатных переключателя:

- **Переслать без автора** — действие «Переслать»: один адресат; обычный оригинал пересылается со скрытым автором, защищённое содержимое и удалённый snapshot отправляются новой копией.
- **Возможность рассылки** — действие «Рассылка»: новые копии без источника одному или нескольким адресатам, включая обычное защищённое содержимое.
- **Выделить от автора** — прежний поиск и выделение сообщений автора.

Существующие ключи nagramix.contextMenu.showForwardWithoutAuthor/showSelectByAuthor и default true не меняются. Новый nagramix.contextMenu.showBroadcastMessages при отсутствии наследует сохранённый showForwardWithoutAuthor, включая false; на чистой установке true. После записи новый выбор независим. Никаких принудительных reset/migration стартового UI нет.

Новые строки используют stable IDs 121–122; старые IDs сохраняются. Заголовок, строки и поисковые описания используют текущий global search и штатные ItemListSwitchItem/ItemListTextItem, темы и шрифты Telegram. Пояснения не создают дополнительных результатов поиска.

Каждое новое меню читает current preferences, перезапуск не нужен; OFF скрывает соответствующий пункт, включая архивные сообщения. Если включён хотя бы один из первых двух пунктов, разрешены также штатные «Копировать»/сохранение в Фото/Файлы обычного защищённого содержимого. При обоих OFF сохраняются штатные ограничения. Отдельный checkbox обхода копирования не добавляется. Настройка скриншотов независима. Секретные чаты, одноразовые/платные/истёкшие и другие специальные медиа сохраняют ограничения; права адресата проверяются прежними native handlers.

Поведение трёх режимов, реализация и сценарии iPhone описаны в [спецификации пересылки/рассылки](message-distribution.md) и [контракте защищённых копий](../../docs/PROTECTED_CONTENT_COPY.md). «Выделить от автора», права удаления, поиск автора и прочие пункты не изменены. Локальные проверки нового кода пройдены; нативная компиляция и физическая проверка ожидаются.
