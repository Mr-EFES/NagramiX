# Настройки действий контекстного меню

Текущая доработка: compile_passed/device_pending, включена в успешную сборку №82. Опубликованный IPA №79 содержит прежние два переключателя; новый «Рассылка» в него не входит.

Путь: **Настройки NagramiX → Интерфейс → Контекстное меню**. Три независимых штатных переключателя:

- **Переслать без** — одиночная пересылка со скрытым автором; удалённый snapshot отправляется одиночной копией.
- **Рассылка** — прежняя отправка новых копий без источника одному или нескольким адресатам.
- **Выделить от автора** — прежний поиск и выделение сообщений автора.

Существующие ключи nagramix.contextMenu.showForwardWithoutAuthor/showSelectByAuthor и default true не меняются. Новый nagramix.contextMenu.showBroadcastMessages при отсутствии наследует сохранённый showForwardWithoutAuthor, включая false; на чистой установке true. После записи новый выбор независим. Никаких принудительных reset/migration стартового UI нет.

Новые строки используют stable IDs 121–122; старые IDs сохраняются. Заголовок, строки и поисковые описания используют текущий global search и штатные ItemListSwitchItem/ItemListTextItem, темы и шрифты Telegram. Пояснения не создают дополнительных результатов поиска.

Каждое новое меню читает current preferences, перезапуск не нужен; OFF скрывает соответствующий пункт, включая архивные сообщения. Поддержка сообщения, доступность адресата и разрешения проверяются действующими native правилами.

Поведение трёх режимов, реализация и сценарии iPhone описаны в [спецификации пересылки/рассылки](message-distribution.md). «Выделить от автора», права удаления, поиск автора и прочие пункты не изменены. Статические проверки нового кода пройдены; нативная компиляция и физическая проверка ожидаются.
