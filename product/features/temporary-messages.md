# Временные сообщения

При включённой функции поддерживаемые одноразовые голосовые воспроизводятся прямо в переписке со штатными огнём, обратным отсчётом и исчезающей дорожкой, без отдельного окна. После окончания доступен повторный запуск; сохранённая временная запись получает анимацию без таймера удаления. При OFF и для кружков прежнее открытие сохраняется. [Контракт и проверки](../../docs/INLINE_TEMPORARY_VOICE.md): source_checked/native_compile_pending/device_pending.

Добавлена [расшифровка голосовых через `→A`](../../docs/TEMPORARY_VOICE_TRANSCRIPTION.md) при активном том же переключателе: выбранные дополнительные способы обрабатывают живые и доступные сохранённые копии. Premium использует штатный серверный запрос только для живого сообщения; серверные ограничения сохраняются. Текст сохраняется локально без запуска воспроизведения или таймера удаления; полная очистка архива удаляет и его. Новая стадия source_checked/native_compile_pending/device_pending; в опубликованном0.8.5/build165 её ещё нет.

Текущая переработка объединяет прежние переключатели «Временные сообщения» и «Повторное открытие» в один пункт «Временные сообщения». На новой установке он выключен. При обновлении включённое значение любого из прежних переключателей сохраняет включённое состояние; изменение переключателя записывает оба прежних ключа. Режим повторного открытия использует локальные данные и не должен отправлять событие потребления поддерживаемого входящего медиа, не меняя обработку прочтения чата. При серверном удалении сохранённая временная копия остаётся доступной при активных «Временных сообщениях», независимо от «Удалённых сообщений». Для сохранённых файлов остаются отправка копии и рассылка; «Репост» отправляет новую копию с текстовой подписью автора. Существующая поддержка отправленных временных вложений сохранена. Исходники проверяются; SDK-сборка и физическая проверка двух аккаунтов ещё не выполнялись. Секретные и защищённые чаты, платные медиа и файлы, не загруженные до потери доступа, не охватываются гарантией.

Контекстное меню использует одинаковые значки для обычных, одноразовых и архивных сообщений: «Переслать» — анимация с человеком, «Разослать» — группа, «Репост» — стрелка. Предпросмотр через аватарку использует те же обработчики отправки локальной копии без включения прочтения исходного чата; проверка на устройстве ожидается.

Актуальная поздняя правка: [постоянная расшифровка и меню](../../docs/TEMPORARY_MEDIA_ACTIONS.md). `→A` постоянно доступна для разрешённых временных голосовых и кружков, включая копии после удаления оригинала другим клиентом. Обычные действия меню используют сохранённые вложения, готовая расшифровка открывается без сервера. Исходники проверяются, новая SDK/проверка iPhone ожидаются; в IPA171 правки нет.

## Исторический контракт до объединения

22 октября исправлено [сохранение собственных исходящих записей](../../docs/OUTGOING_ARCHIVE_FIX.md) после просмотра получателем. Условие — оба пункта ON; при выключении любого временные копии скрываются, применяется штатное истечение Telegram. Source_checked/native_compile_pending/device_pending, в IPA114 исправления нет.

18 октября после физического отчёта о наложении на третьем–четвёртом повторе в 0.5.10 подготовлена [правка штатной анимации кружков](../../docs/ARCHIVED_ROUND_VIDEO_FIX.md): source_checked/native_compile_pending/device_pending, для следующей 0.6.0. Локальный источник, 50% прозрачности и остальные функции архива сохранены. Приведённые ниже результаты компиляции относятся к прежним реализациям.

В «Функции → Сообщения» после «Удалённых сообщений» расположен штатный переключатель «Временные сообщения». Ключ — nagramix.messages.saveTemporaryMessages, начальное значение false только при отсутствии сохранённого выбора. Он включён в общий поиск настроек и использует штатные темы/шрифты Telegram.

Сохранение временных вложений требует ON обоих переключателей. Охватываются входящие и исходящие облачные фото, видео, голосовые, кружки и другие поддерживаемые вложения с AutoremoveTimeoutMessageAttribute / AutoclearTimeoutMessageAttribute, включая viewOnceTimeout. При OFF новые временные сообщения не архивируются и ранее сохранённые временные копии скрыты из переписки; отключение не удаляет уже сохранённые файлы. Основной переключатель OFF останавливает загрузки и скрывает архивные сообщения.

Полные байты копируются из MediaBox в отдельный архив аккаунта, а не остаются только ссылками на сервер. Штатная отметка просмотра/таймер продолжают работать при реальном просмотре оригинала; архивная загрузка сама не отмечает его просмотренным и не меняет серверные сроки. Перед локальным/удалённым истечением сохраняется разрешённый snapshot; expired placeholder отображается его локальной копией без дублирования ID. Копия открывается штатным gallery/player как standalone-сообщение без одноразового таймера.

Файлы сохраняются до явной очистки архива или локального удаления копии; удаление приложения/аккаунта также удаляет его локальные данные. В фоновой приостановке iOS загрузка не гарантируется. Нельзя восстановить байты, которые клиент не успел получить и которые уже недоступны. Прежние исключения секретных чатов, платного/защищённого содержимого чатов, кодов подтверждения и bot-ephemeral сохраняются; индивидуальный CopyProtected временного вложения допускается только при разрешении временных сообщений.

Пользователь подтвердил сохранение полученных и собственных отправленных одноразовых вложений после просмотра или удаления и повторное штатное воспроизведение до очистки архива. Для их локальных snapshot подготовлена [общая правка привязки плеера](../../docs/ARCHIVED_MEDIA_PLAYBACK_FIX.md): compile_passed/device_pending. Схема хранения, defaults и условия сохранения прежние. Наложение на pin и статические проверки выполнены; чистая компиляция №79 и проверка прежнего IPA подтверждают прежнюю правку привязки плеера. Текущая дополнительная [правка геометрии и запуска сохранённых кружков](../../docs/ARCHIVED_ROUND_VIDEO_FIX.md) прошла нативную сборку №82: compile_passed/device_pending. Реальные повторные загрузки/просмотр/истечение/очистка с этой правкой на iPhone ещё ожидают проверки. [Отчёт сборки](../../docs/RELEASE_STATUS.md).

Проверка опубликованного IPA: clean install default OFF; сохранённые ON/OFF после обновления/старта; четыре сочетания переключателей; одноразовые фото/видео/голосовые/кружки до и после просмотра, истечения и перезапуска; реальная отметка просмотра только после открытия оригинала; повторный просмотр локальной копии без сети; обычная очистка кэша; явная очистка архива во время загрузки; включение после получения, но до просмотра; все штатные темы, поиск и увеличенный текст. Подробности хранения — [Удалённые сообщения](deleted-messages.md).
