# Подмена профиля — удалена

Функция «Подмена профиля» (ранее «Ссылка на профиль») удалена по прямой просьбе пользователя. В актуальных исходниках нет её пункта меню, отдельного экрана, редактора ID или автоматического добавления ссылок при отправке. Сохранённое включение прежней функции больше не действует.

Обычные ссылки и упоминания Telegram сохраняются, старые сообщения не изменяются. Эта страница фиксирует удаление; функция исключена из активного реестра. [Статус и границы](../../docs/PROFILE_LINK_MESSAGES.md).
