# Ссылка на профиль в сообщениях

Предыдущая реализация прошла нативную сборку№86; новая версия0.5.4 проходит отдельную сборку, физическая проверка ожидается. [Текущий статус](../../docs/RELEASE_STATUS.md). Физические сценарии остаются непроверенными.

Настройки NagramiX → Функции → Сообщения → Ссылка на профиль. Опция выключена на первом запуске. При включении новые тексты и подписи к медиа становятся кликабельными переходами на выбранный профиль. Переход добавляется стандартными сущностями Telegram; автор сообщения остаётся прежним.

Отдельный экран содержит переключатель «Ссылка в сообщениях», пояснение, имя профиля и его ID, выбор другого пользователя по ID, действие «Использовать мой профиль» и кнопку «Открыть профиль» для проверки назначения. Штатные блоки, темы, шрифты, клавиатура и доступность Telegram сохраняются. По умолчанию выбран свой профиль текущего аккаунта. Другой ID принимается только после проверки доступного пользователю профиля в этом аккаунте.

ID и переключатель сохраняются после перезапуска. Существующие ссылки, упоминания, команды, код и custom emoji не перенаправляются; обычное форматирование сохраняется. Старые сообщения и пересылка с автором остаются прежними. Опция действует на новые текстовые сообщения и подписи, включая отправку без звука, по расписанию и обычную отправку из приложения.

Настройки общие для приложения; «Мой профиль» определяется для отправляющего аккаунта. Если выбранный другой профиль недоступен в аккаунте, сообщение отправляется штатно без новой ссылки, а экран показывает пояснение. В секретных чатах используется tg-ссылка: возможность открыть её зависит также от наличия профиля у получателя. Rich text, результаты inline-ботов, welcome automation и текст без подходящих участков не изменяются. На сложном форматировании действует общий лимит100 сущностей, без удаления прежних сущностей. Share extension не получает отдельную синхронизацию настроек в этой задаче.

Статус: **implemented / compile_passed / device_pending**. В опубликованный IPA предыдущей сборки №84, новая функция не включена. [Реализация и проверки](../../docs/PROFILE_LINK_MESSAGES.md).
