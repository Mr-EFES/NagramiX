# Фото максимального качества

Проверка текущего выпуска: **compile_passed / device_pending**, нативная сборка№86 и независимая проверка опубликованного IPA успешны. [Результат и исходный SHA](../../docs/RELEASE_STATUS.md). Физические сценарии остаются непроверенными.

Функции / Фотографии / **«Фото без сжатия»**, ON по умолчанию при отсутствии сохранённого выбора. Обычные фото отправляются стандартным photo-медиа с JPEG quality100 и native HD cap2560, без увеличения маленьких изображений. Получатели используют обычный просмотрщик своих Telegram-клиентов. Исходные байты/формат/размер не гарантируются.

OFF возвращает сохранённые ручные проценты/HD, они не сбрасываются включением режима. При OFF показывается только ручной процент качества. Отдельный переключатель «Отправлять большие фото» удалён из меню и поиска: максимум уже включает HD2560. Старый HD-ключ сохранён для совместимости ранее выбранного режима OFF. Stable ID137 сохраняется. `nagramix.photos.highQuality` имеет приоритет над read-only fallback прежнего подготовленного `nagramix.photos.original`.

Убран image-document transport и специальный document renderer. Смешанные photo/video albums сохраняют штатную группировку. Явная отправка фото файлом, реальные edits/options и video transport остаются отдельными путями.

**implemented / compile_passed / device_pending**. Нативная сборка№86 пройдена; физическая серверная/cross-client приёмка ещё не выполнена. В предыдущем опубликованном пакете №84 отсутствует. [Контракт](../../docs/HIGH_QUALITY_PHOTOS.md).
