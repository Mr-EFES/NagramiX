# Эмодзи в превью списка чатов

Превью показывает оригинальные пользовательские эмодзи сообщения, включая текстовые и медиа-подписи. Файлы определяются по ID эмодзи и загружаются через штатный механизм Telegram; обычные Unicode-эмодзи и буквальные 🆕/ABC не заменяются. Нового переключателя нет. Обычный и компактный список используют одно поведение.

При отсутствии metadata до загрузки остаётся запасной текст; после получения файла строка обновляется без повторного открытия канала. Смена сообщения, папки или аккаунта не должна показывать изображения из прежнего превью. Исходные сообщения, их форматирование и действия списка сохраняются; prefix медиа учитывается в позициях entities по UTF-16.
