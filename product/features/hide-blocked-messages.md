# Скрывать сообщения заблокированных

Функции → Сообщения → «Скрывать заблокированных». Включено при отсутствии `nagramix.messages.hideBlocked`; сохранённый OFF/ON не сбрасывается. Без пояснения под строкой, с поиском. Stable ID143.

Скрывает в ленте входящие сообщения настоящего автора из чёрного списка текущего аккаунта: личные чаты, обычные группы, супергруппы и темы. Применяется к доступной старой истории, новым сообщениям и архивным копиям. Список загружается полностью, включая страницы после первых 200 записей, и имеет локальный кэш для повторного запуска.

Разблокировка или OFF возвращает сообщения без повторной загрузки удалённой истории: они не удалялись из Postbox/архива. Изменения через профиль, список блокировок и серверные updatePeerBlocked обновляют ленту. Блокировка только историй не считается блокировкой переписки.

Проверяется `message.author`, а не автор пересланного оригинала. Свои исходящие и сообщения без известного автора не скрываются; реальная личность анонимного администратора не выводится из предположений. Другие аккаунты используют свой чёрный список.

Это локальное скрытие содержимого истории, а не запрет серверной доставки сообщений общей группы. Read/unread, системные уведомления, счётчики, список чатов, сетевой приём, поиск вне ленты и права Telegram остаются штатными. На новой установке до первого успешного получения чёрного списка неизвестные блокировки ещё не могут применяться; ошибка сети не считается пустым списком.
