# Опции чатов по тапу

После проверки предыдущей опубликованной сборки №77 пользователь сообщил о сбоях свайпов и уточнил обычное нажатие на аватарку. Исправление прошло статические проверки и нативную компиляцию №79: **compile_passed / device_pending**. Оно включено в успешную чистую сборку №79 и проверенный опубликованный IPA 0.4.8; результат — docs/RELEASE_STATUS.md.

Настройка: «Интерфейс → Чаты → Опции чатов по тапу». Ключ `nagramix.interface.chatActionsOnHold`, default true только при отсутствии значения, stable IDs 8/9, название/поиск и сохранённый выбор не менялись. Пояснение RU/EN уточнено.

## Поведение

| Действие | Опция включена | Опция выключена |
| --- | --- | --- |
| Горизонтальный свайп от аватарки, текста или краёв | Переключение доступных папок; боковых действий нет | Штатные боковые действия |
| Удерживание вне аватарки | Штатное меню без предпросмотра | Штатное удерживание Telegram |
| Обычный тап по аватарке | Полноценный чат без автоматической отметки прочтения, с Back | Такое же открытие без автоматической отметки прочтения |
| Обычный тап вне аватарки | Обычное открытие с прочтением | Обычное открытие с прочтением |
| Удерживание аватарки | Существующий штатный предпросмотр | Существующий штатный предпросмотр |

Меню использует stock генераторы chatContextMenuItems/archiveContextMenuItems/chatForumTopicMenuItems. Прочитано/непрочитано, папки, закрепление, уведомления, архив и удаление доступны по состоянию и правам Telegram, с обычными подтверждениями и отменой. Явное «Пометить прочитанным» не блокируется.

Аватарное открытие относится к обычным строкам чатов, групп, каналов и тем. Результаты поиска сообщений, выбор получателя, inline-списки, editing, строка архива и community сохраняют свои взаимодействия. Вертикальная прокрутка и доступность не переписаны. При отсутствии нескольких папок опция не создаёт их и не меняет штатный жест камеры историй.

## Причины и реализация

В предыдущем IPA №77 folder pan разрешал только leftCenter/rightCenter: native recognizer отказывался от жестов с краёв. В ChatListControllerNode при ON и 2+ папках теперь используются native left/right (края + центр). Остальные проверки доступности/положения списка/навигации и OFF сохранены. ItemListRevealOptionsItemNode сам обновляет gesture flags при пустых options; отдельного pan recognizer нет.

Раньше чтение без отметки давал только удерживаемый stock preview; аватар без истории не принимал обычный tap. Теперь существующий avatar UITapGestureRecognizer и реальный hit test AvatarNode отправляют отдельный nagramiXOpenChatWithoutReadReceipts callback через текущий list/container. Nil gesture/location у preview callback не перегружаются. Callback отвязывается от неактивной папки и привязывается при её возвращении; pickers/preview/inline его не получают. Размеры аватарки не зашиты в обработчик.

Создаётся штатный ChatController в standard(default) с immutable ChatControllerParams.nagramiXReadHistoryDisabled=true до создания history node. Единственный native подписчик вычисляет effectiveValue = value && !nagramiXReadHistoryDisabled. Все bindings истории используют computedCanReadHistoryPromise; штатное canReadHistory.set(true) после overlays/фона и queued foreground emissions не открывают gate. Через штатный gate блокируются автоматические max-read-index, interactive-read actions, чтение реакций/упоминаний и соответствующие метрики. Нет глобального флага и восстановления «непрочитано» задним числом.

Навигация проходит штатные age checks и push/Back с сохранением папки/фильтра. Тихий экран создаётся отдельно (useExisting=false); обычная навигация не переиспользует его, чтобы обычное открытие снова отмечало сообщения прочитанными. Тихий forum open не перенаправляется на список тем. Все обычные ChatControllerParams сохраняют default false для нового параметра.

## Проверки исходников

Изменения выражены в ios/apply_features.py: apply_chat_hold_routing и новый apply_chat_avatar_read_mode. Семь затронутых native Swift исходников проверены по git blob SHA pin Telegram-iOS 12.9.2, 6ad963e5b62d354da79040f388ae2b9132fb17b8.

Полный overlay применился к fresh scoped pin. В сравнении с базой предыдущей опубликованной сборки №77 изменены семь generated Swift-файлов и два RU/EN ресурса; 278 других файлов совпадают побайтно. Обратное исключение 21 вставки восстанавливает семь файлов; отдельный helper совпадает с полным overlay. Пройдены 43 missing/duplicate/repeat проверки. Все изменённые Swift-файлы разбираются tree-sitter без ошибок; Python syntax, метаданные и diff проходят.

Темы, компактные размеры, камера, прокси, истории, архив файлов и остальные функции не изменены. Нативная компиляция новой правки пройдена в №79. UIKit и сетевые read receipts на физическом iPhone ещё не проверены. В маршруте аватарки группа передаётся через штатный groupId._asGroup(), как в соседнем коде Telegram.

## Проверка на iPhone

После команды на новый IPA проверить на iPhone 17 Pro Max / iOS 27.0 через SideStore. Подготовить минимум две папки и непрочитанные входящие; с другого клиента наблюдать отметки отправителя.

| Сценарий | Ожидание | Результат |
| --- | --- | --- |
| ON: быстрые/медленные свайпы в обе стороны из аватарки, имени, сообщения и обоих краёв | Доступные папки перелистываются, действий строки нет | Ожидается |
| ON: удерживание вне аватарки во всех областях | Только stock меню, правильные пункты/права/подтверждения | Ожидается |
| ON и OFF: обычный tap аватарки с историями и без | Полный чат и Back; нет read receipt и сброса unread badge/count | Ожидается |
| Просмотр: прокрутка, поиск, меню, новые входящие, фон/возврат | Автоматическое чтение остаётся отключено; после Back сообщения непрочитаны | Ожидается |
