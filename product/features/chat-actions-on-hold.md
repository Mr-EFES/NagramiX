# Опции чатов по тапу

Актуальная интеграция перенесена на Telegram 13.0; [аудит миграции](../../docs/TELEGRAM_13_MIGRATION.md). Ранее указанные результаты №79 и локальных отдельных проверок относятся к прежней базе; новый нативный результат фиксируется отдельно.

Текущая доработка включена в успешную сборку №82: **implemented / compile_passed / device_pending**. Предыдущий опубликованный IPA №79 её не содержит. Новую сборку запускать только по команде пользователя.

Настройка: «Интерфейс → Чаты → Опции чатов по тапу». Ключ `nagramix.interface.chatActionsOnHold`, default true при отсутствии значения, stable IDs 8/9 и сохранённый выбор не меняются. Аннотация: «Удерживайте любую область строки, кроме аватарки, для штатного меню действий.»

## Поведение

| Действие | Опция включена | Опция выключена |
| --- | --- | --- |
| Горизонтальный свайп от аватарки, текста или краёв | Переключение доступных папок; боковых действий нет | Штатные боковые действия |
| Удерживание вне аватарки | Штатное меню без предпросмотра | Штатное удерживание Telegram |
| Тап или удерживание аватарки | Полноэкранный чат только для просмотра, без поля ввода и автоматической отметки прочтения; возврат назад | Такое же открытие |
| Обычный тап вне аватарки | Обычное открытие с прочтением и полем ввода | Обычное открытие с прочтением и полем ввода |

Меню использует штатные chatContextMenuItems/archiveContextMenuItems/chatForumTopicMenuItems. Прочтение, папки, закрепление, уведомления, архив и удаление следуют текущему состоянию и правам. Темы форума сохраняют отдельные действия темы. «В архив» / «Из архива» выбираются по реальной группе peerGroup; для Избранного и служебного чата Telegram пункт не появляется.

## Причины замечаний и изменение кода

В точном pin Telegram-iOS 13.0 условие archiveEnabled одновременно проверяло !isSavedMessages и peerId == context.account.peerId. Поскольку isSavedMessages означает ровно этот же peerId, условие никогда не выполнялось. Удалено противоречивое требование; штатные updatePeersGroupIdInteractively, archiveChats, Undo, иконки и строки сохранены.

Удерживание аватарки ранее оставалось на маршруте штатного предпросмотра, где доступны действия чата. Теперь область определяется в shouldBegin через native UIView.convert и реальные avatarNode.bounds до анимации. При активации на аватарке отменяется извлечение и ожидающий короткий tap; используется тот же отдельный callback полного просмотра, независимо от настройки. Editing/reveal/pickers/inline/community ограничения сохранены. Движение до удерживания по-прежнему обрабатывают штатные жесты папок.

Полный просмотр создаёт штатный ChatController в standard(default), ChatControllerParams.nagramiXReadHistoryDisabled=true до history node. Существующий gate effectiveValue = value && !nagramiXReadHistoryDisabled остаётся закрытым при foreground и overlays; глобальных флагов и восстановления непрочитанного задним числом нет. Обычное открытие не переиспользует этот экран. Навигация сохраняет age checks, peer/thread, фильтр и Back.

Для этого экземпляра native panel factory возвращает nil вместо composer/subscriber/selection-send панелей; штатная панель поиска сохранена. Keyboard/media input, reply accessory и composer context панели не создаются. Controller.sendMessages и node enqueue callback проверяют флаг; вход в reply/edit и редактирование двойным тапом также заблокированы. Обычные контроллеры сохраняют прежний путь, default параметра factory — false. Пользовательский черновик не очищается.

Durable изменения — ios/apply_features.py, RU/EN Localizable.strings. Новых настроек, ключей, плееров и системы тем нет.

## Проверки

Полный overlay применён к свежим исходникам точного pin f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838. Против предыдущего подготовленного кода изменены шесть native Swift-файлов и два RU/EN ресурса; остальные 320 файлов совпали побайтно. Все шесть исходных native файлов сверены по Git blob SHA. Отдельный helper совпадает с полным overlay, его 14 вставок обратимо восстанавливают baseline bytes. Пройдены 43 проверки отсутствующих/дублированных/уже применённых вставок и повторного применения. Шесть Swift-файлов разобраны tree-sitter без ошибок; проверены точная аннотация, прежние defaults/keys/SettingsUI, Python, метаданные и diff.

Эти проверки не являются Swift type checking или запуском UIKit/сети. Компиляция №79 относится к предыдущей реализации; доработке нужна новая нативная сборка и физическая проверка.

## Проверка опубликованного IPA на iPhone

Подготовить минимум две папки и непрочитанные входящие. С другого клиента наблюдать отметки отправителя.

| Сценарий | Ожидание | Результат |
| --- | --- | --- |
| ON: свайпы в обе стороны из аватарки, текста и краёв, включая медленное начало | Доступные папки перелистываются, боковых действий нет | Ожидается |
| ON: удерживание вне аватарки | Меню с актуальными действиями и правами | Ожидается |
| Контакт, группа, канал в основном списке и папке: «В архив» | Перенос в архив штатным действием, Undo | Ожидается |
| Те же чаты в архиве/папке: «Из архива» | Возврат в основной список | Ожидается |
| Избранное, 777000, тема форума | Недоступные операции не добавляются | Ожидается |
| ON/OFF: короткий tap и удерживание аватарки, с историями и без | Одно полное открытие, нет меню действий/поля ввода/клавиатуры | Ожидается |
| Полный просмотр: прокрутка, поиск, новые входящие, меню, фон/возврат | Нет автоматической отметки прочтения; после Back сохраняется непрочитанное | Ожидается |
| Сохранённый черновик, reply/edit из меню, double-tap edit ON | На экране просмотра нельзя набирать/отправлять; исходный черновик сохранён | Ожидается |
| После Back обычный tap вне аватарки | Обычный чат с чтением и вводом | Ожидается |
| OFF, live toggle, кэшированные папки, Compact, темы, крупный текст, VoiceOver | Остальное поведение сохраняется | Ожидается |

До этой проверки не объявлять подтверждённым поведение на устройстве.
