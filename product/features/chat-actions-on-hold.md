# Опции чатов по тапу

В NagramiX 0.4.7 включено разделение удержания по области строки. Пользователь разрешил сборку/публикацию для физической проверки. Опубликованный IPA №75 содержит прежнее поведение. Новая правка — compile_pending/device_pending.

Настройка: «Интерфейс → Чаты → Опции чатов по тапу». Ключ `nagramix.interface.chatActionsOnHold` сохранён: default true только при отсутствии значения, явный false сохраняется при обновлении/перезапуске. Stable id 8/9, название и глобальный поиск сохранены; пояснение RU/EN уточняет жесты.

## Поведение

При ON:

- короткое нажатие открывает переписку штатным способом;
- долгое удерживание аватарки открывает штатный предпросмотр Telegram без отметки прочтения, с доступным штатным меню;
- долгое удерживание любой другой области строки открывает только штатное меню действий, без предпросмотра переписки;
- горизонтальные свайпы из любой области, включая аватарку, переключают доступные папки; боковые действия строки и полный свайп-действие отключены;
- вертикальная прокрутка, редактирование, перестановка и специальные возможности сохраняют штатные ограничения.

При OFF возвращается стандартное поведение Telegram: боковые свайпы и их действия, обычное открытие и штатное удерживание с предпросмотром. Настройка не создаёт отсутствующие папки и не меняет права пользователя.

Меню использует существующие действия Telegram: прочитано/не прочитано, закрепить/открепить, уведомления, архивировать/вернуть из архива, удалить, добавить/убрать из папки и другие доступные пункты. Наличие пунктов, права, подтверждения и отмена определяются базовым клиентом. Архив и темы форума используют свои штатные генераторы.

## Реализация

Изменения upstream выражены в `ios/apply_features.py`, helper `apply_chat_hold_routing`. Нового распознавателя удержания нет: используется существующий ContextGesture в ContextControllerSourceNode. В shouldBegin сохраняется область первоначального касания до анимации масштаба. Точка переводится в реальные bounds AvatarNode; поэтому обычные/компактные размеры и положение аватарки не зашиты в обработчик.

В activated при ON вне аватарки передаётся позиция в координатах окна через существующий activateChatPreview callback. ChatListController показывает ContextController с уже существующим ChatListContextLocationContentSource. Используются chatContextMenuItems, archiveContextMenuItems и chatForumTopicMenuItems с текущей папкой, promo/joined и параметрами темы форума. Переписка/preview controller не создаются; действия прочтения при открытии меню не выполняются.

На аватарке и при OFF выполняется прежняя ветка предпросмотра; её canReadHistory.set(false) и прочая логика не переписаны. Обычные нажатия, avatar story tap и secondaryAction не изменены. Контекстный жест сохраняет штатную отмену конкурирующих коротких нажатий после удержания. При смене флага незавершённое удерживание отменяется, чтобы старый жест не выполнился с новым режимом.

Прежняя защита свайпов сохранена: пустые reveal options при ON, guard только для ItemListRevealOptionsGestureRecognizer, сначала очистка действий, потом закрытие активного раскрытия. OFF возвращает актуальные сохранённые опции. changedNotification обновляет загруженные/кэшированные строки на main, weak self и очистка наблюдателя сохранены. Папки использовали и продолжают использовать собственный InteractiveTransitionGestureRecognizer. AvatarNode не блокирует горизонтальные жесты. Базовые ContextGesture, ItemListRevealOptionsItemNode, AvatarNode и распознаватель папок не модифицированы.

## Проверки и ограничения

Overlay успешно применён к чистому ограниченному набору pin Telegram-iOS 12.9.2, `6ad963e5b62d354da79040f388ae2b9132fb17b8`. В сравнении с подготовленной компактной геометрией изменены только ChatListItem.swift, ChatListController.swift и одно пояснение в каждом RU/EN ресурсе; 273 файла совпадают. Полное обратное исключение новых вставок восстанавливает два исходных Swift-файла побайтно, включая компактные размеры, stock preview/read guards, обработчики действий, OFF, short tap и accessibility. Модель/default/key, layout/rebind и остальные функции сохранены.

Swift tree-sitter и Python syntax проходят. Десять отрицательных сценариев отсутствующего/дублированного якоря и повторное применение отклоняются корректно; метаданные и git diff --check проходят. Нативной компиляции и выполнения UIKit/UserDefaults для этой правки не было: Linux без Xcode/Swift toolchain, для текущей 0.4.7 сборку пользователь разрешил. Успех прежней сборки №75 не подтверждает новый код. Физические результаты не заявляются.

После отдельной команды проверить на iPhone 17 Pro Max / iOS 27.0 через SideStore:

- ON: удерживание аватарки и всех остальных зон; меню вне аватарки без preview, preview аватарки без прочтения с проверкой у отправителя; короткий тап;
- обычные чаты, группы/каналы, архив, темы форума, длинные имена и последние сообщения;
- штатные пункты меню, папки и права, подтверждение/отмена удаления;
- 2+ папки: быстрые/медленные свайпы в обе стороны из аватарки с/без истории, заголовка, сообщения и правого края; вертикальная прокрутка и отсутствие случайных действий;
- OFF: обе боковые панели и полный свайп, штатное удерживание/preview; ON при раскрытой строке не выполняет старое действие;
- переключение флага во время удержания, возврат к кэшированной папке, сохранённый OFF после перезапуска;
- компактный список ON/OFF, Light/Dark/Night, увеличенный текст, редактирование/перестановка и VoiceOver.
