# Канонический контракт настроек NagramiX

Идентификаторы, значения по умолчанию и видимый пользователю смысл настроек образуют контракт iOS-продукта. Существующие сохранённые ключи нельзя переименовывать без миграции. Заголовки подкатегорий отображаются в верхнем регистре, включая результаты поиска; названия переключателей сохраняют обычное написание.

| Канонический id | По умолчанию | Категория | Назначение |
| --- | --- | --- | --- |
| `interface.hideContactsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Контакты». |
| `interface.hideCallsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Звонки», если она доступна на платформе. |
| `interface.showTabTitles` | `true` | Интерфейс / Вкладки | Показывать названия вкладок. |
| `interface.showSearchTab` | `false` | Интерфейс / Вкладки | Показывать отдельную вкладку или кнопку поиска. |
| `interface.wideChannelPosts` | `true` | Интерфейс / Чаты | Растягивать обычные посты каналов до максимально безопасной ширины. |
| `interface.showChannelBottomPanel` | `false` | Интерфейс / Чаты | Показывать штатную нижнюю панель чтения подписанного канала; OFF скрывает её. Поле публикации постов и кнопка вступления сохраняются. Подготовлено для следующей сборки. |
| `interface.hideReactions` | `false` | Интерфейс / Чаты | Скрывать визуальные реакции под сообщениями и возле времени; сами реакции сохраняются. Подготовлено для следующей сборки. |
| `messages.doubleTapEdit` | `false` | Функции / Сообщения | Двойным тапом открывать штатное редактирование доступного сообщения/поста с проверкой прав и ограничений Telegram. Подготовлено для следующей сборки. |
| `interface.compactChatList` | `false` | Интерфейс / Чаты | Меньшие аватары и текст, одна строка предпросмотра и плотные отступы; высота учитывает увеличенный текст и дополнительные сведения. |
| `interface.chatActionsOnHold` | `true` | Интерфейс / Чаты | При ON удерживание вне аватарки — штатное меню, включая «В архив» / «Из архива». Свайпы из любой области переключают папки; OFF возвращает штатные свайп-действия. В обоих режимах тап и удерживание аватарки открывают полный чат только для просмотра, без поля ввода и отметки прочтения. Доработка подготовлена для следующей сборки. |
| `photos.quality` | `100` | Функции / Фотографии | Качество JPEG исходящих фото и фотоисторий, 0–100%. |
| `photos.sendLarge` | `true` | Функции / Фотографии | Предел стороны сжатого фото 2560 пикселей без увеличения маленьких исходников. |
| `stickers.size` | `100` | Функции / Стикеры и эмодзи | Размер стикеров и крупных эмодзи; 100% — штатный, 0% — минимальный ненулевой. |
| `stickers.showTime` | `true` | Функции / Стикеры и эмодзи | Показывать время; при выключении сохранять статусы доставки и реакции. |
| `interface.hideStories` | `true` | Функции / Истории | Скрывать ленту историй. |
| `video.pipSwipe` | `true` | Прочее / Прочее | Вертикальный свайп по открытому видео включает штатный PiP, если он доступен; OFF — обычное закрытие. |
| `video.backgroundPlayback` | `true` | Функции / Видео | Продолжать звук запущенного native/HLS видео при сворачивании и блокировке экрана, как без PiP, так и с PiP, через штатный плеер и аудиосессию. |
| `downloads.accelerationEnabled` | `false` | Прочее / Загрузка | Включать настройку ускоренного скачивания; OFF сохраняет штатные параметры и скрывает выбор режима. Подготовлено для следующей сборки. |
| `downloads.accelerationMode` | `medium` | Прочее / Загрузка | Только Среднее / Максимум, галочка справа у выбранного уровня. Уровень сохраняется независимо от чекбокса; включение/выключение только чекбоксом. Прежний Штатно нормализуется в Среднее без включения сохранённого OFF. Доработка compile_pending/device_pending. |

| `stories.disableCameraSwipe` | `true` | Функции / Истории | Отключать жест запуска записи истории. |
| `stories.confirmViewing` | `true` | Функции / Истории | Запрашивать подтверждение перед открытием каждой непросмотренной истории. |
| `stories.enableRepost` | `true` | Функции / Истории | Показывать штатное действие репоста истории. |
| `stories.anonymousViewing` | `false` | Функции / Истории | «Просмотр историй инкогнито»: не отправлять новые отметки просмотра из NagramiX, предупреждать перед ответом/реакцией. Не удаляет прежние просмотры; последующий обычный просмотр и другой клиент могут отметить истории просмотренными. [Контракт](features/story-incognito.md); compile_pending/device_pending. |

| `calls.forceTcp` | `false` | Прочее / Звонки | Принудительно использовать TCP для поддерживаемых транспортов аудио- и видеозвонков. |
| `messages.showDeletedMessages` | `false` | Функции / Сообщения | Сохранять текст и полные полученные файлы входящих вложений в отдельный локальный архив и показывать после удаления с учётом исключений. |
| `messages.saveTemporaryMessages` | `false` | Функции / Сообщения | «Временные сообщения», сразу после «Удалённых сообщений». При ON обоих сохранять также временные/одноразовые фото, видео, кружки и голосовые; уже сохранённые копии остаются до очистки. |
| `messages.editHistory` | `false` | Функции / Сообщения | Сохранять и показывать версии сообщений, фактически замеченные этим клиентом. |
| `profiles.showId` | `true` | Интерфейс / Профили | Показывать числовой id пользователя или чата. |
| `profiles.showRegistrationDate` | `true` | Интерфейс / Профили | Показывать явно обозначенную примерную дату регистрации. |
| `profiles.showMutualContactIcon` | `true` | Интерфейс / Профили | Отмечать настоящие взаимные контакты. |
| `contextMenu.showForwardWithoutAuthor` | `true` | Интерфейс / Контекстное меню | «Переслать без»: один адресат, скрытый автор и штатная подготовка отправки. Доработка для следующей сборки. |
| `contextMenu.showBroadcastMessages` | `true`* | Интерфейс / Контекстное меню | «Рассылка»: прежняя отправка копий без автора нескольким адресатам. До первого сохранения наследует видимость прежнего действия «Переслать без»; затем независимый выбор. |
| `contextMenu.showSelectByAuthor` | `true` | Интерфейс / Контекстное меню | Показывать действие «Выделить от автора». |
| `network.dnsProvider` | `system` | Прочее / Сеть | Выбирать системный DNS или разрешённого DoH-провайдера. |
| `network.customDohUrl` | empty | Прочее / Сеть | HTTPS URL, используемый только для пользовательского DoH-провайдера. |
| `network.proxyAutoSwitchEnabled` | `false` | Прочее / Прокси | Включать автоматическое переключение между сохранёнными прокси. |
| `network.proxyAutoSwitchTimeout` | `15` | Прочее / Прокси | Задержка переключения в секундах; допустимы 15, 30 и 60. |
| `network.showProxyButton` | `true` | Прочее / Прокси | Постоянно показывать управление прокси в чатах. |
| `network.hideProxySponsorChannel` | `true` | Прочее / Прокси | Скрывать содержимое спонсорского канала прокси. |

Значения применяются при отсутствии сохранённого ключа (первый запуск новой установки). Явные `true`/`false`, выбранные пользователем, сохраняются при повторных стартах и обновлениях. Скрытые истории и подтверждение просмотра — независимые флаги; подтверждение действует при открытии доступной истории.

Файлы архива не относятся к одноразовому MediaBox-кэшу: штатная очистка кэша не должна удалять завершённую архивную копию. «Очистить локальный архив сообщений» удаляет сообщения, версии и файлы, включая временные, и отменяет загрузки. Сохранение требует получения полного файла и места на устройстве; недоступные до удаления байты восстановить невозможно. Подробности и границы — [Удалённые сообщения](features/deleted-messages.md) и [Временные сообщения](features/temporary-messages.md).

* «Рассылка» включена на чистой установке. При обновлении без нового ключа наследуется сохранённое значение `contextMenu.showForwardWithoutAuthor`, включая false.
