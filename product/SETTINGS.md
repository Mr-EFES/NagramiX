# Канонический контракт настроек NagramiX

Идентификаторы, значения по умолчанию и видимый пользователю смысл настроек образуют контракт iOS-продукта. Существующие сохранённые ключи нельзя переименовывать без миграции.

| Канонический id | По умолчанию | Категория | Назначение |
| --- | --- | --- | --- |
| `interface.hideContactsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Контакты». |
| `interface.hideCallsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Звонки», если она доступна на платформе. |
| `interface.showTabTitles` | `true` | Интерфейс / Вкладки | Показывать названия вкладок. |
| `interface.showSearchTab` | `false` | Интерфейс / Вкладки | Показывать отдельную вкладку или кнопку поиска. |
| `interface.wideChannelPosts` | `false` | Интерфейс / Чаты | Растягивать обычные посты каналов до максимально безопасной ширины. |
| `interface.hideStories` | `false` | Функции / Истории | Скрывать ленту историй. |
| `videoMessages.useRearCamera` | `false` | Функции / Видеосообщения | Запускать следующую запись круглого видео с задней камеры. |
| `stories.disableCameraSwipe` | `false` | Функции / Истории | Отключать жест запуска записи истории. |
| `stories.confirmViewing` | `false` | Функции / Истории | Запрашивать подтверждение перед открытием каждой непросмотренной истории. |
| `stories.enableRepost` | `false` | Функции / Истории | Показывать штатное действие репоста истории. |
| `calls.confirmOutgoing` | `true` | Функции / Звонки | Запрашивать подтверждение перед исходящим звонком. |
| `calls.forceTcp` | `false` | Прочее / Звонки | Принудительно использовать TCP для поддерживаемых транспортов аудио- и видеозвонков. |
| `messages.showDeletedMessages` | `false` | Функции / Сообщения | Показывать локально сохранённые входящие сообщения после удаления с учётом исключений. |
| `messages.editHistory` | `false` | Функции / Сообщения | Сохранять и показывать версии сообщений, фактически замеченные этим клиентом. |
| `profiles.showId` | `true` | Интерфейс / Профили | Показывать числовой id пользователя или чата. |
| `profiles.showRegistrationDate` | `true` | Интерфейс / Профили | Показывать явно обозначенную примерную дату регистрации. |
| `profiles.showMutualContactIcon` | `false` | Интерфейс / Профили | Отмечать настоящие взаимные контакты. |
| `network.dnsProvider` | `system` | Прочее / Сеть | Выбирать системный DNS или разрешённого DoH-провайдера. |
| `network.customDohUrl` | empty | Прочее / Сеть | HTTPS URL, используемый только для пользовательского DoH-провайдера. |
| `network.proxyAutoSwitchEnabled` | `false` | Прочее / Прокси | Включать автоматическое переключение между сохранёнными прокси. |
| `network.proxyAutoSwitchTimeout` | `15` | Прочее / Прокси | Задержка переключения в секундах; допустимы 15, 30 и 60. |
| `network.showProxyButton` | `true` | Прочее / Прокси | Постоянно показывать управление прокси в чатах. |
| `network.hideProxySponsorChannel` | `true` | Прочее / Прокси | Скрывать содержимое спонсорского канала прокси. |

Настройки архива, сети и звонков требуют явной спецификации iOS до реализации. Похожие отладочные флаги upstream не заменяют собственные настройки NagramiX.
