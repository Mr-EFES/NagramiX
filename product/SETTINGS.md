# Канонический контракт настроек NagramiX

22октября добавлено **Функции → Сообщения → «Отправлять без звука»**: автоматическая тихая отправка исходящих сообщений, по умолчанию включена; сохранённые ON/OFF не сбрасываются. [Описание](features/send-silently.md). Source_checked/native_compile_passed/device_pending, в IPA114 не входит.

Текущий выпуск 0.7.1/build127 опубликован: нативная компиляция и пакет проверены; физическая приёмка ещё предстоит. [Текущий статус](../docs/RELEASE_STATUS.md). Физические сценарии остаются непроверенными.

Идентификаторы, значения по умолчанию и видимый пользователю смысл настроек образуют контракт iOS-продукта. Существующие сохранённые ключи нельзя переименовывать без миграции. Заголовки подкатегорий отображаются в верхнем регистре, включая результаты поиска; названия переключателей сохраняют обычное написание.

Настройки отображаются без поясняющих footer-строк под переключателями и кнопками. Актуальные 45 подписей трёх вкладок утверждены 16 октября 2026: [полный список и проверка](../docs/SETTINGS_LABELS_COMPACT.md). Поиск использует те же заголовки, все 45 строк поддерживают штатный перенос без обрезания; шрифты, темы, отступы и категории сохранены. Подписи трёх переключателей контекстного меню отделены от названий действий чата. «Меню чата по удержанию» сохраняет прежний жест, «Автопереход голосовых» остаётся OFF по умолчанию. «Свайп для записи» положительный, OFF на первой установке; UI читает/пишет инверсию прежнего `stories.disableCameraSwipe`, без сброса сохранённого поведения. Остальные keys/defaults/действия прежние. Последняя правка: source_checked/native_compile_passed/device_pending; build92 её не содержит.

Уточнение20октября: Функции → Приватность содержит шесть чекбоксов; прежние online/automaticOffline объединены в «Скрывать «онлайн»». Fresh OFF; сохранённый ON хотя бы одной прежней функции переносится в общий ON. OFF отключает обе защиты и сохраняется при холодном старте. По последнему уточнению максимальный офлайн: общий переключатель сразу подавляет штатные online updates и запрашивает offline без5секундной задержки, повторяет после online-inducing событий и восстановления соединения; частые события не отменяют уже отправленный запрос. Добавлен «Свободный скриншот», fresh OFF; ручной выбор сохраняется. Он разрешает скриншоты и запись экрана доступных защищённых и одноразовых/исчезающих медиа, подавляя создание исходящих screenshot notifications. Платные медиа и коды сохраняют защиту. Дополнительный защищённый экспорт из меню сообщения и галереи требует «Свободный скриншот» и прежние разрешения действий пересылки/рассылки; серверный репост сохраняет штатные ограничения. [Последняя доработка](../docs/MEDIA_PRIVACY_FIXES.md): source_checked/native_compile_pending/device_pending. [Контракт](features/privacy.md), [реализация скриншотов](../docs/SCREENSHOT_PROTECTION_BYPASS.md). source_checked/native_compile_passed/device_pending; новая IPA только по отдельной команде.
