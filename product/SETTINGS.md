# Канонический контракт настроек NagramiX

Идентификаторы, значения по умолчанию и видимый пользователю смысл настроек образуют контракт iOS-продукта. Существующие сохранённые ключи нельзя переименовывать без миграции.

| Канонический id | По умолчанию | Категория | Назначение |
| --- | --- | --- | --- |
| `interface.hideContactsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Контакты». |
| `interface.hideCallsTab` | `true` | Интерфейс / Вкладки | Скрывать вкладку «Звонки», если она доступна на платформе. |
| `interface.showTabTitles` | `true` | Интерфейс / Вкладки | Показывать названия вкладок. |
| `interface.showSearchTab` | `false` | Интерфейс / Вкладки | Показывать отдельную вкладку или кнопку поиска. |
| `interface.wideChannelPosts` | `true` | Интерфейс / Чаты | Растягивать обычные посты каналов до максимально безопасной ширины. |
| `interface.compactChatList` | `false` | Интерфейс / Чаты | Меньшие аватары и одна строка предпросмотра; высота учитывает текст и дополнительные сведения. |
| `interface.chatActionsOnHold` | `true` | Интерфейс / Чаты | Отключать свайп-действия строк чатов, сохраняя штатное удерживание с предпросмотром/меню и переключение папок. |
| `photos.quality` | `100` | Функции / Фотографии | Качество JPEG исходящих фото и фотоисторий, 0–100%. |
| `photos.sendLarge` | `true` | Функции / Фотографии | Предел стороны сжатого фото 2560 пикселей без увеличения маленьких исходников. |
| `stickers.size` | `100` | Функции / Стикеры и эмодзи | Размер стикеров и крупных эмодзи; 100% — штатный, 0% — минимальный ненулевой. |
| `stickers.showTime` | `true` | Функции / Стикеры и эмодзи | Показывать время; при выключении сохранять статусы доставки и реакции. |
| `interface.hideStories` | `true` | Функции / Истории | Скрывать ленту историй. |
| `videoMessages.useRearCamera` | `true` | Функции / Видеосообщения | Запускать следующую запись круглого видео с задней камеры. |
| `stories.disableCameraSwipe` | `true` | Функции / Истории | Отключать жест запуска записи истории. |
| `stories.confirmViewing` | `true` | Функции / Истории | Запрашивать подтверждение перед открытием каждой непросмотренной истории. |
| `stories.enableRepost` | `true` | Функции / Истории | Показывать штатное действие репоста истории. |
| `calls.confirmOutgoing` | `true` | Функции / Звонки | Запрашивать подтверждение перед исходящим звонком. |
| `calls.forceTcp` | `false` | Прочее / Звонки | Принудительно использовать TCP для поддерживаемых транспортов аудио- и видеозвонков. |
| `messages.showDeletedMessages` | `false` | Функции / Сообщения | Показывать локально сохранённые входящие сообщения после удаления с учётом исключений. |
| `messages.editHistory` | `false` | Функции / Сообщения | Сохранять и показывать версии сообщений, фактически замеченные этим клиентом. |
| `profiles.showId` | `true` | Интерфейс / Профили | Показывать числовой id пользователя или чата. |
| `profiles.showRegistrationDate` | `true` | Интерфейс / Профили | Показывать явно обозначенную примерную дату регистрации. |
| `profiles.showMutualContactIcon` | `true` | Интерфейс / Профили | Отмечать настоящие взаимные контакты. |
| `contextMenu.showForwardWithoutAuthor` | `true` | Интерфейс / Контекстное меню | Показывать действие «Переслать без». |
| `contextMenu.showSelectByAuthor` | `true` | Интерфейс / Контекстное меню | Показывать действие «Выделить от автора». |
| `network.dnsProvider` | `system` | Прочее / Сеть | Выбирать системный DNS или разрешённого DoH-провайдера. |
| `network.customDohUrl` | empty | Прочее / Сеть | HTTPS URL, используемый только для пользовательского DoH-провайдера. |
| `network.proxyAutoSwitchEnabled` | `false` | Прочее / Прокси | Включать автоматическое переключение между сохранёнными прокси. |
| `network.proxyAutoSwitchTimeout` | `15` | Прочее / Прокси | Задержка переключения в секундах; допустимы 15, 30 и 60. |
| `network.showProxyButton` | `true` | Прочее / Прокси | Постоянно показывать управление прокси в чатах. |
| `network.hideProxySponsorChannel` | `true` | Прочее / Прокси | Скрывать содержимое спонсорского канала прокси. |

Значения применяются при отсутствии сохранённого ключа (первый запуск новой установки). Явные `true`/`false`, выбранные пользователем, сохраняются при повторных стартах и обновлениях. Скрытые истории и подтверждение просмотра — независимые флаги; подтверждение действует при открытии доступной истории.
